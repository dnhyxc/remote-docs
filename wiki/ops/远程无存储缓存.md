# remotes 静态资源禁止缓存

> **文档角色（本轮主文档）**：`/remotes`（含 `plugins-registry.json`）由短缓存改为 `no-store`。  
> **延伸阅读**：[远程注册静态.md](./远程注册静态.md)（分发总览，缓存策略以本文为准）；[../plugins/插件入口缓存失效.md](../plugins/插件入口缓存失效.md)。

## 1. 背景与目标

原先 remotes 使用 `public, max-age=60`。桌面 WebView / 中间代理仍可能在窗口内复用旧 registry，导致「已上传新插件、清单看起来更新了、实际仍加载旧配置」。

目标：remotes 响应统一 `Cache-Control: no-store, max-age=0, must-revalidate`；images/files 仍 7 天。

## 2. 改动范围

| 路径 | 说明 |
|------|------|
| `apps/backend/src/middleware/serve-upload-static.middleware.ts` | `GET /remotes/...` |
| `apps/backend/src/services/upload/upload-public.controller.ts` | 公开流式读 / `serveRemote` |

## 3. 实现思路

路径属于 `remotes`（或解码后以 `/remotes/` 开头）时写 `no-store`；其余上传静态仍 `max-age=604800`。

## 4. 关键代码对比与注释

### 4.1 `serveUploadStaticMiddleware` 缓存头

**改动前** · `apps/backend/src/middleware/serve-upload-static.middleware.ts`（基线）

```typescript
// 允许跨域嵌入静态资源
res.setHeader('Cross-Origin-Resource-Policy', 'cross-origin');
// registry 宜短缓存，便于单独更新
res.setHeader(
	// 响应头名
	'Cache-Control',
	// remotes：60 秒；images/files：7 天
	folder === 'remotes' ? 'public, max-age=60' : 'public, max-age=604800',
);
```

**改动后** · `apps/backend/src/middleware/serve-upload-static.middleware.ts`（当前，约 L53–L60）

```typescript
// 允许跨域嵌入静态资源
res.setHeader('Cross-Origin-Resource-Policy', 'cross-origin');
// remotes（registry）禁止缓存，避免桌面/代理继续吃旧版
res.setHeader(
	// 响应头名
	'Cache-Control',
	// remotes：禁止存储；其它上传静态仍 7 天
	folder === 'remotes'
		? 'no-store, max-age=0, must-revalidate'
		: 'public, max-age=604800',
);
```

**变更摘要**：remotes 从 60s 短缓存改为禁止缓存。

### 4.2 `serveRemote` / 公开路径流

**改动后** · `apps/backend/src/services/upload/upload-public.controller.ts`（当前，约 L64–L105）

```typescript
// 公开附件流：按路径前缀决定缓存策略
res.setHeader(
	'Cache-Control',
	// /remotes/ 下文件与中间件一致：no-store
	decoded.startsWith('/remotes/')
		? 'no-store, max-age=0, must-revalidate'
		: 'public, max-age=604800',
);

// ... serveRemote 专用接口
// 仅 .json 的 remotes 备用 API，同样禁止缓存
res.setHeader('Cache-Control', 'no-store, max-age=0, must-revalidate');
```

**变更摘要**：控制器两条 remotes 出口与中间件对齐。

## 5. 兼容性与影响

- Nginx 若对 `/remotes/` 另设 `expires`，生产应改为不缓存或与后端一致，否则仍可能吃旧清单。
- Host 侧 force 拉 registry 仍会加 `?t=`（清单防缓存）。**MF entry bust** 已与 `registry.updatedAt` 解耦，改为 Remote `mf-manifest` 内容指纹，见 [插件入口缓存失效.md](../plugins/插件入口缓存失效.md)。
