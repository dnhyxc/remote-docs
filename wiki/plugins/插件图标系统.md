# SVG 插件图标系统：PluginIcon 组件与 SVG 归一化

> **文档角色**：插件图标从「Lucide 图标名」迁移到「SVG URL 内联渲染」的完整实现说明
> **延伸阅读**：[注册图标上传.md](./注册图标上传.md)（图标上传流程）；[插件Vue桥接.md](../plugins/插件Vue桥接.md)

## 1. 背景与目标

此前插件 `menu.icon` / `host.icon` 字段存储的是 Lucide 图标名（如 `"Sparkle"`、`"Puzzle"`），Host 侧通过 `ICON_MAP` 或 `DEFAULT_PLUGIN_HOST_ICONS` 查找对应 React 组件渲染。这种方案存在以下局限：

1. **只能用 Lucide 图标**：插件开发者无法使用自定义品牌图标
2. **图标数量受限**：`ICON_MAP` 必须手动维护，新增图标需改代码
3. **无动画**：Lucide 图标无 hover 画线动画效果

**目标**：将 `icon` 字段改为 SVG 图片 URL，新增 `PluginIcon` 组件从 URL 拉取 SVG 文本、归一化、内联渲染。支持两类图标：
- **描边稿**（Lucide 风格，单路径 stroke）：hover 时用 `stroke-dashoffset` 画线动画
- **填充稿**（iconfont 风格，多 path fill）：hover 时用 `clip-path` 显现动画

## 3. 实现思路

| # | 要点 | 说明 |
|---|------|------|
| 1 | URL 判定 | `isPluginIconUrl` 判断 icon 是否为 URL（`http://`、`/ext-cos/`、`/remotes/`） |
| 2 | 双重 fetch 策略 | 绝对 URL 走 Tauri HTTP 插件（无 CORS）；同源路径用 window `fetch` |
| 3 | SVG 归一化 | `normalizeSvgForHostIcon` 解析 SVG、去脚本/事件、识别 kind（stroke/fill）、归一化配色 |
| 4 | 主题色判定 | `isThemeablePaint` 按色饱和度+亮度判定：近黑灰单色 → `currentColor`，品牌色保留原色 |
| 5 | 描边动画 | `pathLength=1` + `stroke-dasharray: 1` + `stroke-dashoffset: 1→0`，与路径真实周长无关 |
| 6 | 填充动画 | `clip-path: inset(0 100% 0 0 → 0)`，仅对 `kind=fill` 的图标生效 |
| 7 | React 渲染 | `dangerouslySetInnerHTML` + 稳定 `useMemo` 对象引用，避免 `innerHTML` 重建子节点 |
| 8 | 缓存 | `svgCache` Map 按 URL 缓存 `HostSvgParts`，版本号 `kind-v9` |

### 4.1 `PluginIcon` 组件（新增文件）

**对比范围**：`PluginIcon.tsx` 全文件（约 L1–L124）。纯新增，无「改动前」版本。

**当前** · `apps/frontend/src/federation/host/PluginIcon.tsx`（约 L1–L124）

```typescript
// Puzzle 作为默认 fallback 图标
import { Puzzle } from 'lucide-react';
// useEffect + useState 管理异步 fetch 生命周期
import { useEffect, useMemo, useState } from 'react';
// cn 辅助拼接 className
import { cn } from '@/lib/utils';
// COS URL 展示路径（dev/Web 生产 /ext-cos/，Tauri 保留直链）
import { resolveCosUrlForWebDisplay } from '@/utils';
// Tauri HTTP 插件：无 CORS 的跨源 fetch
import { getPlatformFetch } from '@/utils/fetch';
// SVG 归一化工具
import {
	type HostSvgParts,
	isPluginIconUrl,
	normalizeSvgForHostIcon,
} from './pluginIconUrl';

// 组件 props：name 为 SVG URL，className 透传
export type PluginIconProps = {
	// registry menu.icon / host.icon 字段值：SVG 图片 URL
	name?: string;
	className?: string;
};

// 缓存版本号：归一化逻辑升级时 bump 以失效旧缓存
const CACHE_VER = 'kind-v9';
// Map 缓存 URL → HostSvgParts（归一化后的 SVG 片段）
const svgCache = new Map<string, HostSvgParts>();

// 缓存 key 构造：版本号 + URL
function cacheKey(url: string) {
	return `${CACHE_VER}:${url}`;
}

// 跨平台 fetch：绝对 URL 走 Tauri HTTP（无 CORS）；同源路径用 window fetch
async function fetchIconText(src: string): Promise<string> {
	// 判断是否为绝对 http(s) URL
	const doFetch = /^https?:\/\//i.test(src)
		? await getPlatformFetch()
		: globalThis.fetch.bind(globalThis);
	// 走 no-cache 避免拿到旧版本
	const res = await doFetch(src, { cache: 'no-cache' });
	if (!res.ok) throw new Error(`icon fetch ${res.status}`);
	// 返回 SVG 文本
	return res.text();
}

// 主组件
export function PluginIcon({ name, className }: PluginIconProps) {
	// 初始 state：若 URL 已缓存则同步取，否则 null
	const [parts, setParts] = useState<HostSvgParts | null>(() => {
		const key = name?.trim() ?? '';
		return isPluginIconUrl(key) ? (svgCache.get(cacheKey(key)) ?? null) : null;
	});
	// 初始 failed：非 URL 直接标记为失败（渲染 Puzzle fallback）
	const [failed, setFailed] = useState(() => !isPluginIconUrl(name));

	// 异步拉取 + 归一化 + 缓存
	useEffect(() => {
		const key = name?.trim() ?? '';
		// 非 URL：直接失败，渲染 fallback
		if (!isPluginIconUrl(key)) {
			setParts(null);
			setFailed(true);
			return;
		}
		// 命中缓存：直接用
		const cached = svgCache.get(cacheKey(key));
		if (cached) {
			setParts(cached);
			setFailed(false);
			return;
		}

		let cancelled = false;
		setFailed(false);
		setParts(null);

		// URL → 展示路径（dev/Web /ext-cos/，Tauri 保留直链）
		const src = resolveCosUrlForWebDisplay(key);
		void (async () => {
			try {
				const text = await fetchIconText(src);
				// 归一化：解析 SVG、去脚本/事件、识别 kind/theme
				const next = normalizeSvgForHostIcon(text);
				if (!next) throw new Error('invalid svg');
				// 写入缓存
				svgCache.set(cacheKey(key), next);
				if (!cancelled) setParts(next);
			} catch {
				if (!cancelled) {
					setParts(null);
					setFailed(true);
				}
			}
		})();

		// 卸载时取消：避免组件卸载后 setState 警告
		return () => {
			cancelled = true;
		};
	}, [name]);

	// 稳定的 __html 对象引用：React 19 对该 prop 做 === 比较
	const html = useMemo(
		() => (parts ? { __html: parts.innerHTML } : null),
		[parts],
	);

	// 渲染 fallback：fetch 失败或非 URL 时显示 Puzzle
	if (failed || !parts || !html) {
		return (
			<Puzzle
				className={cn('size-4 shrink-0 overflow-visible', className)}
				aria-hidden
			/>
		);
	}

	// 渲染内联 SVG：带 kind/theme 标记，供 CSS 选择器匹配
	return (
		<svg
			xmlns="http://www.w3.org/2000/svg"
			viewBox={parts.viewBox}
			{...parts.rootProps}
			// 供 CSS 选择器识别：stroke/fill 动画分支
			data-plugin-icon-kind={parts.kind}
			// 供 CSS 选择器识别：currentColor（跟主题）/original（品牌色）
			data-plugin-icon-theme={parts.theme}
			className={cn(
				// 基础：尺寸 + overflow-visible 保证 path 动画不被裁剪
				'size-4 shrink-0 overflow-visible plugin-host-icon',
				// current 主题：跟侧栏选中色（hover 变 teal-500）
				parts.theme === 'current' && 'plugin-host-icon--theme',
				className,
			)}
			aria-hidden
			focusable="false"
			// 内联归一化后的 innerHTML（含 pathLength、fill 重写等）
			dangerouslySetInnerHTML={html}
		/>
	);
}
```

**变更摘要**：新增 SVG 内联渲染组件。核心链路：`name(URL)` → `fetch` → `normalizeSvgForHostIcon` → `svgCache` → `dangerouslySetInnerHTML` 渲染。支持 stroke/fill 两种 kind，current/original 两种 theme。

```typescript
export function isPluginIconUrl(value?: string | null): boolean {
	const v = value?.trim();
	if (!v) return false;
	return (
		// 绝对 http(s) URL
		/^https?:\/\//i.test(v) ||
		// 同源 COS 代理路径
		v.startsWith('/ext-cos/') ||

		v.startsWith('/remotes/')
	);
}
```

#### `isThemeablePaint` — 主题色判定

**当前** · `apps/frontend/src/federation/host/pluginIconUrl.ts`（约 L122–L135）

```typescript
// iconfont 常用 #2c2c2c / #333 等近黑灰，白名单会漏
// 低彩度 +（够暗或够亮）视为可跟侧栏色
export function isThemeablePaint(value: string): boolean {
	const v = value.trim().toLowerCase();
	// none / transparent / url() 不可主题化
	if (!v || v === 'none' || v === 'transparent') return false;
	if (v === 'currentcolor' || v === 'inherit') return true;
	if (/^url\(/i.test(v)) return false;
	// 解析 RGB
	const rgb = parseRgb(v);
	if (!rgb) return false;
	const [r, g, b] = rgb;
	// 彩度 = max - min；亮度 = sRGB 相对亮度
	const chroma = Math.max(r, g, b) - Math.min(r, g, b);
	const L = luminance(r, g, b);
	// 近似灰，且偏黑或偏白（含 #2c2c2c）→ 可主题化
	if (chroma <= 24 && (L <= 0.28 || L >= 0.82)) return true;
	return false;
}
```

**变更摘要**：用彩度+亮度双维度判定：近黑灰单色图标 → `currentColor`（跟侧栏选中色），品牌多色图标 → 保留原色。

#### `normalizeSvgForHostIcon` — SVG 归一化主函数

**当前** · `apps/frontend/src/federation/host/pluginIconUrl.ts`（约 L266–L335）

```typescript
// SVG 归一化：消毒 + kind 检测 + 主题判定 + stroke 准备
export function normalizeSvgForHostIcon(svgText: string): HostSvgParts | null {
	const raw = svgText.trim();
	// 空文本或不含 <svg> → 返回 null
	if (!raw || !/<svg[\s>]/i.test(raw)) return null;

	// DOMParser 解析 SVG 文本
	const doc = new DOMParser().parseFromString(raw, 'image/svg+xml');
	// 解析出错 → 返回 null
	if (doc.querySelector('parsererror')) return null;

	const svg = doc.documentElement;
	if (!svg || svg.tagName.toLowerCase() !== 'svg') return null;

	// 消毒：移除 script / foreignObject / iframe / object / embed（安全）
	for (const el of [
		...svg.querySelectorAll('script, foreignObject, iframe, object, embed'),
	]) {
		el.remove();
	}

	// 消毒：移除所有 on* 事件属性 + javascript: href
	for (const el of [svg, ...svg.querySelectorAll('*')]) {
		for (const attr of [...el.attributes]) {
			const name = attr.name;
			const val = attr.value.trim();
			// 移除 onXxx 事件绑定
			if (/^on/i.test(name)) {
				el.removeAttribute(name);
				continue;
			}
			// 移除 javascript: 协议 href
			if (
				(name === 'href' || name === 'xlink:href') &&
				/^javascript:/i.test(val)
			) {
				el.removeAttribute(name);
			}
		}
	}

	// 判定主题策略：近黑灰 → current，多色 → original
	const theme = applyThemeCurrentColor(svg);
	// 判定 kind：stroke（Lucide 描边稿）或 fill（iconfont 填充稿）
	const kind = detectPluginIconKind(svg);
	// stroke 稿：给所有 shape 加 pathLength=1，实现单位 dash
	if (kind === 'stroke') {
		prepareStrokeDraw(svg);
	}

	// 提取 viewBox（默认 24×24）
	const viewBox = svg.getAttribute('viewBox') || '0 0 24 24';
	// 提取根 SVG 的呈现属性，转为 React SVGProps
	const rootProps: SVGProps<SVGSVGElement> = {};
	for (const name of ROOT_PRESENTATION) {
		const val = svg.getAttribute(name);
		if (!val) continue;
		// SVG 属性名 → React camelCase
		if (name === 'stroke-width') rootProps.strokeWidth = val;
		else if (name === 'stroke-linecap')
			rootProps.strokeLinecap = val as 'round';
		else if (name === 'stroke-linejoin')
			rootProps.strokeLinejoin = val as 'round';
		else if (name === 'stroke-opacity') rootProps.strokeOpacity = val;
		else if (name === 'fill-opacity') rootProps.fillOpacity = val;
		else if (name === 'fill') rootProps.fill = val;
		else if (name === 'stroke') rootProps.stroke = val;
		else if (name === 'opacity') rootProps.opacity = Number(val) || val;
	}

	// current 主题：覆盖 fill/stroke 为 currentColor
	if (theme === 'current') {
		if (kind === 'fill') {
			rootProps.fill = 'currentColor';
		} else {
			rootProps.stroke = 'currentColor';
			if (!rootProps.fill) rootProps.fill = 'none';
		}
	}

	// 提取 innerHTML（所有子节点）作为 dangerouslySetInnerHTML 的内容
	const innerHTML = svg.innerHTML.trim();
	if (!innerHTML) return null;

	// 返回归一化后的 SVG 片段
	return { viewBox, kind, theme, rootProps, innerHTML };
}
```

**变更摘要**：SVG 归一化流水线：文本解析 → 消毒（安全）→ 主题判定 → kind 检测 → stroke 准备 → 属性提取 → 返回结构化片段。

```css
		stroke-linejoin: round;
		/* 单位 dash：依赖 pathLength=1（归一化时写入） */
		stroke-dasharray: 1;
		stroke-dashoffset: 1;
		/* 时长可通过 CSS 变量覆盖 */
		animation: lucide-stroke-draw var(--icon-draw-duration, 0.5s) linear forwards;
	}

	/* 插件 fill 图标：clip-path 显现 */
	.lucide-stroke-draw-hover:hover svg.plugin-host-icon[data-plugin-icon-kind="fill"] {
		animation: plugin-icon-fill-draw var(--icon-draw-duration, 0.5s) linear forwards;
	}
}

/* 主题色插件图标：fill 用 !important 压内联 fill */
svg.plugin-host-icon--theme[data-plugin-icon-kind="fill"]
:is(path, circle, rect, ellipse, polygon, polyline) {
	fill: currentColor !important;
}
```

**变更摘要**：
1. stroke 动画：`stroke-dasharray: 80` → `stroke-dasharray: 1`，配合 `pathLength=1` 实现单位路径长度
2. 选择器新增 `not(.plugin-host-icon)` 排除插件图标（避免重复匹配）
3. 新增 `plugin-icon-fill-draw` 动画（clip-path 显现）
4. 新增 `svg.plugin-host-icon--theme[data-plugin-icon-kind="fill"]` 选择器，用 `!important` 覆盖内联 fill
5. 支持 CSS 变量 `--icon-draw-duration` 控制动画时长

## 5. 兼容性与影响

| 项目 | 说明 |
|------|------|
| 破坏性改动 | `DEFAULT_PLUGIN_HOST_ICONS` 不再导出；`PluginHostSurface` 移除 `icons` props。外部若引用需更新 |

## 6. 风险与回归清单

| 风险 | 排查 |
|------|------|
| 插件图标 fetch 404 | 检查 COS URL 是否正确；`resolveCosUrlForWebDisplay` 在 dev/Web 走 `/ext-cos/` |
| SVG 归一化失败 | `normalizeSvgForHostIcon` 返回 null；检查 SVG 是否含 `<script>` 或事件属性被移除 |
| stroke 动画不触发 | 检查 SVG 是否被加了 `pathLength=1`；CSS 选择器是否匹配 |
| fill 动画不触发 | 检查 `data-plugin-icon-kind` 是否为 `"fill"`；`clip-path` 动画是否生效 |
| 主题色不跟随 | 检查 `data-plugin-icon-theme` 是否为 `"current"`；`svg.plugin-host-icon--theme` 选择器是否匹配 |
| Sidebar 插件图标缺失 | `ICON_MAP` 找不到 → PluginIcon 兜底 → 非 URL → Puzzle fallback |

建议回归：
1. Sidebar：内置 Lucide 图标 + 插件 SVG 图标均正确显示
2. PluginHostSurface：抽屉触发器图标正确显示
3. 主题切换：`current` 主题图标跟随选中色变化
4. hover 动画：stroke 图标画线、fill 图标 clip-path 显现
5. 降级：无 icon 字段 / fetch 失败 → Puzzle fallback
6. Tauri：绝对 URL SVG 通过 Tauri HTTP 插件无 CORS 问题
