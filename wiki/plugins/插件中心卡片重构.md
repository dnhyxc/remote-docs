## 1. 背景与目标

改动前，插件中心（`/plugins`）是一个**扁平列表**：所有插件不分类型堆在一起，卡片信息密度低——标题 + 描述 + `id · v版本` + 路由 + 信任级别，但**没有图标**、**没有「进入入口」**、**无法区分「业务内嵌插件」与「独立路由应用」**。随着接入的 Remote 既有 `host`（业务面内嵌/surface 槽）型插件，也有仅 `injectRoute: true`（独立路由注入、无侧栏）型应用，扁平列表已无法让用户快速定位。

本次改动对插件中心做两件事：

1. **Tab 分类**：顶部新增「插件 / 应用」两个 Tab，按 `host` / `injectRoute` 推断 `catalogKind`，带计数徽章；空态文案按 Tab 分别给。
2. **卡片重构**：卡片改为「图标 + 标题 + 版本 + 上架开关」头区、「描述」中区、「路由 · 侧栏 · 信任 + 进入按钮」底栏（`CardFooter`）的三段式结构；应用类卡片底栏出现「进入」按钮可直接跳转路由。

## 2. 改动范围

**apps/frontend（宿主侧）**

- `apps/frontend/src/views/plugins/index.tsx` — 核心改动：新增 `CatalogTab` 类型与 `catalogKind` / `pluginIconUrl` / `trustLabel` 辅助函数；新增 `tab` 状态与 `visible` / `counts` 派生；顶部 header 改为 Tab + 描述 + 编辑配置；卡片由「`CardHeader` + `CardContent`」重构为「`CardHeader`（含图标）+ `CardDescription` + `CardFooter`（含进入按钮）」。
- `apps/frontend/src/i18n/locales/zh-CN.ts` — 新增 Tab 标签、空态、信任级别中文释义、侧栏状态、进入按钮等文案；精简 `plugins.page.desc`；补充 `injectRoute` / `menu` 字段帮助文案。
- `apps/frontend/src/i18n/locales/en-US.ts` — 同步英文文案。

## 3. 实现思路

1. **分类依据：`host` / `injectRoute` 推断 `catalogKind`**：registry 没有显式 `kind` 字段，按现有结构推断——`p.host` 存在（业务面内嵌 / surface 槽）或 `p.injectRoute === false`（宿主业务树已挂 `PluginHostPage`）归为 **plugin**；其余（`injectRoute` 非 false，即由 `PluginManager` 注入顶层路由）归为 **app**。这覆盖了「内嵌插件」与「独立路由应用」两类，且不需要 registry 加新字段；注释里留了口子：若后续要运营手标，再给 registry 加 `kind`。
2. **Tab 计数用 `useMemo` 派生**：`counts` 遍历 `plugins` 按 `catalogKind` 累加；`visible` 按 `tab` 过滤。两个 `useMemo` 依赖 `plugins`（`counts`）与 `[plugins, tab]`（`visible`），避免每次渲染重算。Tab 切换只改 `visible`，不重拉 registry。
3. **图标优先 `menu.icon` / `host.icon`，缺省按 Tab 兜底**：`pluginIconUrl(p)` 取 `p.menu?.icon || p.host?.icon`；有值则渲染 `PluginIcon`（既有组件，支持 SVG URL），无值时 app Tab 用 `AppWindow`、plugin Tab 用 `Puzzle` 兜底。图标底座统一 `size-11 rounded-md bg-theme/10`，上架态 `text-teal-500`、下架态 `text-textcolor/50`。
4. **信任级别本地化释义**：`trustLabel` 用 `plugins.card.trust.${trust}` 查 i18n；命中则拼成 `trust（释义）`（如 `untrusted（未信任）`），未命中（i18n 返回 key 本身）则回退原始 `trust` 字符串。这避免硬编码信任级别展示，同时让 registry 新增信任级别时不崩。
5. **应用类卡片「进入」按钮**：`isApp = tab === 'app'` 时，`CardFooter` 右侧出现「进入」按钮（`SquareArrowOutUpRight` 图标），`disabled` 条件为 `!onShelf || busy || !p.routePath`——未上架 / 切换中 / 无路由时禁用。点击 `navigate(p.routePath)` 跳转。插件类（`plugin` Tab）不显示该按钮，因为业务内嵌插件入口在业务页内，不在插件中心跳转。
6. **卡片三段式 + `mt-auto` 撑底**：`Card` 用 `flex flex-col`，`CardFooter` 加 `mt-auto` 让底栏始终贴底，即使描述短也能让一排卡片的底栏水平对齐。`gap-0` + `py-0` 把卡片内边距交给 `CardHeader` / `CardFooter` 自管，避免默认 `gap-2 py-4` 把内容撑松。
7. **底栏信息单行 truncate**：路由、侧栏有无、信任级别拼成一行 `<p className="truncate">`，`min-w-0 flex-1` 保证长路由不撑破布局。侧栏状态用 `plugins.card.sidebar.on/off`（有/无），配合 `plugins.card.sidebar`（侧栏）标签。
8. **i18n 文案精简与补充**：`plugins.page.desc` 从长句精简为「默认全部关闭；关闭后基座不再加载，相关入口也会隐藏。」；新增 `plugins.page.tabsAria`（Tab 组 aria-label）、`plugins.page.tab.plugin/app`、`plugins.page.empty.plugin/app`、`plugins.card.enter`、`plugins.card.trust.first-party/partner/untrusted`、`plugins.card.sidebar(.on/.off)`；并补充 `injectRoute` 与 `menu` 字段帮助文案，说明「`true` + 不写 `menu` = 仅路由、无侧栏」「省略 `menu` = 仅路由/内嵌，不进左侧菜单」。

                () => plugins.filter((p) => catalogKind(p) === tab),
                [plugins, tab],
        );

        // 新增：统计两类数量，供 Tab 徽章展示；依赖 [plugins]，列表变更时重算
        const counts = useMemo(() => {
                // plugin 计数
                let plugin = 0;
                // app 计数
                let app = 0;
                // 遍历全量插件按 catalogKind 累加
                for (const p of plugins) {

## 5. 测试与回归建议

- 切换「插件 / 应用」Tab，确认列表按 `catalogKind` 正确分流，计数徽章随 registry 变化更新。
- 卡片图标：有 `menu.icon` / `host.icon` 的插件显示 `PluginIcon`；无图标时 app Tab 显示 `AppWindow`、plugin Tab 显示 `Puzzle`。
- 应用类卡片底栏「进入」按钮：上架态可点跳转 `routePath`；未上架 / 切换中 / 无路由时禁用。
- 信任级别展示：`untrusted` 显示为 `untrusted（未信任）`；未知级别回退原始字符串。
- 底栏单行 `truncate`：长路由不撑破卡片，多卡片底栏水平对齐（`mt-auto` 贴底）。
- 空态：plugin Tab 空显示「暂无插件（业务内嵌 / surface 槽）」；app Tab 空显示「暂无应用（独立路由注入）」。
- 中英文切换：Tab 标签、空态、进入按钮、信任释义、侧栏状态均跟随语言。
