# 插件中心卡片 border 显式主题色（避免远程插件污染白边）

## 1. 背景与目标

插件中心页面（路由 `/plugins`）以网格形式展示所有已注册插件，每张卡片由 shadcn/ui 的 `Card` 组件渲染。改动前，卡片 `className` 只写了裸 `border` 工具类，并未显式指定边框颜色，边框颜色会回退到 Tailwind 的 `border-border`（对应 CSS 变量 `--border`）。

在主项目接入 Module Federation 远程插件后，远程插件的样式可能通过共享样式表或全局 CSS 渗透到主站，污染 `--border` 变量或 `.border` 的 `border-color`，导致插件中心卡片出现不期望的「白边」，与 `bg-theme/5` 的浅主题底色脱节、视觉割裂。

**目标**：在卡片 `className` 中显式追加 `border-theme/5`，把边框颜色钉死到主题色族（与背景 `bg-theme/5` 同源），从源头规避远程插件样式污染 `border-border` 带来的白边问题。

## 2. 改动范围

- `apps/frontend/src/views/plugins/index.tsx`（约 L106–L108，`Card` 的 `className` 由 `cn(...)` 拼接处）

仅一处 className 字符串变更，不涉及组件结构、props、事件或样式隔离框架本身。

## 3. 实现思路

1. **根因定位**：裸 `border` 只声明 `border-width` 与 `border-style`，`border-color` 由 Tailwind 的 `border-border`（`--border`）提供。一旦远程插件改写 `--border` 或注入 `.border { border-color: ... }`，卡片边框即被污染。
2. **显式覆盖**：追加 `border-theme/5`，使 `border-color` 直接绑定到 `--theme` 主题色并以 5% 透明度呈现，优先级高于被污染的 `border-border`，且与背景 `bg-theme/5` 同色族，视觉统一。
3. **为何不改 `--border` 变量或样式隔离层**：样式隔离（`@scope` + MutationObserver）解决的是「远程插件污染主站」的通用治理，成本高且可能影响其它页面；此处只需在受影响的卡片局部显式钉色，是最小侵入的定点修复。
4. **为何不删除 `border`**：仍需 `border` 提供 `border-width: 1px` 与 `border-style: solid`，`border-theme/5` 只负责颜色，二者配合才完整。
5. **注释留痕**：在 `className` 拼接处补一行中文注释，说明为何显式 `border-theme/5`，避免后续维护者误删。

## 4. 关键代码对比与注释

### 4.1 `PluginsPage` 中插件卡片 `Card` 元素（`apps/frontend/src/views/plugins/index.tsx`）

**对比范围**：`plugins.map` 回调内 `return` 的 `<Card>...</Card>` 完整 JSX 元素（从开标签到闭合）。

**改动前** · `apps/frontend/src/views/plugins/index.tsx`（基线，约 L106–L147）

```tsx
// 插件卡片容器 Card 开标签，作为 grid 中的单个卡片
<Card
  // React key 取插件 id，保证列表重排时 DOM 复用正确
  key={p.id}
  // className 通过 cn() 工具函数合并静态类名与条件类名
  className={cn(
    // 旧版静态类名：gap-2 控制子节点间距，py-4 上下内边距，flex flex-col 纵向排列
    // justify-around 子节点均分间距，border 裸边框（颜色回退到 border-border，存在被远程插件污染风险）
    // bg-theme/5 主题色 5% 透明度背景，shadow-none 去掉默认阴影
    'gap-2 py-4 flex flex-col justify-around border bg-theme/5 shadow-none',
    // 下架（onShelf 为 false）时整体降到 80% 不透明度，视觉弱化
    !onShelf && 'opacity-80',
  )}
>
  // CardHeader 容纳标题行与描述，grid-cols-1 单列，[.border-b]:pb-0 去掉底边 padding
  <CardHeader className="grid-cols-1 gap-2 px-4 [.border-b]:pb-0">
    // 标题与上架开关横向排列的容器
    <div className="flex items-center justify-between gap-3">
      // 卡片标题，min-w-0 配合 flex-1 防止长标题撑破布局
      <CardTitle className="min-w-0 flex-1 text-base">
        // 渲染插件标题：按 locale 取 registry.title，缺省回退到插件 id
        {pluginTitle(p, locale)}
      </CardTitle>
      // 右侧操作区：状态文案 + 上架开关，shrink-0 防止被压缩
      <div className="flex shrink-0 items-center gap-2">
        // 上架/下架状态文案，text-xs 小字、不换行
        <span className="text-textcolor/55 text-xs whitespace-nowrap">
          // 在架显示「上架」文案
          {onShelf
            ? t('plugins.shelf.on')
            // 下架显示「下架」文案
            : t('plugins.shelf.off')}
        </span>
        // 上架开关组件，busy（正在切换）时禁用
        <Switch
          // checked 绑定插件 enabled 状态
          checked={onShelf}
          // busy 时禁用交互，防止重复点击
          disabled={busy}
          // 切换时调用 onToggle，void 忽略 Promise 返回值
          onCheckedChange={(v) => void onToggle(p.id, v)}
          // 无障碍标签
          aria-label={t('plugins.shelf.toggle')}
        />
      </div>
    </div>
    // 卡片描述，line-clamp-3 限制最多三行，text-justify 两端对齐
    <CardDescription className="text-textcolor/70 line-clamp-3 text-sm leading-relaxed text-justify">
      // 渲染插件描述：按 locale 取 registry.description，缺省用占位文案
      {pluginBlurb(p, locale, t)}
    </CardDescription>
  </CardHeader>
  // CardContent 展示插件元信息，text-xs 小字、低对比度
  <CardContent className="px-4 text-xs text-textcolor/45">
    // 插件 id 与版本号，font-mono 等宽字体
    <p className="font-mono">
      // 形如「plugin-id · v1.0.0」
      {p.id} · v{p.version}
    </p>
    // 插件路由路径，truncate 防止过长溢出
    <p className="mt-1 truncate">
      // 形如「路由：/plugins/xxx」
      {t('plugins.card.route')}: {p.routePath}
    </p>
    // 插件信任级别
    <p className="mt-1">
      // 形如「信任：trusted」
      {t('plugins.card.trust')}: {p.trust}
    </p>
  </CardContent>
</Card>
```

## 5. 兼容性与影响

- **兼容性**：纯 className 增量，无 API、props、事件变更，对调用方零影响。
- **视觉影响**：在未发生样式污染时，`border-theme/5` 与原 `border-border` 视觉接近（均为浅色细边），几乎无感知；在发生远程插件污染时，卡片边框不再变白，保持主题色族一致。
- **影响范围**：仅 `/plugins` 页面的卡片列表，不涉及其它页面或组件。
- **回归建议**：
  - 验证 `/plugins` 页面在亮/暗主题下卡片边框颜色正常。
  - 加载远程插件后回到 `/plugins` 页面，确认卡片边框不再出现白边。
  - 下架状态（`opacity-80`）下边框仍可见且颜色正确。
