# 插件主题（light/dark）热推送

> 延伸阅读：
> - [模块联邦插件语言同步.md](./模块联邦插件语言同步.md)（locale 热推送机制，本次 theme 热推送与之对称）
> - [插件iframe主题下发.md](./插件iframe主题下发.md)（untrusted iframe 的主题 + CSS 变量下发，本次复用其 `onAppearanceChange` 通道）

## 1. 背景与目标

模块联邦（MF）插件通过 `HostBridgeProps.api.theme` 获取宿主当前的亮/暗主题。改动前，`theme` 与 `locale` 不同——`locale` 已有热推送机制（`withLiveLocale` + `eventBus.emit('locale')`），但 `theme` 只在 `createHostBridge` 创建时调用一次 `capabilities.getTheme()`，之后即使宿主切换了深浅主题，插件侧拿到的仍是创建时的旧值。

这导致：**宿主切到暗色主题后，已加载的 trusted 插件仍显示为亮色**，直到插件被卸载重新加载。

本次改动把 `theme` 做成与 `locale` 完全对称的热推送模型：

1. **`FederationPlugin`** 新增 `theme?: HostTheme` prop，内部用 `useState` 持有当前主题；未显式传 `theme` 时，通过 `capabilities.getTheme()` 取初值并订阅 `capabilities.onAppearanceChange` 跟随变化。
2. **`PluginHostView`** 新增 `theme?: HostTheme` prop，通过 `withLiveTheme` 覆写 `bridge.api.theme`，并在 `useEffect` 中 `eventBus.emit(pluginId, 'theme', theme)` 向已激活的 trusted 插件广播。
3. **向后兼容**：`theme` 为 `undefined`（旧调用方不传）时，保持历史行为——`api.theme` 冻结在创建时的值，不发 `theme` 事件，避免误触发旧插件的主题切换逻辑。

## 2. 改动范围

| 文件 | 改动 |
|------|------|
| `packages/federation-kit/src/react/FederationPlugin.tsx` | 新增 `theme` prop、`theme` state、`onAppearanceChange` 订阅、向 `PluginHostView` 传 `theme` |
| `packages/federation-kit/src/react/PluginHostView.tsx` | 新增 `theme` prop、`withLiveTheme` 函数、`theme` eventBus emit、`liveBridge` 应用 `withLiveTheme` |
| `packages/federation-kit/docs/host-guide/桥接权限.md` | 更新注释：`theme` 不再是「创建时冻结」，改为「热推送靠 FederationPlugin + withLiveTheme + eventBus.emit('theme')」 |

## 3. 实现思路

1. **与 locale 对称设计**：`theme` 的 state 管理、订阅、热推路径完全照搬 `locale` 的模式，降低理解成本和出错概率。
2. **复用 `onAppearanceChange` 通道**：`onAppearanceChange` 原本是为 untrusted iframe 的 CSS 变量下发设计的（见 [插件iframe主题下发.md](./插件iframe主题下发.md)）。本次 trusted 插件的 theme 热推送直接复用同一回调，只取 `appearance.theme` 字段——`accent` 等变化时 `setTheme(next.theme)` 传入同值，React 会跳过重渲染，无副作用。
3. **`theme === undefined` 守卫**：`PluginHostView` 中 `theme` 为 `undefined` 时不发事件、不覆写 `bridge.api.theme`，保证旧调用方（没传 `theme`）行为不变。
4. **两层推送**：trusted 插件通过 `eventBus.emit('theme')` 接收；`bridge.api.theme` 覆写确保插件同步读取时也拿到最新值。untrusted iframe 的主题仍走原 `attachIframeBridge` 的 appearance 通道，不受本次改动影响。

### 4.1 `FederationPlugin.tsx`：新增 theme prop 与状态管理

**改动前** · `packages/federation-kit/src/react/FederationPlugin.tsx`（基线）

```typescript
// 引入类型：仅 PluginHostConfig，无 HostTheme
import type { PluginHostConfig } from '../config/types';

// Props 中只有 locale，无 theme
export type FederationPluginProps = {
	// …省略其它字段…
	locale?: HostLocale;
	ErrorBoundary?: PluginHostViewProps['ErrorBoundary'];
	host?: FederationPluginHost;
};

export function FederationPlugin({
	// …解构 locale，无 theme…
	locale: localeProp,
}: FederationPluginProps) {
	// locale state + 订阅 onLocaleChange
	const [locale, setLocale] = useState<HostLocale>(
		() => localeProp ?? host.config.capabilities.getLocale(),
	);

	useEffect(() => {
		if (localeProp) {
			setLocale(localeProp);
			return;
		}
		setLocale(host.config.capabilities.getLocale());
		return host.config.capabilities.onLocaleChange?.((next) => {
			setLocale(next);
		});
	}, [host, localeProp]);

	// 传给 PluginHostView 时只有 locale，无 theme
	return createElement(PluginHostView, {
		pluginId: id,
		manager: host.manager,
		locale,
		iframeBridge,
		// …
	});
}
```

**改动后** · `packages/federation-kit/src/react/FederationPlugin.tsx`（当前源码，L11、L66–L67、L86、L110–L137、L148）

```typescript
// 引入 HostTheme 类型，用于 theme prop 与 state
import type { HostTheme, PluginHostConfig } from '../config/types';

// Props 新增 theme 字段，可选；缺省走 capabilities.getTheme + onAppearanceChange
export type FederationPluginProps = {
	// …省略其它字段…
	locale?: HostLocale;
	/** 可选；缺省跟 capabilities.getTheme + onAppearanceChange */
	theme?: HostTheme;
	ErrorBoundary?: PluginHostViewProps['ErrorBoundary'];
	host?: FederationPluginHost;
};

export function FederationPlugin({
	// 解构 theme，命名为 themeProp 以避免与内部 state 冲突
	locale: localeProp,
	theme: themeProp,
}: FederationPluginProps) {
	// locale state 保持不变
	const [locale, setLocale] = useState<HostLocale>(
		() => localeProp ?? host.config.capabilities.getLocale(),
	);

	// 新增 theme state：初值取 themeProp 或 capabilities.getTheme()
	const [theme, setTheme] = useState<HostTheme>(
		() => themeProp ?? host.config.capabilities.getTheme(),
	);

	// locale 订阅 effect 保持不变
	useEffect(() => {
		if (localeProp) {
			setLocale(localeProp);
			return;
		}
		setLocale(host.config.capabilities.getLocale());
		return host.config.capabilities.onLocaleChange?.((next) => {
			setLocale(next);
		});
	}, [host, localeProp]);

	// 新增 theme 订阅 effect，与 locale 对称
	useEffect(() => {
		// 显式传了 themeProp 则直接用，不订阅
		if (themeProp) {
			setTheme(themeProp);
			return;
		}
		// effect 挂载时取一次当前主题，对齐 Host 状态
		setTheme(host.config.capabilities.getTheme());
		// 复用 onAppearanceChange 通道；只取 theme 字段
		// accent 等变化时 next.theme 不变，同值 setTheme 被 React 跳过
		return host.config.capabilities.onAppearanceChange?.((next) => {
			// Host 切亮/暗只走此回调；不 setTheme 则 state 仍是旧值，PluginHostView 跟不上
			setTheme(next.theme);
		});
	}, [host, themeProp]);

	// 传给 PluginHostView 时新增 theme
	return createElement(PluginHostView, {
		pluginId: id,
		manager: host.manager,
		locale,
		theme,
		iframeBridge,
		// …
	});
}
```

**变更摘要**：新增 `theme` prop、`theme` state、`onAppearanceChange` 订阅，结构与 `locale` 完全对称。

### 4.2 `PluginHostView.tsx`：新增 withLiveTheme 与 theme 事件推送

**改动前** · `packages/federation-kit/src/react/PluginHostView.tsx`（基线）

export type PluginHostViewProps = {
	pluginId: string;
	manager: PluginHostManager;
	locale: HostLocale;
	iframeBridge: AttachIframeBridgeOptions;
	// …

// 只有 withLiveLocale，无 withLiveTheme

	bridge: HostBridgeProps,

	return {
		...bridge,
		api: {
			...bridge.api,

		},

	locale,
	iframeBridge,
	// …

	useEffect(() => {
		if (status !== 'activated') return;

		() => (loaded?.bridge ? withLiveLocale(loaded.bridge, locale) : null),

**改动后** · `packages/federation-kit/src/react/PluginHostView.tsx`（当前源码，L14、L47–L52、L78–L89、L160、L233–L244）

```typescript
// 引入 HostTheme 类型
import type { HostTheme } from '../config/types';

// Props 新增 theme 字段，带 JSDoc 说明热推机制
export type PluginHostViewProps = {
	pluginId: string;
	manager: PluginHostManager;
	locale: HostLocale;
	/**
	 * 当前 chrome 主题（light/dark）。传入后与 locale 一样热推：
	 * withLiveTheme 覆写 bridge.api.theme + eventBus.emit('theme')。
	 * 缺省则保持历史行为（api.theme 创建时冻结、无热推）。
	 */
	theme?: HostTheme;
	iframeBridge: AttachIframeBridgeOptions;
	// …
};

// withLiveLocale 保持不变
function withLiveLocale(
	bridge: HostBridgeProps,
	locale: HostLocale,
): HostBridgeProps {
	return {
		...bridge,
		api: {
			...bridge.api,
			locale,
		},
	};
}

// 新增 withLiveTheme，与 withLiveLocale 对称：覆写 bridge.api.theme
function withLiveTheme(
	bridge: HostBridgeProps,
	theme: HostTheme,
): HostBridgeProps {
	return {
		...bridge,
		api: {
			...bridge.api,
			theme,
		},
	};
}

export function PluginHostView({
	// 解构新增 theme
	pluginId,
	manager,
	locale,
	theme,
	iframeBridge,
	// …
}: PluginHostViewProps) {
	// locale eventBus emit 保持不变
	useEffect(() => {
		if (status !== 'activated') return;
		eventBus.emit(pluginId, 'locale', locale);
	}, [pluginId, status, locale]);

	// 新增 theme eventBus emit，与 locale 对称
	// 守卫：theme === undefined 时不发，避免旧调用方误触发
	useEffect(() => {
		if (status !== 'activated' || theme === undefined) return;
		eventBus.emit(pluginId, 'theme', theme);
	}, [pluginId, status, theme]);

	// liveBridge 先应用 withLiveLocale，再按需应用 withLiveTheme
	const liveBridge = useMemo(() => {
		if (!loaded?.bridge) return null;
		// 始终应用 locale（locale 是必传 prop）
		let bridge = withLiveLocale(loaded.bridge, locale);
		// 仅在 theme 传入时覆写 api.theme
		if (theme !== undefined) bridge = withLiveTheme(bridge, theme);
		return bridge;
	}, [loaded?.bridge, locale, theme]);
	// …
}
```

**变更摘要**：新增 `withLiveTheme` 函数（与 `withLiveLocale` 对称）、`theme` eventBus emit、`liveBridge` 条件应用 `withLiveTheme`。`theme === undefined` 时全部跳过，保证向后兼容。

## 5. 运行时数据流

```
Host 切换主题
    │
    ▼
capabilities.onAppearanceChange(appearance)
    │
    ▼
FederationPlugin useEffect → setTheme(appearance.theme)
    │
    ▼
PluginHostView 收到 theme prop
    ├─ withLiveTheme 覆写 bridge.api.theme （同步读取最新值）
    └─ eventBus.emit(pluginId, 'theme', theme) （异步广播）
           │
           ▼
    插件侧 eventBus.on('theme', handler) 响应切换
```

## 6. 回归清单

- [ ] 宿主切换浅/深主题后，已加载的 trusted 插件同步切换（无需重新加载插件）
- [ ] 切换强调色（accent）不触发插件主题变化（`setTheme` 同值跳过）
- [ ] 显式传 `theme` prop 给 `FederationPlugin` 时，以 prop 为准，不订阅 `onAppearanceChange`
- [ ] 旧调用方不传 `theme` 时，`api.theme` 保持创建时的值，不发 `theme` 事件（向后兼容）
- [ ] locale 热推送不受影响（`withLiveLocale` 仍正常工作）
- [ ] untrusted iframe 的主题仍走 `attachIframeBridge` appearance 通道，不受本次改动影响
