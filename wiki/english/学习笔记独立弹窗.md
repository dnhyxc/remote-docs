# 学习笔记独立弹窗与多窗口同步

## 1. 背景与目标

### 1.1 问题

学习笔记此前只能在主窗口内通过 Module Federation（MF）插件页打开，编辑区与侧栏、其它学习模块共享同一视口。当用户在背词、练习、看资源库的同时想记笔记时，必须来回切换路由，无法「边学边记」。

桌面端（Tauri）天然支持多窗口，但直接 `window.open` 打开一个 MF 插件页会面临三个工程难题：

1. **多窗口数据一致性**：主窗与弹窗都在编辑同一篇笔记，或一窗保存后另一窗仍显示旧内容，需要跨窗口实时同步草稿 / 已保存 / 已删除等状态。
2. **托管关窗保存**：用户点 ❌ 关闭弹窗时，若直接销毁 WebView，未保存的草稿会丢失；`async` 保存请求会被 WebView 销毁掐断，需要在 Rust 侧 `prevent_close` → 通知前端 await 保存 → 再 `destroy`。
3. **外观跟随**：弹窗需要实时跟随主窗的主题（深 / 浅）、强调色、语言切换，避免出现「主窗深色、弹窗浅色」的割裂。

### 1.2 目标

- 在桌面端为学习笔记提供一个**独立弹窗窗口**（`learning-notes-popout`），与主窗并排，支持边学边记。
- 建立**跨窗口同步总线**（BroadcastChannel）：草稿、已保存、已删除、列表变更、选篇切换等消息在主窗 ↔ 弹窗间实时双向同步。
- 实现**托管关窗保存**：Rust 拦截关闭 → 前端 await 保存（含 store 快照 / DOM 兜底 / keepalive 三重保障）→ 保存成功后再 `destroy` 窗口。
- 实现**外观跟随**：主题 / 强调色 / 语言通过 BroadcastChannel + EventBus 双通道从主窗广播到弹窗。
- 包装 Host HTTP：插件内任何笔记增删改请求成功后**自动广播**跨窗同步消息，无需插件侧手动埋点。
- 提供 **DOM 兜底同步**：当插件尚未暴露 MobX store 时，退化到 ProseMirror DOM 级别的草稿同步与关窗读取。

### 3.2 关键决策

1. **为什么用 BroadcastChannel 而非 Tauri EventBus？**
   - BroadcastChannel 是 Web 标准 API，在 Tauri 多 WebView（同源）和纯 Web 多标签页下都能工作，不依赖原生桥。
   - Tauri 的 `emit`/`listen` 需要每个窗口都注册监听器且仅限桌面端；BroadcastChannel 一次 `postMessage` 所有同源窗口都能收到，代码更简单。
   - 外观同步（theme / accent / locale）也复用同一 BroadcastChannel 机制，避免两套通道。

2. **为什么托管关窗要在 Rust 侧 prevent_close？**
   - 前端 `onCloseRequested` 的 `preventDefault` 在 Tauri 上不可靠（WKWebView 的关闭时序可能跳过 JS 回调）。
   - Rust 侧 `WindowEvent::CloseRequested` 是原生事件循环的一部分，`api.prevent_close()` 能可靠阻止窗口销毁，随后 `eval` 调用前端 `__DNHYXC_HOST_WINDOW_CLOSE__` 全局函数触发保存，保存完成后再 `close_webview_window`（内部先标记 `ALLOW_CLOSE` 再 `destroy`），形成「拦截 → 保存 → 销毁」闭环。
   - RunEvent 兜底：`on_window_event` 绑定可能因时序遗漏，`run` 闭包里的 `RunEvent::WindowEvent` 做第二道拦截。

3. **为什么 HTTP 包装自动广播而非插件手动埋点？**
   - 学习笔记是 MF 插件，源码在独立仓库 `remotePlugins/LearningNotes`，宿主不应假设插件会主动广播。
   - 宿主在 `federation/runtime` 包装 `HostHttpClient`，拦截所有笔记增删改请求（URL 前缀 `/english-learning/notes` + POST/PUT/DELETE），成功后自动 `publishLearningNotesSync`，插件无感获得跨窗同步。

4. **为什么有 StoreSync 和 DomSync 两套？**
   - 插件理想情况下暴露 MobX store（`window.__DNHYXC_LN_STORE__`），宿主通过 `connectStore(binding)` 用 `applyRemoteDraft` / `applyRemoteSaved` 等 API 精确同步，避免 `execCommand` 漏删空行。
   - 但插件 store 异步挂载，且老版本插件可能不暴露 store，此时 DomSync 通过 `MutationObserver` 监听 ProseMirror 挂载、`execCommand('insertHTML')` 应用远端草稿，作为兜底。
   - `patchLearningNotesPlugin` 包装插件 `default` 组件，在 `useEffect` 中同时安装 `installLearningNotesApiSync`（store 路径）和 `attachLearningNotesDomSync`（DOM 兜底），两条路径互不冲突（DomSync 检测到 store 存在时自动让位）。

5. **为什么关窗保存有三重保障？**
   - **第一重**：`store.autoSaveIfDirty({ silent: true })`——插件自身的脏保存逻辑，最精确。
   - **第二重**：`saveLearningNoteAwait`——从 store 快照读 html/title，await fetch PUT/POST，成功后广播 `list-changed`。
   - **第三重**：`store.flushNoteOnPageHide()` + `flushLearningNotesDomKeepaliveOnClose`——`keepalive: true` 的 fetch，即使 WebView 即将销毁也能发出去（浏览器保证请求完成）。
   - 三重从精确到兜底，确保任何场景下草稿不丢。

6. **为什么窗口 ID 用 sessionStorage？**
   - `getLearningNotesWindowId` 在每个窗口首次调用时生成 UUID 并存入 `sessionStorage`，同一窗口后续复用。
   - 接收消息时 `if (msg.windowId === localWindowId) return` 过滤自发回环。
   - sessionStorage 而非 localStorage：每个窗口（标签页 / WebView）有独立 sessionStorage，不会串；localStorage 全局共享会导致所有窗口拿到同一 ID。

### 3.3 数据流

#### 打开弹窗

```
用户点「独立打开」
  → NotesSession.onClick → openLearningNotesPopoutWindow()
  → onCreateWindow({ label: 'learning-notes-popout', url: '/english-learning/notes/popout', ... })
  → Tauri: focus_webview_window(label)  // 已存在则置顶
  → Tauri: attach_managed_window_close(label)  // 绑定 CloseRequested
  → 新窗加载 /english-learning/notes/popout → popout.tsx
  → main.tsx: installHostWindowCloseBridge() + 懒加载 useLearningNotesPopoutCloseSave
  → popout.tsx: useHostAppearanceSync() + useLearningNotesPopoutCloseSave()
  → LearningNotesPluginHost → PluginHostPage → MF 插件加载
  → patchLearningNotesPlugin: 包装 default → installLearningNotesApiSync + attachLearningNotesDomSync
  → 插件挂载 store 到 window.__DNHYXC_LN_STORE__ → 轮询命中 → connectStore(binding)
```

#### 草稿同步

```
弹窗编辑器 onChange
  → DomSync: onEditorInput → debounce 180ms → flushDraft → publishLearningNotesSync({ type: 'draft', ... })
  或 StoreSync: publishLocalLearningNotesDraft → publishLearningNotesSync({ type: 'draft', ... })
  → BroadcastChannel.postMessage
  → 主窗 subscribeLearningNotesSync 收到
  → handleRemoteMessage: binding.getEditingId() === noteId → applyRemoteDraft → 编辑器 setContent
```

#### 关窗保存

```
用户点 ❌
  → Rust: WindowEvent::CloseRequested → api.prevent_close() → eval __DNHYXC_HOST_WINDOW_CLOSE__(label)
  → 前端: runManagedWindowClose(label) → 遍历 handlers
  → saveLearningNotesOnWindowClose()
    → store.autoSaveIfDirty() 成功? return
    → saveLearningNoteAwait(html, title) 成功? → publish list-changed
    → store.flushNoteOnPageHide() / flushLearningNotesDomKeepaliveOnClose 兜底
  → invoke('close_webview_window', { label }) → Rust: ALLOW_CLOSE.insert(label) → win.destroy()
```

#### 外观跟随

```
主窗切换主题
  → theme.ts: changeTheme → onEmit('theme') + broadcastHostAppearance({ kind: 'theme', value })
  → BroadcastChannel.postMessage
  → 弹窗 useHostAppearanceSync: subscribeHostAppearance → changeTheme(value, false)
  → 弹窗 document.documentElement.setAttribute('data-theme', value)
```

### 4.1 `learning_notes_popout.rs`（纯新增）

**来源** · `apps/frontend/src-tauri/src/system/learning_notes_popout.rs`（纯新增，约 L1–L95）

```rust
// 托管关窗模块文档注释：创建时绑定 on_window_event；关闭按钮 ❌ → prevent → 通知前端保存 → destroy
//! 托管关窗：创建时 attach on_window_event；❌ → prevent → 通知前端 → destroy。

// 引入标准库 HashSet（存放允许关闭的窗口 label）与 LazyLock（全局静态初始化）
use std::collections::HashSet;
// 引入 Mutex 用于多线程安全地读写 HashSet
use std::sync::{LazyLock, Mutex};

// 引入 Tauri 的 Emitter（emit 事件）、Manager（get_webview_window）、WindowEvent（关闭请求类型）
use tauri::{Emitter, Manager, WindowEvent};

// 学习笔记弹窗的固定 label，与 capabilities/default.json 中 windows 数组一致
pub const LEARNING_NOTES_POPOUT_LABEL: &str = "learning-notes-popout";

// 前端全局函数名：Rust eval 调用它来触发前端保存流程
const HOST_CLOSE_HOOK: &str = "globalThis.__DNHYXC_HOST_WINDOW_CLOSE__";
// Tauri emit 事件名：与前端 listen 的事件名一致，作为 eval 的补充通道
pub const HOST_CLOSE_EVENT: &str = "host://host-window-close";

// 全局集合：记录哪些 label 被允许直接关闭（保存完成后插入，下次 prevent_close 放行）
static ALLOW_CLOSE: LazyLock<Mutex<HashSet<String>>> =
// LazyLock 延迟初始化，首次访问时创建 Mutex 包裹的空 HashSet
	LazyLock::new(|| Mutex::new(HashSet::new()));
// 全局集合：记录哪些 label 已绑定 on_window_event，避免重复绑定
static ATTACHED: LazyLock<Mutex<HashSet<String>>> = LazyLock::new(|| Mutex::new(HashSet::new()));

// 判断 label 是否为受托管的学习笔记弹窗
pub fn managed_label(label: &str) -> bool {
	// 仅当 label 等于固定常量时返回 true
	label == LEARNING_NOTES_POPOUT_LABEL
}

// 通知前端窗口即将关闭：先 emit 事件，再 eval 全局函数，双通道确保前端收到
fn notify_frontend_close(app: &tauri::AppHandle, label: &str) {
	// 尝试获取该 label 对应的 WebView 窗口
	let Some(win) = app.get_webview_window(label) else {
		// 窗口不存在则直接返回
		return;
	};
	// 通过 Tauri emit 事件通知前端（前端可 listen 该事件）
	let _ = win.emit(HOST_CLOSE_EVENT, label);
	// 构造 JS 脚本：调用前端全局函数 __DNHYXC_HOST_WINDOW_CLOSE__(label)
	let script = format!(
		"try{{const f={HOST_CLOSE_HOOK};if(typeof f==='function')f({label:?});}}catch(e){{console.error('[hostWindowClose]',e)}}"
	);
	// 在该 WebView 中执行脚本，触发前端保存流程
	let _ = win.eval(&script);
}

// 处理 CloseRequested 事件：决定是放行还是拦截+通知前端
fn on_close_requested(label: &str, event: &WindowEvent, app: &tauri::AppHandle) {
	// 仅处理 CloseRequested 事件，其它窗口事件忽略
	let WindowEvent::CloseRequested { api, .. } = event else {
		return;
	};
	// 从 ALLOW_CLOSE 集合中移除该 label；移除成功说明此前已标记允许关闭
	let allow = ALLOW_CLOSE
		.lock()
		.ok()
		// remove 返回 bool（是否存在），then_some 将 true 映射为 Some(())，false 映射为 None
		.and_then(|mut g| g.remove(label).then_some(()))
		.is_some();
	if allow {
		// 已标记允许关闭，放行（窗口正常销毁）
		return;
	}
	// 未标记允许关闭：阻止原生关闭
	api.prevent_close();
	// 通知前端执行保存流程
	notify_frontend_close(app, label);
}

// RunEvent 全局兜底：在 lib.rs 的 run 闭包中调用，处理所有窗口的 CloseRequested
pub fn handle_close_requested(
	label: &str,
	event: &WindowEvent,
	app: &tauri::AppHandle,
) {
	// 仅处理受托管的 label，非托管窗口直接返回
	if !managed_label(label) {
		return;
	}
	// 委托给 on_close_requested
	on_close_requested(label, event, app);
}

// Tauri 命令：子窗创建后由前端 invoke，绑定该 WebviewWindow 的 CloseRequested 事件
#[tauri::command]
pub fn attach_managed_window_close(app: tauri::AppHandle, label: String) -> Result<(), String> {
	// 仅处理受托管的 label
	if !managed_label(&label) {
		// 非托管 label 直接返回 Ok
		return Ok(());
	}
	{
		// 加锁访问 ATTACHED 集合
		let mut attached = ATTACHED.lock().map_err(|e| e.to_string())?;
		// 若该 label 已绑定过，直接返回 Ok（幂等）
		if !attached.insert(label.clone()) {
			return Ok(());
		}
	}

	// 获取该 label 对应的 WebView 窗口
	let win = app
		.get_webview_window(&label)
		// 窗口不存在则返回错误
		.ok_or_else(|| format!("window not found: {label}"))?;

	// 克隆 AppHandle 以便在闭包中使用（move 语义）
	let app_handle = app.clone();
	// label 的引用，用于闭包
	let label_for = label;
	// 绑定该窗口的 on_window_event 回调
	win.on_window_event(move |event| {
		// 每次窗口事件都调用 on_close_requested（仅 CloseRequested 会真正处理）
		on_close_requested(&label_for, event, &app_handle);
	});

	// 绑定成功
	Ok(())
}

// Tauri 命令：前端保存完成后 invoke，真正销毁窗口
#[tauri::command]
pub fn close_webview_window(app: tauri::AppHandle, label: String) -> Result<(), String> {
	// 获取该 label 对应的 WebView 窗口
	let win = app
		.get_webview_window(&label)
		.ok_or_else(|| format!("window not found: {label}"))?;
	// 加锁向 ALLOW_CLOSE 集合插入该 label，标记为允许关闭
	if let Ok(mut g) = ALLOW_CLOSE.lock() {
		// 插入后下次 CloseRequested 会被放行
		g.insert(label);
	}
	// 销毁窗口（触发 CloseRequested → 因 ALLOW_CLOSE 含此 label → 放行 → 真正销毁）
	win.destroy().map_err(|e| e.to_string())
}
```

```typescript
// 模块文档注释：Tauri 托管关窗流程——Rust prevent_close → eval/emit → 前端 await 保存 → invoke destroy
/**
 * Tauri 托管关窗：Rust prevent_close → eval / emit → await 保存 → destroy。
 */
// 引入弹窗 label 常量
import {
	LEARNING_NOTES_POPOUT_LABEL,
} from '@/views/englishLearning/notes/labels';
// 引入 Tauri 运行时检测
import { isTauriRuntime } from './runtime';

// 关窗 handler 类型：可同步或异步，返回 void 或 Promise<void>
export type HostWindowCloseHandler = () => void | Promise<void>;

// Tauri emit 事件名，与 Rust 侧 HOST_CLOSE_EVENT 常量一致
export const HOST_WINDOW_CLOSE_EVENT = 'host://host-window-close';

// 声明全局 Window 上存在可选的关窗钩子函数（Rust eval 调用）
declare global {
	interface Window {
		// Rust eval 调用的前端全局函数
		__DNHYXC_HOST_WINDOW_CLOSE__?: (label: string) => void;
	}
}

// 受托管的窗口 label 集合：目前仅学习笔记弹窗
export const MANAGED_HOST_WINDOW_LABELS = new Set<string>([
	// 学习笔记弹窗 label
	LEARNING_NOTES_POPOUT_LABEL,
]);

// 每个 label 对应的 handler 集合（支持多个 handler）
const handlers = new Map<string, Set<HostWindowCloseHandler>>();
// 正在进行的关窗保存 Promise（防重入）
const inflight = new Map<string, Promise<void>>();

// 桥是否已安装（幂等）
let bridgeInstalled = false;

// 注册某 label 的关窗 handler，返回注销函数
export function registerHostWindowCloseHandler(
	label: string,
	handler: HostWindowCloseHandler,
): () => void {
	// 若该 label 无 handler 集合则创建
	if (!handlers.has(label)) handlers.set(label, new Set());
	// 添加 handler 到集合
	handlers.get(label)!.add(handler);
	// 返回注销函数：从集合中移除该 handler
	return () => {
		handlers.get(label)?.delete(handler);
	};
}

// 执行托管关窗流程：遍历 handler → 保存 → invoke close_webview_window
async function runManagedWindowClose(label: string): Promise<void> {
	// 非托管 label 直接返回
	if (!MANAGED_HOST_WINDOW_LABELS.has(label)) return;
	// 若已有进行中的关窗 Promise，复用之（防重入）
	const existing = inflight.get(label);
	if (existing) return existing;

	// 构建保存任务
	const job = (async () => {
		// 遍历该 label 的所有 handler，逐个 await
		for (const fn of handlers.get(label) ?? []) {
			try {
				// 执行 handler（保存逻辑）
				await fn();
			} catch (e) {
				// handler 失败不阻断后续 destroy
				console.warn('[hostWindowClose] handler failed', label, e);
			}
		}
		// 动态导入 Tauri invoke
		const { invoke } = await import('@tauri-apps/api/core');
		// 调用 Rust 命令真正销毁窗口（Rust 会先标记 ALLOW_CLOSE 再 destroy）
		await invoke('close_webview_window', { label });
	})();

	// 记录进行中的 Promise
	inflight.set(label, job);
	try {
		// 等待保存 + destroy 完成
		await job;
	} finally {
		// 完成后清除进行中标记
		inflight.delete(label);
	}
}

// 安装关窗桥：设置全局函数 + 监听 Tauri 事件（在 main.tsx 调用一次）
export function installHostWindowCloseBridge(): void {
	// 非桌面端或已安装则跳过
	if (!isTauriRuntime() || bridgeInstalled) return;
	// 标记已安装
	bridgeInstalled = true;

	// 设置 Rust eval 调用的全局函数
	window.__DNHYXC_HOST_WINDOW_CLOSE__ = (label: string) => {
		// 触发托管关窗流程
		void runManagedWindowClose(label);
	};

	// 异步安装 Tauri 事件监听（双通道：onCloseRequested + listen emit）
	void (async () => {
		// 动态导入 Tauri webviewWindow API
		const { getCurrentWebviewWindow } = await import(
			'@tauri-apps/api/webviewWindow'
		);
		// 动态导入 Tauri event listen
		const { listen } = await import('@tauri-apps/api/event');
		// 获取当前窗口
		const win = getCurrentWebviewWindow();
		// 当前窗口 label
		const label = win.label;
		// 非托管窗口不安装监听
		if (!MANAGED_HOST_WINDOW_LABELS.has(label)) return;

		// 关窗执行函数
		const onClose = () => runManagedWindowClose(label);

		// 第一通道：Tauri onCloseRequested 事件（前端原生）
		await win.onCloseRequested(async (event) => {
			// 阻止默认关闭
			event.preventDefault();
			// 执行保存 + destroy
			await onClose();
		});

		// 第二通道：Rust emit 的 HOST_WINDOW_CLOSE_EVENT（Rust eval 的补充）
		await listen<string>(HOST_WINDOW_CLOSE_EVENT, (ev) => {
			// 仅处理本窗口的事件
			if (ev.payload === label) void onClose();
		});
	})();
}
```

```typescript
	handler: (payload: HostAppearancePayload) => void,
): () => void {
	// 获取 channel
	const ch = getAppearanceChannel();
	// 不支持则返回空函数
	if (!ch) return () => {};
	// 消息处理函数
	const fn = (ev: MessageEvent<HostAppearancePayload>) => {
		// 取出 data

		// 调用 handler
		handler(data);
	};

	// 返回注销函数
```

```typescript
// 引入主题类型与 hook
import {
	type AccentId,
	type ThemeName,
	useTheme,
} from './theme';

// hook 文档注释：Popout 等独立窗跟随主窗主题/强调色/语言
/** Popout 等独立窗：跟随主窗主题 / 强调色 / 语言 */
export function useHostAppearanceSync() {
	// 从 useTheme 获取 changeTheme / changeAccent（emit=false 不再广播，避免回环）
	const { changeTheme, changeAccent } = useTheme();
	// 从 useI18n 获取 setLocale
	const { setLocale } = useI18n();

	// 副作用：订阅外观变更
	useEffect(() => {
		// 应用外观 payload
		const apply = (payload: HostAppearancePayload) => {
			// 主题变更
			if (payload.kind === 'theme') {
				// changeTheme 第二参数 false 表示不再广播（避免回环）
				void changeTheme(payload.value as ThemeName, false);
			} else if (payload.kind === 'accent') {
				// 强调色变更
				void changeAccent(payload.value as AccentId, false);
			} else if (payload.kind === 'locale') {
				// 语言变更
				setLocale(payload.value, { emitEvent: false });
			}
		};

		// 注销函数数组
		const unsubs: Array<() => void> = [];
		// 订阅 BroadcastChannel 外观变更
		unsubs.push(subscribeHostAppearance(apply));

		// 异步订阅 Tauri 事件（作为 BroadcastChannel 的补充通道）
		void (async () => {
			// 订阅 theme 事件
			const themeUn = await onListen<ThemeName>('theme', (value) => {
				if (typeof value === 'string') apply({ kind: 'theme', value });
			});
			// 订阅 accent 事件
			const accentUn = await onListen<AccentId>('accent', (value) => {
				if (typeof value === 'string') apply({ kind: 'accent', value });
			});
			// 订阅 locale 事件
			const localeUn = await onListen('locale', (value) => {
				if (value === 'zh-CN' || value === 'en-US') {
					apply({ kind: 'locale', value });
				}
			});
			// 收集注销函数
			unsubs.push(themeUn, accentUn, localeUn);
		})();

		// 清理函数
		return () => {
			for (const u of unsubs) u();
		};
	}, [changeAccent, changeTheme, setLocale]);
}
```

```typescript
function getChannel(): BroadcastChannel | null {
	// 不支持 BroadcastChannel 则返回 null
	if (typeof BroadcastChannel === 'undefined') return null;
	if (!channel) {
		// 创建 BroadcastChannel（同一浏览器中不同页面/窗口/iframe 之间的通信）
		channel = new BroadcastChannel(LEARNING_NOTES_SYNC_CHANNEL);
		// 收到消息时分发给所有 handler
		channel.onmessage = (ev: MessageEvent<LearningNotesSyncMessage>) => {
			// 取出 data
			const msg = ev.data;
			// 校验为对象且含 type 字段
			if (!msg || typeof msg !== 'object' || !('type' in msg)) return;
			// 遍历 handler 逐个调用
			for (const h of handlers) {
				try {
					h(msg);
				} catch (e) {
					console.error('[learningNotesSync]', e);
				}
			}
		};
	}
	return channel;

	// SSR 无 sessionStorage 返回 'ssr'
	if (typeof sessionStorage === 'undefined') {
		return 'ssr';
	}
	// 从 sessionStorage 读取
	let id = sessionStorage.getItem(WINDOW_ID_KEY);
	if (!id) {
		// 不存在则生成 UUID 或退而求其次的时间戳+随机数
		id =
			typeof crypto !== 'undefined' && 'randomUUID' in crypto
				? crypto.randomUUID()
				: `w-${Date.now()}-${Math.random().toString(36).slice(2)}`;
		// 存入 sessionStorage
		sessionStorage.setItem(WINDOW_ID_KEY, id);
	}
	return id;
}

	// 获取 channel
	const ch = getChannel();
	// 通过 BroadcastChannel 广播到其它窗口
	ch?.postMessage(msg);
	// 同时分发给本窗口的 handler（本地回环）
	for (const h of handlers) {
		try {
			h(msg);
		} catch (e) {
			console.error('[learningNotesSync] local', e);
		}
	}
```

```typescript
// 包装 HostHttpClient：笔记增删改成功后自动广播跨窗同步
/** 包装 Host HTTP：笔记增删改成功后自动广播跨窗同步 */
export function wrapLearningNotesHttp(
	http: HostHttpClient | undefined,
): HostHttpClient | undefined {
	// 无 http 则原样返回
	if (!http) return http;
	// 获取本窗口 ID
	const windowId = getLearningNotesWindowId();

	// 变更后处理：判断是否为笔记增删改，是则广播
	const afterMutation = (
		method: string,
		url: string,
		body: unknown,
		result: unknown,
	) => {
		// 非笔记增删改请求跳过
		if (!isNotesMutation(method, url)) return;
		// 从 URL 提取笔记 ID
		const id = noteIdFromUrl(url);
		// 解包请求体
		const payload = unwrapBody(body);

		// DELETE 请求
		if (method === 'delete' && id) {
			// 广播已删除
			publishLearningNotesSync({ type: 'deleted', noteId: id, windowId });
			// 广播列表变更
			publishLearningNotesSync({ type: 'list-changed', reason: 'delete', windowId });
			return;
		}

		// POST / PUT：从响应中提取笔记数据
		const data =
			result && typeof result === 'object' && 'data' in (result as object)
				? (result as { data?: unknown }).data
				: result;
		const row =
			data && typeof data === 'object' ? (data as Record<string, unknown>) : null;
		// 笔记 ID 优先取响应 row.id，其次 URL 中的 id，再次请求体 payload.id
		const noteId =
			(typeof row?.id === 'string' ? row.id : null) ??
			id ??
			(typeof payload?.id === 'string' ? payload.id : null);

		if (noteId) {
			// 更新跟踪 ID
			trackedNoteId = noteId;
			// 提取正文 HTML（兼容 row.html / row.content / payload.html / payload.content）
			const html =
				(typeof row?.html === 'string' ? row.html : null) ??
				(typeof row?.content === 'string' ? row.content : null) ??
				(typeof payload?.html === 'string' ? payload.html : null) ??
				(typeof payload?.content === 'string' ? payload.content : '');
			// 提取标题
			const title =
				(typeof row?.title === 'string' ? row.title : null) ??
				(typeof payload?.title === 'string' ? payload.title : '');
			// 广播已保存
			publishLearningNotesSync({
				type: 'saved',
				noteId,
				html,
				title,
				windowId,
				updatedAt:
					typeof row?.updatedAt === 'string' ? row.updatedAt : undefined,
			});
		}
		// 广播列表变更
		publishLearningNotesSync({
			type: 'list-changed',
			reason: method,
			windowId,
		});
	};

	// detail 请求成功后跟踪 noteId（用于后续 DOM 同步）
	const trackDetail = (url: string) => {
		const id = noteIdFromUrl(url);
		// 仅纯 detail URL（无 query）才跟踪
		if (id && url.includes(NOTES_API_PREFIX) && !url.includes('?')) {
			trackedNoteId = id;
		}
	};

	// 返回包装后的 http 对象
	return {
		// 包装 GET：跟踪 detail noteId
		get: (async (url: string) => {
			const res = await http.get(url);
			trackDetail(url);
			return res;
		}) as HostHttpClient['get'],
		// 包装 POST：变更后广播
		post: (async (url: string, body?: unknown) => {
			const res = await http.post(url, body);
			afterMutation('post', url, body, res);
			return res;
		}) as HostHttpClient['post'],
		// 包装 PUT：变更后广播
		put: (async (url: string, body?: unknown) => {
			const res = await http.put(url, body);
			afterMutation('put', url, body, res);
			return res;
		}) as HostHttpClient['put'],
		// 包装 DELETE：变更后广播
		delete: (async (url: string) => {
			const res = await http.delete(url);
			afterMutation('delete', url, undefined, res);
			return res;
		}) as HostHttpClient['delete'],
	};
```

```typescript
	msg: LearningNotesSyncMessage,
	binding: LearningNotesSyncStoreBinding | null,
	localWindowId: string,
) {
	// 过滤自发消息
	if ('windowId' in msg && msg.windowId === localWindowId) return;

	switch (msg.type) {
		// 列表变更：刷新列表
		case 'list-changed':
			void binding?.refreshList();
			break;
		// 已删除：应用删除 + 刷新列表
		case 'deleted':
			binding?.applyRemoteDeleted(msg.noteId);
			void binding?.refreshList();
			break;
		// 已保存：仅当本窗预览或编辑同一篇时应用
		case 'saved':
			if (
				binding &&
				(binding.getPreviewId() === msg.noteId ||
					(msg.html.trim() && binding.getEditingId() === msg.noteId))
			) {
				binding.applyRemoteSaved(msg.noteId, {
					html: msg.html,
					title: msg.title,
				});
			}
			void binding?.refreshList();
			break;
		// 草稿：仅当本窗编辑或预览同一篇时应用
		case 'draft':
			if (
				binding &&
				(binding.getEditingId() === msg.noteId ||
					binding.getPreviewId() === msg.noteId)
			) {
				binding.applyRemoteDraft(msg.noteId, msg);
			}
			break;
		// 状态快照：请求方收到回复后应用草稿或预览
		case 'state-snapshot':
			if (
				!binding ||
				(binding.getEditingId() !== msg.noteId &&
					binding.getPreviewId() !== msg.noteId)
			) {
				break;
			}
			// 有草稿 HTML 则应用草稿
			if (msg.draft?.html.trim()) {
				binding.applyRemoteDraft(msg.noteId, {
					html: msg.draft.html,
					text: msg.draft.text,
					title: msg.draft.title,
					revision: msg.draft.revision,
					uploadSessionId: msg.draft.uploadSessionId,
					dirty: msg.draft.dirty,
				});
			} else if (msg.preview?.html.trim()) {
				// 否则应用预览
				binding.applyRemoteDraft(msg.noteId, {
					html: msg.preview.html,
					text: '',
					title: msg.preview.title,
					revision: 0,
				});
			}
			break;
		default:
			break;
	}
}
```

```typescript
function handleRemote(msg: LearningNotesSyncMessage) {

	if ('windowId' in msg && msg.windowId === getLearningNotesWindowId()) return;
	// 查找插件根
	const root = findPluginRoot();
	if (!root) return;

	// 选篇消息：更新跟踪 ID
	if (msg.type === 'selection' && msg.noteId) {
		setTrackedLearningNotesNoteId(msg.noteId);
		return;

	if (tryGetLearningNotesStoreFromGlobal()) return;

	if (msg.type === 'draft' && msg.noteId === getTrackedLearningNotesNoteId()) {
		// 标记正在应用远端
		applyingRemote = true;

			// 恢复
			applyingRemote = false;
```

```typescript
	// 获取 store

	// 预览模式下不保存
	if (store?.preview) return;

		const ok = await store.autoSaveIfDirty({ silent: true });
		if (ok) return;

	let saved = false;
	if (snap && hasNoteBody(snap.html, snap.text)) {
		saved = await saveLearningNoteAwait({
			id: noteId,
			title: snap.title,
			html: snap.html,
			uploadSessionId,
```

```typescript
	const store = tryGetLearningNotesStoreFromGlobal();

					dirty: snap.dirty,

export function createLearningNotesModulesApi() {
	// 获取本窗口 ID
	const windowId = getLearningNotesWindowId();
	// store 同步注销函数
	let storeDispose: (() => void) | null = null;

	// 连接 store
	const connectStore = (binding: LearningNotesSyncStoreBinding) => {
		// 先注销旧的
		storeDispose?.();
		// 挂载 store 同步
		storeDispose = attachLearningNotesStoreSync(binding);
		// 返回注销函数
		return () => {
			storeDispose?.();
			storeDispose = null;
		};
	};

	// 订阅同步消息
	subscribeLearningNotesSync((msg) => {
		// 过滤自发消息
		if (msg.windowId === windowId) return;
		// 请求状态：回复本窗状态快照
		if (msg.type === 'request-state') {
			publishLocalStateSnapshot(msg.noteId, windowId);
			return;
		}
		// 对端点开同一篇：仅当本窗有未保存编辑时主动推，避免用干净副本盖掉对端草稿
		if (msg.type === 'selection' && msg.noteId) {
			const store = tryGetLearningNotesStoreFromGlobal();
			if (!store) return;
			const binding = createLearningNotesSyncBinding(store);
			// 本窗正在编辑该篇才推送
			if (binding.getEditingId() !== msg.noteId) return;
			const snap = readEditorSnapshot(store);
			// 仅 dirty 时推送
			if (snap?.dirty) publishLocalStateSnapshot(msg.noteId, windowId);
		}
	});

	// 返回冻结的模块 API 对象
	return Object.freeze({
		// 是否为弹窗窗口
		isPopoutWindow: () => isLearningNotesPopoutPath(),
		// 获取窗口 ID
		getWindowId: () => windowId,

		consumeInitialNoteId: (): string | null => {

			} catch {
				return null;
			}
		},
		// sync 子对象
		sync: Object.freeze({
			// 发布选篇切换

			},

			}) => {
```

```typescript
	// 已 patch 则跳过
	if (mod[PATCHED]) return;
	// 保存原始组件
	const Original = mod.default;
	// 原始组件非函数则跳过

				disposeStore();
				disposeDom();
			};
		}, [props.api]);

		// 渲染原始插件组件
		return createElement(Original, props);
	}

	// 替换 default
	mod.default = LearningNotesWithHostSync;
	// 标记已 patch
	mod[PATCHED] = true;

export function patchLearningNotesPluginManager(manager: PluginManager) {
	// 绑定原始 ensurePlugin
	const original = manager.ensurePlugin.bind(manager);
	// 覆盖 ensurePlugin
	manager.ensurePlugin = async (id, opts) => {
		// 先调用原始
		const result = await original(id, opts);
		// learningNotes 插件激活后 patch 模块
		if (id === 'learningNotes' && result.status === 'activated') {
			patchModDefault(result.mod as PluginMod);
		}
		return result;
	};

	// 已激活的插件也 patch
	const loaded = manager.get('learningNotes');
	if (loaded?.status === 'activated') {
```

### 4.27 `LearningNotesPluginHost.tsx`（纯新增）

**来源** · `apps/frontend/src/views/englishLearning/notes/LearningNotesPluginHost.tsx`（纯新增，约 L1–L69）

```typescript
import { useEffect, useState } from 'react';
// 引入 MF 插件宿主页
import { PluginHostPage } from '@/federation';
// 引入同步总线
import {
	getLearningNotesWindowId,
	subscribeLearningNotesSync,
} from '@/federation/capabilities/learningNotesSyncBus';
// 引入 DOM 同步的 remount 判定
import { shouldRemountLearningNotesOnListChange } from '@/federation/capabilities/learningNotesDomSync';
// 引入 store 同步
import {
	createLearningNotesSyncBinding,
	refreshLearningNotesListIfOpen,
	tryGetLearningNotesStoreFromGlobal,
} from '@/federation/capabilities/learningNotesStoreSync';

// Props 类型
type Props = {
	className?: string;
};

// 插件宿主页组件：列表变更时刷新或 remount
/**
 * 学习笔记插件宿主页：列表变更时尝试 refreshList；无 store 时安全 remount 拉新列表。
 */
export function LearningNotesPluginHost({ className }: Props) {
	// remount 计数器
	const [remountKey, setRemountKey] = useState(0);

	// 副作用：订阅同步消息
	useEffect(() => {
		return subscribeLearningNotesSync((msg) => {
			// 过滤自发消息
			if ('windowId' in msg && msg.windowId === getLearningNotesWindowId()) {
				return;
			}
			// 仅处理 list-changed / deleted / saved
			if (
				msg.type !== 'list-changed' &&
				msg.type !== 'deleted' &&
				msg.type !== 'saved'
			) {
				return;
			}

			// 获取 store
			const store = tryGetLearningNotesStoreFromGlobal();
			if (store) {
				// 有 store：通过 binding 精确应用
				const binding = createLearningNotesSyncBinding(store);
				if (msg.type === 'deleted') {
					// 应用删除
					binding.applyRemoteDeleted(msg.noteId);
				} else if (
					msg.type === 'saved' &&
					(store.preview?.id === msg.noteId ||
						(msg.html.trim() && store.editingId === msg.noteId))
				) {
					// 应用已保存
					binding.applyRemoteSaved(msg.noteId, {
						html: msg.html,
						title: msg.title,
					});
				}
				// 刷新列表（仅展开时）
				refreshLearningNotesListIfOpen();
				return;
			}

			// 无 store：安全 remount（编辑器无焦点且最近无输入时）
			if (shouldRemountLearningNotesOnListChange()) {
				setRemountKey((k) => k + 1);
			}
		});
	}, []);

	// 渲染 MF 插件宿主页（key 变化触发 remount）
	return (
		<PluginHostPage
			key={remountKey}
			pluginId="learningNotes"
			className={className}
		/>
	);
}
```

## 5. 兼容性与影响

- **新增能力，不破坏既有**：弹窗是新增入口，原有 `/english-learning/notes` 内嵌页保持不变，仅内部改用 `LearningNotesPluginHost` + `LearningNotesSyncRelay`（功能等价 + 跨窗同步增强）。
- **桌面端独有**：弹窗仅在 Tauri 桌面端可用；纯 Web 端 `onCreateWindow` 走 Web `window.open` 分支，同步总线（BroadcastChannel）在多标签页间同样工作。
- **权限新增**：capabilities 新增 `core:window:allow-close`，仅影响弹窗窗口的 `destroy` 调用，不影响其它窗口。
- **插件无感**：HTTP 包装与插件 patch 对插件透明，插件无需修改即可获得跨窗同步。
- **向下兼容**：插件未暴露 store 时走 DOM 兜底；`changeAccent` 新增 `emit` 参数默认 `true`，现有调用方无需改动。

## 6. 风险与回归建议

- **关窗保存时序**：Rust `prevent_close` → eval → 前端 await 保存 → `close_webview_window`，任一环节异常可能导致窗口卡住不关。回归点：弹窗编辑后点 ❌，确认保存成功后窗口关闭；断网时点 ❌，确认窗口仍可关闭（保存失败不阻断 destroy）。
- **BroadcastChannel 兼容**：部分旧浏览器不支持 `BroadcastChannel`，`getChannel` 返回 null 后消息仅在本地 handler 分发，跨窗同步失效但不崩溃。回归点：Web 端多标签页打开笔记页，确认同步行为或优雅降级。
- **草稿冲突**：两窗同时编辑同一篇笔记，BroadcastChannel 草稿可能互相覆盖。当前策略是「有 dirty 时才推」，但无 OT/CRDT。回归点：两窗同时编辑同一篇不同段落，确认内容不丢（最坏情况后保存者覆盖）。
- **DOM 兜底 execCommand**：`document.execCommand('insertHTML')` 已废弃，在部分浏览器可能有边界问题。回归点：无 store 时远端草稿同步，确认空行不丢、光标位置合理。
- **插件 patch 幂等**：`patchModDefault` 用 Symbol 标记防重复，但若插件热重载可能需要重新 patch。回归点：插件下线再上线，确认同步仍工作。
- **主题回环**：`changeTheme(value, false)` / `changeAccent(value, false)` 第二参数 false 防止广播回环。回归点：主窗切主题 → 弹窗跟随 → 弹窗不再广播，确认无死循环。
- **窗口聚焦**：macOS 上 `focus_webview_window` 比 `setFocus` 可靠。回归点：弹窗已打开时再点「独立打开」，确认窗口置顶而非新建。
