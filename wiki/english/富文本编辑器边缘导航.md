# 学习笔记富文本编辑器 Cmd/Ctrl+↑↓ 文档首尾导航

## 1. 背景与目标

学习笔记富文本编辑器（RichEditor）首位是 atom 类型的 `title` 节点，其后是正文 `block+`。此前用户按 `Cmd/Ctrl+↑` 想跳到文档开头时，`TitleNode.appendTransaction` 的选区纠正逻辑会把光标钉到**文末**（`Selection.atEnd`），导致快捷键方向与预期相反。此外，编辑器缺少「一键滚到顶/底」的快捷键支持。

本轮改动新增 `DocEdgeNav` 扩展，提供 `Cmd/Ctrl+↑`（滚到顶 + 光标落正文开头）与 `Cmd/Ctrl+↓`（滚到底 + 光标落文末）两个快捷键；同时修正 `TitleNode.appendTransaction` 中非法选区的纠正方向，从 `Selection.atEnd` 改为 `TextSelection.near(..., 1)`（向前寻找最近的可放置位置），确保 `Cmd+↑` 落点不被纠到文末。

**延伸阅读**：[学习笔记富文本编辑.md](../ideas/notes/学习笔记富文本编辑.md)（富文本编辑器总览）、[富文本编辑器核心修复.md](./富文本编辑器核心修复.md)（核心优化）、[学习笔记编辑器打磨.md](./学习笔记编辑器打磨.md)（打磨）

## 2. 改动范围

- `apps/remote-plugins/src/components/design/RichEditor/extensions/index.ts`：新增 `scrollEditorViewport` 辅助函数、`DocEdgeNav` 扩展；`createExtensions` 注册 `DocEdgeNav`。
- `apps/remote-plugins/src/components/design/RichEditor/title/TitleNode.ts`：`appendTransaction` 中非法选区纠正方向从 `Selection.atEnd` 改为 `TextSelection.near`。

## 3. 实现思路

1. **新增 `DocEdgeNav` 扩展**：用 TipTap `Extension.create` 注册 `Mod-ArrowUp` / `Mod-ArrowDown` 两个键盘快捷键；代码块内放行原生行为（`return false`）。
2. **`Cmd+↑` 落点计算**：取文档首位 `title` 节点的 `nodeSize + 1`（跳过 atom title），用 `setTextSelection(start)` 把光标钉到正文开头；若文档为空则 `focus('start')` 兜底。
3. **`Cmd+↓` 落点**：直接 `editor.commands.focus('end')`，TipTap 会把光标放到文档末尾。
4. **滚动视口**：新增 `scrollEditorViewport` 辅助函数，从 `editor.view.dom` 向上查找 `[data-slot="scroll-area-viewport"]`（ScrollArea 组件的滚动容器），手动设置 `scrollTop` 为 0 或 `scrollHeight`。
5. **修正 `TitleNode.appendTransaction`**：旧逻辑在 `needsFix` 时用 `bodyEmpty ? TextSelection.create(titleSize+1) : Selection.atEnd(nextDoc)`——非空正文时一律钉到文末，导致 `Cmd+↑` 设置的正文开头选区被 `appendTransaction` 纠正回文末。改为统一使用 `TextSelection.near(nextDoc.resolve(titleSize+1), 1)`（向前找最近可放光标位置），既兼容空正文也避免把正文开头的合法选区纠正到文末。
6. **注册顺序**：`DocEdgeNav` 放在 `TabIndent` 之后、`EmptyParagraphDelete` 之前，priority 默认，不影响其它扩展的快捷键拦截。

**改动后** · `apps/remote-plugins/src/components/design/RichEditor/extensions/index.ts`（当前，约 L42–L51）

```typescript
// 辅助函数签名：接收编辑器实例与滚动方向，无返回值
function scrollEditorViewport(
	// editor 只需 view.dom 字段，用最小接口类型避免耦合完整 Editor
	editor: { view: { dom: Element } },
	// to 控制scrollTop目标：'top' 滚到顶，'bottom' 滚到底
	to: 'top' | 'bottom',
) {
	// 从编辑器 DOM 根节点向上查找 ScrollArea 的滚动视口容器
	const vp = editor.view.dom.closest(
		// ScrollArea 组件渲染的滚动容器带有此 data-slot 属性
		'[data-slot="scroll-area-viewport"]',
	) as HTMLElement | null;
	// 找不到滚动容器时直接返回，不做任何操作
	if (!vp) return;
	// 'top' 设为 0（滚到顶），'bottom' 设为 scrollHeight（滚到底）
	vp.scrollTop = to === 'top' ? 0 : vp.scrollHeight;
}
```

**变更摘要**：新增辅助函数，从编辑器 DOM 向上查找 ScrollArea 视口并设置 `scrollTop`。

**改动后** · `apps/remote-plugins/src/components/design/RichEditor/extensions/index.ts`（当前，约 L53–L79）

```typescript
// JSDoc 注释：说明扩展用途——Cmd/Ctrl+↑↓ 滚到顶/底并落光标，避开 title atom 把 ↑ 纠到文末
/** Cmd/Ctrl+↑↓：滚到顶/底并落光标（避开 title atom 把 ↑ 纠到文末） */
// 创建 TipTap Extension，name 为 'docEdgeNav'
const DocEdgeNav = Extension.create({
	// 扩展名称，用于内部注册与调试
	name: 'docEdgeNav',
	// 注册键盘快捷键
	addKeyboardShortcuts() {
		// 返回快捷键映射对象
		return {
			// Mod-ArrowUp：Cmd(macOS)/Ctrl(Windows) + ↑
			'Mod-ArrowUp': ({ editor }) => {
				// 代码块内放行原生行为（让代码块自己处理上下键）
				if (editor.isActive('codeBlock')) return false;
				// 取文档首个子节点（期望为 title atom）
				const title = editor.state.doc.firstChild;
				// 计算「正文开头」位置：有 title 时取 titleSize+1，否则取 1
				const start =
					title?.type.name === 'title' ? title.nodeSize + 1 : 1;
				// 若计算位置在文档范围内，设置文本选区到该位置并聚焦
				if (start <= editor.state.doc.content.size) {
					editor.chain().setTextSelection(start).focus().run();
				} else {
					// 文档为空时兜底聚焦到开头
					editor.commands.focus('start');
				}
				// 滚动视口到顶部
				scrollEditorViewport(editor, 'top');
				// 返回 true 表示已处理，阻止默认行为
				return true;
			},
			// Mod-ArrowDown：Cmd/Ctrl + ↓
			'Mod-ArrowDown': ({ editor }) => {
				// 代码块内放行原生行为
				if (editor.isActive('codeBlock')) return false;
				// 聚焦到文档末尾
				editor.commands.focus('end');
				// 滚动视口到底部
				scrollEditorViewport(editor, 'bottom');
				// 返回 true 表示已处理
				return true;
			},
		};
	},
});
```

**变更摘要**：新增 `DocEdgeNav` 扩展，注册 `Mod-ArrowUp`/`Mod-ArrowDown` 两个快捷键，分别滚到顶/底并设置光标位置。

## 5. 兼容性与影响

- **兼容性**：纯新增快捷键扩展 + 修正选区纠正方向，不影响已有编辑、保存、导出流程。
- **行为变化**：`Cmd/Ctrl+↑` 现在滚到顶并落光标到正文开头（旧版无此快捷键）；`Cmd/Ctrl+↓` 滚到底并落光标到文末。代码块内两个快捷键均放行原生行为。
- **`appendTransaction` 影响**：非法选区不再被钉到文末，改为钉到正文开头附近；空正文场景行为与旧版一致（`TextSelection.near` 在空正文时也会找到 `titleSize+1`）。
- **风险与回归**：建议测试 ① 空笔记按 `Cmd+↑`；② 有图片的笔记按 `Cmd+↑`（GapCursor 不受影响）；③ 代码块内按 `Cmd+↑/↓`（应放行原生）；④ 长文窗口化编辑器按 `Cmd+↑/↓`（ScrollArea 视口查找）。
