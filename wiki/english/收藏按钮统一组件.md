# 收藏按钮统一组件：FavoriteToggleButton 与每日反馈合并

> 解决「收藏按钮在多处重复实现、每日答对/答错反馈分散为两个组件、练习答题页无法直接收藏当前题」等问题。
> 本轮新建**统一的 `FavoriteToggleButton` 组件**（单词 / 经典句二选一），合并 `DailyCorrectFeedback` + `DailyWrongFeedback` 为单一 `DailyFeedback`（按 `variant` 区分），在听写/拼写练习答题页顶栏与每日记词反馈页嵌入收藏按钮；同步把 `DailyPlayIconButton` 改造为 `Button + Tooltip` 包装，统一交互外观。
> 姊妹文档：收藏状态会话级缓存（`isVocabularyFavorited` / `resolveVocabularyFavoriteId` 等 API 基础）见 [收藏状态会话级缓存.md](./收藏状态会话级缓存.md)；每日记词三阶段状态机见 [每日记词实现.md](./每日记词实现.md)；练习会话顶栏布局见 [练习会话控件.md](./练习会话控件.md)。

若与仓库最新源码不一致，**以源码为准**。

## 1. 背景与目标

### 1.1 用户视角

1. **每日记词答题反馈里想收藏当前词**：答对 / 答错后进入反馈页，此前只有播放钮，要收藏得退出反馈页 → 资源库找到该词 → 点星标，体验割裂；
2. **听写 / 拼写练习答题时也想收藏**：题卡顶栏此前只有「提示」按钮，没有收藏入口；
3. **答对 / 答错反馈页分散**：`DailyCorrectFeedback` 与 `DailyWrongFeedback` 两个组件 90% 结构相同，仅图标 / 配色不同，维护时改一处要改两份；
4. **播放钮与收藏钮外观不齐**：`DailyPlayIconButton` 用原生 `<button>`，与新生 `FavoriteToggleButton`（基于 `Button` + `Tooltip`）风格不一致。

### 1.2 本轮目标

| 层级 | 目标 |
| ---- | ---- |
| 新组件 | 新建 `FavoriteToggleButton`，按 `kind: 'vocab' \| 'classic'` 分发到单词 / 经典句两套收藏 Hook，封装 toggle 逻辑（含 busy 锁、Tooltip 文案、aria-pressed / aria-busy） |
| 每日反馈合并 | 删 `DailyCorrectFeedback` / `DailyWrongFeedback`，新建单一 `DailyFeedback`（`variant: 'correct' \| 'wrong'` 控制图标与配色），在反馈头里嵌入 `FavoriteToggleButton` |
| 练习答题页 | `practice/Session.tsx` 的 `prompt` 阶段顶栏 trailing 改为 `FavoriteToggleButton + 提示按钮` 组合（原先只有提示按钮） |
| 播放钮统一 | `DailyPlayIconButton` 改为基于 `Button` + `Tooltip` 包装，与 `FavoriteToggleButton` 视觉对齐 |
| 类型与数据 | `DailyVocabCard` / `PracticeVocabItem` / `PracticeClassicItem` 补 `favoriteId?: string \| null`；`loadDailyCards` / `practice/utils/fetchWords.ts` / `practice/utils/item.ts` 把后端回填的 `favoriteId` 透传到题卡 |
| 视觉微调 | `components/ui/button.tsx` 的 `secondary` / `ghost` / `link` 三个 variant 的 hover 配色从 `teal-500` 调到 `teal-400`，与新按钮的 `text-teal-500 / hover:text-teal-400` 风格对齐 |

### 1.3 设计约束

| 约束 | 说明 |
| ---- | ---- |
| 不重写收藏逻辑 | `FavoriteToggleButton` 内部仍调 `useIncrementalVocabFavoriteStatus` / `useIncrementalClassicQuoteFavoriteStatus` 的新 API（详见姊妹稿），不复制 status 查询代码 |
| 单次实例只处理一种 kind | 一个 `FavoriteToggleButton` 只接一个 item，`kind` 在 props 上静态确定；不混用单词 + 经典句 |
| busy 锁组件内自管 | `useState(false)` 维护 `favBusy`，请求期间禁用重复点击；失败由 http 客户端统一 Toast，不在组件内处理 |
| `DailyFeedback` 单一来源 | 删除旧两组件后，`DailyCardSession` 用 `variant` 切换，结构对齐 |
| `practiceFavoriteToggleProps` 仅做类型分发 | 不在 helper 内调 Hook，把 `PracticeItem` 转为 `FavoriteToggleButtonProps` 字面量 |

### 3.2 `FavoriteToggleButton` 设计要点

- **props 联合类型**：`{ kind: 'vocab'; item: VocabFavoriteToggleItem } | { kind: 'classic'; item: ClassicQuoteFavoriteToggleItem }`，强制调用方在编译期确定 kind；
- **内部 hook `useFavoriteToggleBindings`**：根据 kind 选择对应收藏 Hook，构造 `itemKey`（vocab 用 `normalizeEnglishVocabWordKey`、classic 用 `classicQuoteFavoriteContentKey`），暴露 `isFavorited` / `onToggle` / `favBusy` / 文案；
- **toggle 流程**：
  1. `checkFavorited()` 判定当前是否已收藏（走新 API `isXxxFavorited`）；
  2. 已收藏 → `resolveFavoriteId()` 取真实 id，调 `removeXxxFavorite(id)` + `clearFavorite()`；取不到 id 时直接 `clearFavorite()` 防星标卡死；
  3. 未收藏 → `addXxxFavorite(item)` 拿 `newId`，`setFavoriteId(newId)`；
- **视觉**：基于 `Button`（`variant="link" size="sm"`）+ `Tooltip`，`Star` 图标在已收藏时 `fill-current`；`aria-pressed` / `aria-busy` 满足无障碍。

### 3.3 `DailyFeedback` 合并思路

- 把旧两组件的 4 处差异（`Icon`、`panelClassName`、`headerClassName`、`iconClassName`、`textClassName`）抽到 `FEEDBACK_VARIANT` 映射表，按 `variant: 'correct' | 'wrong'` 取；
- 其余结构（`SessionPromptPanel` + header + 播放钮 + 详情行）原样保留；
- header 右侧 `gap-3` 容器内新增 `<FavoriteToggleButton kind="vocab" item={card} />`，与 `DailyPlayIconButton` 并排。

### 3.4 练习答题页嵌入思路

- `PracticeVocabItem` / `PracticeClassicItem` 类型补 `favoriteId`；
- `fetchWords.ts` 各装配函数透传 `favoriteId`（单词收藏来源 `row.favoriteId ?? row.id`、其它 `row.favoriteId ?? null`、经典句收藏来源 `row.id`、其它 `row.favoriteId ?? null`）；
- `item.ts` 新增 `practiceFavoriteToggleProps(item)`：按 `item.contentKind` 分发为 `{ kind: 'vocab', item }` 或 `{ kind: 'classic', item }`，直接 spread 给 `FavoriteToggleButton`；
- `Session.tsx` 的 `phase === 'prompt'` 分支 trailing 改为 `<div className="flex shrink-0 items-center gap-2">`，内含 `FavoriteToggleButton` 与原提示 `Button`（外加 `Tooltip` 包装）。

### 3.5 `DailyPlayIconButton` 改造思路

- 把原生 `<button>` 改为 `<Button variant="link" size="sm">`，外加 `<Tooltip side="top" content={playLabel}>` 包装；
- 图标尺寸从 `size-4` 调到 `size-4.5`，与新 `FavoriteToggleButton` 的 `Star` 一致；
- `padding` 用 `px-0!` 覆盖默认 link 横向 padding，保持紧凑。

## 4. 关键代码对比与注释

### 4.1 新组件：`FavoriteToggleButton`（纯新增）

**对比范围**：`FavoriteToggleButton` 组件 + 内部 `useFavoriteToggleBindings` hook 完整定义（纯新增，无改动前版本）。

**改动后** · `apps/frontend/src/views/englishLearning/components/FavoriteToggleButton.tsx`（当前，约 L1–L230）

```typescript
// 引入通用 Button 基础组件（统一外观）
import { Button } from '@ui/index';
// 引入星标图标（已收藏时填充）
import { Star } from 'lucide-react';
// 引入 React hooks：useCallback 缓存回调、useMemo 缓存派生值、useState 维护 busy
import { useCallback, useMemo, useState } from 'react';
// 引入 i18n hook
import { useI18n } from '@/hooks';
// 引入经典句收藏增量 Hook
import { useIncrementalClassicQuoteFavoriteStatus } from '@/hooks/useIncrementalClassicQuoteFavoriteStatus';
// 引入单词收藏增量 Hook
import { useIncrementalVocabFavoriteStatus } from '@/hooks/useIncrementalVocabFavoriteStatus';
// 引入 cn 类名合并工具
import { cn } from '@/lib/utils';
// 引入收藏 service + 类型 + wordKey/contentKey 归一化函数
import {
  addEnglishClassicQuoteFavorite,
  addEnglishVocabularyFavorite,
  classicQuoteFavoriteContentKey,
  type EnglishClassicQuoteItem,
  type EnglishVocabularyItem,
  normalizeEnglishVocabWordKey,
  removeEnglishClassicQuoteFavorite,
  removeEnglishVocabularyFavorite,
} from '@/service';
// 引入通用 Tooltip 组件（鼠标悬停提示）
import Tooltip from '@/components/design/Tooltip';

// 单词 toggle item 类型：扩展带可选 favoriteId
export type VocabFavoriteToggleItem = EnglishVocabularyItem & {
  favoriteId?: string | null;
};

// 经典句 toggle item 类型：扩展带可选 favoriteId
export type ClassicQuoteFavoriteToggleItem = EnglishClassicQuoteItem & {
  favoriteId?: string | null;
};

// 组件 props 联合类型：kind 静态决定走单词还是经典句
export type FavoriteToggleButtonProps =
  | {
      // 单词分支
      kind: 'vocab';
      item: VocabFavoriteToggleItem;
      className?: string;
    }
  | {
      // 经典句分支
      kind: 'classic';
      item: ClassicQuoteFavoriteToggleItem;
      className?: string;
    };

// 内部 hook：根据 kind 装配收藏绑定
function useFavoriteToggleBindings(props: FavoriteToggleButtonProps) {
  // 取 i18n 翻译函数
  const { t } = useI18n();
  // 解构 kind
  const { kind } = props;
  // vocab 分支取 item
  const vocabItem = kind === 'vocab' ? props.item : null;
  // classic 分支取 item
  const classicItem = kind === 'classic' ? props.item : null;

  // 单词 hook 入参 items（仅 1 条）
  const vocabCardItems = useMemo(
    () => (vocabItem ? [{ word: vocabItem.word }] : []),
    [vocabItem?.word],
  );
  // 经典句 hook 入参 items（仅 1 条）
  const classicCardItems = useMemo(
    () => (classicItem ? [{ english: classicItem.english }] : []),
    [classicItem?.english],
  );

  // 调单词收藏 Hook
  const vocabStatus = useIncrementalVocabFavoriteStatus(vocabCardItems);
  // 调经典句收藏 Hook
  const classicStatus =
    useIncrementalClassicQuoteFavoriteStatus(classicCardItems);

  // 计算当前 itemKey：vocab 走 wordKey、classic 走 contentKey
  const itemKey =
    kind === 'vocab' && vocabItem
      ? normalizeEnglishVocabWordKey(vocabItem.word)
      : classicItem
        ? classicQuoteFavoriteContentKey(classicItem.english)
        : '';

  // 当前是否已收藏：用 isXxxFavorited 三级优先级判定（传入内嵌 favoriteId）
  const isFavorited =
    kind === 'vocab' && vocabItem
      ? vocabStatus.isVocabularyFavorited(vocabItem.word, vocabItem.favoriteId)
      : classicItem
        ? classicStatus.isClassicQuoteFavorited(
            classicItem.english,
            classicItem.favoriteId,
          )
        : false;

  // 稳定回调：判定当前是否已收藏（供 onToggle 内调用）
  const checkFavorited = useCallback(() => {
    // vocab 分支
    if (kind === 'vocab' && vocabItem) {
      return vocabStatus.isVocabularyFavorited(
        vocabItem.word,
        vocabItem.favoriteId,
      );
    }
    // classic 分支
    if (classicItem) {
      return classicStatus.isClassicQuoteFavorited(
        classicItem.english,
        classicItem.favoriteId,
      );
    }
    // 兜底：未收藏
    return false;
    // deps：item + status 函数 + kind
  }, [classicItem, classicStatus, kind, vocabItem, vocabStatus]);

  // 稳定回调：取真实 favoriteId（走 resolveXxxFavoriteId 兜底 session / 内嵌）
  const resolveFavoriteId = useCallback(() => {
    // vocab 分支
    if (kind === 'vocab' && vocabItem) {
      return vocabStatus.resolveVocabularyFavoriteId(
        vocabItem.word,
        vocabItem.favoriteId,
      );
    }
    // classic 分支
    if (classicItem) {
      return classicStatus.resolveClassicQuoteFavoriteId(
        classicItem.english,
        classicItem.favoriteId,
      );
    }
    // 兜底：undefined
    return undefined;
  }, [classicItem, classicStatus, kind, vocabItem, vocabStatus]);

  // 稳定回调：调接口加收藏，返回新 id
  const addFavorite = useCallback(async () => {
    // vocab 分支
    if (kind === 'vocab' && vocabItem) {
      const res = await addEnglishVocabularyFavorite(vocabItem);
      return res.data?.id;
    }
    // classic 分支
    if (classicItem) {
      const res = await addEnglishClassicQuoteFavorite(classicItem);
      return res.data?.id;
    }
    // 兜底
    return undefined;
  }, [classicItem, kind, vocabItem]);

  // 稳定回调：调接口取消收藏
  const removeFavorite = useCallback(
    (id: string) =>
      kind === 'vocab'
        ? removeEnglishVocabularyFavorite(id)
        : removeEnglishClassicQuoteFavorite(id),
    [kind],
  );

  // 稳定回调：写入新 favoriteId 到 session
  const setFavoriteId = useCallback(
    (id: string) => {
      // vocab 分支
      if (kind === 'vocab') {
        vocabStatus.setVocabularyFavoriteId(itemKey, id);
        return;
      }
      // classic 分支
      classicStatus.setClassicQuoteFavoriteId(itemKey, id);
    },
    [classicStatus, itemKey, kind, vocabStatus],
  );

  // 稳定回调：清空 session（取消收藏时调用）
  const clearFavorite = useCallback(() => {
    // vocab 分支
    if (kind === 'vocab') {
      vocabStatus.clearVocabularyFavorite(itemKey);
      return;
    }
    // classic 分支
    classicStatus.clearClassicQuoteFavorite(itemKey);
  }, [classicStatus, itemKey, kind, vocabStatus]);

  // 文案：未收藏时的 tooltip / aria-label
  const favoriteLabel =
    kind === 'vocab'
      ? t('englishLearning.vocab.favoriteWord')
      : t('englishLearning.classic.favoriteQuote');
  // 文案：已收藏时的 tooltip / aria-label
  const unfavoriteLabel =
    kind === 'vocab'
      ? t('englishLearning.vocab.unfavoriteWord')
      : t('englishLearning.classic.unfavoriteQuote');

  // busy 锁状态
  const [favBusy, setFavBusy] = useState(false);

  // 稳定回调：toggle 主流程
  const onToggle = useCallback(async () => {
    // 无 itemKey 或正在 busy 直接 return
    if (!itemKey || favBusy) return;
    // 进入 busy
    setFavBusy(true);
    try {
      // 已收藏分支
      if (checkFavorited()) {
        // 取真实 favoriteId
        const favoriteId = resolveFavoriteId();
        // 取不到 id 时（理论上不应发生）直接清空 session 防卡死
        if (!favoriteId) {
          clearFavorite();
          return;
        }
        // 调接口取消收藏
        await removeFavorite(favoriteId);
        // 清空 session（内部会 patch 列表快照 + bump revision）
        clearFavorite();
      } else {
        // 未收藏分支：调接口加收藏
        const newId = await addFavorite();
        // 接口返回新 id 时写入 session
        if (newId) setFavoriteId(newId);
      }
    } catch {
      // 错误提示由 http 客户端统一处理
    } finally {
      // 退出 busy
      setFavBusy(false);
    }
  }, [
    // deps：所有用到的回调 + busy + itemKey
    addFavorite,
    checkFavorited,
    clearFavorite,
    favBusy,
    itemKey,
    removeFavorite,
    resolveFavoriteId,
    setFavoriteId,
  ]);

  // 返回绑定
  return {
    favBusy,
    isFavorited,
    onToggle,
    favoriteLabel,
    unfavoriteLabel,
  };
}

// 组件主体
export function FavoriteToggleButton({
  // className 单独透传
  className,
  // 其余 props（kind / item）
  ...props
}: FavoriteToggleButtonProps) {
  // 取内部 hook 绑定
  const { favBusy, isFavorited, onToggle, favoriteLabel, unfavoriteLabel } =
    useFavoriteToggleBindings(props);

  // 渲染：Tooltip + Button + Star
  return (
    <Tooltip side="top" content={isFavorited ? unfavoriteLabel : favoriteLabel}>
      <Button
        type="button"
        variant="link"
        size="sm"
        // 无障碍：busy 状态
        aria-busy={favBusy}
        // 点击触发 toggle（async 包 void）
        onClick={() => void onToggle()}
        className={cn(
          // 基础尺寸 + 圆角 + 过渡
          'h-8 w-8 shrink-0 cursor-pointer rounded-md p-0 transition-colors',
          // busy 时半透明
          favBusy && 'opacity-60',
          // 已收藏 teal-500、未收藏次级文本色
          isFavorited ? 'text-teal-500' : 'text-textcolor/55',
          // 透传外部 className
          className,
        )}
        // 无障碍：press 状态
        aria-pressed={isFavorited}
        // 无障碍：aria-label（与 tooltip 同步）
        aria-label={isFavorited ? unfavoriteLabel : favoriteLabel}
      >
        <Star
          // 图标尺寸
          className={cn('size-4.5', isFavorited && 'fill-current')}
          aria-hidden
        />
      </Button>
    </Tooltip>
  );
}
```

**变更摘要**：新增统一 `FavoriteToggleButton` 组件，内部 `useFavoriteToggleBindings` hook 按 kind 分发到单词 / 经典句收藏 Hook；toggle 流程含 busy 锁、Tooltip 文案、aria 无障碍属性。

## 5. 兼容性与影响

### 5.1 行为变化

| 维度 | 改前 | 改后 |
| ---- | ---- | ---- |
| 每日记词反馈页 | 仅播放钮 | 播放钮 + 收藏钮并排 |
| 听写/拼写答题页顶栏 | 仅提示按钮（带文字） | 收藏钮 + 提示钮（仅图标 + Tooltip） |
| 答对 / 答错反馈组件 | 两个独立组件 | 单一 `DailyFeedback`，variant 切换 |
| 播放钮外观 | 原生 button，size-4 图标 | Button+Tooltip 包装，size-4.5 图标 |
| 提示按钮 hover 色 | teal-500 / teal-600 | teal-500 / teal-400 |

### 5.2 兼容性

- **后端**：无改动（仅消费前端 Hook 的新 API，详见姊妹稿）。
- **类型**：`favoriteId` 设为可选，旧调用方不破坏。
- **i18n**：`hintShow` 文案变更仅影响 Tooltip / aria-label 文本，无逻辑影响。
- **删除文件**：`DailyCorrectFeedback` / `DailyWrongFeedback` 删除后，仅 `DailyCardSession` 直接引用，已同步改造。

### 5.3 风险与回归

| 风险 | 触发条件 | 回归建议 |
| ---- | ---- | ---- |
| 收藏钮在反馈页点击无效 | `itemKey` 为空（item.word / english 异常） | `onToggle` 开头 `if (!itemKey) return`，星标保持未收藏 |
| 提示按钮无 Tooltip 时悬停无文案 | `canHint=false` 时 `aria-label` 仍存在 | Tooltip content 与 aria-label 同源，无障碍体验一致 |
| `DailyFeedback` variant 配色错位 | 传入未知 variant | TypeScript 联合类型约束，编译期保证 |
| 按钮配色全局影响 | 旧页面用 `link` variant 期望 hover teal-500 | 视觉差异极小（teal-500 → teal-400），全局回归一遍主要入口 |
