# 练习与今日记词会话草稿续练

## 1. 背景与目标

此前练习（`practice`）与今日记词（`daily`）的阶段（setup / running / summary 或 intro / session / done）由组件内 `useState` 持有，并用 URL query `run=1` 标记「正在作答」。这种设计下，**刷新页面或直接复制作答链接打开会丢失整队题目、进度与已答结果**，必须重新从设置页开始，体验割裂；同时随机题序在刷新后会重新洗牌，续练也对不上原队列。

本次改造把「练习会话 / 记词会话」整体序列化为 `sessionStorage` JSON 快照：

- 阶段由 **URL pathname**（`/session`、`/summary`、`/done`）决定，不再用内存 `useState`；
- 整队题目、当前下标、已答结果、轮次、配置等在每次状态变化时落盘到 `sessionStorage`；
- URL 携带 `sid`，刷新时按 sid 读快照恢复状态，做到**刷新不丢进度、随机题序可续**；
- 设置页/介绍页提供「继续上次 / 放弃续练」横幅，用户可显式选择续练或丢弃；
- 登出时按用户维度清空所有草稿，避免账号串号。

## 3. 实现思路

### 3.1 存储结构

每个用户、每个会话用一条 `sessionStorage` 条目存完整快照，外加一条「活跃指针」指向当前未完成的 sid：

```mermaid

  subgraph Legend["图例"]
    L1["矩形：模块/数据<br/>🆕：本轮新增"]
  end
  subgraph SS["sessionStorage（同标签页生命周期）"]
    direction LR
    subgraph Prac["练习草稿 el-practice-draft:"]
      AB["<b>正文 el-practice-draft:{userId}:{sid}</b><br/>━━━<br/>• JSON：v/sid/phase/config/queue/index/results…<br/>• 整队冻结，随机题序可续"]
      AKV["<b>活跃指针 active:{userId}:vocab</b><br/>━━━<br/>• 值=当前未完成 sid<br/>• 按 contentKind 分槽"]
      AKC["<b>活跃指针 active:{userId}:classic</b><br/>━━━<br/>• 经典句独立槽，互不覆盖"]
    end
    subgraph Daily["记词草稿 el-daily-draft:"]
      DB["<b>正文 el-daily-draft:{userId}:{sid}</b><br/>━━━<br/>• JSON：v/sid/phase/cards/index/pendingRecords…"]
      DAK["<b>活跃指针 active:{userId}</b><br/>━━━<br/>• 单槽（记词只有一种 contentKind）"]
    end
  end
  AB -. "sid 写入" .-> AKV
  AB -. "sid 写入" .-> AKC
  DB -. "sid 写入" .-> DAK
```

**读图要点**：正文按 `sid` 分键，活跃指针按 `userId[:kind]` 分键；`peekXxxUnfinished` 先读活跃指针拿到 sid，再读正文校验版本与 phase；`replaceXxxDraft` 会先清掉同槽旧正文再写新的。

### 3.2 状态机与路由

阶段由 URL pathname 唯一决定，组件内不再持有 `phase` state：

```mermaid
flowchart TD
  Start(["进入练习/记词"]) --> P{pathname?}
  P -->|/practice 或 /daily| Setup["setup / intro<br/>读取活跃草稿 → 显示续练 banner"]
  P -->|/session| Run["running / session<br/>按 sid 读快照恢复队列与进度"]
  P -->|/summary 或 /done| Sum["summary / done<br/>按 sid 读快照恢复轮次与结果"]
  Setup -->|"开始 → 生成 sid + 写快照<br/>navigate /session?sid="| Run
  Run -->|"答题完成 → 写快照<br/>navigate /summary?sid="| Sum
  Sum -->|"继续练习/重练错题 → keepSid<br/>navigate /session?sid="| Run
  Run -->|"返回设置 → clearDraft(sid)<br/>navigate /setup"| Setup
```

### 3.3 续练时序

用户在设置页看到未完成草稿、点「继续上次」的核心链路：

```mermaid
sequenceDiagram
  participant U as 用户
  participant Page as 练习/记词页
  participant Draft as sessionDraft 模块
  participant SS as sessionStorage

  U->>Page: 进入 setup/intro 页
  Page->>Draft: peekXxxUnfinished(kind)
  Draft->>SS: get(active:{userId}:kind)
  SS-->>Draft: sid
  Draft->>SS: get(body:{sid})
  SS-->>Draft: 快照 JSON
  Draft-->>Page: { sid, phase, current, total, … }
  Page->>U: 渲染续练 banner（继续/放弃）
  U->>Page: 点击「继续上次」
  Page->>Draft: loadDraft(sid) → 校验 v/phase
  Draft-->>Page: 完整快照
  Page->>Page: applyDraftToState（写回 mode/queue/index…）
  Page->>Draft: saveDraft(next)（可选写回新模式）
  Page->>Page: navigate /session 或 /summary
```

**读图要点**：续练不重新拉取题目，直接用快照里的 `queue`；`onContinueResume` 可把 Setup 当前选择的 `mode` 写回快照再进 session；切换题量/顺序会弹确认，确认后丢弃旧草稿开新局。

## 4. 关键代码对比与注释

### 4.1 `sessionDraftStorage.ts` 通用读写壳（纯新增）

**来源** · `apps/frontend/src/views/englishLearning/utils/sessionDraftStorage.ts`（新增，全文 L1–L51）

```typescript
// 顶部块注释：说明本模块是练习与今日记词草稿共用的 sessionStorage JSON 读写壳
/**
 * sessionStorage JSON 读写壳（练习 / 今日记词草稿共用）
 */
// 从登录态 store 取当前用户 id，用于把草稿按用户分作用域，避免同浏览器多账号串号
import { getLoggedInUserId } from '@/store/loggedInUserId';

// 导出：生成当前用户作用域字符串，未登录返回 'anon'
export function sessionDraftUserScope(): string {
	// 取登录用户 id（数字），未登录为 0 或非法
	const id = getLoggedInUserId();
	// id>0 转字符串作为作用域，否则用 'anon' 兜底，保证 key 永不空
	return id > 0 ? String(id) : 'anon';
}

// 导出：按 key 读并反序列化为 T，失败/无值返回 null
export function sessionDraftGet<T>(key: string): T | null {
	// SSR 或无 sessionStorage 环境直接返回 null，避免 ReferenceError
	if (typeof sessionStorage === 'undefined') return null;
	// 用 try/catch 包裹 JSON.parse，脏数据不影响页面
	try {
		// 从 sessionStorage 取原始字符串
		const raw = sessionStorage.getItem(key);
		// 空值直接返回 null，不进入 parse
		if (!raw) return null;
		// 反序列化为泛型 T 并断言返回
		return JSON.parse(raw) as T;
	} catch {
		// 解析失败（JSON 损坏）返回 null，调用方当作无草稿处理
		return null;
	}
}

// 导出：把 value 序列化为 JSON 写入 key，成功返回 true
export function sessionDraftSet(key: string, value: unknown): boolean {
	// 无 sessionStorage 环境返回 false，调用方据此跳过后续逻辑
	if (typeof sessionStorage === 'undefined') return false;
	// try/catch 捕获配额超限（QuotaExceededError）等写入异常
	try {
		// JSON 序列化后写入，日期等对象可被正确序列化
		sessionStorage.setItem(key, JSON.stringify(value));
		// 写入成功返回 true
		return true;
	} catch (e) {
		// 写入失败打印警告，便于排查配额或序列化问题
		console.warn('[sessionDraft] set failed', key, e);
		// 返回 false 通知调用方落盘失败
		return false;
	}
}

/**
 * 清除某前缀下全部键（登出用）。
 * sessionStorage 无按前缀删除 API，且草稿 key 含动态 sid，只能扫库匹配；
 * 须先收集再删：边遍历边 removeItem 会导致下标前移漏删；也不能 clear()（会清掉同页其它数据）。
 */
export function sessionDraftRemove(key: string): void {
	// 无 sessionStorage 环境直接 return，不报错
	if (typeof sessionStorage === 'undefined') return;
	// try/catch 防止私有模式等环境下 removeItem 抛异常
	try {
		// 按 key 删除条目
		sessionStorage.removeItem(key);
	} catch {
		/* 删除失败静默忽略，不影响主流程 */
	}
}

// 导出：清除某前缀下全部键，登出时按用户维度清空草稿
/** 清除某前缀下全部键（登出用） */
export function sessionDraftClearPrefix(prefix: string): void {
	// 无 sessionStorage 环境直接返回
	if (typeof sessionStorage === 'undefined') return;
	// 先收集待删 key，避免遍历中删除导致索引错乱
	const keys: string[] = [];
	// 遍历 sessionStorage 全部条目
	for (let i = 0; i < sessionStorage.length; i++) {
		// 取第 i 个 key（可能为 null）
		const k = sessionStorage.key(i);
		// 命中前缀才收集，空值跳过
		if (k?.startsWith(prefix)) keys.push(k);
	}
	// 逐个删除收集到的 key
	for (const k of keys) sessionDraftRemove(k);
}
```

### 4.2 `practiceSessionDraft.ts` 练习会话快照（纯新增）

**来源** · `apps/frontend/src/views/englishLearning/practice/utils/practiceSessionDraft.ts`（新增，关键函数 L1–L177）

```typescript
// 顶部块注释：整队 queue 冻结保证随机顺序可续；active 按 contentKind 分槽互不覆盖
/**
 * 练习会话 sessionStorage 快照（整队 queue 冻结，保证随机顺序可续）
 * active 按 contentKind（vocab / classic）分槽，互不覆盖
 */
// 从通用壳导入 5 个读写函数，练习侧不直接碰 sessionStorage
import {
	sessionDraftClearPrefix,
	sessionDraftGet,
	sessionDraftRemove,
	sessionDraftSet,
	sessionDraftUserScope,
} from '../../utils/sessionDraftStorage';
// 导入练习相关类型，快照字段类型与业务状态对齐
import type {
	PracticeAttemptResult,
	PracticeContentKind,
	PracticeCountOption,
	PracticeItem,
	PracticeMode,
	PracticeOrder,
	PracticeReportSaveMode,
	PracticeSessionCursor,
	PracticeSessionRound,
	PracticeSetupConfig,
} from '../types';

// 草稿版本号常量，后续结构变更时升级用于迁移
export const PRACTICE_DRAFT_VERSION = 1 as const;
// key 前缀常量，与记词侧区分
export const PRACTICE_DRAFT_KEY_PREFIX = 'el-practice-draft';

// 练习草稿完整结构类型
export type PracticeSessionDraft = {
	// 版本号，用于兼容性校验
	v: typeof PRACTICE_DRAFT_VERSION;
	// 会话 id，URL 上的 sid 与此对齐
	sid: string;
	// 阶段：作答中或结算
	phase: 'running' | 'summary';
	// 设置页配置（mode/order/count/source…）
	config: PracticeSetupConfig;
	// 整队题目（冻结随机顺序）
	queue: PracticeItem[];
	// 当前题下标
	index: number;
	// 本轮已答结果
	results: PracticeAttemptResult[];
	// 历轮结果（多轮续练用）
	sessionRounds: PracticeSessionRound[];
	// 分页游标（continue 拉取下一批用）
	sessionCursor: PracticeSessionCursor | null;
	// 已练过的词 key 集合
	practicedKeys: string[];
	// 关联的报告 id（可空）
	sessionReportId: string | null;
	// 最后写入时间
	updatedAt: string;
};

// 内部：把 undefined 或非法 kind 规整为 vocab 或 classic
function normalizeKind(kind: PracticeContentKind | undefined): PracticeContentKind {
	// 仅 classic 视为 classic，其余（含 undefined）一律按 vocab 处理
	return kind === 'classic' ? 'classic' : 'vocab';
}

// 内部：正文 key = 前缀:用户域:sid
function bodyKey(sid: string): string {
	// 拼出按用户、按 sid 隔离的正文 key
	return `${PRACTICE_DRAFT_KEY_PREFIX}:${sessionDraftUserScope()}:${sid}`;
}

// 内部：活跃指针 key = 前缀:active:用户域:kind
function activeKey(kind: PracticeContentKind): string {
	// 按 contentKind 分槽，vocab 与 classic 各存各的活跃 sid
	return `${PRACTICE_DRAFT_KEY_PREFIX}:active:${sessionDraftUserScope()}:${kind}`;
}

// M2 旧指针 key（未分 kind），读取时迁移到新槽后删除
/** M2 旧指针（未分 kind）；读时迁到 vocab/classic 槽后删除 */
function legacyActiveKey(): string {
	// 旧版只有一条不分 kind 的活跃指针
	return `${PRACTICE_DRAFT_KEY_PREFIX}:active:${sessionDraftUserScope()}`;
}

// 内部：把旧版单槽活跃指针迁移到按 kind 分槽的新结构
function migrateLegacyActive(): void {
	// 读旧指针的 sid
	const legacySid = sessionDraftGet<string>(legacyActiveKey());
	// 无旧指针直接返回
	if (!legacySid) return;
	// 用旧 sid 加载正文草稿
	const draft = loadPracticeDraft(legacySid);
	// 迁移完删除旧指针，避免重复迁移
	sessionDraftRemove(legacyActiveKey());
	// 正文不存在则不迁移
	if (!draft) return;
	// 取草稿自身的 contentKind
	const kind = normalizeKind(draft.config.contentKind);
	// 仅当新槽为空时写入，避免覆盖用户已开的新草稿
	if (!sessionDraftGet<string>(activeKey(kind))) {
		// 把旧 sid 写入对应 kind 的新活跃槽
		sessionDraftSet(activeKey(kind), legacySid);
	}
}

// 导出：取某 contentKind 的当前活跃 sid
export function getPracticeActiveSid(kind: PracticeContentKind): string | null {
	// 先做旧指针迁移，保证升级用户也能续练
	migrateLegacyActive();
	// 读取对应 kind 槽的活跃 sid
	return sessionDraftGet<string>(activeKey(normalizeKind(kind)));
}

// 导出：设置某 contentKind 的活跃 sid（null 表示清除）
export function setPracticeActiveSid(kind: PracticeContentKind, sid: string | null): void {
	// 计算目标 kind 的活跃 key
	const key = activeKey(normalizeKind(kind));
	// sid 为空时删除该槽指针
	if (!sid) {
		sessionDraftRemove(key);
		return;
	}
	// sid 非空时写入指针
	sessionDraftSet(key, sid);
}

// 导出：按 sid 加载草稿并做版本/结构校验
export function loadPracticeDraft(sid: string): PracticeSessionDraft | null {
	// 从正文 key 读取 JSON
	const draft = sessionDraftGet<PracticeSessionDraft>(bodyKey(sid));
	// 不存在、版本不匹配、sid 不一致都视为无效
	if (!draft || draft.v !== PRACTICE_DRAFT_VERSION || draft.sid !== sid) {
		return null;
	}
	// phase 不在合法集合则无效
	if (draft.phase !== 'running' && draft.phase !== 'summary') return null;
	// config 缺失或 queue 不是数组则无效
	if (!draft.config || !Array.isArray(draft.queue)) return null;
	// 校验通过返回草稿
	return draft;
}

// 导出：保存草稿并同步设置活跃指针
export function savePracticeDraft(draft: PracticeSessionDraft): boolean {
	// 取草稿的 contentKind 用于定位活跃槽
	const kind = normalizeKind(draft.config.contentKind);
	// 写入正文：补 v 与 updatedAt，用 satisfies 保证类型完整
	const ok = sessionDraftSet(bodyKey(draft.sid), {
		...draft,
		v: PRACTICE_DRAFT_VERSION,
		updatedAt: new Date().toISOString(),
	} satisfies PracticeSessionDraft);
	// 写入成功才更新活跃指针，避免指针指向不存在的正文
	if (ok) setPracticeActiveSid(kind, draft.sid);
	// 返回写入结果
	return ok;
}

// 导出：清除指定 sid 的草稿并清理对应活跃指针
export function clearPracticeDraft(sid: string): void {
	// 先加载草稿拿到其 contentKind
	const draft = loadPracticeDraft(sid);
	// 删除正文
	sessionDraftRemove(bodyKey(sid));
	// 有草稿则只清对应 kind 槽；无草稿则两槽都检查，防止孤儿指针
	const kinds: PracticeContentKind[] = draft
		? [normalizeKind(draft.config.contentKind)]
		: ['vocab', 'classic'];
	// 遍历可能的 kind 槽
	for (const kind of kinds) {
		// 仅当该槽指针正好指向本 sid 时才清除
		if (sessionDraftGet<string>(activeKey(kind)) === sid) {
			setPracticeActiveSid(kind, null);
		}
	}
}

// 导出：新开局时替换同 contentKind 的旧活跃正文（避免堆积）
/** 新开局：仅替换同 contentKind 的旧活跃正文 */
export function replacePracticeDraft(draft: PracticeSessionDraft): boolean {
	// 定位新草稿的 kind 槽
	const kind = normalizeKind(draft.config.contentKind);
	// 取该槽旧活跃 sid
	const prev = getPracticeActiveSid(kind);
	// 旧 sid 存在且与新 sid 不同时，先清旧正文与指针
	if (prev && prev !== draft.sid) clearPracticeDraft(prev);
	// 保存新草稿（会自动写活跃指针）
	return savePracticeDraft(draft);
}

// 导出：登出时清空当前用户所有练习草稿
export function clearAllPracticeDrafts(): void {
	// 按前缀清除，涵盖正文与所有活跃指针
	sessionDraftClearPrefix(`${PRACTICE_DRAFT_KEY_PREFIX}:`);
}

// 未完成信息类型，供 Setup 页 banner 展示
export type PracticeUnfinishedInfo = {
	// 会话 id
	sid: string;
	// 阶段
	phase: 'running' | 'summary';
	// 当前做到第几题
	current: number;
	// 总题数
	total: number;
	// 内容类型
	contentKind: PracticeContentKind;
	// 练习模式
	mode: PracticeMode;
	// 出题顺序

	// 题量
	count: PracticeCountOption;
	// 报告保存方式
	reportSaveMode: PracticeReportSaveMode;
	// 来源展示名（词库/收藏等）
	/** 词库 / 收藏等来源展示名（来自草稿 config） */

export function peekPracticeUnfinished(kind: PracticeContentKind): PracticeUnfinishedInfo | null {
	// 规整 kind
	const want = normalizeKind(kind);
	// 取该 kind 活跃 sid
	const sid = getPracticeActiveSid(want);
	// 无活跃 sid 表示无未完成
	if (!sid) return null;
	// 加载正文
	const draft = loadPracticeDraft(sid);
	// 正文无效则无
	if (!draft) return null;
	// kind 不一致（异常）则无
	if (normalizeKind(draft.config.contentKind) !== want) return null;
	// running 阶段队列为空不算未完成
	if (draft.phase === 'running' && draft.queue.length === 0) return null;
	// summary 阶段无轮次不算未完成
	if (draft.phase === 'summary' && draft.sessionRounds.length === 0) {
		return null;
	}
	// 总题数至少为 1，避免除零或 current>total
	const total = Math.max(1, draft.queue.length);
	// 来源标题去空白
	const sourceTitle = draft.config.sourceTitle?.trim() || undefined;
	// 组装展示信息
	return {
		sid: draft.sid,
		phase: draft.phase,
		// current 从 1 开始，且不超过 total
		current: Math.min(draft.index + 1, total),
		total,
		contentKind: want,
		mode: draft.config.mode,
		order: draft.config.order,
		count: draft.config.count,
		// reportSaveMode 兼容旧草稿缺省
		reportSaveMode: draft.config.reportSaveMode ?? 'manual',
		sourceTitle,
	};
}
```

```typescript
	pathname: string,
	search: string,
	navState: unknown,
```

## 5. 行为变化与兼容性

| 维度        | 改动前                          | 改动后                                                  |
| ----------- | ------------------------------- | ------------------------------------------------------- |
| 阶段来源    | 组件 `useState` + `run=1` query | URL pathname（`/session`、`/summary`、`/done`）         |

| URL         | `?run=1`                        | `?sid=<uuid>`，`run` 参数被删除                         |

**兼容性**：

- 旧版 `run=1` 链接：进入后 `stripLegacyRun` / `syncModeToSearch` 会删除 `run`，阶段按 pathname 判定，无 `sid` 时回 setup；
- 旧版不分 kind 的练习活跃指针：`migrateLegacyActive` 读取时迁移到 vocab/classic 分槽后删除；
- 草稿版本号 `v=1`，`loadXxxDraft` 严格校验版本，未来结构升级需 bump 版本并写迁移；
- 仅前端改动，无后端接口变更。

## 6. 风险与回归

- **sessionStorage 配额**：练习整队 `queue`（含经典句全文）可能较大，百题练习 JSON 可达数百 KB；`sessionDraftSet` 捕获 `QuotaExceededError` 后返回 false，此时续练不可用但不崩溃，需关注超大题量场景。
- **跨标签页**：sessionStorage 同标签页内共享，新标签页打开同 sid 链接会各自读快照但写入互不影响（sessionStorage 按标签页隔离），多标签同时续练可能产生两份状态，属预期（用户主动复现链接）。
- **登出时序**：`resetUserState` 在登出流程内同步清空草稿；若登出前页面已卸载，sessionStorage 会随标签页关闭自然清除，无残留风险。
- **面包屑**：`Header` 现按 pathname 判断阶段，需回归 `/practice`、`/practice/session`、`/practice/summary`、`/daily`、`/daily/session`、`/daily/done` 六种路径的面包屑显示。
- **续练 banner 交互**：需回归「继续上次」「放弃续练」「改题量确认」「改顺序确认」「开始新练习替换确认」五条路径。
- **报告续练**：`reports/Detail.tsx` 的 continue 现走 `englishPracticeSessionUrl`，需回归从报告详情继续练习能正确带 sid 并恢复队列。
