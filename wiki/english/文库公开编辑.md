# 资源库编辑、重命名与公共词库

> **文档角色**：说明单词库 / 语句库「编辑弹窗、标题修改、是否公开」的前后端实现与权限边界。**（更新：仅所有者可改可见性）**
> **延伸阅读**：[英语学习文库导入.md](./英语学习文库导入.md)、[英语学习文库UX与删除.md](./英语学习文库UX与删除.md)

## 1. 背景与目标

用户需要在**资源库**列表中维护词库元数据：**仅库的所有者本人**可**重命名自己的库**并**设置该库是否公开**；**超级管理员不再能修改他人的库**。

导入或新建的库**默认私有**（`is_public = false`），公开须由**所有者**在编辑弹窗内**手动开启**，不会自动公开。

## 3. 实现思路

1. **数据模型**：单词库 / 语句库主表增加 `is_public`（默认 `false`）及索引；列表项 DTO 增加 `isPublic`、`isOwned`。
2. **可见性查询**：列表与读库断言改为「**自有 OR 公共**」；删除、改标题仍仅**创建者**（`assert*Owned`）。
3. **公开写权限（本轮改动）**：`PATCH .../visibility` 改为**仅所有者**可写——后端先 `assert*LibraryOwned(userId, libraryId)` 断言库存在且属于当前用户，**超级管理员对他人库同样被拒**（返回 `NotFoundException`「库不存在或无权访问」）。前端用 `canEditVisibility = isOwned !== false` 控制弹窗内 Switch。
4. **编辑入口（本轮改动）**：**仅所有者**（`isOwned !== false`）可见编辑入口（含已公开库）；**他人库（含超管查看他人库）一律不显示编辑入口**。弹窗内标题与公开开关对非自有库均不可用。
5. **公共徽章**：列表标题旁 `isPublic` 时展示 i18n「公共」标签，**所有登录用户**均可见（标识该库为全站可读）。
6. **UI 组件**：编辑弹窗使用 `@design/Model`；标题输入使用 `Input` 的 `showCount` + `maxLength={50}`（与导入页一致；后端 title 上限 200，超长会被服务端截断）。
7. **回车保存**：弹窗打开且有未保存变更时，**Enter** 等同点击保存（标题输入框内 Enter 亦触发；`canSave && !saving` 时生效）。
8. **记词 / 练习抽词**：`createLibraryMemorizeEligibleQueryBuilder` 等 join 库表时同样允许 `userId OR lib.isPublic`，公共库词条可参与今日记词与练习队列。

// 分页列出当前用户可见的单词库（自有 + 公共）
async listVocabularyLibraries(userId: number, options?) {
	// 用 query builder 组装条件；别名 lib 便于引用列
	const rows = await this.vocabLibraryRepo
		.createQueryBuilder('lib')
		// 条件：当前用户创建的库，或已被标记为公共的库
		.where('(lib.userId = :userId OR lib.isPublic = true)', { userId })
		// 按创建时间倒序，最新库排在最前
		.orderBy('lib.createdAt', 'DESC')
		// 限制本页返回条数
		.take(limit)
		// 跳过前 offset 条，实现分页
		.skip(offset)
		// 执行查询取回实体数组
		.getMany();
	// 映射为列表项 DTO 并注入 isOwned，供前端判断编辑 / 删除权限
	return rows.map((r) => this.mapVocabularyLibraryListItem(r, userId));

// 更新单词库公开状态：user 传入、库 id、新公开值
async updateVocabularyLibraryVisibility(
	// 当前操作用户 id
	userId: number,
	// 目标库 id
	libraryId: string,
	// 请求体 DTO：仅含 isPublic
	dto: UpdateLibraryVisibilityDto,
	// 返回更新后的列表项
): Promise<VocabularyLibraryListItem> {
	// 旧前置：先校验当前用户是否有超级管理员角色
	if (!(await this.userService.userHasSuperAdminRole(userId))) {
		// 非超管直接 403，普通用户无法改公开状态
		throw new ForbiddenException('需要超级管理员权限');
	}
	// 旧：仅按 id 查询库，不带所有权条件
	const lib = await this.vocabLibraryRepo.findOne({
		// 查询条件：id 匹配
		where: { id: libraryId },
	});
	// 库不存在则抛 404
	if (!lib) {
		throw new NotFoundException('单词库不存在');
	}
	// 记录改动前的公开状态，供关闭公开时清理续读占位
	const wasPublic = lib.isPublic;
	// 写入新的公开状态
	lib.isPublic = dto.isPublic;
	// 落库
	const saved = await this.vocabLibraryRepo.save(lib);
	// 由公开转私有：清理非所有者的续读占位记录
	if (wasPublic && !saved.isPublic) {
		// 按库类型与库 id、所有者 id 清理续读
		await this.purgeLibraryItemsResumeExceptOwner(
			'vocab',
			libraryId,
			saved.userId,
		);
	}
	// 通知缓存层可见性已变化，触发列表缓存失效
	await this.libraryCache.onLibraryVisibilityChanged('vocab', saved.userId);
	// 读取当前用户在该库的续读偏移
	const resume = await this.getLibraryItemsResumeOffset(
		userId,
		'vocab',
		libraryId,
	);
	// 返回带 isOwned / resume 的列表项
	return this.mapVocabularyLibraryListItem(saved, userId, resume);
}

### 4.4 前端超管 Hook（已不再用于资源库可见性）

> 本功能已改为仅所有者判定，**不再使用** `useIsSuperAdmin`；该 Hook 保留给其它入口使用。

**来源**：`apps/frontend/src/hooks/useIsSuperAdmin.ts`（约 L12–L42）

```typescript
/** 与后端 userHasSuperAdminRole 对齐；须已登录且 roles 含超级管理员 */
// 判定某用户信息对象是否为超级管理员
export function checkIsSuperAdmin(userInfo): boolean {
	// 归一化用户 id 为数字，便于健壮判断
	const id = Number(userInfo?.id);
	// id 非法（NaN / 非正数）视为未登录，直接返回非超管
	if (!Number.isFinite(id) || id <= 0) return false;
	// 任一角色命中 id=1 或中英文超管名，即视为超管
	return userInfo?.roles?.some(
		(r) => r?.id === 1 || r?.name === "超级管理员" || r?.name === "Super Admin",
	);
}

/** 监听 userInfoChanged / storage，登录或资料更新后自动刷新 */
// 响应式 Hook：返回当前用户是否超管
export function useIsSuperAdmin(): boolean {
	// 初始化：从本地存储读取用户信息，作为首帧判定依据
	const [userInfo, setUserInfo] = useState(() =>
		JSON.parse(getStorage(USER_INFO_STORAGE_KEY) || "{}"),
	);
	// 订阅存储与自定义事件，任一变化即重读，保证登录后即时同步
	useEffect(() => {
		// 同步函数：重新解析存储中的用户信息并写入状态
		const sync = () =>
			setUserInfo(JSON.parse(getStorage(USER_INFO_STORAGE_KEY) || "{}"));
		// 监听同源多窗口的 storage 事件
		window.addEventListener("storage", sync);
		// 监听应用内 userInfoChanged，覆盖本窗登录 / 改资料场景
		window.addEventListener("userInfoChanged", sync);
		// 卸载时移除监听，避免重复订阅与内存泄漏
		return () => {
			/* remove listeners */
		};
	}, []);
	// 每次渲染用最新 userInfo 计算是否超管
	return checkIsSuperAdmin(userInfo);
}
```

### 4.7 回车快捷保存

**来源**：`apps/frontend/src/views/englishLearning/library/components/LibraryEditDialog.tsx`（约 L152–L167）

```typescript
/** 弹层打开时回车等同点击保存（标题输入框内 Enter 亦触发） */
// 监听全局键盘：弹层打开且有变更时 Enter 触发保存
useEffect(() => {
	// 弹层未打开则无需监听，提前返回
	if (!open) return;
	// 键盘按下处理器：拦截 Enter 触发保存
	const onKeyDown = (e: KeyboardEvent) => {
		// 非 Enter、长按重复、保存中、无变更时一律忽略
		if (e.key !== 'Enter' || e.repeat || saving || !canSave) return;
		// 取事件目标元素，判断是否处于多行输入上下文
		const el = e.target as HTMLElement | null;
		// 排除多行 / 下拉 / 富文本，单行 Input 仍走保存
		if (el?.closest('textarea, select, [contenteditable="true"]')) {
			// 命中排除项则直接返回，避免误触保存
			return;
		}
		// 阻止默认行为，避免 Form 提交或换行
		e.preventDefault();
		// 阻止冒泡，避免触发 Dialog 默认回车行为
		e.stopPropagation();
		// 复用保存流程，void 表示不等待其 Promise
		void handleSave();
	};
	// 捕获阶段监听，先于 Dialog 默认行为拿到事件
	window.addEventListener('keydown', onKeyDown, true);
	// 卸载或依赖变化时移除监听，避免重复绑定
	return () => window.removeEventListener('keydown', onKeyDown, true);
}, [open, canSave, saving, handleSave]);
```

与 `@design/Confirm` 的 `confirmOnEnter` 差异：本弹窗**允许**在标题 `Input` 聚焦时 Enter 保存，便于改完名直接提交。

## 5. 兼容性与影响

| 场景 | 行为 |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| 未跑 migration | 列表 / PATCH 可能因缺列失败，需执行 `library-public` 等迁移 |
| 普通用户（非所有者） | 可见公共库与「公共」徽章；**他人库（含他人公开库）无编辑 / 删除入口**；不可改他人库公开 |
| 库所有者 | **可编辑自有库**：改名 + 切换公开；公开后全站登录用户可用；可删除自有库 |
| 超级管理员 | **不再能编辑 / 公开他人库**；对自己创建的库与普通用户一致（本轮行为变化） |
| 默认导入 | `is_public = false`，须**所有者本人**在编辑弹窗手动公开 |

**前后端 title 长度**：前端限制 50 字（与导入页一致），后端 DTO 上限 200；若需完全一致可后续统一常量。

## 6. 建议回归

1. 所有者：打开自有库编辑弹窗，可改名、可切换「设为公共」，Enter / 保存生效；保存后列表标题同步。
2. 所有者开启公开后：另一账号在列表见到该库与「公共」徽章，可浏览 / 练习；关闭后从他人列表消失（续读占位清理）。
3. 超管：打开他人库（含已公开库）时**编辑入口不可见**；直接 PATCH 他人库 visibility 应被拒（`NotFoundException`「库不存在或无权访问」）。
4. 非所有者浏览公开库：编辑弹窗名称只读、无公开开关。
5. 弹窗 `showCount` 随输入更新；有变更时 Enter 快捷保存行为不变。
