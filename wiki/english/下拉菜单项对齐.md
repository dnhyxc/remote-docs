# 下拉菜单项对齐（导出 / 标注来源）

> **文档角色**：说明英语学习**导出下拉菜单**与**标注来源下拉菜单**的菜单项统一为「撑满宽度 + 水平垂直居中」，并收窄标注来源菜单的最小宽度。

## 1. 背景与目标

导出下拉菜单（`ExportMenu`）与标注来源下拉菜单（`Annotate`）中，菜单项此前仅靠 `justify-center`（且未显式撑满宽度），文字居中不稳定、视觉上易偏左 / 错位；标注来源菜单的 `min-w-34` 对「导入 / 自动标注」这类短文案又留白偏多。

本轮把两类菜单的 `DropdownMenuItem` 统一为 **`flex w-full items-center justify-center text-center`**，并把标注来源菜单的 `min-w-34` 收窄为 **`min-w-28`**，使菜单项文字居中、宽度更贴合内容，多个菜单之间对齐一致。

## 2. 改动范围

- `apps/frontend/src/views/englishLearning/components/export/ExportMenu.tsx`（菜单项 `className`）
- `apps/frontend/src/views/englishLearning/components/classic/Annotate.tsx`（菜单内容 `className` + 两个菜单项 `className`）

## 3. 实现思路

1. `justify-center` 只控制主轴对齐，菜单项默认宽度为内容宽度；补 `w-full` 让项撑满内容区，`flex items-center` 保证图标与文字垂直居中，`text-center` 让多行文本也居中。
2. 标注来源菜单把 `min-w-34`（8.5rem）收窄为 `min-w-28`（7rem），减少「导入 / 自动标注」短文案两侧的空白，使菜单更紧凑。
3. 纯样式改动，**无跨模块数据流，略图**。

## 4. 关键代码对比与注释

### 4.1 `ExportMenu` 菜单项（`apps/frontend/src/views/englishLearning/components/export/ExportMenu.tsx`）

**对比范围**：`return (...)` 内 `visible.map` 渲染的 `DropdownMenuItem` 元素及其上下文（约 L142–L164）。

**改动前** · `apps/frontend/src/views/englishLearning/components/export/ExportMenu.tsx`（基线，约 L144）

```typescript
// 遍历可见导出项，逐项渲染菜单
{visible.map((item) => {
	// 计算当前项是否在导出中（决定禁用与 spinner）
	const busy = busyIds.has(item.id);
	// 返回单个菜单项元素
	return (
		// 旧：仅 justify-center 与 gap，未撑满宽度、未显式垂直居中
		<DropdownMenuItem
			// 稳定键：用于 React 复用与 busy 集合匹配
			key={item.id}
			// 旧样式：水平居中 + 图标间距
			className="justify-center gap-1.5"
			// 项自身禁用或整体 busy 时禁用该项
			disabled={item.disabled || busy}
			// 选中回调：先阻止默认关闭，再手动关闭并执行导出
			onSelect={(e) => {
				// 阻止默认（避免 Radix 自动关闭触发时序问题）
				e.preventDefault();
				// 手动关闭菜单
				setMenuOpen(false);
				// 执行该项导出
				runItem(item);
			}}
		>
			// busy 时渲染一个小 spinner 占位
			{busy ? (
				// 导出中指示器：小尺寸、不参与收缩
				<Spinner
					className="size-3.5 shrink-0 text-textcolor"
					aria-hidden
				/>
				// 非 busy 渲染空
			) : null}
			// 渲染业务传入的菜单项文案 / 节点
			{item.label}
		</DropdownMenuItem>
	);
})}
```

### 4.2 `Annotate` 标注来源菜单

**对比范围**：`DropdownMenu` 声明起笔到 `DropdownMenuContent` 闭合（含两个 `DropdownMenuItem`，约 L306–L343）。**摘录从 `DropdownMenu` 符号起笔，保留触发区上下文**。

**改动前** · `apps/frontend/src/views/englishLearning/components/classic/Annotate.tsx`（基线，约 L306–L343）

```typescript
// 标注来源下拉菜单：hover 展开 / 收起
<DropdownMenu open={menuOpen} onOpenChange={setMenuOpen}>
	// 触发区：文本或图标触发器
	<DropdownMenuTrigger asChild>
		// 按 variant 选择文本或图标触发
		{variant === 'text' ? textTrigger : iconTrigger}
	</DropdownMenuTrigger>
	// 菜单内容：对齐方式与最小宽度
	<DropdownMenuContent
		// 右对齐，贴近触发按钮
		align="end"
		// 与触发区垂直间距 6px
		sideOffset={6}
		// 关闭虚拟滚动，内容少无需
		scrollable={false}
		// 旧：最小宽度 8.5rem
		className="min-w-34"
		// 关闭时不自动聚焦回触发区，避免抖回
		onCloseAutoFocus={(e) => e.preventDefault()}
		// 鼠标移入保持展开
		onMouseEnter={openMenu}
		// 鼠标移出延迟收起
		onMouseLeave={scheduleCloseMenu}
		// 阻止点击冒泡，避免触发外层逻辑
		onClick={(e) => e.stopPropagation()}
	>
		// 第一项：在线自动标注 / 查看进度
		<DropdownMenuItem
			// 旧：仅水平居中
			className="justify-center"
			// 导入中禁用
			disabled={importing}
			// 选中回调
			onSelect={(e) => {
				// 阻止默认关闭
				e.preventDefault();
				// 触发起始标注
				onOnlineSelect();
			}}
		>
			// 运行中显示「查看进度」，否则显示「自动标注」
			{running
				? t('englishLearning.annotateTasks.viewProgress')
				: t('englishLearning.annotateSource.menuOnline')}
		</DropdownMenuItem>
		// 第二项：导入标注 JSON
		<DropdownMenuItem
			// 旧：仅水平居中
			className="justify-center"
			// 导入中或运行中禁用
			disabled={importing || running}
			// 选中回调
			onSelect={(e) => {
				// 阻止默认关闭
				e.preventDefault();
				// 触发导入流程
				onImportSelect();
			}}
		>
			// 显示导入菜单文案
			{t('englishLearning.annotateSource.menuImport')}
		</DropdownMenuItem>
	</DropdownMenuContent>
</DropdownMenu>
```

## 5. 兼容性与影响

- **纯样式**：仅调整 `className`，不影响导出 / 导入逻辑、`onSelect` 行为与 i18n 文案。
- **一致化**：导出菜单与标注来源菜单的菜单项对齐方式统一，视觉更整齐。
- **宽度**：标注来源菜单最小宽度收窄，长文案（如「查看进度」）按内容自适应，不会截断。
