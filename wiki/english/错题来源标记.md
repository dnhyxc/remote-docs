## 1. 背景与目标

原错题集只有「用户 + 规范化词形」唯一约束，无法区分错题来自「今日记词」还是「练习」。重置今日记词进度时，如果直接删错题，会误删练习产生的错题；如果不删，今日记词的旧错题会残留。

本篇新增**错题来源标记**：

- 错题表新增 `source` 字段，取值 `dailyMemorize`（今日记词）/ `practice`（练习）/ 空字符串（历史/未指定）。
- 批量入库时 `source` 仅写入**新建行**，已存在行不覆盖来源（保持首次入库来源）。
- 重置今日记词进度时，仅删除 `source='dailyMemorize'` 且属于记词记录词形的错题，保护练习侧错题。

## 3. 实现思路

### 3.1 关键决策

1. **source 仅写入新建行，不覆盖已有来源**：同一词形可能先在练习中错（`practice`），又在今日记词中错。保持首次入库来源，避免重置记词时误删练习错题。
2. **source 用空字符串默认值而非 nullable**：历史行默认为空串，查询 `source='dailyMemorize'` 时自然排除，无需处理 null。
3. **重置记词时按「记词记录词形 ∩ source=dailyMemorize」删错题**：双重约束确保只删今日记词产生且确实在记词记录中的错题，不误删练习侧同词形错题。
4. **source 长度限制 32**：与 report 的 source 字段同口径，预留 `dailyMemorize`/`practice` 等短标识。

### 3.2 错题来源写入与重置流程

```mermaid
flowchart TD
  A[今日记词结算<br/>保存错题] -->|source=dailyMemorize| Batch[batchAddVocabularyMistakes]
  B[练习结算<br/>保存错题] -->|source=practice 或不传| Batch

  Batch --> Exists{该词形已存在?}
  Exists -->|否| Insert[新建行<br/>写入 source]
  Exists -->|是| Update[仅更新 lastUserInput<br/>不覆盖 source]

  C[重置今日记词进度] --> Reset[resetDailyMemorizeLibraryProgress]
  Reset --> Recs[查 daily_memorize_record<br/>取所有 wordKey]
  Recs --> Del[delete mistakes<br/>where wordKey IN (...) AND source='dailyMemorize']
  Del -->|不误删| Protect[练习侧同词形错题<br/>因 source=practice 保留]
```

### 4.4 服务层：batchAddVocabularyMistakes 写 source（`english-learning.service.ts`）

**改动后** · `apps/backend/src/services/english-learning/english-learning.service.ts`（当前，L5172–L5250）

```typescript
/**
 * 批量加入错题集：新词形插入；已存在且本轮错拼不同则更新 lastUserInput；错拼相同则跳过。
 * source 仅写入新建行，不覆盖已有来源。
 */
async batchAddVocabularyMistakes(
	userId: number,
	items: VocabularyMistakeBatchItemDto[],
	source?: string,
): Promise<{ added: number; updated: number; skipped: number }> {
	// 空数组直接返回
	if (!items.length) {
		return { added: 0, updated: 0, skipped: 0 };
	}

	// source 归一化：trim + 截断 32，空则空串
	const sourceTag =
		typeof source === 'string' ? source.trim().slice(0, 32) : '';

	// 按规范化词形去重，保留最后一个
	const byKey = new Map<string, VocabularyMistakeBatchItemDto>();
	for (const item of items) {
		const wordKey = this.normalizeVocabularyFavoriteWordKey(item.word);
		if (!wordKey) continue;
		if (!byKey.has(wordKey)) {
			byKey.set(wordKey, item);
		}
	}

	const keys = [...byKey.keys()];
	if (keys.length === 0) {
		return { added: 0, updated: 0, skipped: items.length };
	}

	// 查已存在的行，只取 id/wordKey/lastUserInput
	const existing = await this.vocabMistakeRepo.find({
		where: { userId, wordKey: In(keys) },
		select: ['id', 'wordKey', 'lastUserInput'],
	});
	const existingByKey = new Map(existing.map((r) => [r.wordKey, r] as const));

	// 分离：需插入的 key（不存在）
	const toInsertKeys = keys.filter((k) => !existingByKey.has(k));
	// 需更新的列表（存在且错拼不同）
	const toUpdate: Array<{ id: string; lastUserInput: string }> = [];
	const toUpdateKeys: string[] = [];

	for (const wordKey of keys) {
		const row = existingByKey.get(wordKey);
		if (!row) continue;
		const item = byKey.get(wordKey)!;
		const nextInput = this.normalizeMistakeLastUserInput(
			item.lastUserInput,
			500,
		);
		const prevInput = (row.lastUserInput ?? '').trim();
		// 错拼不同才更新 lastUserInput，相同则跳过
		if (nextInput !== prevInput) {
			toUpdate.push({ id: row.id, lastUserInput: nextInput });
			toUpdateKeys.push(wordKey);
		}
	}

	// 插入新建行：写入 sourceTag（来源仅此处写入）
	if (toInsertKeys.length > 0) {
		const rows = toInsertKeys.map((wordKey) => {
			const item = byKey.get(wordKey)!;
			return this.vocabMistakeRepo.create({
				userId,
				wordKey,
				word: item.word.trim(),
				ipa: typeof item.ipa === 'string' ? item.ipa : '',
				pos: typeof item.pos === 'string' ? item.pos.trim().slice(0, 32) : '',
				segmentation:
					typeof item.segmentation === 'string'
						? item.segmentation.trim().slice(0, 500)
						: '',
				translationZh: item.translationZh ?? '',
				example: item.example ?? '',
				// 来源写入新建行
				source: sourceTag,
				lastUserInput: this.normalizeMistakeLastUserInput(
					item.lastUserInput,
					500,
				),
			});
		});
		await this.vocabMistakeRepo.save(rows);
	}

	// 更新已存在行：仅更新 lastUserInput，不动 source
	if (toUpdate.length > 0) {
		await this.vocabMistakeRepo.save(
			toUpdate.map(({ id, lastUserInput }) =>
				this.vocabMistakeRepo.create({ id, lastUserInput }),
			),
		);
	}

	const skipped = keys.length - toInsertKeys.length - toUpdate.length;
	// 标记入库的错题为待复习
	await this.markMistakesDueForReview(userId, 'vocab', [
		...toInsertKeys,
		...toUpdateKeys,
	]);

	return {
		added: toInsertKeys.length,
		updated: toUpdate.length,
		skipped,
	};
}
```

**变更摘要**：`source` 仅在 `toInsertKeys` 新建行时写入 `sourceTag`；更新分支只改 `lastUserInput`，不覆盖已有 `source`。

### 4.5 服务层：resetDailyMemorizeLibraryProgress 按 source 删错题（`english-learning.service.ts`）

```typescript
/**
 * 重置词汇库记词进度：清空记词记录与对应复习状态；
 * 错题集仅移除来源为今日记词（source=dailyMemorize）的条目。
 */
async resetDailyMemorizeLibraryProgress(userId: number): Promise<{
	recordsRemoved: number;
	reviewStatesRemoved: number;
	mistakesRemoved: number;
}> {
	// 查所有记词记录，取 wordKey 去重
	const rows = await this.dailyMemorizeRecordRepo.find({
		where: { userId },
		select: ['wordKey'],
	});
	const wordKeys = [
		...new Set(rows.map((r) => r.wordKey.trim()).filter(Boolean)),
	];

	// 删除所有记词记录
	const recordsResult = await this.dailyMemorizeRecordRepo.delete({
		userId,
	});

	let reviewStatesRemoved = 0;
	let mistakesRemoved = 0;
	if (wordKeys.length > 0) {
		// 删除这些词形的复习状态
		const rsResult = await this.practiceReviewStateRepo.delete({
			userId,
			contentKind: 'vocab',
			itemKey: In(wordKeys),
		});
		reviewStatesRemoved = rsResult.affected ?? 0;
		// 仅删除 source=dailyMemorize 的错题，保护练习侧错题
		const mistakeResult = await this.vocabMistakeRepo.delete({
			userId,
			wordKey: In(wordKeys),
			source: 'dailyMemorize',
		});
		mistakesRemoved = mistakeResult.affected ?? 0;
	}

	return {
		recordsRemoved: recordsResult.affected ?? 0,
		reviewStatesRemoved,
		mistakesRemoved,
	};
}
```

**变更摘要**：删除错题时加 `source: 'dailyMemorize'` 条件，只清今日记词产生的错题；练习侧同词形错题（`source='practice'` 或空串）保留。

## 5. 兼容性与影响

- **历史数据**：`source` 列默认空串，历史行自动为 `''`；重置记词时只删 `source='dailyMemorize'`，历史错题不受影响。
- **来源保护**：同一词形先在练习中错（`practice`），后在今日记词中错，更新分支不覆盖 source，仍为 `practice`；重置记词时不误删。
- **破坏性**：无；纯增量字段。

## 6. 建议回归

1. **今日记词错题入库**：今日记词答错后保存错题，数据库 `english_vocabulary_mistake.source` 应为 `dailyMemorize`。
2. **练习错题入库**：练习答错后保存错题，`source` 应为 `practice`（或空串，取决于是否传 source）。
3. **来源不覆盖**：同一词形先在练习中错（source=practice），再在今日记词中错，`source` 仍为 `practice`。
4. **重置记词进度**：调用 `resetDailyMemorizeLibraryProgress`，仅 `source='dailyMemorize'` 的错题被删除；练习侧错题保留。
5. **空 source 兼容**：不传 source 时，新建行 `source=''`，行为与改动前一致。
