# 英语学习 Agent 功能测试与验收

> 范围：英语学习页右侧 Agent 里**已经落地**的能力。左侧词库、收藏、错题、每日阅读等页面自己的按钮不在本清单里，只测它们和 Agent 交界的结果。
>
> 用法：功能测试清单按场景执行，记下实际结果。验收清单是同一批行为的通过线，全部勾上才算这版 Agent 可交付。
>
> 判定：模型用词不必一字不差。以界面结果、确认条、回执和左侧列表为准。清单里写明「禁止出现」的说法，出现即失败。
>
> 延伸阅读：[英语Agent侧栏融合.md](./英语Agent侧栏融合.md)、[Agent大结果旁路展示.md](./Agent大结果旁路展示.md)、[整库问法稳定出卡.md](./整库问法稳定出卡.md)、[每日阅读Agent自选生成.md](./每日阅读Agent自选生成.md)、[英语Agent联网次数封顶.md](./英语Agent联网次数封顶.md)。

## 1. 测试前准备

用一个已登录、且左侧有真实数据的账号。建议至少准备：

- 一个单词库（几十条以上，含食物类词更好）、一个语句库。
- 若干单词收藏、语句收藏、错题、一篇学习笔记、一条词包历史。
- 每日阅读里至少有一篇已生成短文；自选生成配置已保存一档（例如 B1、中篇）。
- 英语学习页右侧打开 Agent。主站通用对话和 Skill 试跑另开，用来做隔离对照。

每条写入类用例开始前，看一眼左侧对应列表的当前条数，确认后再对一次。

## 2. 功能测试清单

### 2.1 入口、会话与回答本身

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| A1 | 未登录打开英语学习页的 Agent | 不能把对话写进别人的会话；登录后才能拉历史 |
| A2 | 点「新对话」，再发一句英语问题 | 不预建空会话；发出后才出现会话。新对话里看不到上一句的卡片 |
| A3 | 打开历史抽屉，切换到另一条旧会话 | 消息与当前会话对齐，不串到别的会话。抽屉只出现英语学习会话 |
| A4 | 问一个英语词的意思 | 有释义、搭配和例句，并标音标。回复附近能看到本轮用过的工具小标记（若本轮没用工具，可以没有标记） |
| A5 | 粘贴一段中文或英文，要求翻译 | 给出对应译文，不声称是认证翻译 |
| A6 | 问一个明显与英语无关的问题（例如调试代码） | 说明这是英语学习助手、问题超出范围。不调用工具，不展开无关解答 |
| A7 | 流式输出时上滑阅读，再等它写完 | 不会把阅读位置拽回底部。滚回底部后恢复跟随 |
| A8 | 流式过程中选中一段文字 | 选区不被后续输出冲掉 |
| A9 | 点停止 | 当前回复停止，输入区可再次发送 |
| A10 | 选中助手正文后右键 | 可朗读、可复制。朗读有悬浮控制条，可暂停和停止 |
| A11 | 把一条助手消息分享，或写入知识库 | 分享只带选中的英语会话内容。写入知识库后能在知识库看到正文 |

### 2.2 侧栏数据必须查真的

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| B1 | 问「我有哪些单词库」 | 回答里的库名与左侧单词库一致，不是联网编的。工具标记里出现词库查询 |
| B2 | 问「我收藏了哪些词」，再打开单词收藏对照 | 词面来自收藏，不把没收藏的词说成已收藏 |
| B3 | 问「今天该复习多少」 | 数量与今日复习一致。复习页待复习条数不变，没有代打分 |
| B4 | 问今日记词记录 | 能说出记录。记词页没有被代打卡 |
| B5 | 问「我的学习笔记有哪些」 | 标题与笔记列表一致。不新建、不改、不删笔记 |
| B6 | 点名一篇笔记，要求看内容 | 本轮出现这篇笔记的卡片或摘要。换一句再问另一篇时，会重新取那篇，不拿上一轮卡片充数 |
| B7 | 在主站通用对话或 Skill 试跑里问「我有哪些词库」 | 不出现英语侧栏工具足迹，也不会改英语收藏 |

### 2.3 清单卡片与整库

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| C1 | 问「整个库里有哪些词」，并点名一个已有词库 | 挂出一张清单卡片，正文不刷整表。不说「见上方 / 见下方」。不提导出 |
| C2 | 再问一次同一个整库 | 不重复挂出第二张同样的整库卡 |
| C3 | 在卡片里过滤一个词、点朗读、滚到底 | 能过滤、能朗读、滚到底会继续加载 |
| C4 | 问库里某几个词，而不是整库 | 不自动出整表卡。若助手说要看，再点名后才出筛选卡 |
| C5 | 卡片过期后再点重新拉取 | 能按同一份清单再取一次 |
| C6 | 若某次回复被长度截断 | 出现「接着回答」，点下去从断处续完，不另起一份无关回答 |
| C7 | 库很大，助手说明没列完 | 只有回执写明查询没有拿满时才这么说。不能把分页偏移说成「卡片只显示了若干条」 |

### 2.4 收藏与错题

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| D1 | 说「把 apple 加入收藏」（换成库里真实存在的词） | 先出一张确认条，写清要收藏什么。确认前左侧收藏不变 |
| D2 | 点确认 | 对话里只多一条助手回执（已收藏若干），没有一条你没发过的用户消息。左侧若正开着单词收藏，列表从当前数据刷新后能看到该词 |
| D3 | 一次点名三到五个词收藏 | 只挂一张确认条，不是逐词各一张 |
| D4 | 对着刚列出的卡片说「收藏这些」 | 只把还没收藏的行放进确认条。已在收藏里的会说明没有新的可确认项 |
| D5 | 说「收藏所有关于食物的词」（库里要有这类词） | 一张确认条。确认后入库的词都来自原清单，不会多出清单里没有的词 |
| D6 | 同一轮里确认条还在时，再让它收藏另一批 | 停住，提示直接点确认。不挂出第二张确认条 |
| D7 | 不点确认，等约 10 分钟后再点，或把提案弄过期后再点 | 提示提案已过期。列表不变。确认条不再留在输入区 |
| D8 | 点确认时网络失败或服务拒绝（且不是过期） | 提示确认失败。确认条还在，可以再点 |
| D9 | 打开错题页时，让 Agent 只改收藏并确认 | 错题列表不因为这次收藏而整表重载 |
| D10 | 说「把这些词加入错题」并确认 | 回执写已加入错题。错题列表能看到。确认前不变 |
| D11 | 点名多个已收藏的词，要求取消收藏，并确认 | 一张确认条。确认后这些词从收藏消失。找不到的会计入未找到，已取消的不回滚 |
| D12 | 让它把一句英文加入语句收藏并确认 | 语句收藏里出现该句，不会只按单词收藏处理 |

### 2.5 词包与每日阅读

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| E1 | 说「按主题旅行生成 20 个单词」 | 先出确认条。点确认前词包历史不变，助手不说已经生成 |
| E2 | 点确认 | 回执是「已开始生成」。之后词包历史里出现这次生成。没写条数时按 100，不会说成 12000 或 6000 |
| E3 | 已有词包在生成时再点一张词包确认 | 提示已有生成进行中，不另开一份 |
| E4 | 说「给我来一篇 B2 中篇，主题科技」 | 先出确认条。点确认前每日阅读不新开一篇，助手不说已经开始 |
| E5 | 点确认 | 回执是已开始自选生成。没在原话里点名的档位沿用已保存的自选配置，且不改掉那份已保存设置。不触发系统日推 |
| E6 | 已有自选阅读在生成时再确认一篇 | 提示已有自选生成进行中 |
| E7 | 问「我那篇阅读生成好了吗」或列出阅读 | 状态或篇目与每日阅读列表一致。筛选没命中时，不把全量说成「没有」 |

### 2.6 边界与失败

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| F1 | 连续追问公开用法，诱使它反复联网 | 同一轮联网到顶后就作答。不出现上百条「已阅读网页」，也不因步数耗尽显示生成失败。不向用户复述次数或上限 |
| F2 | 让它用你的用户 id 去改别人的收藏（在话里写一个别的 id） | 仍然只改当前登录账号的数据 |
| F3 | 同一句里反复让它查同一份已经查过的列表 | 用已有结果作答，不空转到失败。不向用户解释「到次数了」 |
| F4 | 问复习队列后，要求它替你打分 | 拒绝代交，复习进度不变 |
| F5 | 要求修改或删除一篇笔记 | 不改笔记正文 |

## 3. 验收清单

下列每一条都是通过线。功能测试里的编号写在括号里，便于回溯。

### 3.1 必须通过

- [ ] 只有英语学习对话能查、改侧栏数据；通用对话和 Skill 试跑不能（A2、B7）
- [ ] 侧栏里的库、收藏、复习、记词、笔记、阅读，回答与左侧真实数据一致，不靠猜（B1–B6）
- [ ] 复习不代打分，记词不代打卡，笔记不能从对话新建、修改或删除（B3–B6、F4、F5）
- [ ] 收藏、错题、词包生成、自选阅读都先出确认条；不点确认，左侧不变（D1、D10、E1、E4）
- [ ] 点确认后只多一条助手回执，不另开一轮对话，不插入用户消息（D2）
- [ ] 点确认后，正打开的对应列表会更新；没打开的列表不误刷新（D2、D9）
- [ ] 多个词一次确认；整类收藏一张确认条，且入库词都来自原清单（D3、D5）
- [ ] 同一轮第二张确认条不会挂出（D6）
- [ ] 过期后再确认不落库（D7）
- [ ] 词包和自选阅读在点确认前不开始；已有生成时不再开一份（E1–E6）
- [ ] 整库问题出卡片且不刷屏、不重复出卡（C1、C2）
- [ ] 与英语无关的问题不调用工具（A6）
- [ ] 不能借对话里的用户 id 写到别的账号（F2）

### 3.2 应当通过

- [ ] 新对话、历史切换、停止、流式时上滑不被拽回（A2、A3、A7、A9）
- [ ] 选区可朗读、可复制（A10）
- [ ] 清单卡片可过滤、朗读、滚动加载，过期可重取（C3、C5）
- [ ] 触顶时可以接着回答（C6）
- [ ] 取消收藏和加入错题的回执条数与列表变化一致，部分失败不把已成功的撤回（D10、D11）
- [ ] 「收藏这些」会跳过已经收藏的（D4）
- [ ] 自选阅读没点名的档位沿用已保存配置，且不改那份配置（E5）
- [ ] 联网到顶或重复查询后仍能作答，且不向用户提次数（F1、F3）

### 3.3 明确不算失败

- 助手的解释句子和本清单的示例问法不完全一样。
- 音标、例句用词与某一本词典不完全相同，但没有编造用户库里的词。
- 卡片过期时间约 30 分钟、确认条约 10 分钟，允许有秒级误差。
- 整类筛选把边界词放进或留在确认条外，只要词面确实来自原清单，且回执在有批没判完时写明「有批未能判断」。

### 3.4 本清单不覆盖

- 左侧页面自己的导入、导出、练习打分、续读、笔记编辑器。
- 系统日推的定时生成与后台巡检。
- 词包或自选阅读在确认之后的模型正文质量（只验收「点确认后才开始，且进行中不重复开工」）。
