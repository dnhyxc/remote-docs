# 学习笔记保存时标题为空自动聚焦标题输入框

## 1. 背景与目标

学习笔记保存时后端会校验标题非空，标题为空时保存失败并 Toast 提示。但此前保存失败后光标停留在正文，用户需要手动点击标题输入框才能补填标题，体验不流畅。

本轮改动新增 `focusTitle` 回调，在 `onSave` 保存失败且标题为空时自动滚动到顶部并聚焦标题 `<input>`，引导用户立即补填标题。

**延伸阅读**：[学习笔记CRUD.md](./学习笔记CRUD.md)（CRUD 与保存流程）、[学习笔记富文本编辑.md](../ideas/notes/学习笔记富文本编辑.md)（富文本编辑器总览）、[富文本编辑器边缘导航.md](./富文本编辑器边缘导航.md)（同轮编辑器导航修复）

## 2. 改动范围

- `apps/remote-plugins/src/views/learning-notes/index.tsx`：新增 `focusTitle` `useCallback`；`onSave` 两条保存路径（长文 `pagedSave` 与普通 `editor`）均提取 `title` 变量，保存失败时若 `dirty && !title` 则调用 `focusTitle()`。

## 3. 实现思路

1. **`focusTitle` 回调**：从 `editorRef.current` 取编辑器实例，通过 `editor.view.dom.closest('.rich-editor')` 找到编辑器根容器，再向下查找 `[data-slot="scroll-area-viewport"]` 滚动视口置顶、`.rich-editor-note-title input` 标题输入框并 `focus()`。
2. **`onSave` 两路径统一处理**：长文路径（`pagedSaveRef.current`）和普通路径（`editorRef.current`）都先把 `title` 提取为局部变量，传给 `store.saveNote`，保存返回 `false` 时检查 `dirty && !title.trim()`（长文）或 `dirty && !title`（普通）后调用 `focusTitle()`。
3. **仅在 dirty 时触发**：若笔记未修改（`!dirty`），即使标题为空也不自动聚焦，避免首次加载空笔记时抢焦点。
4. **`useCallback` 依赖**：`focusTitle` 无依赖（只用 ref 和 DOM 查询）；`onSave` 依赖新增 `focusTitle`。

## 4. 关键代码对比与注释

### 4.1 `focusTitle`（`apps/remote-plugins/src/views/learning-notes/index.tsx`）

**对比范围**：`const focusTitle = useCallback(...)` 全定义。本次**纯新增**，无改动前版本。

**改动前** · `apps/remote-plugins/src/views/learning-notes/index.tsx`（基线）

> 本次纯新增，基线中不存在该回调。

**改动后** · `apps/remote-plugins/src/views/learning-notes/index.tsx`（当前，约 L112–L125）

```typescript
// 新增回调：保存失败且标题为空时，滚动到顶并聚焦标题输入框
const focusTitle = useCallback(() => {
	// 从 ref 取编辑器实例
	const editor = editorRef.current;
	// 编辑器不存在或已销毁时直接返回
	if (!editor || editor.isDestroyed) return;
	// 从编辑器 DOM 向上查找 .rich-editor 根容器
	const root = editor.view.dom.closest('.rich-editor');
	// 找不到根容器时返回
	if (!root) return;
	// 在根容器内查找 ScrollArea 滚动视口
	const vp = root.querySelector(
		'[data-slot="scroll-area-viewport"]',
	) as HTMLElement | null;
	// 视口存在时滚动到顶部，让标题可见
	if (vp) vp.scrollTop = 0;
	// 在根容器内查找标题 input（TitleView 渲染的 .rich-editor-note-title input）
	const input = root.querySelector(
		'.rich-editor-note-title input',
	) as HTMLInputElement | null;
	// 聚焦标题输入框（可选链避免 null 报错）
	input?.focus();
// 空依赖数组：只用 ref 和 DOM 查询，不依赖任何响应式变量
}, []);
```

**变更摘要**：新增 `focusTitle` 回调，查找编辑器根容器 → 滚动视口置顶 → 聚焦标题 `<input>`。

### 4.2 `onSave`（`apps/remote-plugins/src/views/learning-notes/index.tsx`）

**对比范围**：`const onSave = useCallback(async () => {...}, [...])` 全定义（含长文 `paged` 分支与普通 `editor` 分支）。

**改动前** · `apps/remote-plugins/src/views/learning-notes/index.tsx`（基线，约 L112–L131）

```typescript
// 保存回调：支持长文 paged 与普通 editor 两条路径
const onSave = useCallback(async () => {
	// 长文路径：pagedSaveRef 存在时走分块保存
	const paged = pagedSaveRef.current;
	if (paged) {
		// 直接调用 store.saveNote，title 内联在参数中
		const ok = await store.saveNote({
			// 标题从 paged.getTitle() 取
			title: paged.getTitle(),
			// 正文从 paged.getText() 取
			text: paged.getText(),
			// HTML 从 paged.getHTML() 取
			html: paged.getHTML(),
			// dirty 标记传入
			dirty,
		});
		// 保存成功时清除脏标记
		if (ok) markClean();
		// 保存失败时无额外处理（旧版）
		return;
	}
	// 普通路径：从 editorRef 取编辑器
	const editor = editorRef.current;
	// 编辑器不存在或已销毁时返回
	if (!editor || editor.isDestroyed) return;
	// 直接调用 store.saveNote，title 内联在参数中
	const ok = await store.saveNote({
		// 标题从 getDocTitleText 取并 trim
		title: getDocTitleText(editor.state.doc).trim(),
		// 正文从 editor.getText 取并 trim
		text: editor.getText({ blockSeparator: '\n\n' }).trim(),
		// HTML 从 editor.getHTML 取
		html: editor.getHTML(),
		// dirty 标记传入
		dirty,
	});
	// 保存成功时清除脏标记
	if (ok) markClean();
	// 保存失败时无额外处理（旧版）
// 依赖数组：markClean / store / dirty / t
}, [markClean, store, dirty, t]);
```

**改动后** · `apps/remote-plugins/src/views/learning-notes/index.tsx`（当前，约 L127–L152）

```typescript
// 保存回调：支持长文 paged 与普通 editor 两条路径
const onSave = useCallback(async () => {
	// 长文路径：pagedSaveRef 存在时走分块保存
	const paged = pagedSaveRef.current;
	if (paged) {
		// 先提取 title 为局部变量，供后续空值检查
		const title = paged.getTitle();
		// 调用 store.saveNote
		const ok = await store.saveNote({
			// 标题传入
			title,
			// 正文从 paged.getText() 取
			text: paged.getText(),
			// HTML 从 paged.getHTML() 取
			html: paged.getHTML(),
			// dirty 标记传入
			dirty,
		});
		// 保存成功时清除脏标记
		if (ok) markClean();
		// 保存失败 + 有修改 + 标题为空 → 聚焦标题输入框
		else if (dirty && !title.trim()) focusTitle();
		// 长文路径结束
		return;
	}
	// 普通路径：从 editorRef 取编辑器
	const editor = editorRef.current;
	// 编辑器不存在或已销毁时返回
	if (!editor || editor.isDestroyed) return;
	// 先提取 title 为局部变量，供后续空值检查
	const title = getDocTitleText(editor.state.doc).trim();
	// 调用 store.saveNote
	const ok = await store.saveNote({
		// 标题传入
		title,
		// 正文从 editor.getText 取并 trim
		text: editor.getText({ blockSeparator: '\n\n' }).trim(),
		// HTML 从 editor.getHTML 取
		html: editor.getHTML(),
		// dirty 标记传入
		dirty,
	});
	// 保存成功时清除脏标记
	if (ok) markClean();
	// 保存失败 + 有修改 + 标题为空 → 聚焦标题输入框
	else if (dirty && !title) focusTitle();
// 依赖数组：新增 focusTitle
}, [focusTitle, markClean, store, dirty, t]);
```

**变更摘要**：① 两条保存路径都把 `title` 提取为局部变量；② 保存失败（`!ok`）且 `dirty && !title` 时调用 `focusTitle()` 聚焦标题输入框；③ `useCallback` 依赖数组新增 `focusTitle`。

## 5. 兼容性与影响

- **兼容性**：仅修改 `onSave` 回调行为，不影响编辑、预览、列表加载等流程。
- **行为变化**：保存失败且标题为空时，编辑器自动滚动到顶部并聚焦标题输入框（旧版无此行为）。未修改（`!dirty`）的笔记即使标题为空也不触发。
- **长文 vs 普通路径**：长文路径用 `!title.trim()`（因 `paged.getTitle()` 可能返回空白字符串），普通路径用 `!title`（`getDocTitleText` 已 `trim`）。
- **风险与回归**：建议测试 ① 新建笔记不填标题直接保存 → 应聚焦标题；② 有标题正常保存 → 不应触发聚焦；③ 未修改的空标题笔记按 Cmd+S → 不应触发聚焦；④ 长文编辑器空标题保存 → 滚动到顶并聚焦。
