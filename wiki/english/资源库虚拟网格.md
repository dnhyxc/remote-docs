# 资源库虚拟网格：行级 Virtuoso + 自适应列数

> **路径已收口**：本文引用的 `library/hooks/useLibraryWordsList.ts` 已在本轮重命名为 `hooks/useEnglishLearningList.ts`。完整变更见 [英语学习列表模块收口.md](./英语学习列表模块收口.md)。

> 解决英语学习资源库（单词库 / 经典语句库）右侧词条列表在**千级词条**场景下首屏渲染慢、滚动卡顿的问题。  
> 方案：外层 `react-virtuoso` 做**行级虚拟滚动**（按行挂载，每行内用 CSS Grid 平铺 N 列），列数由视口宽度实时计算（单词库自适应 1–N 列，经典句库 1/2 两档）；入场支持按 `initialScrollItemIndex` 定位续读。  
> 延伸阅读：[资源库词条续读.md](./资源库词条续读.md)（跨会话进度）、[资源库列表单向虚拟滚动.md](./资源库列表单向虚拟滚动.md)（Hook 端配合此组件的改造）。

若与仓库最新源码不一致，**以源码为准**。

---

## 1. 背景与目标

### 1.1 用户视角

同一资源库有数千条词条时，用原生 `<div className="grid">` 把全部卡片**一次性渲染进 DOM**，会出现：

1. 进入库时首屏需要等上千个卡片全部挂载才能交互（3000 词约 2–4s 白屏）；
2. 滚动过程中 DOM 节点过多，浏览器布局/绘制压力大，中低端设备掉帧；
3. 配合双向分页 / 续读时，prepend 会把所有节点重新布局，视觉卡顿。

**改后**：任何时刻只挂载可视区 + 前后缓冲的「行」（每行内包含 N 张卡片），首屏与滚动性能基本与词条总数解耦。

### 1.2 设计约束

| 约束 | 说明 |
| --- | --- |
| 不等高卡片 | 单词卡片和经典句卡片高度不固定，不能用定高虚拟列表 |
| 行级粒度 | 以「行」为 Virtuoso 的 Item（行内 CSS Grid 列），避免单卡挂载导致列错位 |
| 自适应列数 | 单词库：按视口宽计算 1–N 列（每列最小 256px）；经典句库：<448px 单列，≥448px 双列 |
| 续读定位 | 传入 `initialScrollItemIndex`（词条级索引），内部换算成行索引 |
| 与 ScrollArea 集成 | 使用 Virtuoso 的 `customScrollParent`，不接管滚动容器 |
| 宽过度量 | overscan 400px + increaseViewportBy 400px，避免快速滚动空白 |

## 3. 实现思路

### 3.1 两层结构：Virtuoso 行 + 行内 CSS Grid

把「一维虚拟滚动」与「二维网格布局」解耦：

```
视口（ScrollArea viewport）
 └── Virtuoso（行级，customScrollParent = 视口）
      ├── Row 0
      │    └── CSS Grid（cols=2/3/4...）
      │         ├── Card 0 ├── Card 1 ├── Card 2 ...
      ├── Row 1
      │    └── CSS Grid（同一列数）
      │         ├── Card N ├── Card N+1 ...
```

- 外层 Virtuoso：只负责「哪些行在可视区」，把行作为 data item 传入。
- 内层每行一个 CSS Grid：列数由 `useLibraryGridColumns` 实时计算，`chunkRows` 函数把 items 按当前列数切分为行。
- 行级 key：拼接该行所有卡片的 `getItemKey`，确保增删时精确比对。

### 3.2 词条索引 ↔ 行索引换算（续读定位）

Virtuoso 只接受「行索引」作为 `initialTopMostItemIndex`，而续读数据是词条级的：

```
initialScrollItemIndex = 253（第 253 条词条）
columns = 3
→ initialTopMostItemIndex.index = floor(253 / 3) = 84（第 84 行）
→ align: 'start'（让该行顶对齐视口）
```

### 3.3 列数计算模式

单词库 (`vocab`) 与经典句库 (`classic`) 使用不同策略：

| mode | 策略 | 阈值 |
| --- | --- | --- |
| `vocab` | `floor((width + 16) / (256 + 16))`，每列最小 256px，列间距 16px | 动态，视口越宽列数越多 |
| `classic` | 两档：<448px → 1 列；≥448px → 2 列 | 与 Tailwind `@min-[28rem]:grid-cols-2` 对齐（28rem = 448px） |

列数变化时 `chunkRows` 会重新分块，Virtuoso 按新行 key 重新挂载。

### 3.4 首帧 ready 信号：双 rAF

Virtuoso 完成首帧绘制后需要通知父级，以收起续读场景下的蒙层 Loading（避免从缓存恢复或预取数据时先看到空列表再闪内容）：

```
requestAnimationFrame (第 1 帧：Virtuoso 把行塞到 DOM)
  → requestAnimationFrame (第 2 帧：浏览器完成布局/绘制)
     → 调用 onReady()
```

用 `cancelled` 开关 + effect cleanup 保证组件卸载时不触发过期回调。

### 4.1 `useLibraryGridColumns` Hook（新建，纯新增）

**来源**：`apps/frontend/src/views/englishLearning/library/hooks/useLibraryGridColumns.ts`（当前，约 L1–L43）

```typescript
// 引入 React 的 RefObject 引用类型（用于取视口 DOM）
import { type RefObject, useEffect, useState } from 'react';

// 列数模式：vocab=单词库（自适应多列），classic=经典句库（1/2 两档）
export type LibraryGridColumnMode = 'vocab' | 'classic';

// 单词库每列最小宽度（像素）：保证卡片在窄屏下不会被挤扁
const VOCAB_COL_MIN_PX = 256;
// 单词库列与列之间的间距（像素）：与 Tailwind gap-4 一致（1rem = 16px）
const VOCAB_GAP_PX = 16;
// 经典句库双列阈值：视口宽 ≥ 448px 时用 2 列；与 Tailwind @min-[28rem] 一致
const CLASSIC_TWO_COL_MIN_PX = 448;

// 自定义 Hook：根据视口宽度 + 模式，计算当前应该显示几列
export function useLibraryGridColumns(
	// 视口容器的 ref（ScrollArea 的 viewport，或外层 div）
	viewportRef: RefObject<HTMLDivElement | null>,
	// 列数计算模式
	mode: LibraryGridColumnMode,
) {
	// 列数 state：默认 1 列，等视口就绪后立即 update() 覆盖
	const [columns, setColumns] = useState(1);

	// 副作用：挂载时初始化 + 视口尺寸变化时重算；仅 mode / viewportRef 变化时重跑
	useEffect(() => {
		// 拿到视口 DOM
		const el = viewportRef.current;
		// 拿不到（SSR / ref 尚未挂载）就跳过
		if (!el) return;

		// 列数更新函数：读取 clientWidth 后按模式计算
		const update = () => {
			// 视口当前宽度（不含滚动条的内容宽）
			const width = el.clientWidth;
			if (mode === 'classic') {
				// 经典句库：只有 1 列 / 2 列 两档，与原有 Tailwind 断点对齐
				setColumns(width >= CLASSIC_TWO_COL_MIN_PX ? 2 : 1);
				// 经典模式直接返回，不走下面 vocab 的自适应公式
				return;
			}
			// 单词库自适应：每列占 (256 + 16)px；用 (宽+间隙) / (列宽+间隙)，避免首列重复减间隙
			setColumns(
				Math.max(
					// 至少 1 列（窄屏下不能算成 0）
					1,
					Math.floor(
						(width + VOCAB_GAP_PX) / (VOCAB_COL_MIN_PX + VOCAB_GAP_PX),
					),
				),
			);
		};

		// 立即执行一次：保证首帧就是正确的列数，避免先 1 列再跳多列
		update();
		// 用 ResizeObserver 监听视口尺寸变化（比 window.resize 更精准，只盯这个容器）
		const ro = new ResizeObserver(update);
		// 订阅视口元素
		ro.observe(el);
		// 清理：组件卸载 / 依赖变化时断开观察，避免内存泄漏
		return () => ro.disconnect();
	}, [mode, viewportRef]);

	// 返回计算好的列数，给 chunkRows + 行内 CSS Grid 用
	return columns;
}
```

### 4.2 `LibraryVirtuosoGrid` 组件（新建，纯新增）

**来源**：`apps/frontend/src/views/englishLearning/library/components/LibraryVirtuosoGrid.tsx`（当前，约 L1–L168）

```typescript
/**
 * 资源库虚拟网格：按行 Virtuoso + 行内 CSS Grid，支持不等高卡片。
 */

// 引入通用加载动画
import { Spinner } from '@ui/index';
// 引入 React 类型与 Hook
import {
	type ReactNode,
	type RefObject,
	useEffect,
	useMemo,
	useRef,
	useState,
} from 'react';
// 引入 react-virtuoso：行级虚拟滚动组件
import { Virtuoso } from 'react-virtuoso';
// 引入 cn 工具：合并 className
import { cn } from '@/lib/utils';
// 引入列数 Hook 与类型（同目录下）
import {
	type LibraryGridColumnMode,
	useLibraryGridColumns,
} from '../hooks/useLibraryGridColumns';

// 加载更多占位行：复用给 vocab / classic 两个面板（比在外面写重复 JSX 更短）
export function LibraryListLoadMoreRow({ label }: { label: string }) {
	return (
		// 外层：水平居中、垂直居中、灰色文字、小字号
		<div className="text-textcolor/50 flex items-center justify-center gap-1.5 py-4 text-xs">
			{/* Spinner 尺寸与文字匹配，aria-hidden 给读屏软件忽略 */}
			<Spinner className="size-3.5 text-textcolor/50" aria-hidden />
			{/* 文案：通常为 t('common.loadingMore') */}
			{label}
		</div>
	);
}

// 组件 Props 泛型：TItem 是单条词条的类型（单词/经典句）
export type LibraryVirtuosoGridProps<T> = {
	// 当前窗口已加载的所有词条数组
	items: T[];
	// ScrollArea 视口 ref：作为 Virtuoso 的自定义滚动父容器
	viewportRef: RefObject<HTMLDivElement | null>;
	// 列数模式：决定列数计算策略
	columnMode: LibraryGridColumnMode;
	// 入场时要滚动到的词条索引（跨会话续读用；内部会换算成行索引）
	initialScrollItemIndex?: number;
	// 行与行的间距 className：默认 gap-4（16px）
	rowClassName?: string;
	// 最外层 Virtuoso className
	className?: string;
	// 每张卡片外层的 className（经典句可能需要加 padding）
	itemClassName?: string;
	// 为单个词条生成稳定 key：用于 React diff + Virtuoso computeItemKey
	getItemKey: (item: T, dataIndex: number) => string;
	// 渲染单张卡片：由调用方传入（单词库 vs 经典句库样式不同）
	itemContent: (item: T, dataIndex: number) => ReactNode;
	// Virtuoso 触底回调：触发下一页加载
	onEndReached: () => void;
	// 首帧绘制完成回调：收起续读蒙层 Loading
	onReady?: () => void;
};

// 内部行结构：Virtuoso 的 data 是行，每行包含多个词条
type LibraryGridRow<T> = {
	// 行 key：拼接该行所有卡片 key
	key: string;
	// 该行的词条切片
	items: T[];
	// 该行第 1 条的全局索引（dataIndex），用于换算卡片级索引
	startIndex: number;
};

// 辅助函数：把一维 items 数组按当前列数切为二维行数组
function chunkRows<T>(
	items: T[],
	columns: number,
	getItemKey: (item: T, dataIndex: number) => string,
): LibraryGridRow<T>[] {
	// 非法列数或无词条：返回空数组
	if (columns < 1 || items.length === 0) return [];
	// 结果行数组
	const rows: LibraryGridRow<T>[] = [];
	// 从 0 开始，每次跳 columns 步长
	for (let i = 0; i < items.length; i += columns) {
		// 切出该行的词条切片
		const slice = items.slice(i, i + columns);
		// 记录该行的起始 dataIndex
		const startIndex = i;
		// 行 key：拼接该行所有卡片的 key + 列内位置，保证增删时精确
		const key = slice
			.map((item, col) => getItemKey(item, startIndex + col))
			.join('|');
		// 推入结果数组
		rows.push({ key, items: slice, startIndex });
	}
	return rows;
}

// 主组件：泛型 T = 词条类型
export function LibraryVirtuosoGrid<T>({
	items,
	viewportRef,
	columnMode,
	initialScrollItemIndex = 0,
	rowClassName = 'gap-4',
	className,
	itemClassName,
	getItemKey,
	itemContent,
	onEndReached,
	onReady,
}: LibraryVirtuosoGridProps<T>) {
	// 当前视口 DOM（Virtuoso 需要非 null 才能渲染；先 undefined，等 effect 赋值）
	const [scrollParent, setScrollParent] = useState<HTMLElement | null>(null);
	// 计算当前列数（视口宽 + 模式）
	const columns = useLibraryGridColumns(viewportRef, columnMode);
	// onReady ref：让双 rAF 回调始终取到最新版本（避免 props.onReady 变化时仍执旧值）
	const onReadyRef = useRef(onReady);
	// 每次渲染同步 ref
	onReadyRef.current = onReady;

	// 把 viewportRef.current 赋给 scrollParent state：Virtuoso 需要稳定的 DOM 引用
	useEffect(() => {
		setScrollParent(viewportRef.current);
	}, [viewportRef]);

	// 行数组：依赖 items / columns / getItemKey，任意一项变化重新分块
	const rows = useMemo(
		() => chunkRows(items, columns, getItemKey),
		[items, columns, getItemKey],
	);

	// 首帧 ready：等 Virtuoso 渲染完行后，双 rAF 再回调 onReady
	useEffect(() => {
		// 视口或行数组为空时不触发（没内容可绘制）
		if (!scrollParent || rows.length === 0) return;
		// 取消标记：effect 清理时阻止过期回调
		let cancelled = false;
		// 第 1 个 rAF：浏览器下一帧，此时 Virtuoso 把行节点塞进 DOM
		const id = requestAnimationFrame(() => {
			// 第 2 个 rAF：再下一帧，此时浏览器已经完成布局 / 绘制（避免空屏）
			requestAnimationFrame(() => {
				// 未取消才执行回调
				if (!cancelled) onReadyRef.current?.();
			});
		});
		// effect 清理：取消 rAF（避免组件卸载后回调报错）
		return () => {
			cancelled = true;
			cancelAnimationFrame(id);
		};
	}, [scrollParent, rows.length]);

	// 续读定位：把「词条级索引」换算为「行级索引 + 对齐方式」
	const initialTopMostItemIndex = useMemo(() => {
		// 未传续读或列数非法：让 Virtuoso 用默认（从 0 开始）
		if (initialScrollItemIndex <= 0 || columns < 1) return undefined;
		// 返回 Virtuoso 接受的对象：行索引 + 顶对齐视口
		return {
			// floor(词条索引 / 列数) = 行索引
			index: Math.floor(initialScrollItemIndex / columns),
			align: 'start' as const,
		};
	}, [initialScrollItemIndex, columns]);

	// 行内 CSS Grid 的 className：按模式选不同写法
	const rowGridClassName = cn(
		// 基础：占满宽、不被 flex 压缩
		'grid w-full shrink-0',
		// 行间距（默认 gap-4）
		rowClassName,
		// 经典句库：直接用 Tailwind 断点类（与原有 map 渲染保持一致）
		columnMode === 'classic' && (columns === 2 ? 'grid-cols-2' : 'grid-cols-1'),
	);

	// 行内 CSS Grid 的内联 style：仅单词库用内联 gridTemplateColumns，因为列数是动态整数
	const rowGridStyle =
		columnMode === 'vocab'
			? {
					// repeat(columns, minmax(0, 1fr))：每列等宽，允许内容最小 0（长词不撑破）
					gridTemplateColumns: `repeat(${columns}, minmax(0, 1fr))`,
				}
			: undefined;

	// 视口未就绪或无行：返回 null（让父层 loading 持续显示）
	if (!scrollParent || rows.length === 0) {
		return null;
	}

	// 渲染 Virtuoso
	return (
		<Virtuoso
			// 外层 className：占满宽 + 传入自定义
			className={cn('w-full', className)}
			// 自定义滚动容器：用 ScrollArea 的 viewport，不让 Virtuoso 自建 scroll
			customScrollParent={scrollParent}
			// data = 行数组（一维），Virtuoso 会根据可视区渲染行
			data={rows}
			// 入场首行：续读定位换算出的行索引 + 对齐
			initialTopMostItemIndex={initialTopMostItemIndex}
			// 行级 key：用 chunkRows 拼好的 key（基于该行所有卡片 key）
			computeItemKey={(_index, row) => row.key}
			// 前后预渲染像素数：上下各 400px，快速滑动时减少空白
			overscan={{ main: 400, reverse: 400 }}
			// 增广可视区尺寸：上下各加 400px，减少边缘边界触发
			increaseViewportBy={{ top: 400, bottom: 400 }}
			// 最小过扫行数：顶/底至少 2 行，短列表也不会过度挂载
			minOverscanItemCount={{ top: 2, bottom: 2 }}
			// 距离底部多少像素时算「触底」：200px（比默认松一点，体验更顺）
			atBottomThreshold={200}
			// 触底回调：由外层 fetchMore 实现下一页加载
			endReached={onEndReached}
			// 行渲染：每行外层 div → 内层 CSS Grid → 遍历该行切片渲染卡片 → 底部 16px 行间距
			itemContent={(_index, row) => (
				<div>
					{/* 行内 CSS Grid：className + 可选 style */}
					<div className={rowGridClassName} style={rowGridStyle}>
						{/* 遍历该行的词条切片 */}
						{row.items.map((item, col) => {
							// 还原回全局词条级 dataIndex
							const dataIndex = row.startIndex + col;
							return (
								<div
									// 单卡外层 key：与 getItemKey 一致（React diff）
									key={getItemKey(item, dataIndex)}
									// min-w-0：保证长文本不撑破 grid 列；允许自定义额外 className
									className={cn('min-w-0', itemClassName)}
								>
									{/* 调用方传入的实际卡片内容（单词卡 / 经典句卡） */}
									{itemContent(item, dataIndex)}
								</div>
							);
						})}
					</div>
					{/* 行与行之间的 16px 间距：用独立 div 高度撑开，避免 grid gap 影响滚动估算 */}
					<div className="h-4 shrink-0" aria-hidden />
				</div>
			)}
		/>
	);
}
```

### 4.3 单词库面板：列表渲染接入虚拟网格（改动前 / 改动后）

**改动前** · `apps/frontend/src/views/englishLearning/library/vocabulary/index.tsx`（基线，列表渲染核心段）

```tsx
// 双向分页仍用 ScrollArea；内层强制 block（覆盖默认 flex/table），
// 避免桌面 WKWebView 在 prepend 时把 scrollTop 打回 0 导致黑屏。
<ScrollArea
	// 视口 ref：给 onScroll / fetchPrevious 钉视口
	ref={scrollViewportRef}
	// 外层布局：最小高度 0、flex 占剩余、左右 16px 内边距、下 16px 内边距
	className="min-h-0 flex-1 px-4 pb-4"
	// 视口内层 className：关闭滚动锚点 + 强制 block 布局（防 WK prepend 回弹）
	viewportClassName="[overflow-anchor:none] [&>div]:block! [&>div]:min-h-0! [&>div]:h-auto! [&>div]:w-full! [&>div]:min-w-0!"
	// 滚动：方向判定 + 触底/触顶自动加载
```

## 5. 兼容性与影响

| 项 | 说明 |
| --- | --- |
| 破坏性 | 无；词条列表行为不变，只是渲染策略透明替换 |
| 缓存 | 与原 `libraryWordsListCache` 缓存兼容（items 数组不变），Virtuoso 根据 items 重新分块 |
| prepend 支持 | 本组件只支持正向（向 items 末尾 append）；双向分页（向上 prepend）能力已在 `useLibraryWordsList.ts` 中删除，改由一次性预取 0→resumeOffset 的整段覆盖 |
| 列数变化 | 列数变化时 Virtuoso 按新行 key 重新分块，会有一次挂载（用户感知：轻微闪一下）；因为列数只在视口宽度突变时变化，实际体验可接受 |
| SSR | 首次 SSR 输出空节点（无 scrollParent），客户端 useEffect 赋值后立即渲染；符合预期 |
| 读屏 | 卡片 aria-label 与旧版完全一致；LibraryVirtuosoGrid 行间距 div 标 aria-hidden |
