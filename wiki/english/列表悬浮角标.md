# 列表悬浮角标

> **路径已校正**：本文「改动范围」与「相关源码路径」中的滚动注册表路径原为 `library/utils/libraryVirtuosoScrollRegistry.ts`，实际已上移到 `utils/libraryVirtuosoScrollRegistry.ts`（与 Hook 上移同步）。完整路径变更见 [英语学习列表模块收口.md](./英语学习列表模块收口.md)。

## 1. 背景与目标

英语学习的收藏、错题集、每日记词记录等列表页面改用虚拟滚动（Virtuoso）后，长列表无法用原生滚动条快速跳转顶/底。虚拟滚动容器截获了滚动事件，导致浏览器滚动条不再覆盖整个可滚动内容，用户只能一页页滚到底，体验割裂。

本次新增「列表悬浮角标」组件系统，在列表右下角浮动一个按钮：

- 可滚动且未触底时显示「置底」按钮，点击后平滑滚到底部附近。
- 触底后切换为「置顶」按钮，点击后平滑滚回顶部。

核心难点是 **FAB 锚点停靠逻辑**：点击「置底」后按钮不能直接停在绝对底部，否则会立即触发 `endReached` 加载更多，导致无限向下加载。方案是点击「置底」后把视口停到加载区上方的一个锚点位置（`getFabBottomAnchor`），并标记 `fabAnchorPinned = true`；此时 `endReached` 被拦截，按钮维持「置顶」形态。当用户手动继续向下滚入加载区时，释放锚点，恢复常规触底判定与加载更多。

## 3. 实现思路

### 3.1 FAB 模式切换

Hook 内部维护一个 `mode` 状态（`'hidden' | 'toBottom' | 'toTop'`），并在 `updateMode` 中根据视口几何计算下一个模式：

- 内容不足以滚动（`maxScroll <= MIN_SCROLLABLE_PX`）→ `'hidden'`，隐藏按钮。
- 已触底（`atTrueBottom`）或锚点停靠且到达锚点（`fabAnchorPinned && atFabAnchor`）→ `'toTop'`，显示「置顶」。
- 其余可滚动情况 → `'toBottom'`，显示「置底」。

`modeRef` 同步缓存最新模式，避免回调里读到陈旧闭包，也用于 `updateMode` 去重（`modeRef.current === next` 时跳过 `setState`）。

### 3.2 锚点停靠机制

「置底」点击不直接滚到 `maxScroll`，而是滚到 `getFabBottomAnchor(vp)` 返回的锚点：`maxScroll - inset`，其中 `inset = min(FAB_BOTTOM_INSET_PX, maxScroll - MIN_SCROLLABLE_PX)`。`FAB_BOTTOM_INSET_PX = LIBRARY_LIST_AT_BOTTOM_THRESHOLD_PX + 80`，确保锚点落在加载区（`maxScroll - 200`）之上 80px，避免立即触发 `endReached`。

点击后置 `fabAnchorPinned = true`，按钮立即切到 `'toTop'`。锚点释放条件（任一满足即 `false`）：

1. 用户向上滚离锚点超过 `FAB_ANCHOR_RELEASE_PX`（48px）→ 说明用户主动上滚，放弃停靠。
2. 触达真正底部（`atTrueBottom`）或进入加载区（`inLoadZone`）→ 说明用户主动滚入加载区，恢复常规加载。

### 3.3 endReached 拦截

`shouldBlockLibraryListEndReached(vp)` 在 `fabAnchorPinned` 为真且视口未进入加载区时返回 `true`，`LibraryVirtuosoGrid` 的 `endReached` 回调据此提前 `return`，不调用 `onEndReached`。一旦用户滚入加载区，函数返回 `false`，加载正常触发，同时 `updateMode` 释放锚点。

### 3.4 composeViewportScroll 组合滚动事件

`Virtuoso` 的 `customScrollParent` 自身需要绑定 `onScroll`，而 Hook 也需要监听同一滚动来更新模式。`composeViewportScroll(...handlers)` 把多个 `UIEventHandler` 串联成一个，避免在接入处手写嵌套调用，保持滚动监听单一来源。

### 3.5 ResizeObserver 自适应

列表数据异步加载、窗口缩放都会改变 `scrollHeight`。`useEffect` 内创建 `ResizeObserver` 观察视口，尺寸变化时调用 `updateMode` 重新判定模式；首次挂载用 `setTimeout(0)` + `requestAnimationFrame` 双保险，确保 DOM 布局完成后再读取几何值，避免初始读到 0 高度。

```typescript
// 引入悬浮角标的模式联合类型（hidden / toBottom / toTop），用于驱动按钮显隐与图标
import type { ScrollFabMode } from '@design/Assistant';
// 从 React 引入 Hook 所需的类型与基础能力（RefObject、事件处理器类型、四个内置 Hook）
import {
	// 视口 ref 的类型，对应承载 Virtuoso 自定义滚动容器的 div
	type RefObject,
	// 滚动事件处理器类型，用于组合与返回 onScroll 回调
	type UIEventHandler,
	// 缓存函数，用于固化 updateMode / 点击 / onScroll 等回调避免重复创建
	useCallback,
	// 副作用 Hook，用于首次挂载与依赖变化时建立/清理监听
	useEffect,
	// 可变 ref，用于在回调内读取最新的模式值而不触发重渲染
	useRef,
	// 状态 Hook，驱动按钮模式的渲染
	useState,
} from 'react';
// 从滚动注册表引入程序化滚动接口：滚到指定位置 / 滚到顶部
import {
	// 把指定视口滚动到目标 scrollTop（可指定行为 smooth/auto）
	scrollLibraryListViewport,
	// 把指定视口滚动回顶部（可指定行为 smooth/auto）
	scrollLibraryListViewportToTop,
} from '../utils/libraryVirtuosoScrollRegistry';

// 判定「真正触底」的容差像素：scrollTop 距 maxScroll 在此值内即视为到底
const BOTTOM_THRESHOLD_PX = 8;
// 判定「内容可滚动」的最小像素：maxScroll 不超过此值时隐藏 FAB，避免无意义按钮
const MIN_SCROLLABLE_PX = 4;
// 列表触底/加载区阈值：距底部 200px 内即进入加载区，与 Virtuoso atBottomThreshold 对齐
export const LIBRARY_LIST_AT_BOTTOM_THRESHOLD_PX = 200;
// FAB 置底锚点内缩量：在加载区阈值基础上再退 80px，确保锚点停在加载区之上
const FAB_BOTTOM_INSET_PX = LIBRARY_LIST_AT_BOTTOM_THRESHOLD_PX + 80;
// 锚点释放阈值：用户向上滚离锚点超过此值时释放停靠，恢复常规触底判定
const FAB_ANCHOR_RELEASE_PX = 48;

// 模块级锚点停靠标志：true 表示当前 FAB 停在锚点上，需拦截 endReached
let fabAnchorPinned = false;

// 外部可调用的锚点状态写入器，供点击逻辑与拦截逻辑共用同一标志
export function setListScrollFabAnchorPinned(pinned: boolean): void {
	// 写入模块级标志，决定 endReached 是否被拦截
	fabAnchorPinned = pinned;
}

// 判定当前是否应拦截 endReached：仅在锚点停靠且未进入加载区时拦截
export function shouldBlockLibraryListEndReached(vp: HTMLElement): boolean {
	// 未处于锚点停靠态，直接放行 endReached
	if (!fabAnchorPinned) return false;
	// 计算最大可滚动距离，防止负值
	const maxScroll = Math.max(0, vp.scrollHeight - vp.clientHeight);
	// 判定视口是否已进入加载区（距底部在阈值内）
	const inLoadZone =
		vp.scrollTop >= maxScroll - LIBRARY_LIST_AT_BOTTOM_THRESHOLD_PX;
	// 进入加载区则放行（返回 false），否则拦截（返回 true）
	return !inLoadZone;
}

// 计算置底锚点的 scrollTop：停在加载区上方，避免立即触发 endReached
function getFabBottomAnchor(vp: HTMLElement): number {
	// 计算最大可滚动距离，防止负值
	const maxScroll = Math.max(0, vp.scrollHeight - vp.clientHeight);
	// 内容不足以滚动时锚点设为 0（顶部）
	if (maxScroll <= MIN_SCROLLABLE_PX) return 0;
	// 内缩量取「配置内缩」与「maxScroll 留 MIN_SCROLLABLE_PX」的较小值，防止锚点为负
	const inset = Math.min(
		// 期望的内缩像素（加载区阈值 + 80）
		FAB_BOTTOM_INSET_PX,
		// 确保锚点至少留出 MIN_SCROLLABLE_PX 的可滚动余量
		Math.max(0, maxScroll - MIN_SCROLLABLE_PX),
	);
	// 返回锚点位置：最大可滚动距离减去内缩量
	return maxScroll - inset;
}

// 组合多个滚动事件处理器为一个，供 customScrollParent 的 onScroll 复用
export function composeViewportScroll(
	// 接收任意数量的可选滚动处理器
	...handlers: Array<UIEventHandler<HTMLDivElement> | undefined>
): UIEventHandler<HTMLDivElement> {
	// 返回聚合后的滚动处理器
	return (e) => {
		// 依次调用每个传入的处理器，undefined 自动跳过
		for (const handler of handlers) handler?.(e);
	};
}

// 列表悬浮角标主 Hook：输入视口 ref 与内容键，输出模式与回调
export function useListScrollCornerFab(
	// 承载滚动容器的 div ref（customScrollParent 对应元素）
	viewportRef: RefObject<HTMLDivElement | null>,
	// 内容键：列表数据/页变化时触发重新计算模式（如切换收藏/错题 tab）
	contentKey?: unknown,
	// 是否启用 FAB，默认 true；禁用时隐藏并释放锚点
	enabled = true,
) {
	// 按钮模式状态，初始隐藏
	const [mode, setMode] = useState<ScrollFabMode>('hidden');
	// 模式的 ref 镜像，供回调内同步读取最新值，避免闭包陈旧
	const modeRef = useRef<ScrollFabMode>('hidden');

	// 根据当前视口几何重新计算并更新模式的核心函数
	const updateMode = useCallback(() => {
		// 禁用场景：释放锚点并把模式置为隐藏
		if (!enabled) {
			// 清除锚点停靠标志
			setListScrollFabAnchorPinned(false);
			// 仅当当前非隐藏时才更新，避免无谓渲染
			if (modeRef.current !== 'hidden') {
				// 同步 ref
				modeRef.current = 'hidden';
				// 同步状态
				setMode('hidden');
			}
			// 禁用时无需后续判定
			return;
		}
		// 读取视口 DOM，可能尚未挂载
		const vp = viewportRef.current;
		// 视口未就绪时跳过本次判定
		if (!vp) return;
		// 计算最大可滚动距离，防止负值
		const maxScroll = Math.max(0, vp.scrollHeight - vp.clientHeight);
		// 计算置底锚点位置
		const anchor = getFabBottomAnchor(vp);
		// 判定是否真正触底（距底部在容差内）
		const atTrueBottom = vp.scrollTop >= maxScroll - BOTTOM_THRESHOLD_PX;
		// 判定是否到达锚点位置（距锚点在容差内）
		const atFabAnchor = vp.scrollTop >= anchor - BOTTOM_THRESHOLD_PX;
		// 判定是否进入加载区（距底部在阈值内）
		const inLoadZone =
			vp.scrollTop >= maxScroll - LIBRARY_LIST_AT_BOTTOM_THRESHOLD_PX;

		// 锚点停靠态下，若用户向上滚离锚点超过释放阈值，则释放停靠
		if (fabAnchorPinned && vp.scrollTop < anchor - FAB_ANCHOR_RELEASE_PX) {
			// 释放锚点停靠标志
			setListScrollFabAnchorPinned(false);
		}
		// 真正触底或进入加载区时释放锚点，恢复常规触底判定
		if (atTrueBottom || inLoadZone) {
			// 释放锚点停靠标志
			setListScrollFabAnchorPinned(false);
		}

		// 默认下一模式为隐藏
		let next: ScrollFabMode = 'hidden';
		// 仅当内容可滚动时才考虑显示按钮
		if (maxScroll > MIN_SCROLLABLE_PX) {
			// 触底或锚点停靠且到达锚点 → 显示置顶
			if (atTrueBottom || (fabAnchorPinned && atFabAnchor)) {
				// 切换为置顶模式
				next = 'toTop';
			} else {
				// 其余可滚动情况 → 显示置底
				next = 'toBottom';
			}
		}
		// 与当前模式相同则跳过，避免无谓渲染
		if (modeRef.current === next) return;
		// 同步 ref
		modeRef.current = next;
		// 同步状态触发重渲染
		setMode(next);
	}, [enabled, viewportRef]);

	// 暴露给接入方的滚动事件处理器，滚动时刷新模式
	const onScrollCornerFab = useCallback<UIEventHandler<HTMLDivElement>>(() => {
		// 委托给 updateMode 重新判定
		updateMode();
	}, [updateMode]);

	// FAB 点击处理器：根据当前模式执行置底或置顶
	const onScrollCornerFabClick = useCallback(() => {
		// 读取视口 DOM
		const vp = viewportRef.current;
		// 视口未就绪时直接返回
		if (!vp) return;
		// 当前为置底模式 → 滚到锚点并切换为置顶
		if (modeRef.current === 'toBottom') {
			// 标记锚点停靠，拦截后续 endReached
			setListScrollFabAnchorPinned(true);
			// 取锚点位置作为目标 scrollTop
			const top = getFabBottomAnchor(vp);
			// 用 auto 行为瞬时滚到锚点（避免 smooth 滚动过程中途触发判定抖动）
			scrollLibraryListViewport(vp, top, 'auto');
			// 立即切换为置顶模式
			modeRef.current = 'toTop';
			// 同步状态
			setMode('toTop');
		// 当前为置顶模式 → 释放锚点并平滑滚回顶部
		} else if (modeRef.current === 'toTop') {
			// 释放锚点停靠标志
			setListScrollFabAnchorPinned(false);
			// 平滑滚动回顶部
			scrollLibraryListViewportToTop(vp, 'smooth');
		}
	}, [viewportRef]);

	// 副作用：启用时建立首次计算与 ResizeObserver；禁用时清理并隐藏
	useEffect(() => {
		// 禁用场景：释放锚点并隐藏按钮
		if (!enabled) {
			// 清除锚点停靠标志
			setListScrollFabAnchorPinned(false);
			// 同步 ref 为隐藏
			modeRef.current = 'hidden';
			// 同步状态为隐藏
			setMode('hidden');
			// 不再建立监听
			return;
		}
		// 局部保存 ResizeObserver 引用以便清理
		let ro: ResizeObserver | null = null;
		// 用 setTimeout(0) 延迟到当前同步任务后再读几何，确保 DOM 已布局
		const tid = window.setTimeout(() => {
			// 首次同步计算一次模式
			updateMode();
			// 再用 rAF 在下一帧重算，兼容布局延迟完成的情况
			requestAnimationFrame(updateMode);
			// 读取视口 DOM
			const vp = viewportRef.current;
			// 视口就绪则建立尺寸监听
			if (vp) {
				// 创建 ResizeObserver，尺寸变化时刷新模式
				ro = new ResizeObserver(() => updateMode());
				// 观察视口元素
				ro.observe(vp);
			}
		}, 0);
		// 清理函数：卸载或依赖变化时移除定时器与监听
		return () => {
			// 清除挂起的首帧定时器
			window.clearTimeout(tid);
			// 断开 ResizeObserver
			ro?.disconnect();
		};
	}, [contentKey, enabled, updateMode, viewportRef]);

	// 向接入方返回模式、滚动处理器与点击处理器
	return { mode, onScrollCornerFab, onScrollCornerFabClick };
}
```

## 5. 兼容性与影响

- **向后兼容**：FAB 默认 `enabled = true`，对未接入的列表无影响；`variant` 未传时 `ScrollFab` 回退原有变体，不破坏既有调用方。
- **加载更多行为**：锚点停靠期间 `endReached` 被拦截，分页加载暂停；用户手动滚入加载区后立即释放锚点并恢复加载，体验与原生触底一致。
- **回归建议**：
  - 收藏 / 错题 / 每日记词三列表分别验证：置底后停在锚点、按钮切置顶、滚入加载区恢复加载、置顶平滑回顶。
  - 列表数据为空或不足一屏时 FAB 应隐藏。
  - 窗口缩放 / 切换 tab（`contentKey` 变化）后模式应重算。
  - 断网或加载失败时锚点不应卡死，确认 `atTrueBottom` / `inLoadZone` 释放路径覆盖异常态。
