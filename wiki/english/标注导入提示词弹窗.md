# 标注导入提示词弹窗

## 延伸阅读

- [经典句导出与标注导入.md](./经典句导出与标注导入.md)：整集标注的导出 / 导入主流程，本专题升级「手动导入」入口的交互与提示词。
- [句子成分标识.md](./句子成分标识.md)：导入弹窗里的生成提示词已写明 `roleZh` 闭集与句法规则，产出的 JSON 可直接带成分入库。
- [句内词标注缓存与批量标注.md](./句内词标注缓存与批量标注.md)：导入成功后清前端内存缓存（`clearSentenceWordAnnotationCache`），让练习页拿到新标注。
- [卡片单条重标.md](./卡片单条重标.md)：手动导入与单卡在线重标是两条互斥路径，在线预热进行中导入会被拦住。

---

## 1. 背景与目标

语句库 / Pack 的「标注」入口原本是 hover 二选一：在线标注、手动导入。手动导入点下去直接弹系统文件选择框（隐藏 `<input type="file">` + `click()`），用户拿到一个空白文件框，不知道该往里放什么格式、怎么生成。随着本轮新增 `roleZh` 句子成分（见 [句子成分标识.md](./句子成分标识.md)），手动导入的 JSON 也需要带 `roleZh`，更需要一份**可复制的生成提示词**告诉第三方工具 / 模型怎么产出合规文件。

本轮把手动导入入口从「直接弹文件框」升级为一个 **Model 弹窗**：

- 弹窗内展示一段**可一键复制**的生成提示词（`ANNOTATION_IMPORT_PROMPT`），写明输出 schema、`posZh` / `roleZh` 闭集、句法规则与两个例句，用户复制到任意模型即可生成 `.json`。
- 弹窗主体是**拖拽上传区**（`DragDropFileUpload`），支持点击选文件或拖入 `.json`，比隐藏 input 体验好。
- 提示词区可滚动、可选中复制文字；滚动条与选中文字不会误触发文件选择。
- 复制成功有「已复制」反馈（图标切换 + 1 秒自动恢复）。

核心目标：让手动导入从「黑盒文件框」变成「有提示词、可拖拽、带反馈」的自服务流程，同时把 `roleZh` 规则同步给第三方生成路径。

## 3. 实现思路

### 3.1 提示词即契约：`ANNOTATION_IMPORT_PROMPT`

这段常量是给第三方模型 / 应用的「生产规范」，内容与后端在线标注的 `prompt.ts` 闭集保持一致：

- 输出顶层 `{ "items": [...] }`，每个 item 只有 `english` 和 `words`；`english` 必须原样复制（不翻译、不改大小写标点空格）。
- 每个词含 `word` / `posZh` / `ipa` / `meaningZh` / `roleZh` 五个字段。
- `posZh` 闭集、`ipa` 英式 RP 规则、`meaningZh` 按本句搭配释义——与在线标注 prompt 对齐。
- **`roleZh` 规则**：闭集 10 项、先分主从句、每个词只标所在分句功能、「主语和谓语」仅用于缩合（I'm / he's）、并给出两个完整例句（`Why are you smiling?` 与 `The old man made him happy.` 的逐词标注）。
- 末尾要求：能输出 `.json` 文件优先，否则用 markdown json 代码块；禁止纯文本输出；JSON 必须可完整解析。

这段提示词是**纯前端常量**，不随后端版本自动同步——后端 `prompt.ts` 改闭集时需手动同步这里（文档化此依赖，见 §5 风险）。

### 3.2 弹窗结构：拖拽区包裹提示词

`<Model>` 打开后，主体是一个 `DragDropFileUpload`：

- `pickFiles={pickImportJsonFiles}`：点击区域调统一文件选择器 `pickEnglishLearningJsonFile()`（复用 `englishLearningImportFile`，与知识库导入、JSON 导入同一入口，跨端一致），accept 拒绝时弹「文件类型不符」。
- `accept={JSON_IMPORT_ACCEPT}` + `acceptExtensionOnly`：只接受 `.json`。
- `onFiles`：取 `result.accepted[0]` 调 `importFile(file)`。
- 拖拽区内部放一个 `ScrollArea`（高 80），里面是提示词卡片：标题 + 复制按钮 + `<pre>` 展示 `ANNOTATION_IMPORT_PROMPT`。
- 提示词区的 `onClick` 做了防护：点击滚动条（`[data-slot="scroll-area-scrollbar"]`）或正在选中文字时 `stopPropagation`，避免误触发外层拖拽区的文件选择。

### 3.3 复制反馈：`promptCopied` + 定时器

`copyPrompt` 调 `copyToClipboard(ANNOTATION_IMPORT_PROMPT)`，成功后置 `promptCopied=true` 并起 1 秒定时器恢复；失败弹错误 toast。`copiedTimer` ref 在卸载时 `clearTimeout`（与已有的 `closeTimerRef` 清理合并在同一个 `useEffect` 清理函数里）。按钮图标在 `Copy` 与 `CheckCircle` 间切换，文案在 `common.copy` / `common.copied` 间切换。

### 3.4 `importFile` 抽取：从 `onFileChange` 解耦

原来导入逻辑写在 `onFileChange`（读 `e.target.files[0]`）里。现在抽成 `importFile(file: File)`，接收 `File` 参数，`onFiles` 回调直接传文件。逻辑不变：读文本 → `parseAnnotationImportJson` → 调 `importEnglishSentenceWordAnnotations` → 清前端缓存 → 按 accepted/skipped/overwritten 弹 toast → 成功关弹窗。`importing` 守卫保留，避免重复导入。

### 3.5 与在线预热互斥

`onImportSelect` 里原有判断保留：若 `EnglishAnnotateSource.isSourceRunning` 为 true（在线预热进行中），弹 info 提示并拦住导入，避免 LLM 回写覆盖刚导入的同 key。这一逻辑从改前的 `fileRef.click()` 前搬到 `setImportOpen(true)` 前，行为不变。

```typescript
输入文件顶层是 { "title": "", "items": [ ... ] }。每条 item 含 english，以及 translationZh、source、noteZh。只根据 english 标注。不要把 title、translationZh、source、noteZh 写进输出。

words 覆盖该句每一个词，顺序与句中一致，不要跳词或合并。每个词含 word、posZh、ipa、meaningZh、roleZh。
word 保留句中原词的大小写。
posZh 只能是：冠词、限定词、名词、动词、助动词、形容词、副词、介词、代词、连词、数词、感叹词、短语。
ipa 用英式 RP 的 Unicode，不要加 // 或 []。例：dance→dɑːns，water→ˈwɔːtə，car→kɑː（词尾 r 不发音）。
th：清音 θ（think、with、three），浊音 ð（this、that、the）。with 标 wɪθ，不要标 wɪð。
meaningZh 按本句搭配和语法功能释义，2 到 12 个字，不要只抄词典第一义。
roleZh 按该词在本句中的句法功能标注。先分析句子结构，再落标签。必须准确，符合严格句法分析，禁止按词性猜测。
roleZh 只能是：主语、谓语、主语和谓语、宾语、表语、定语、状语、补语、同位语、其他成分。
先分出主句和从句。每个词只标它所在分句里的功能。
主语是句法主语的中心词，包括形式主语 it、there。
谓语是谓语动词词组里的助动词、情态动词和主要动词，包括疑问句里提前的助动词。主语和谓语分开标。
「主语和谓语」只用于一个词里同时含有主语和谓语的缩合，如 I'm、he's、that's、what's。已经分开的词禁止用这个标签。
宾语是及物动词或介词的宾语中心词。双宾语的两个中心词都标「宾语」。
表语是系动词后说明主语的形容词或名词中心词，以及作表语的介词。
补语是宾语补足语或主语补足语的中心词，不与宾语、表语混用。
定语是修饰名词的冠词、限定词、形容词、名词，以及作定语的介词。中心词仍标它所在短语的句法功能。
状语是修饰动词、形容词、副词或全句的副词和介词，包括句首疑问副词。状语内部的宾语和定语仍按内部功能标注，不要整段都标「状语」。
同位语是对前一词复指说明的中心词。
其他成分是并列连词、从属连词、感叹词，以及不承担上述功能的词。
连续同一成分写同一个 roleZh；中间隔了别的成分就分开。不要把词性写进 roleZh。
能确定就必须填写。只有残缺到无法判断句法功能时才留空字符串。
例：Why are you smiling? → Why=状语，are=谓语，you=主语，smiling=谓语。
例：The old man made him happy. → The=定语，old=定语，man=主语，made=谓语，him=宾语，happy=补语。
助动词标「助动词」；the、a、an 标「冠词」；this、that、my、your 标「限定词」。
字符串里不要出现未转义的英文双引号。
如果一次写不完，只输出已经写完的句子。JSON 必须能被完整解析，不要截断在半个对象。
```

```typescript
				});
				return null;
			}
			throw e;
		}
	}, [t]);

	// 导入单个文件：从 onFileChange 抽出，接收 File 参数，供拖拽 onFiles 调用
	const importFile = useCallback(
		(file: File) => {
			// 防重复导入
			if (importing) return;
			setImporting(true);
			void (async () => {
				try {
					// 读文件文本
					const text = await file.text();
					// 解析为标注 items（校验格式，拒原句导出）
					const items = parseAnnotationImportJson(text);
					// 调后端导入接口
					const res = await importEnglishSentenceWordAnnotations({
						source,
						libraryId: libraryId?.trim(),
						streamId: streamId?.trim(),
						items,
						silent: true,
					});
					// 清前端内存缓存，让练习页拿到新标注
					clearSentenceWordAnnotationCache();
					const accepted = res.data?.accepted ?? 0;
					const skipped = res.data?.skipped ?? 0;
					const overwritten = res.data?.overwritten ?? 0;
					// 部分导入：accepted>0 即成功，不与 quoteCount 比较
					if (accepted <= 0) {
						Toast({
							type: 'error',
							title: t('englishLearning.annotateSource.importAllSkipped', {
								skipped,
							}),
						});
						return;
					}
					Toast({
						type: 'success',
						title: t('englishLearning.annotateSource.importSuccess', {
							accepted,
							skipped,
							overwritten,
						}),
					});
					// 成功后关弹窗
					setImportOpen(false);
				} catch (err) {
					const code =
						err instanceof AnnotationImportFormatError ? err.message : '';
					const titleKey =
						code === 'classic_quotes'
							? 'englishLearning.annotateSource.importClassicFile'
							: code === 'empty' || code === 'no_valid_items'
								? 'englishLearning.annotateSource.importEmpty'
								: code
									? 'englishLearning.annotateSource.importInvalid'
									: 'englishLearning.annotateSource.importFailed';
					Toast({ type: 'error', title: t(titleKey) });
				} finally {
					setImporting(false);
				}
			})();
		},
		[importing, libraryId, source, streamId, t],
	);
```

**变更摘要**：新增 `importOpen` / `promptCopied` 状态与 `copiedTimer`；`onImportSelect` 改为开弹窗；新增 `copyPrompt` / `pickImportJsonFiles`；把原 `onFileChange` 的导入逻辑抽成 `importFile(file)`，成功后 `setImportOpen(false)` 关弹窗。`fileRef` 与 `onFileChange` 随隐藏 input 一并删除。

## 5. 兼容性与影响

- **交互升级不破坏导入契约**：`importFile` 的解析、接口调用、清缓存、toast 逻辑与改前 `onFileChange` 完全一致，只是入口从隐藏 input 换成弹窗拖拽。导入结果（accepted/skipped/overwritten）语义不变。
- **提示词与后端闭集需手动同步**：`ANNOTATION_IMPORT_PROMPT` 是前端常量，后端 `prompt.ts` 若调整 `roleZh` 闭集（增删成分名），这里必须同步改，否则第三方生成的文件会带后端不认识的成分名（被 `normalizeRoleZh` 归为空串，不画色块但不报错）。这是已知维护点。
- **跨端一致**：`pickEnglishLearningJsonFile` 是统一文件选择器，Web 与桌面端体验一致；选错类型统一提示「文件类型不符」，与知识库导入、JSON 导入同入口（见既有约定）。
- **卸载安全**：`copiedTimer` 与 `closeTimerRef` 在同一个 `useEffect` 清理函数里 `clearTimeout`，组件卸载不会留定时器。
- **导入中锁弹窗**：`onOpenChange` 在 `importing` 时拒绝关闭，避免用户在导入进行中关弹窗导致状态错乱；导入结束（成功/失败）后 `importing` 置 false，可正常关闭。
