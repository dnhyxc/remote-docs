# 学习笔记：未保存脏标记（保存图标橙点）

> **文档角色（本轮主文档）**：编辑笔记有变更时，工具栏保存图标右上角显示橙点。  
> **延伸阅读**：[学习笔记富文本编辑.md](../ideas/notes/学习笔记富文本编辑.md)；[学习笔记远程.md](./学习笔记远程.md)；Host 侧同类交互见 [../plugins/插件注册宿主API.md](../plugins/插件注册宿主API.md)。

## 1. 背景与目标

编辑学习笔记时，用户难以判断当前内容相对上次保存是否有改动。对齐插件注册表页的「未保存橙点」：有 diff 时在 **保存** 图标上显示小圆点；保存成功后清除。

## 2. 改动范围

| 路径 | 说明 |
|------|------|
| `apps/remote-plugins/src/views/learning-notes/index.tsx` | `dirty` / `baselineHtmlRef` / 保存后 `markClean` |
| `apps/remote-plugins/src/views/learning-notes/components/Editor.tsx` | 长文编辑器 `onChange` 透传（若有） |
| `apps/remote-plugins/src/store/learningNotes.ts` | `saveNote` 返回 `boolean` 供 UI 判断成败 |

## 3. 实现思路

1. 编辑器就绪时记录 `baselineHtmlRef = getHTML()`，`dirty=false`。
2. `onChange` → 比较当前 HTML 与 baseline → `setDirty`。
3. `saveNote` 成功返回 `true` 后 `markClean()`。
4. 橙点样式与 Registry 一致：`absolute right-0 top-0 size-2 rounded-full bg-orange-500`。

## 4. 关键代码对比与注释

### 4.1 dirty 状态与保存

**改动前** · `apps/remote-plugins/src/views/learning-notes/index.tsx`（基线，保存片段）

```typescript
const onSave = useCallback(async () => {
	const paged = pagedSaveRef.current;
	if (paged) {
		// 旧：await 保存，不关心返回值，无 dirty
		await store.saveNote({
			title: paged.getTitle(),
			text: paged.getText(),
			html: paged.getHTML(),
		});
		return;
	}
	const editor = editorRef.current;
	if (!editor || editor.isDestroyed) return;
	await store.saveNote({
		title: getDocTitleText(editor.state.doc).trim(),
		text: editor.getText({ blockSeparator: '\n\n' }).trim(),
		html: editor.getHTML(),
	});
}, [store]);
```

**改动后** · `apps/remote-plugins/src/views/learning-notes/index.tsx`（当前，约 L90–L131）

```typescript
// 取当前正文 HTML（长文走 paged API，否则 TipTap）
const currentHtml = useCallback(() => {
	const paged = pagedSaveRef.current;
	if (paged) return paged.getHTML();
	const editor = editorRef.current;
	if (!editor || editor.isDestroyed) return '';
	return editor.getHTML();
}, []);

// 以当前 HTML 为基线并清除脏标记
const markClean = useCallback(() => {
	baselineHtmlRef.current = currentHtml();
	setDirty(false);
}, [currentHtml]);

// 内容变更时比对 baseline
const syncDirty = useCallback(() => {
	setDirty(currentHtml() !== baselineHtmlRef.current);
}, [currentHtml]);

const onSave = useCallback(async () => {
	const paged = pagedSaveRef.current;
	if (paged) {
		// 保存成功才 markClean
		const ok = await store.saveNote({
			title: paged.getTitle(),
			text: paged.getText(),
			html: paged.getHTML(),
		});
		if (ok) markClean();
		return;
	}
	const editor = editorRef.current;
	if (!editor || editor.isDestroyed) return;
	const ok = await store.saveNote({
		title: getDocTitleText(editor.state.doc).trim(),
		text: editor.getText({ blockSeparator: '\n\n' }).trim(),
		html: editor.getHTML(),
	});
	if (ok) markClean();
}, [markClean, store]);
```

**变更摘要**：引入 baseline / dirty；保存成功后清点。

### 4.2 工具栏橙点

**改动后** · 同文件 `toolbarExtra`（当前，约 L167–L186）

```typescript
<Btn
	title={
		store.saving
			? t('learningNotes.saving')
			: store.editingId
				? t('learningNotes.update')
				: t('learningNotes.save')
	}
	onClick={() => void onSave()}
	disabled={store.saving}
	className="relative"
>
	<Save size={15} />
	{dirty ? (
		<span
			className="pointer-events-none absolute right-0 top-0 size-2 rounded-full bg-orange-500"
			aria-hidden
		/>
	) : null}
</Btn>
```

**变更摘要**：有未保存变更时保存图标显示橙点。

## 5. 兼容性与影响

- 仅编辑态工具栏；预览态无保存按钮，无橙点。
- 切换笔记 / 重建编辑器会在 `onReady`/`onCreate` 重置 baseline。
