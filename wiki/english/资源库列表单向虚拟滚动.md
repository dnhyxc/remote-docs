# 资源库列表单向虚拟滚动：移除双向分页 + 续读窗口并发预取

> **路径已收口**：本文代码块中的 `library/hooks/useLibraryWordsList.ts` 已在本轮重命名为 `hooks/useEnglishLearningList.ts`（类型 `LibraryWordsListResult` → `ElListPageResult`）。完整变更见 [英语学习列表模块收口.md](./英语学习列表模块收口.md)。

> 解决旧版「双向分页（向上 prepend + 向下 append）」在 react-virtuoso 行级虚拟滚动方案下**不再需要向上拉取**的复杂度问题，同时把「首次进库只取 1 页（resumeOffset 所在页）」改为**从 offset=0 开始并发预取覆盖续读位置的完整窗口**，配合虚拟网格的 `initialScrollItemIndex` 直接滚动到续读条。
> 延伸阅读：[资源库虚拟网格.md](./资源库虚拟网格.md)（行级虚拟滚动 UI）、[资源库词条预取并发.md](./资源库词条预取并发.md)（分块 + 并发工具）、[资源库词条续读.md](./资源库词条续读.md)（跨会话进度持久化）。

若与仓库最新源码不一致，**以源码为准**。

## 1. 背景与目标

### 1.1 问题：旧版双向分页的 4 个痛点

旧版 `useLibraryWordsList` 的设计配合「非虚拟化的普通滚动列表」：

| 痛点 | 说明 |
| --- | --- |
| 双向复杂度 | 向上 prepend 需要 `flushSync` + 手动 `scrollHeight` 补偿钉视口，代码长且 WKWebView 易闪烁；`suppressScrollLoadRef` / `scrollLoadArmedRef` 等守卫多，心智负担大 |
| 进库只拉 1 页 | 续读 offset=3000 时进库只拉 `[3000, 3100)`，首屏只有 100 条；用户上滑触发 prepend 再补前面，体验不连贯 |
| 虚拟网格不兼容 prepend | react-virtuoso 的「**行级虚拟化**」假设列表从已知起点（通常 index=0）开始递增渲染；prepend 改 startOffset 会打破 Virtuoso 的 item index 与数据 index 的对齐，需额外适配 |
| 无缓存恢复 | 只有 `setLibraryWordsListCache` 保存，没有 `getLibraryWordsListCache` + `cacheCoversResumeOffset` 判断，组件重挂载时无法跳过网络请求 |

### 1.2 目标

1. **移除双向分页**：删掉 `fetchPrevious` / `loadingPrevious` / `hasPreviousRef` / `suppressScrollLoadRef` / `scrollLoadArmedRef` 等向上加载相关全部状态与守卫，只保留向下 `fetchMore`。
2. **预取续读窗口**：`fetchFirstPage` 改名为 `fetchInitialWindow`，根据 `resumeOffset` 计算需要覆盖到 `[0, resumeOffset + pageSize)` 的范围，用 `buildLibraryPrefetchChunks` + `mapWithConcurrency` 并发拉取，首屏直接呈现完整窗口。
3. **虚拟网格对齐**：用 `initialScrollItemIndex` 代替 `initialScrollTop` 作为滚动锚点，Virtuoso 直接滚到对应 item。
4. **缓存恢复短路**：进库先尝试 `restoreFromCache`，缓存窗口能覆盖续读 offset 则跳过网络请求直接恢复 UI。
5. **列表就绪门闩**：新增 `listReadyRef`（加载/恢复完成后通过 `markListReady` 置 true），避免渲染首帧前 `onEndReached` 误触。

## 3. 实现思路

### 3.1 从「双向滑动窗口」到「单向窗口 + 并发预取」

```
旧版（双向滑动窗口）：
进库时 start=end=3000 ──拉 1 页──▶ window=[3000,3100)
                      ┌───────────────────────────────┐
用户上滑 ◀──prepend── │ [2900,3000) [3000,3100) │──append──▶ 用户下滑
                      └───────────────────────────────┘
问题：Virtuoso 需要从 index=0 开始；上滑 prepend 要钉视口，代码复杂

新版（单向窗口 + 并发预取）：
进库时 resumeOffset=3000，计算 end = 3000 + pageSize = 3100
把 [0, 3100) 分 4 块：[0,1000) [1000,2000) [2000,3000) [3000,3100)
并发 3 个 worker 拉这 4 块 ──合并──▶ window=[0,3100), startOffset=0
                                 initialScrollItemIndex = 3000
                                    ↓
                      Virtuoso 直接滚到第 3000 条
                      用户向下滚动 → fetchMore 正常 append
```

### 3.2 进库时序

```
libraryId 变化
  │
  ├─ 计算 resumeOffset = alignResumeOffset(initialResumeOffset, pageSize)
  │
  ├─ 尝试 restoreFromCache(libraryId, resumeOffset)
  │    ├─ 缓存不存在 / 不覆盖 resumeOffset → 返回 false，继续
  │    └─ 缓存覆盖 → 恢复 state + markListReady，结束（不走网络）
  │
  ├─ buildLibraryPrefetchChunks(resumeOffset, pageSize) → chunks
  │
  ├─ mapWithConcurrency(chunks, 3, fetchPageWithRetry) → pages
  │
  ├─ pages 合并为 list，scrollIndex = min(resumeOffset, list.length-1)
  │
  └─ applyWindow(id, 0, list, lib, scrollIndex, hasMore)
         ├─ startOffset=0, endOffset=list.length
         ├─ setItems(list)
         ├─ setInitialScrollItemIndex(scrollIndex)   ← Virtuoso 锚点
         └─ setResume(scrollIndex) + persistCache
```

### 3.3 关键状态变更对照

| 分类 | 改动前（双向分页） | 改动后（单向预取） |
| --- | --- | --- |
| 首屏加载函数 | `fetchFirstPage`：只拉 resumeOffset 所在 1 页 | `fetchInitialWindow`：并发拉 [0, resumeOffset+pageSize) |
| 向上加载 | `fetchPrevious` + `loadingPrevious` + `hasPreviousRef` + `suppressScrollLoadRef` + `scrollLoadArmedRef` + `lastScrollTopRef` + `fetchingPrevRef` + `flushSync` 钉视口 | **全部移除** |
| 向下加载守卫 | `scrollLoadArmedRef`（用户滚动/点击后允许无限加载） | `listReadyRef`（首屏渲染完成后才允许 onEndReached）+ `lastMoreOffsetRef`（相同 offset 防重复） |
| 锚点方式 | `initialScrollTop`（像素级，需缓存恢复 scrollTop） | `initialScrollItemIndex`（item index 级，Virtuoso 原生支持）+ `initialScrollTop`（缓存恢复 fallback） |
| 缓存恢复 | 无 `restoreFromCache`，重挂载必走网络 | 新增 `restoreFromCache`：`cacheCoversResumeOffset` 判定覆盖则短路，恢复 UI + 续读位置 |
| fetchPageWithRetry 签名 | `(id, offset)` → limit 固定 pageSize | `(id, limit, offset)` → 每块可拉满 1000，减少总请求数 |
| 返回对象 | 无 `initialScrollItemIndex`、无 `onEndReached` | 新增 `initialScrollItemIndex`（Virtuoso 用）+ `onEndReached`（Virtuoso 触底回调） |

### 4.3 `applyWindow` + `fetchFirstPage`/`fetchInitialWindow` + 新增 `restoreFromCache`

这是本次改动的**核心逻辑**：首屏加载从「只拉 1 页续读页」变为「并发预取完整窗口 + 可选缓存恢复短路」。

```typescript
			// id：库 ID

			// 清理正在向上加载标记
			fetchingPrevRef.current = false;

			suppressScrollLoadRef.current = true;
			// 无限加载未启用：等用户交互后才 armed
			scrollLoadArmedRef.current = false;

			setLoading(true);
			// 清 loadingMore
			setLoadingMore(false);
			// 清 loadingPrevious
			setLoadingPrevious(false);
			// 清初始 scrollTop（首次加载不恢复像素位置）
			setInitialScrollTop(0);
			// 重置 scrollTop ref
			scrollTopRef.current = 0;
			// 重置上次 scrollTop 记录
			lastScrollTopRef.current = 0;
			// 窗口起始 = 续读偏移（双向模式：中间一页）
			startOffsetRef.current = resumeOffset;
			// 窗口结束 = 续读偏移（等请求返回后再延长）
			endOffsetRef.current = resumeOffset;
			// 假设有更多向下数据（加载完成后按实际修正）
			hasMoreRef.current = true;
			// 向上有数据当且仅当续读偏移 > 0（旧版允许 prepend 回拉）
			hasPreviousRef.current = resumeOffset > 0;

			setItems([]);
			// 清库元信息
			setResolvedLibrary(null);

				let startOffset = resumeOffset;

				let data = await fetchPageWithRetry(id, startOffset);
				// 世代或库 ID 变化：请求已过期，直接丢弃
				if (gen !== loadGenRef.current || libraryIdRef.current !== id) return;
				// 解析词条数组（兜底空数组）
				let list = Array.isArray(data.items) ? data.items : [];
				// 特殊情况：续读偏移在末尾之后，返回空；回退到从头拉第一页

					// 重新拉取第 0 页

					list = Array.isArray(data.items) ? data.items : [];

				const resolved = data.library ?? null;

				applyWindow(id, startOffset, list, resolved);
			} catch {
				// 世代变化：丢弃错误处理
				if (gen !== loadGenRef.current) return;
				// 失败：清空 items
				setItems([]);
				// 标记无更多向下数据
				hasMoreRef.current = false;
				// 标记无更多向上数据
				hasPreviousRef.current = false;

				Toast({
					type: 'error',
					title: tRef.current('englishLearning.library.wordsLoadFailed'),
				});
			} finally {
				// 世代匹配：关闭 loading + 解除 suppress
				if (gen === loadGenRef.current) {
					// 关闭首屏 loading
					setLoading(false);
					// 下一帧解除 scroll suppress：允许后续滚动触发加载
					requestAnimationFrame(() => {
						suppressScrollLoadRef.current = false;
					});
				}
			}
		},
		// 依赖：applyWindow + fetchPageWithRetry
		[applyWindow, fetchPageWithRetry],
	);
```

```typescript
				page > 0 ? page : alignResumeOffset(cached.startOffset, pageSize);
			// 重置 lastMoreOffset：恢复后可重新触发 fetchMore
			lastMoreOffsetRef.current = -1;
			// 计算 Virtuoso 的 initialTopMostItemIndex：目标相对 index = page - cached.startOffset
			const scrollIndex = Math.min(
				// 下界 0 保护
				Math.max(0, page - cached.startOffset),
				// 上界保护：不超过最后一条
				Math.max(0, cached.items.length - 1),
			);
			// 恢复 items state
			setItems(cached.items);
			// 恢复库元信息
			setResolvedLibrary(cached.resolvedLibrary);
			// 设置像素级 scrollTop（fallback，Virtuoso 会优先用 scrollItemIndex）
			setInitialScrollTop(cached.scrollTop);
			// 设置 Virtuoso item 级锚点
			setInitialScrollItemIndex(scrollIndex);
			// 首屏 loading 关闭
			setLoading(false);
			// loadingMore 关闭
			setLoadingMore(false);
			// 清理 fetchingMore 标记
			fetchingMoreRef.current = false;
			// 恢复成功：返回 true，调用方跳过网络请求
			return true;
		},
		// 依赖：cacheNamespace（取缓存用）+ pageSize（对齐需要）
		[cacheNamespace, pageSize],
	);

	// **fetchFirstPage 重命名为 fetchInitialWindow**：并发预取 [0, resumeOffset+pageSize) 完整窗口
	const fetchInitialWindow = useCallback(
		async (
			// id：库 ID
			id: string,
			// gen：加载世代号
			gen: number,
			// resumeOffset：对齐后的续读偏移
			resumeOffset: number,
		) => {
			// 首屏加载中：标记未就绪，禁止 Virtuoso onEndReached 提前触发
			listReadyRef.current = false;
			// 清理 fetchingMore 标记
			fetchingMoreRef.current = false;
			// 重置 lastMoreOffset：允许首次 fetchMore
			lastMoreOffsetRef.current = -1;
			// 显示首屏 loading
			setLoading(true);
			// 清 loadingMore
			setLoadingMore(false);
			// 清初始 scrollTop（网络路径不依赖像素恢复）
			setInitialScrollTop(0);
			// 清 initialScrollItemIndex，稍后设置
			setInitialScrollItemIndex(0);
			// 重置 scrollTop ref
			scrollTopRef.current = 0;
			// 清空旧 items
			setItems([]);
			// 清空旧库元信息
			setResolvedLibrary(null);
			try {
				// **Step 1：分块**——把 [0, resumeOffset+pageSize) 按 1000 切分成尽量少的请求
				const chunks = buildLibraryPrefetchChunks(resumeOffset, pageSize);
				// **Step 2：并发拉取**——3 个 worker 同时请求，每块满 1000
				const pages = await mapWithConcurrency(
					// 分块数组（每项含 limit/offset）
					chunks,
					// 并发数
					PREFETCH_CONCURRENCY,
					// 单任务：调用 fetchPageWithRetry 拉该块数据
					(chunk) => fetchPageWithRetry(id, chunk.limit, chunk.offset),
				);
				// 世代或库变化：丢弃并发结果
				if (gen !== loadGenRef.current || libraryIdRef.current !== id) return;

				// **Step 3：结果合并**——按分块顺序（mapWithConcurrency 保证结果序与输入序一致）合并词条
				const list: TItem[] = [];
				// 库元信息：取第一个非空值（通常首块就带 library，后续块可能不带）
				let lib: TLibrary | null = null;
				// 遍历各分块结果页
				for (const page of pages) {
					// 当前页词条（兜底空数组）
					const chunk = Array.isArray(page.items) ? page.items : [];
					// push 到合并列表末尾
					list.push(...chunk);
					// 遇到非空 library 就记录（先到优先）
					if (page.library) lib = page.library;
				}

				// **Step 4：空结果回退**——窗口为空 + resumeOffset>0（续读位置靠后但库被清空了），回退从头拉
				if (list.length === 0 && resumeOffset > 0) {
					// 回退请求：只拉第 0 页 pageSize 条
					const fallback = await fetchPageWithRetry(id, pageSize, 0);
					// 再次检查世代/库 ID
					if (gen !== loadGenRef.current || libraryIdRef.current !== id) {
						return;
					}
					// 回退页词条（兜底空数组）
					const fallbackList = Array.isArray(fallback.items)
						? fallback.items
						: [];
					// 是否还有更多：用 pageSize 判断（回退场景只拉 1 页）
					const hasMore = fallbackList.length >= pageSize;
					// 写入窗口：startOffset=0、scrollIndex=0（回退从头开始）
					applyWindow(
						// 库 ID
						id,
						// 窗口起始：0
						0,
						// 回退词条
						fallbackList,
						// 回退库元信息
						fallback.library ?? null,
						// 锚点：0
						0,
						// 是否还有更多
						hasMore,
					);
					// 回退分支结束
					return;
				}

				// **Step 5：计算 Virtuoso 锚点**——滚动到 resumeOffset 位置，但不越界
				const scrollIndex = Math.min(
					// 下界 0（resumeOffset 不会 < 0，保险用 max）
					Math.max(0, resumeOffset),
					// 上界：最后一条（若 resumeOffset 超过总条数，钉在最后一条）
					Math.max(0, list.length - 1),
				);
				// 取最后一页结果（用于判断是否还有更多数据：最后一块拉满 = 有更多）
				const lastPage = pages.at(-1);
				// 取最后一块分块定义（含 limit）
				const lastChunk = chunks.at(-1);
				// 计算 hasMore：最后一页的词条长度 == 最后一块请求的 limit，说明大概率还有下一页
				const hasMore =
					(lastPage?.items.length ?? 0) === (lastChunk?.limit ?? 0);
				// **Step 6：写入窗口**——startOffset=0（新版虚拟网格必须从 0 起算）
				applyWindow(id, 0, list, lib, scrollIndex, hasMore);
			} catch {
				// 世代变化：丢弃错误
				if (gen !== loadGenRef.current) return;
				// 失败：清空 items
				setItems([]);
				// 标记无更多
				hasMoreRef.current = false;
				// 错误 Toast：加载失败文案
				Toast({
					type: 'error',
					title: tRef.current('englishLearning.library.wordsLoadFailed'),
				});
			} finally {
				// 世代匹配：关闭 loading + 就绪门闩打开
				if (gen === loadGenRef.current) {
					// 关闭首屏 loading
					setLoading(false);
					// **关键**：下一帧打开就绪门闩，Virtuoso 触底可以触发 fetchMore
					markListReady();
				}
			}
		},
		// 依赖：applyWindow + fetchPageWithRetry + markListReady + pageSize（回退分支用）
		[applyWindow, fetchPageWithRetry, markListReady, pageSize],
	);
```

**变更摘要**：
- `fetchPageWithRetry` 签名：新增 `limit` 参数，分块可满 1000；依赖从 `[pageSize]` 变为空数组（全 ref 化）。
- `applyWindow` 签名：新增 `scrollItemIndex`（Virtuoso 锚点）与 `hasMore`（显式传入，不再用 list 长度推断）；`startOffset` 恒为 0。
- 新增 `restoreFromCache`：缓存覆盖续读位置时短路恢复 UI，跳过网络。
- `fetchFirstPage` → `fetchInitialWindow`：并发预取 [0, end) 窗口并合并，锚定 scrollItemIndex；空窗口时回退到 offset=0 单页请求。
- 新增 `markListReady` + `loadingRef`：首帧门闩与 `loading` 守卫。

## 5. 兼容性与影响

### 5.1 行为变化（用户可感知）

| 场景 | 旧版 | 新版 | 体验变化 |
| --- | --- | --- | --- |
| 深库首次进入（resumeOffset=3000） | 首屏只有 100 条 [3000,3100)，向上滚动才慢慢补前面 | 瞬间呈现 [0,3100) 3100 条，Virtuoso 直接滚到 3000 条，**向下/向上都立即有内容** | 首屏更完整，无「上滑补加载」交互 |
| 重进同一库（组件重新挂载） | 每次都要重新拉网络 | 缓存覆盖续读位置则**秒开无网络**；未覆盖才走并发预取 | 频繁切库体验大幅提升 |
| 向下滚动到底 | `scrollLoadArmedRef` 守卫 + 用户滚动/点击后才允许 | 首屏 `markListReady` 后 Virtuoso 自动响应 `onEndReached`，无需用户额外交互 | 加载更多触发更自然 |
| 向上滚动 | 触发 `fetchPrevious` prepend 拉前面数据 | 向上滚动**不再触发请求**（窗口 0→end 已完整） | 不再有 prepend 钉视口导致的 WKWebView 闪烁 |

### 5.2 调用方接口兼容

- `UseLibraryWordsListOptions` 字段签名**完全不变**：调用方（单词库列表页、经典句库列表页）**无需改代码**。
- 返回对象：
  - 保留 `items` / `setItems` / `resolvedLibrary` / `loading` / `loadingMore` / `initialScrollTop` / `onViewportScroll`（语义一致）。
  - **移除** `loadingPrevious` / `onWheel`：若旧调用方有引用会报错，但调用方已同步改为用 `LibraryVirtuosoGrid` 组件，不再用这些字段。
  - **新增** `initialScrollItemIndex` / `onEndReached`：新组件 `LibraryVirtuosoGrid` 消费。

### 5.3 风险与回归建议

| 建议回归场景 | 验证点 |
| --- | --- |
| 大库深续读（1 万条以上） | 首次进入并发请求数 ≤ `chunks.length`，进度条正常消失，Virtuoso 能滚到 resumeOffset 位置；hasMore 判断正确 |
| 续读 offset 超过总条数边界 | 触发 fallback 到第 0 页，Toast 正常显示或 fallback 成功 |
| 缓存恢复 + 快速切库 | `restoreFromCache` 返回 true 时不发起请求；快速切库（A→B→A）命中缓存后不重复 fetchInitialWindow |
| fetchMore 失败重试 | 断网模拟失败后，`lastMoreOffsetRef` 回退 -1，重试联网后再滚到底部能再次触发 fetchMore |
| 同一 offset 快速多触底 | `lastMoreOffsetRef === offset` 守卫阻止重复请求 |
| 网络失败 loading 清理 | 并发预取中失败后，`loading` false + `markListReady`（或 restoreFromCache 成功）后可正常 scroll |
