## 1. 背景与目标

在本次改动之前，对话发送按钮的视觉与交互逻辑**散落**在两处：

1. `apps/frontend/src/components/design/ChatEntry/index.tsx`（主对话输入条）—— 内联了约 150 行 JSX：停止生成钮（`Target` + 呼吸动画）、Tauri 语音输入模式下拉菜单（`DropdownMenu` + 悬停展开/延时关闭）、纯文本发送钮（`Rocket`）。同时把 `inputModeMenuOpen` / `closeInputModeMenuTimerRef` 等菜单状态机耦合在 ChatEntry 主体里，导致 ChatEntry 行数膨胀、语音菜单逻辑无法独立测试。
2. `apps/frontend/src/views/knowledge/KnowledgeAssistantEntry.tsx`（知识库助手轻量输入条）—— 又**重复**实现了一遍停止钮 + 发送钮的 JSX，仅样式常量不同（`border-teal-500/30 bg-teal-500/20` vs ChatEntry 的 `from-teal-300/80 to-teal-500/80`）。两份实现各自漂移，图标、loading 态、无障碍文案难以统一。

本次改动把「发送钮视觉」与「发送钮状态机（停止 / 发送 / 语音菜单）」**抽取为两个独立组件**：

- `MessageSendButton`：纯视觉底座（`Button` + teal 主题样式 + 图标/loading 插槽），不持业务状态。
- `MessageSendControl`：状态机外壳，按 `loading` / `onStop` / `voiceMenu` 三态分发到 `MessageStopButton` / `VoiceMenuSendButton` / `MessageSendButton`。

抽取后 ChatEntry 与 KnowledgeAssistantEntry 都只需 `<MessageSendControl ... />` 一行，菜单状态机内聚在 `VoiceMenuSendButton` 闭包里，ChatEntry 主体减少约 200 行、5 个 `useCallback`/`useState` 与 3 处 effect 依赖。

## 2. 改动范围

**新增（纯新增文件）**

- `apps/frontend/src/components/design/MessageSendButton/MessageSendButton.tsx` — 发送钮视觉底座 + `MESSAGE_SEND_BUTTON_CLASS` 样式常量。
- `apps/frontend/src/components/design/MessageSendButton/MessageSendControl.tsx` — 状态机外壳 + `VoicePrimaryIcon` / `MessageStopButton` / `VoiceMenuSendButton` 三个内部子组件。
- `apps/frontend/src/components/design/MessageSendButton/index.ts` — 统一 barrel 导出。

**修改（接入方替换内联 JSX）**

- `apps/frontend/src/components/design/ChatEntry/index.tsx` — 删除内联停止钮 / 语音菜单 / 发送钮 JSX 与 `inputModeMenuOpen` 状态机；改为 `<MessageSendControl ... />`。
- `apps/frontend/src/views/knowledge/KnowledgeAssistantEntry.tsx` — 删除重复的停止钮 / 发送钮 JSX；改为 `<MessageSendControl ... />`。

## 3. 实现思路

1. **视觉底座与状态机分离**：`MessageSendButton` 只管「长什么样」（teal 渐变 + ring + 图标插槽 + loading spinner），`MessageSendControl` 只管「按什么状态渲染什么」（loading && onStop → 停止钮；voiceMenu → 语音菜单；否则 → 纯发送钮）。接入方只需声明状态，不关心 JSX 结构。
2. **样式常量统一出口**：`MESSAGE_SEND_BUTTON_CLASS` 是发送钮的 Tailwind 类集合（`from-teal-300/10 to-teal-500/10` 浅底 + `ring-2 ring-teal-400/35` + `border-teal-500/10`），比旧版 `from-teal-300/80 to-teal-500/80` 实底更轻、更贴合卡片背景；停止钮 `STOP_BUTTON_CLASS` 用 `rose-500` 警示色。两常量都从 `MessageSendControl.tsx` 内部引用，外部只通过 props 传 className 叠加。
3. **语音菜单状态机内聚**：`VoiceMenuSendButton` 自带 `menuOpen` / `closeTimerRef`，把原来散在 ChatEntry 的 `openInputModeMenu` / `scheduleCloseInputModeMenu` / `handleInputModeMenuOpenChange` 三个 callback 收进一个组件，并实现「悬停展开、离开延时 220ms 关闭、点击直接发送并关菜单」的交互。ChatEntry 因此少维护一份菜单状态，卸载清理也由 `VoiceMenuSendButton` 的 `clearCloseTimer` 闭包自洽。
4. **主按钮 onClick 不吞事件**：`VoiceMenuSendButton` 的 `handlePrimaryClick` 先 `e.stopPropagation()` 阻止冒泡到 `DropdownMenuTrigger`（否则会触发菜单 toggle），再 `setMenuOpen(false)` 关菜单，最后 `void onSend()`。保证点发送钮 = 发送 + 关菜单，不会误开菜单。
5. **三态分发顺序固定**：`MessageSendControl` 主体先判 `loading && onStop` → 停止钮；再按 `voiceMenu` 有无分流；都不命中走纯 `MessageSendButton`。顺序与原 ChatEntry 嵌套三元一致，勿调换。
6. **props 语义对齐旧实现**：`sendDisabled` 控制按钮 `disabled`；`sendDisabledHint` 仅在 Web 且禁用时作 `title` 提示；`sendLoading` 控制发送钮是否转 spinner（知识库场景：loading 但无 onStop，发送钮转圈而非变停止钮）；`voiceMenu` 不传则纯发送钮（Web 端无语音）。

### 4.1 `MESSAGE_SEND_BUTTON_CLASS` 与 `MessageSendButton`（`apps/frontend/src/components/design/MessageSendButton/MessageSendButton.tsx`）

> 纯新增文件。仅展示改动后。

**改动后** · `apps/frontend/src/components/design/MessageSendButton/MessageSendButton.tsx`（新增，约 L1–L60）

```typescript
// 导入 Button 基础组件（shadcn/ui Button，从 @ui/index barrel）
import { Button } from '@ui/index';
// 导入 loading 图标 Loader2 与默认发送图标 Rocket
import { Loader2, Rocket } from 'lucide-react';
// 导入 React 类型与 forwardRef
import { type ComponentProps, forwardRef, type ReactNode } from 'react';
// 导入 cn 类名合并工具
import { cn } from '@/lib/utils';

// 发送钮统一视觉样式常量：浅底渐变 + ring + 边框，供 MessageSendButton 与 VoiceMenuSendButton 复用
export const MESSAGE_SEND_BUTTON_CLASS =
// lucide 描边 hover 抽线动画
'lucide-stroke-draw-hover ' +
// 尺寸：8.5×8.5（约 34px），flex 居中
'h-8.5 w-8.5 flex shrink-0 items-center justify-center rounded-full ' +
// 边框 + ring：teal 极淡边框 + 中等强度 ring 光晕
'border border-teal-500/10 ring-2 ring-teal-400/35 ' +
// 背景：teal 双色极浅渐变（10% 透明），比旧版 80% 实底更贴合卡片
'bg-linear-to-r from-teal-300/10 to-teal-500/10 ' +
// 内边距归零（Button size=icon 自带 p-0，显式声明兜底）
'p-0 text-teal-500 shadow-none ' +
// hover 加深背景与文字色
'hover:bg-teal-500/15 hover:text-teal-500 ' +
// 禁用态半透明
'disabled:opacity-45 ' +
// svg 不裁剪溢出（描边动画需要）
'[&_svg]:overflow-visible';

// MessageSendButton 的 props 类型：基于 Button 但去掉 children/variant/size（内部接管）
export type MessageSendButtonProps = Omit<
// 取 Button 的全部属性
ComponentProps<typeof Button>,
// 去掉 children（用 icon/loadingIcon/children 三选一接管）
'children' | 'variant' | 'size'
> & {
// true 时展示 loadingIcon（默认 Loader2），仍由 disabled 控制是否可点
loading?: boolean;
// 传入时完全自定义图标区（语音 Mic/停录 Square 等）
children?: ReactNode;
// 默认图标区（默认 Rocket），未传 children 时使用
icon?: ReactNode;
// loading 时的图标（默认 Loader2 旋转）
loadingIcon?: ReactNode;
// 未传 aria-label 时的默认无障碍文案
sendLabel?: string;
};

// MessageSendButton 组件：forwardRef 透传 ref，方便外层聚焦 / 测量
export const MessageSendButton = forwardRef<
// ref 类型：原生 button
HTMLButtonElement,
// props 类型
MessageSendButtonProps
>(function MessageSendButton(
// 解构 props：loading 默认 false，sendLabel 默认「发送」，type 默认 button
{
loading = false,
children,
icon,
loadingIcon,
sendLabel = '发送',
className,
type = 'button',
'aria-label': ariaLabel,
// 其余透传到 Button（onClick / disabled / title 等）
...rest
},
// 外层传入的 ref
ref,
) {
// 计算图标区内容：children 优先，其次 loading→loadingIcon/Loader2，再次 icon/Rocket
const content =
// 有自定义 children 直接用
children ??
// loading 态：loadingIcon 或默认 Loader2 旋转
(loading
? (loadingIcon ?? <Loader2 className="h-4 w-4 animate-spin" />)
// 否则：icon 或默认 Rocket 倾斜 -45°
: (icon ?? <Rocket className="h-4 w-4 -rotate-45" />));

// 渲染 Button：variant=ghost + size=icon，套统一样式常量
return (
<Button
// 透传 ref
ref={ref}
// type 默认 button，避免表单提交
type={type}
// variant 固定 ghost（无背景，靠 className 接管）
variant="ghost"
// size 固定 icon（正方形）
size="icon"
// 无障碍标签：优先 ariaLabel，回退 sendLabel
aria-label={ariaLabel ?? sendLabel}
// 合并统一样式与外层 className（外层可叠加）
className={cn(MESSAGE_SEND_BUTTON_CLASS, className)}
// 透传其余 props
{...rest}
>
// 渲染图标区内容
{content}
</Button>
);
});

// 默认导出
export default MessageSendButton;
```

**变更摘要**：纯新增。`MESSAGE_SEND_BUTTON_CLASS` 统一发送钮视觉（浅底 + ring + teal 描边）；`MessageSendButton` 用 `forwardRef` 透传 ref，`children ?? loadingIcon ?? icon` 三级图标回退，`aria-label` 回退 `sendLabel`。

```typescript
// 从 @ui/index 导入 Button 与 DropdownMenu 系列组件
import {
Button,
DropdownMenu,
DropdownMenuContent,
DropdownMenuItem,
DropdownMenuLabel,
DropdownMenuSeparator,
DropdownMenuTrigger,
} from '@ui/index';
// 导入图标：Keyboard 文本模式 / Loader2 loading / Mic 麦克风 / Rocket 发送 / Square 停录 / Target 停止生成
import { Keyboard, Loader2, Mic, Rocket, Square, Target } from 'lucide-react';
// 导入 React 类型与 hooks
import {
type MouseEvent,
type ReactNode,
useCallback,
useRef,
useState,
} from 'react';
// 导入 cn 类名合并工具
import { cn } from '@/lib/utils';
// 导入视觉底座 MessageSendButton
import { MessageSendButton } from './MessageSendButton';

// 停止钮外层 span 包裹样式：呼吸动画 + 尺寸
const STOP_WRAP_CLASS =
// inline-flex 居中 + 底边距 + 8×8
'inline-flex mb-1 h-8 w-8 items-center justify-center rounded-full ' +
// 呼吸动画（CSS keyframes animate-chat-stop-breathe）
'animate-chat-stop-breathe motion-reduce:animate-none';

// 停止钮按钮样式：rose 警示色 + 描边动画
const STOP_BUTTON_CLASS =
// 描边 hover 抽线动画
'lucide-stroke-draw-hover p-0 ' +
// 尺寸 8.5×8.5
'h-8.5 w-8.5 flex shrink-0 items-center justify-center rounded-full ' +
// rose 边框 + 半透明背景
'border border-rose-500/30 bg-rose-500/20 text-rose-500 ' +
// hover 加深
'hover:bg-rose-500/30 hover:text-rose-500 shadow-none ' +
// svg 不裁剪
'[&_svg]:overflow-visible';

// 语音菜单 props 类型（Tauri 桌面端语音输入模式）
export type MessageSendControlVoiceMenu = {
// 无正文时禁用输入（知识库左侧无正文）
disableTextInput?: boolean;
// 当前输入模式：文本 / 语音
inputMode: 'text' | 'voice';
// 切换输入模式回调
onInputModeChange: (mode: 'text' | 'voice') => void;
// 语音 UI 是否激活（inputMode===voice 时）
voiceUiActive: boolean;
// 是否正在录音
voiceRecording: boolean;
// 是否正在转写
voiceTranscribing: boolean;
// 语音态主钮是否展示发送图标（有正文时切回发送）
voicePrimaryShowsSend: boolean;
// 文案 i18n
labels?: {
inputMode?: string;
text?: string;
voice?: string;
};
};

// MessageSendControl 主体 props 类型
export type MessageSendControlProps = {
// 生成中
loading?: boolean;
// loading 且有 onStop 时展示停止生成钮
onStop?: () => void;
// 停止钮无障碍文案
stopLabel?: string;
// 发送钮禁用
sendDisabled?: boolean;
// 发送回调
onSend: () => void | Promise<void>;
// 发送钮无障碍文案
sendLabel?: string;
// Web 发送禁用时的 title 提示
sendDisabledHint?: string;
// 非停止态且 loading 时，发送钮展示 spinner（知识库等）
sendLoading?: boolean;
// Tauri 语音输入模式菜单；不传则仅展示发送钮
voiceMenu?: MessageSendControlVoiceMenu;
// 外层容器 className
className?: string;
};

// 语音态主钮图标：按 voicePrimaryShowsSend / voiceUiActive / 转写 / 录音 状态返回不同图标
function VoicePrimaryIcon({
voicePrimaryShowsSend,
voiceUiActive,
voiceTranscribing,
voiceRecording,
}: Pick<
MessageSendControlVoiceMenu,
// 仅取这四个字段
| 'voicePrimaryShowsSend'
| 'voiceUiActive'
| 'voiceTranscribing'
| 'voiceRecording'
>) {
// 有正文时展示发送图标
if (voicePrimaryShowsSend) {
return <Rocket className="h-4 w-4 -rotate-45" />;
}
// 非语音态也展示发送图标
if (!voiceUiActive) {
return <Rocket className="h-4 w-4 -rotate-45" />;
}
// 转写中展示 Loader2 旋转
if (voiceTranscribing) {
return <Loader2 className="h-4 w-4 animate-spin" />;
}
// 录音中展示 Square 停录
if (voiceRecording) {
return <Square className="h-3.5 w-3.5 fill-current" />;
}
// 默认展示 Mic 麦克风
return <Mic className="h-4 w-4" />;
}

function MessageStopButton({

}: {

// 无障碍文案，默认「停止生成」

return (

// 语音菜单发送钮：DropdownMenu 悬停展开 + 主钮点击发送
function VoiceMenuSendButton({
voiceMenu,
sendDisabled,
sendLabel,
onSend,
}: {
// 语音菜单配置
voiceMenu: MessageSendControlVoiceMenu;
// 发送禁用
sendDisabled?: boolean;
// 发送文案
sendLabel?: string;
// 发送回调
onSend: () => void | Promise<void>;
}) {
// 解构语音菜单配置
const {
disableTextInput,
inputMode,
onInputModeChange,
voiceUiActive,
voiceRecording,
voiceTranscribing,
voicePrimaryShowsSend,
labels,
} = voiceMenu;

// 菜单开闭状态（受控）
const [menuOpen, setMenuOpen] = useState(false);
// 延时关闭定时器引用
const closeTimerRef = useRef<number | null>(null);

// 清除延时关闭定时器
const clearCloseTimer = useCallback(() => {
// 定时器存在才清除
if (closeTimerRef.current !== null) {
window.clearTimeout(closeTimerRef.current);
closeTimerRef.current = null;
}
}, []);

// 延时 220ms 关闭菜单：避免鼠标从 trigger 移到 content 间隙误关
const scheduleCloseMenu = useCallback(() => {
// 先清旧定时器
clearCloseTimer();
// 设新定时器：220ms 后关闭
closeTimerRef.current = window.setTimeout(() => {
closeTimerRef.current = null;
setMenuOpen(false);
}, 220);
}, [clearCloseTimer]);

// 立即展开菜单（trigger 悬停时调用）
const openMenu = useCallback(() => {
// 无正文禁用时直接 return（知识库无正文场景）
if (disableTextInput) return;
// 清延时关闭
clearCloseTimer();
// 展开菜单
setMenuOpen(true);
}, [clearCloseTimer, disableTextInput]);

// DropdownMenu 受控开闭：禁用时强制关
const handleMenuOpenChange = useCallback(
(next: boolean) => {
// 禁用输入时强制关菜单
if (disableTextInput) {
setMenuOpen(false);
return;
}
// 否则跟随受控值
setMenuOpen(next);
},
[disableTextInput],
);

// 主钮点击：阻止冒泡（否则触发 DropdownMenu toggle），关菜单，发送
const handlePrimaryClick = (e: MouseEvent<HTMLButtonElement>) => {
// 阻止冒泡到 DropdownMenuTrigger，避免误开菜单
e.stopPropagation();
// 关菜单
setMenuOpen(false);
// 触发发送（void 忽略 Promise）
void onSend();
};

return (
// DropdownMenu：modal=false 不抢焦点，受控开闭
<DropdownMenu
// 不开 modal 避免焦点陷阱影响输入条
modal={false}
// 禁用输入时强制关，否则受控
open={disableTextInput ? false : menuOpen}
// 开闭回调
onOpenChange={handleMenuOpenChange}
>
// 触发器：asChild 让 MessageSendButton 成为 trigger
<DropdownMenuTrigger asChild>
<MessageSendButton
// 录音时加 pulse + ring 高亮
className={cn(
voiceUiActive && voiceRecording && 'animate-pulse ring-teal-400/60',
)}
// 悬停展开菜单（禁用时不绑）
onPointerEnter={disableTextInput ? undefined : openMenu}
// 离开延时关菜单
onPointerLeave={disableTextInput ? undefined : scheduleCloseMenu}
// 点击：发送并关菜单
onClick={handlePrimaryClick}
// 发送禁用
disabled={sendDisabled}
// 无障碍文案
sendLabel={sendLabel}
>
// 主钮图标：按语音状态分发
<VoicePrimaryIcon
voicePrimaryShowsSend={voicePrimaryShowsSend}
voiceUiActive={voiceUiActive}
voiceTranscribing={voiceTranscribing}
voiceRecording={voiceRecording}
/>
</MessageSendButton>
</DropdownMenuTrigger>
// 菜单内容：向上弹出，右对齐
<DropdownMenuContent
// 向上弹出（菜单在输入条上方）
side="top"
// 右对齐
align="end"
// 与 trigger 间距 6px
sideOffset={6}
// 最小宽度 26（约 104px）
className="min-w-26"
// 进入菜单内容：清关闭定时器
onPointerEnter={clearCloseTimer}
// 离开菜单内容：延时关闭
onPointerLeave={scheduleCloseMenu}
// 关闭时阻止自动聚焦，避免抢走输入条焦点
onCloseAutoFocus={(e) => e.preventDefault()}
>
// 菜单标题：输入模式
<DropdownMenuLabel className="text-xs font-normal text-textcolor/60">
{labels?.inputMode ?? '输入模式'}
</DropdownMenuLabel>
// 分隔线
<DropdownMenuSeparator />
// 文本输入项
<DropdownMenuItem
className={cn(
// 间距
'gap-2',
// 当前模式高亮 teal
inputMode === 'text' &&
'text-teal-500 focus:text-teal-500 data-highlighted:text-teal-500',
)}
// 选中切到文本模式
onSelect={() => onInputModeChange('text')}
>
<Keyboard
className={cn(
// 图标尺寸
'h-3.5 w-3.5 shrink-0 text-textcolor/95',
// 当前模式高亮
inputMode === 'text' && 'text-teal-500',
)}
/>
{labels?.text ?? '文本输入'}
</DropdownMenuItem>
// 语音输入项
<DropdownMenuItem
className={cn(
'gap-2',
inputMode === 'voice' &&
'text-teal-500 focus:text-teal-500 data-highlighted:text-teal-500',
)}
// 选中切到语音模式
onSelect={() => onInputModeChange('voice')}
>
<Mic
className={cn(
'h-3.5 w-3.5 shrink-0 text-textcolor/95',
inputMode === 'voice' && 'text-teal-500',
)}
/>
{labels?.voice ?? '语音输入'}
</DropdownMenuItem>
</DropdownMenuContent>
</DropdownMenu>

}

// MessageSendControl 主体：按三态分发
export function MessageSendControl({
loading,
onStop,
stopLabel,
sendDisabled,
onSend,
sendLabel = '发送',
sendDisabledHint,
sendLoading,
voiceMenu,
className,
}: MessageSendControlProps) {
// 状态 1：生成中且有提供 onStop → 停止生成钮
if (loading && onStop) {
return <MessageStopButton onClick={onStop} stopLabel={stopLabel} />;
}

// 否则按是否传 voiceMenu 分流发送钮
const sendButton: ReactNode = voiceMenu ? (
// 状态 2：语音菜单态（Tauri 桌面端）
<VoiceMenuSendButton
voiceMenu={voiceMenu}
sendDisabled={sendDisabled}
sendLabel={sendLabel}
onSend={onSend}
/>
) : (
// 状态 3：纯发送钮（Web 端无语音）
<MessageSendButton
// 禁用时展示提示 title
title={sendDisabled ? sendDisabledHint : undefined}
sendLabel={sendLabel}
// 点击发送
onClick={() => void onSend()}
// 禁用
disabled={sendDisabled}
// loading 时转 spinner
loading={sendLoading}
/>
);

return (
// 外层容器：底边距 + flex 居中 + 间距
<div className={cn('mb-1 flex items-center gap-1', className)}>
{sendButton}
</div>
);
}

// 默认导出
export default MessageSendControl;
```

**变更摘要**：纯新增。`VoicePrimaryIcon` 按四态分发图标；`MessageStopButton` 独立停止钮；`VoiceMenuSendButton` 自带 `menuOpen`/`closeTimerRef` 菜单状态机（悬停展开、220ms 延时关、点击发送）；`MessageSendControl` 主体按 `loading&&onStop` / `voiceMenu` / 否则三态分发。

## 5. 验收清单

- [ ] 主对话发送：输入内容后点发送钮能正常发送；空内容时发送钮禁用并展示 `sendDisabledHint` title。
- [ ] 停止生成：生成中展示停止钮（rose 呼吸动画），点击停止。

- [ ] 知识库助手：loading 时发送钮转 spinner；有 stopGenerating 时变停止钮。
- [ ] 视觉：发送钮浅底渐变（teal 10%）+ ring 光晕，暗色主题下不刺眼；与 ChatEntry 旧实底样式对比确认更贴合卡片。
