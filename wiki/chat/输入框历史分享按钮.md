# 输入框内嵌历史与分享按钮

> 文档角色：本篇记录**智能对话页「历史对话 / 分享」入口从悬浮图标迁入输入框工具条**的实现（当前生效）。
>
> 延伸阅读：
> - 分享链路本身（勾选、顺序、附件）：[分享.md](./分享.md)
> - 历史抽屉行内重命名：[会话标题重命名.md](./会话标题重命名.md)
> - 输入条发送按钮三态封装：[消息发送按钮封装.md](./消息发送按钮封装.md)

## 1. 背景与目标

改动前，对话页左上角悬浮着一个 `History` 图标和（有会话 id 时）一个 `Waypoints` 分享图标，`absolute` 定位盖在消息区上，并用 `locale === 'zh-CN' ? 'left-29.5' : 'left-34.5'` 这种按界面语言硬编码像素的 hack 对齐侧边栏。问题有三：

- **遮挡与定位脆弱**：悬浮图标压在消息区上层，窄窗口或语言切换时位置靠手调像素维持，容易漂移。
- **可发现性差**：两个小图标没有文字，新用户不知道能点。
- **入口语义分散**：「新对话」在输入框工具条里，「历史对话」「分享」却悬浮在消息区，同一组会话级操作被拆到两处。

本轮把两个入口做成 ChatEntry 工具条里的正式按钮：「历史对话」排在「新对话」之后、「分享」排在「联网搜索」之后，图标 + 文字，悬浮图标块整体删除。

## 3. 实现思路

1. **入口内嵌而非悬浮**：按钮放进 ChatEntry 既有工具条（「新对话」「上传附件」「联网搜索」同一排），复用同一套 `lucide-stroke-draw-hover` 描边动画与 `bg-theme/5` 幽灵按钮样式，视觉与交互与其它入口一致；不再占消息区上层，也不需要按语言算左边距。
2. **全部可选 props，调用方零破坏**：`onHistoryClick` / `historyActive` / `onShareClick` / `showShare` 均为可选；不传就不渲染，知识库助手、英语 Agent 等其它复用 ChatEntry 的页面不受影响。
3. **状态语义保留**：历史抽屉已打开时按钮高亮（teal 描边 + 底色）且 `disabled` 禁点，与旧悬浮图标「打开后变 teal 不再响应点击」的行为对齐；`aria-pressed` 同步表达开关态。分享按钮沿用旧条件（有会话 id 且会话不在加载中、且不在分享勾选态），并沿用 `loading` 时禁点的工具条惯例。
4. **展示条件上收调用方**：`showShare` 由 chat 页计算（`params?.id && !isCurrentSessionLoading && !isSharing`）后传入，ChatEntry 只负责「给就渲染」，组件不发路由参数请求，保持纯展示。
5. **文案复用 + 新增**：历史按钮复用既有 `chat.sessionList.title`；分享按钮新增 `chat.share.action`，中英各一条。

无跨模块数据流、无分支失败路径与落库，属单域 UI 入口迁移，按规范略图。

## 5. 兼容性与影响

- **用户可感知**：对话页左上角悬浮的历史 / 分享小图标消失，改为输入框工具条里的「历史对话」「分享」文字按钮；打开历史抽屉后按钮高亮且不可再点。分享入口的可见条件不变（须已进入某条会话且会话加载完）。
- **兼容**：ChatEntry 4 个新 props 全部可选，知识库助手、英语学习 Agent、电子书助手等其它复用方不传即不渲染，行为零变化。
- **破坏性**：无；旧悬浮图标块及其 locale 定位 hack 彻底删除，无开关。

## 6. 风险与回归

建议回归路径：

- 新会话（无 id）：工具条有「新对话」「历史对话」，无「分享」；发首条消息得到会话 id 后「分享」出现。
- 打开历史抽屉：历史按钮变 teal 高亮且不可再点；关掉抽屉恢复可点。
- 分享勾选态：进入分享后「分享」按钮消失（`isSharing` 为 true），退出分享态恢复。
- 生成中：分享与联网搜索按钮均禁点，历史按钮不受影响。
- 语言切换 en-US：按钮文字变 History / Share，布局不再依赖语言相关像素 hack。
- 知识库助手 / 英语 Agent 页：输入框工具条不出现这两个按钮（未传 props）。
