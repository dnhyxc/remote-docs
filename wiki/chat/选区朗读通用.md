# 选区朗读通用化重构：`SelectionSpeak` 组件化与跨域复用

> **现行实现见** [助手选区朗读指南.md](./助手选区朗读指南.md)。本文保留为**历史 / 重构对照**（改前改后、组件化过程），不作为现行 API 说明书。

## 1. 背景与目标

此前，选区朗读功能仅在「英语学习 Agent」中实现，核心逻辑散落在 `views/englishLearning/agent/` 目录下，无法被「电子书 MOKE 助手」等其它对话场景复用。

本次重构的核心目标是将**选区朗读能力通用化**，将其抽离至 `components/design/SelectionSpeak` 目录，封装为标准的 `@design` 组件，使其能被任何需要文本朗读的聊天助手（英语学习、电子书、未来的知识库助手等）直接复用。

## 2. 改动范围

## 3. 实现思路

### 3.1 功能组件化

将选区朗读的核心能力从「英语学习」业务域中抽离，形成独立的 `design/SelectionSpeak` 模块。采用 **两层架构**：

- **底层 `useSelectionSpeak`**：纯状态管理 Hook，负责 TTS 播放控制、暂停/恢复/倍速、句子高亮预览更新。不涉及任何 UI 渲染。
- **顶层 `SelectionSpeakBar`**：纯 UI 组件，根据 `useSelectionSpeak` 返回的状态渲染悬浮控制条（播放/暂停、停止、倍速调节），支持拖动和缩放。

两者解耦，`useSelectionSpeak` 也可独立用于非 UI 场景（如单元测试或后台播放）。

### 3.2 助手级集成 Hook

新增 `useAssistantSelectionSpeak` Hook，作为助手组件的**一站式集成入口**。它封装了：

- 选区右键菜单项的生成（`getSelectionContextMenuItems`）
- Footer 上悬浮控制条的渲染（`floatAbove`）
- 对外暴露 `stop` 方法供外部调用
- 开播前钩子（`onBeforeStart`），用于电子书场景中先停掉章节听书
- 控制条的拖动边界自动解析（通过 `[data-app-layout]` 选择器定位 Layout 根节点，无需传面板 ref）

调用方只需：
```typescript
const selectionSpeak = useAssistantSelectionSpeak({ onBeforeStart });
```
即可获得完整的选区朗读能力，无需分别处理菜单、控制条和播放逻辑。

### 3.3 悬浮控制条交互增强

旧版控制条仅是一个固定在输入框上方的简单横条。新版引入：

- **拖动支持**：用户可通过左侧拖动手柄将控制条拖到 Layout 内任意位置，拖动后控制条切换为 `position: fixed` 定位，始终限制在 `[data-app-layout]` 边界内。
- **缩放支持**：右下角（`se`）和右上角（`ne`）两个缩放角，可调整控制条的宽高。当高度超过 `72px` 时自动切换为纵向布局（文本在上、操作按钮在下），低于则保持横向布局。
- **边界自适应**：面板尺寸变化时（如窗口缩放），`ResizeObserver` 会自动校正控制条位置和尺寸，防止溢出。
- **自定义初始尺寸**：通过 `initialWidth`/`initialHeight` 属性可指定控制条的初始大小，电子书助手场景设置为 `344px`。

### 3.4 语言键名通用化

将原先绑定在 `englishLearning.selection.*` 下的国际化键名迁移至 `assistant.selection.*`，使其适用于所有助手场景（英语学习、电子书等）。

**改动后** · `apps/frontend/src/components/design/SelectionSpeak/useSelectionSpeak.ts`（当前，约 L37-L278）

```typescript
// 新版：引入 onAudioTime 回调获取真实音频进度，配合 onSentence 做降级
export function useSelectionSpeak() {
    // 新增多个 ref 用于精确控制
    const shownSiRef = useRef(0);       // 当前已展示的句下标，避免重复 setPreview
    const audioClockRef = useRef(false);  // 是否已拿到真实音频时钟（duration > 0）
    const waitingRef = useRef(false);     // 是否正在等待当前段 TTS（loading 态）
    const delayTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null); // 延迟定时器

    // 封装清除延迟定时器的逻辑，防止停播后仍改 preview
    const clearDelay = useCallback(() => {
        if (delayTimerRef.current == null) return;
        clearTimeout(delayTimerRef.current);
        delayTimerRef.current = null;
    }, []);

    const start = useCallback((rawText: string) => {
        // ...
        const ok = await playListenPlainText(plain, {
            // 真实音频时钟回调：优先使用 speech 与听书同一套 cadence 句下标
            onAudioTime: ({ baseSi, duration, sentenceIndex }) => {
                // 会话已过期则忽略
                if (seq !== seqRef.current) return;
                // duration 无效时只钉到本段首句，不锁死 audioClock
                if (!(duration > 0) || !Number.isFinite(duration)) {
                    applySentence(baseSi);
                    return;
                }
                // 拿到真实进度后锁死 audioClock，不再依赖 onSentence
                audioClockRef.current = true;
                clearDelay();
                // 用真实 sentenceIndex 计算当前句
                const clipSi = typeof sentenceIndex === 'number' && Number.isFinite(sentenceIndex)
                    ? Math.max(0, sentenceIndex) : 0;
                applySentence(baseSi + clipSi);
            },
            // 估句回调：仅在无真实进度时作降级；延迟 CADENCE_LEAD 抵消提前量
            onSentence: (si, info) => {
                if (seq !== seqRef.current) return;
                // 首包 80% 提前切句：下一句音频还没出，跳过
                if (info.early) return;
                // 已有真实进度或正在等待 TTS 时完全交给 onAudioTime
                if (audioClockRef.current || waitingRef.current) return;
                // 本机等无 progress：抵消 cadence 的 0.35s lead（随语速缩短延迟）
                clearDelay();
                const delayMs = (CADENCE_LEAD_SEC / Math.max(RATE_MIN, rateRef.current)) * 1000;
                delayTimerRef.current = setTimeout(() => {
                    delayTimerRef.current = null;
                    if (seq !== seqRef.current) return;
                    // 延迟期间若已拿到真实时钟，则丢弃这次估句
                    if (audioClockRef.current) return;
                    applySentence(si);
                }, delayMs);
            },
        });
        // ...
    }, [applySentence, clearDelay]);

    // 停止朗读：作废会话、清状态与预览，并硬停底层播放
    const stop = useCallback(() => {
        seqRef.current += 1;
        pausedRef.current = false;
        audioClockRef.current = false;
        waitingRef.current = false;
        shownSiRef.current = 0;
        clearDelay();
        textRef.current = '';
        plainRef.current = '';
        sentencesRef.current = [];
        stopAllPlayback();
        setStatus('idle');
        setPreview('');
    }, [clearDelay]);
    // ...
}
```

**变更摘要**：新版引入 `onAudioTime` 真实音频进度回调作为主要句更新来源，`onSentence` 仅在无音频时钟时做降级（带延迟补偿）。同时新增多个 ref 精确管理会话状态，避免竞态条件。

```typescript
// 新版：支持拖拽、缩放、自适应布局的悬浮控制条
// 拖动边界通过全局 [data-app-layout] 选择器自动解析，无需调用方传 ref
const LAYOUT_BOUNDS_SEL = '[data-app-layout]';

// 解析 Layout 根节点作为拖动/缩放边界
function resolveBoundsEl(): HTMLElement {
    return (
        document.querySelector<HTMLElement>(LAYOUT_BOUNDS_SEL) ??
        document.documentElement
    );
}

// 尺寸状态：null 表示未设尺寸，走默认 class + 内容高
const [size, setSize] = useState<Size | null>(() =>
    resolveInitialSize(initialWidth, initialHeight),
);
const sizeRef = useRef<Size | null>(size);

// 拖动时将控制条从 absolute 切换为 fixed 定位
const promoteToFixed = useCallback((bar, barRect, box) => {
    if (fixedPosRef.current == null) {
        bar.classList.remove('absolute', 'bottom-full', 'left-1/2', 'mb-[9px]', '-translate-x-1/2');
        bar.classList.add('fixed');
        applyFixedStyle(current);
        setFixedPos(current);
    }
    return current;
}, [applyFixedStyle]);

// 右下角缩放：底边固定，向下/向右扩展
const onResizePointerDown = useCallback((corner) => (e) => {
    // 记录起始位置和尺寸
    const originW = sizeRef.current?.w ?? barRect.width;
    const originH = sizeRef.current?.h ?? barRect.height;
    // 首次缩放时初始化尺寸状态
    if (sizeRef.current == null) {
        const seeded = clampSize(originW, originH, box, pos.left, pos.top);
        sizeRef.current = seeded;
        setSize(seeded);
    }
    // ...
}, [boundsRef, promoteToFixed, applySizeStyle]);

// 右上角缩放：底边固定，向上增高
const onResizePointerMove = useCallback((e) => {
    if (resize.corner === 'ne') {
        // clampSizeNe 固定底边，计算新的 top
        const { size: next, top } = clampSizeNe(
            resize.originW + dx,    // 新宽度
            resize.originH - dy,    // 新高度（向上拖为正）
            resize.box,
            resize.left,
            resize.bottom,  // 固定底边
        );
        // 尺寸跨越 STACK_H 阈值时触发布局切换
        if (prevH >= STACK_H !== next.h >= STACK_H) {
            setSize(next);
            setFixedPos(pos);
        }
    }
    // ...
}, [applySizeStyle, applyFixedStyle]);

// 渲染时根据 stacked 状态切换布局
const stacked = (size?.h ?? 0) >= STACK_H;

return (
    <div
        ref={barRef}
        className={cn(
            // 根据是否有尺寸决定是否应用默认宽度 class
            !sized && width,
            'relative z-9999 flex gap-1 rounded-md border border-theme/10 ...',
            isFixedVisual
                ? 'fixed'
                : 'absolute bottom-full left-1/2 mb-[9px] -translate-x-1/2',
            // 纵向布局时 flex-col，横向时 flex-row
            stacked ? 'flex-col items-stretch px-0' : 'flex-row items-center px-1.5',
        )}
        style={{
            // 动态绑定 left/top（拖动位置）和 width/height（缩放尺寸）
            ...(isFixedVisual && fixedPosRef.current
                ? { left: fixedPosRef.current.left, top: fixedPosRef.current.top }
                : null),
            ...(sized
                ? { width: (sizeRef.current ?? size).w, height: (sizeRef.current ?? size).h }
                : null),
        }}
    >
        {stacked ? (
            // 纵向布局：文本在上，操作按钮在下
            <>
                <SpeakPreview text={preview} stacked />
                {controls}
            </>
        ) : (
            // 横向布局：操作按钮在左，文本在右
            <>
                {controls}
                <SpeakPreview text={preview} stacked={false} />
            </>
        )}
        // 右下角缩放手柄（SE 角）
        <button onPointerDown={onResizePointerDown('se')} onPointerMove={onResizePointerMove} ... />
        // 右上角缩放手柄（NE 角）
        <button onPointerDown={onResizePointerDown('ne')} onPointerMove={onResizePointerMove} ... />
    </div>
);
```

**变更摘要**：引入 `Size` 状态管理宽高，两个缩放手柄（`ne`/`se`），当高度跨越 `STACK_H`（72px）阈值时自动切换横/纵布局。拖拽首次触发时将控制条从 `absolute` 切换为 `fixed` 定位。拖动边界通过 `[data-app-layout]` 选择器自动解析，不再需要调用方传 `boundsRef`。

```typescript
// 新版：封装为通用 Hook，助手组件只需一行调用即可接入
// 不再需要传 boundsRef——控制条通过 [data-app-layout] 选择器自动定位边界
export function useAssistantSelectionSpeak(
    // 参数兼容：传 () => void（仅 onBeforeStart）或 options 对象
    opts?: (() => void) | AssistantSelectionSpeakOptions,
) {
    // 内部处理 i18n 上下文，调用方无需关心
    const { t } = useI18n();
    // 调用底层 Hook 获取播放控制逻辑
    const speak = useSelectionSpeak();

    // 兼容函数简写：传 () => void 等同于 { onBeforeStart: () => void }
    const normalized = typeof opts === 'function' ? { onBeforeStart: opts } : (opts ?? {});
    // 用 ref 存 onBeforeStart，避免闭包陈旧
    const onBeforeStartRef = useRef(normalized.onBeforeStart);
    onBeforeStartRef.current = normalized.onBeforeStart;
    const initialWidth = normalized.initialWidth;
    const initialHeight = normalized.initialHeight;

    // 封装 start 方法：开播前先调用外部钩子（如听书页先停章节听书）
    const start = useCallback((text: string) => {
        onBeforeStartRef.current?.();
        return speak.start(text);
    }, [speak.start]);

    // 生成右键菜单项工厂，内部已用通用 i18n 键名
    const getSelectionContextMenuItems = useMemo(
        () => createSelectionSpeakMenu(t, start),
        [t, start],
    );

    // 生成悬浮控制条 JSX，内部处理 visible 逻辑
    // SelectionSpeakBar 内部自动通过 [data-app-layout] 解析拖动边界
    const floatAbove = useMemo(
        () =>
            speak.visible ? (
                <SelectionSpeakBar
                    status={speak.status}
                    rate={speak.rate}
                    preview={speak.preview}
                    onTogglePlay={speak.togglePlay}
                    onStop={speak.stop}
                    onRateChange={speak.setRate}
                    initialWidth={initialWidth}
                    initialHeight={initialHeight}
                />
            ) : null,
        [boundsRef, speak.visible, speak.status, speak.rate, speak.preview, ...],
    );

    // 对外暴露统一接口
    return { getSelectionContextMenuItems, floatAbove, stop: speak.stop, visible: speak.visible };
}
```

**变更摘要**：`useAssistantSelectionSpeak` 作为桥接层，将底层 `useSelectionSpeak`、菜单工厂和 UI 组件封装为一个开箱即用的接口。调用方只需传入可选配置，即可获得完整的选区朗读能力。控制条的拖动边界通过 `[data-app-layout]` 选择器自动解析，不再需要传 `boundsRef`。
