# 登出统一 + 多窗主题同步（performLogout + setThemeToAllWindows）

> 归档态实现说明。关于窗轻量化与菜单「关于」分支见 [./关于窗口轻量化.md](../tauri/关于窗口轻量化.md)、[./Tauri系统菜单快捷键.md](../tauri/Tauri系统菜单快捷键.md)。

## 1. 背景与目标

桌面端有**三处登出入口**（侧边栏按钮、File 菜单「退出登录」、token 401 自动登出），原本各自手写清态逻辑，导致：

1. **逻辑漂移**：侧边栏 `onLogout` 只清 `token` + `userStore.clearUserInfo()` + `navigate('/login')`，缺 `http.setAuthToken('')` 与 `userInfoChanged` 事件；File 菜单 `listen('logout')` 只清 `token` + `http.setAuthToken('')`，不跳转、不清 `userStore`；401 走 `notifyUnauthorized` 又是另一套。三处行为不一致，切换账号后偶发残留。
2. **多窗主题不同步**：`changeTheme` 只写 store + `onEmit('theme')`，关于窗等子窗标题栏不跟随；`onCreateWindow` 已存在窗只 `setFocus`，主题变化后子窗仍用旧主题。
3. **关于窗首帧主题被系统接管**：原代码 `await getValue('theme')` 异步读主题，首帧常取 `undefined`，被系统深色接管。

本改动：①新增 `performLogout(navigate?)` 集中清态 + 跳转，侧边栏 / File 菜单 / 401 都复用；②`changeTheme` 改写后 `setThemeToAllWindows(chrome)` 同步所有 Tauri 窗标题栏（含 about）；③新增 `readWindowChromeThemeSync()` 从 localStorage 同步读主题，`onCreateWindow` 与关于窗 listen 用它预对齐；④`onCreateWindow` 已存在窗先 `setTheme` 再 `unminimize + show + setFocus`。

## 2. 改动范围

- `apps/frontend/src/router/authSession.ts`（新增 `performLogout`）
- `apps/frontend/src/router/index.tsx`（`listen('logout')` 改 `performLogout`）
- `apps/frontend/src/components/design/Sidebar/index.tsx`（`onLogout` 改 `performLogout`）
- `apps/frontend/src/hooks/theme.ts`（新增 `readWindowChromeThemeSync`；`changeTheme` 加 `setThemeToAllWindows`）
- `apps/frontend/src/utils/tauri.ts`（`onCreateWindow` 已存在窗 `setTheme + show + setFocus`；`setThemeToAllWindows` 已存在，本次被 `changeTheme` 调用）
- `apps/frontend/src/hooks/i18n.ts`（`getValue/setValue` 改从 `@/utils/store` 引，避免聚合出口循环依赖）

## 3. 实现思路

1. **`performLogout` 单点清态**：同步清 `localStorage.token/userInfo` + `resetUserState()` + `dispatchEvent('userInfoChanged')`，再异步 `http.setAuthToken('')` 与 `userStore.clearUserInfo()`，最后按 `navigate` 是否传入决定 `navigate('/login')` 还是 `window.location.replace('/login')`。
2. **避免循环依赖**：`performLogout` 不静态 `import userStore/http`，改 `void import('@/utils/fetch').then(...)` 与 `void import('@/store/user').then(...)` 动态引，绕开 `utils ↔ authSession ↔ store` 静态循环。
3. **三入口复用**：侧边栏 `onLogout` 传 `navigate`；File 菜单 `listen('logout')` 传 `router.navigate`；401 `notifyUnauthorized` 内部已对齐 `performLogout` 清态逻辑（仅跳转策略不同）。
4. **`changeTheme` 同步多窗**：改写 `theme`/`themeType` 到 store 后，`void import('@/utils/tauri').then(({ setThemeToAllWindows }) => setThemeToAllWindows(chrome))` 把 `chrome`（black→dark，其余→light）广播给所有 Tauri 窗口（含 about）。
5. **`readWindowChromeThemeSync` 同步读**：从 `localStorage.dnhyxc_theme_bootstrap` → `dnhyxc_settings_json.theme/themeType` → 旧 `theme` 三级回退，**同步**返回 `'light' | 'dark'`，供 `onCreateWindow` 与关于窗 listen 首帧预对齐。
6. **`onCreateWindow` 已存在窗 setTheme**：拿到 `existing` 后先 `setTheme(theme)`（try/catch 容错），再 `unminimize + show + setFocus`，确保子窗第二次打开时主题跟着主窗变。

### 4.1 集中清态入口（`apps/frontend/src/router/authSession.ts` · `performLogout`）

**对比范围**：新增 `performLogout` 函数（旧版无对应物，仅有 `notifyUnauthorized`）。

**改动后** · `apps/frontend/src/router/authSession.ts`（当前，约 L1–L28）

```typescript
// 顶层只静态 import 不依赖 utils/store 的两个模块，避免循环依赖
import { requiresAuthForPath } from '@/router/authPaths';
import { resetUserState } from '@/store/resetUserState';

// 401 去重标志
let handlingUnauthorized = false;

/** 主动退出登录（含 Tauri 菜单）：清登录态并跳转登录页 */
export function performLogout(
	// navigate 可选：传入则用 SPA navigate，不传则 window.location.replace 整页刷新
	navigate?: (to: string) => void | Promise<void>,
): void {
	// SSR 兜底，window 未定义直接返回
	if (typeof window === 'undefined') return;

	// 同步清 storage，避免 userStore 静态 import 造成 utils↔authSession 循环依赖
	// token 必清
	localStorage.removeItem('token');
	// userInfo 也清（部分页面从 localStorage 直接读）
	localStorage.removeItem('userInfo');
	// resetUserState：清各 MobX store 的用户态（书架/草稿/助手对话等）
	resetUserState();
	// 派发 userInfoChanged 事件，让监听该事件的组件（头像/侧栏等）即时刷新
	window.dispatchEvent(new Event('userInfoChanged'));

	// 异步清 http Authorization header：动态 import 避免静态循环
	void import('@/utils/fetch').then(({ http }) => http.setAuthToken(''));
	// 异步清 userStore.userInfo：动态 import 避免静态循环
	void import('@/store/user').then((m) => m.default.clearUserInfo());

	// 跳转策略：有 navigate 用 SPA，否则整页 replace
	if (navigate) {
		// SPA navigate：保留 React 状态但切到 /login
		void navigate('/login');
		return;
	}
	// 无 navigate：若当前不在 /login 则整页 replace（更彻底，适合菜单触发）
	if (window.location.pathname !== '/login') {
		window.location.replace('/login');
	}
}
```

**变更摘要**：新增 `performLogout`——同步清 `token/userInfo` + `resetUserState` + `userInfoChanged` 事件，异步清 `http` header 与 `userStore`，按 `navigate` 是否传入决定 SPA 或整页跳转；动态 import 规避静态循环依赖。

**改动后** · `apps/frontend/src/hooks/theme.ts`（当前，约 L1–L3 + L117–L136 + L283–L300）

```typescript
// 新 import：拆细——onEmit 从 @/utils/event，getValue/setValue 从 @/utils/store
import { useEffect, useState } from 'react';
import { onEmit } from '@/utils/event';
import { getValue, setValue } from '@/utils/store';

// 新增：Tauri 窗口标题栏 light/dark，与 changeTheme 写入的 theme 一致（black→dark，其余→light）
export function readWindowChromeThemeSync(): 'light' | 'dark' {
	// 一级回退：bootstrap storage（首屏同步读，避免闪烁）
	const name = readThemeBootstrapSync();
	// black 主题 → dark 标题栏
	if (name === 'black') return 'dark';
	// 其它已命名主题 → light 标题栏
	if (name) return 'light';
	try {
		// 二级回退：dnhyxc_settings_json（tauri-plugin-store 在 localStorage 的镜像）
		const j = localStorage.getItem('dnhyxc_settings_json');
		if (j) {
			const o = JSON.parse(j) as { theme?: string; themeType?: string };
			// theme 字段优先（changeTheme 写的 chrome 值）
			if (o.theme === 'dark' || o.theme === 'light') return o.theme;
			// themeType=black → dark
			if (o.themeType === 'black') return 'dark';
			// 其它 themeType → light
			if (o.themeType) return 'light';
		}
	} catch {
		// ignore：JSON 解析失败回退
	}
	// 三级回退：旧 theme key（兼容老版本）
	const legacy = localStorage.getItem('theme');
	if (legacy === 'dark' || legacy === 'light') return legacy;
	// 兜底：light（避免 undefined 被系统深色接管）
	return 'light';
}

// ... 改造后的 changeTheme
const changeTheme = async (themeName: ThemeName, emit = true) => {
	const themeItem = THEMES.find((t) => t.name === themeName);
	if (themeItem?.type === 'color') {
		setTheme(themeName);
		setThemeClass(themeName);
		persistThemeBootstrap(themeName);
		// chrome = black→dark，其余→light，与 Tauri 窗标题栏语义对齐
		const chrome = themeName === 'black' ? 'dark' : 'light';
		// 写 store：theme（chrome）+ themeType（主题名）
		await setValue('theme', chrome);
		await setValue('themeType', themeName);
		// 同步所有 Tauri 窗标题栏（含 about）
		// 动态 import 避免静态循环：theme.ts ↔ utils/tauri ↔ utils/store
		void import('@/utils/tauri').then(({ setThemeToAllWindows }) => {
			void setThemeToAllWindows(chrome);
		});
	}
	if (emit) {
		// 发主题变化事件，各页面监听 onListen('theme') 跟随
		onEmit('theme', themeName);
	}
};
```

**变更摘要**：新增 `readWindowChromeThemeSync`——三级回退（bootstrap → settings_json → 旧 theme）同步读 chrome 主题；`changeTheme` 写完 store 后 `setThemeToAllWindows(chrome)` 广播给所有 Tauri 窗口；`import` 拆细避免循环依赖。

## 5. 兼容性与影响

- **登出三入口行为统一**：侧边栏 / File 菜单 / 401 都走 `performLogout` 或其清态子集，避免逻辑漂移；切换账号后不再残留上一账号 userStore / http header。
- **多窗主题同步**：主窗切主题后 `setThemeToAllWindows` 广播给 about 等所有子窗；`onCreateWindow` 已存在窗也 `setTheme`；关于窗首帧用 `readWindowChromeThemeSync` 预对齐。
- **循环依赖**：`performLogout` / `changeTheme` 用动态 import 规避 `utils ↔ authSession ↔ store` 静态循环；`hooks/i18n.ts` / `hooks/theme.ts` 拆细 import。
- **回归点**：①侧边栏点登出后 token / userInfo / userStore / http header 是否全清；②File 菜单「退出登录」是否走 SPA 跳转（不整页刷新）；③主窗切深色后已开的关于窗标题栏是否跟随；④关于窗第二次打开主题是否与主窗一致；⑤401 自动登出与手动登出清态是否一致。
