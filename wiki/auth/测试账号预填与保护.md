## 1. 背景与目标

为在线演示与联调，需要一个**固定的测试账号**：用户访问首页时带 `?u=dnhyxc-ai` 查询参数，登录页自动预填用户名和密码（掩码），用户一键登录；登录后该账号**禁止修改资料、购买会员、忘记密码、绑定/解绑微信**，防止演示账号被篡改导致后续用户无法体验。

核心诉求：

1. **预填**：URL 带 `u=dnhyxc-ai` 时，登录页用户名/密码自动填入；密码字段只存掩码（`••••`），审查元素不泄露真密码。
2. **跨页保持**：从首页跳到登录页时，通过 `sessionStorage` 记住演示提示，登录页无需再带 URL 参数也能预填。
3. **保护**：测试账号在个人资料、账号设置、会员充值、忘记密码、微信绑定等入口一律拦截并 Toast 提示。
4. **脱敏**：个人资料页对测试账号邮箱做中间脱敏显示。

## 3. 实现思路

### 3.1 预填数据流

```
.env (VITE_DEMO_LOGIN_USERNAME/PASSWORD)
  → constants/index.ts (DEMO_LOGIN_USERNAME / DEMO_LOGIN_PASSWORD / MASK)
    → URL ?u=dnhyxc-ai → rememberDemoLoginHint → sessionStorage
      → getDemoLoginPrefill → login-form defaultValues
        → onSubmit → resolveDemoLoginPassword(掩码→真密码) → encrypt → login API
```

### 3.2 关键决策

1. **密码只存掩码**：`DEMO_LOGIN_PASSWORD_MASK = '•'.repeat(len)`，表单 DOM 永远不包含真密码，审查元素只能看到圆点；提交时 `resolveDemoLoginPassword` 将掩码还原为真密码再加密。
2. **条件校验绕行**：演示账号密码是掩码（全是 `•`），无法通过正常密码强度校验（≥8 位 + 字母+数字+特殊符号）。`formSchema` 从 `z.object().superRefine()` 改为条件分支：命中演示账号 + 掩码密码 → 跳过校验；否则走原有强度规则。
3. **`sessionStorage` 跨页保持**：首页带 `?u=dnhyxc-ai` 时写入 `sessionStorage`；跳到登录页时无需 URL 参数也能从 `sessionStorage` 读取预填；登录成功或首页无参数时清除。
4. **保护统一出口**：`isProtectedAccountUsername` = `isDemoLoginUsername`，二者同源（`PROTECTED_ACCOUNT_USERNAME = DEMO_LOGIN_USERNAME`），所有页面只需调一个函数。
5. **密码框禁止显示**：`revealable={!hidePasswordReveal}` + `readOnly={hidePasswordReveal}`，测试账号时密码框不可点击显示、不可编辑，防止用户修改掩码后无法登录。
6. **邮箱脱敏**：`maskEmail` 对本地名 >5 位的邮箱保留首 3 + 尾 3，中间替换为 `*`；≤5 位保留首尾各 1；≤2 位全替换。

export * from './membershipPlans';

export const DEMO_LOGIN_USERNAME =
// 读取 VITE_DEMO_LOGIN_USERNAME 环境变量，trim 后使用；未配置时回退空串

// 密码掩码：用圆点替换真密码，长度与真密码一致；表单 DOM 只存此掩码

export const PROTECTED_ACCOUNT_USERNAME = DEMO_LOGIN_USERNAME;

export function isDemoLoginUsername(u?: string | null): boolean {
// 仅当配置了演示用户名且传入值精确匹配时返回 true
	return Boolean(DEMO_LOGIN_USERNAME) && u === DEMO_LOGIN_USERNAME;
}
// 判定给定用户名是否为受保护账号：当前等同 isDemoLoginUsername
export function isProtectedAccountUsername(username?: string | null): boolean {
// 直接委托给 isDemoLoginUsername，保持单一真相源
	return isDemoLoginUsername(username);
}
// sessionStorage 中存储演示用户名的键名
const DEMO_LOGIN_HINT_KEY = 'demoLoginUsername';
/**
 * 记住/清除演示登录提示：仅未登录且 URL 含 u=演示用户名 时写入 sessionStorage
 */
export function rememberDemoLoginHint(
// URL 查询参数 u 的值
	u?: string | null,
// 当前路径名，用于区分首页与其他页面
	pathname?: string,
): void {
// SSR 安全守卫：无 sessionStorage 时直接返回
	if (typeof sessionStorage === 'undefined') return;
// 判断当前是否已登录（有有效 token）
	const loggedIn = hasValidAuthToken();
// 首页特殊处理：首页带 u 参数且未登录时写入提示，否则清除
	if (pathname === '/') {
// 未登录且 u 是演示用户名 → 写入 sessionStorage
		if (!loggedIn && isDemoLoginUsername(u)) {
			sessionStorage.setItem(DEMO_LOGIN_HINT_KEY, DEMO_LOGIN_USERNAME);
		} else {
// 已登录或非演示用户名 → 清除提示
			sessionStorage.removeItem(DEMO_LOGIN_HINT_KEY);
		}
// 首页处理完毕
		return;
	}
// 非首页：已登录时清除提示
	if (loggedIn) {
		sessionStorage.removeItem(DEMO_LOGIN_HINT_KEY);
// 已登录则直接返回
		return;
	}
// 未登录且 u 为空或空串时不做操作
	if (u == null || u === '') return;
// 非首页、未登录、u 是演示用户名 → 写入
	if (isDemoLoginUsername(u)) {
		sessionStorage.setItem(DEMO_LOGIN_HINT_KEY, DEMO_LOGIN_USERNAME);
// 写入后返回
		return;
	}
// 非演示用户名 → 清除旧提示
	sessionStorage.removeItem(DEMO_LOGIN_HINT_KEY);
}
/**
 * 获取演示登录预填数据：URL 或 sessionStorage 命中时返回 {username, password(掩码)}
 */
export function getDemoLoginPrefill(): {
// 返回的用户名（演示用户名）
	username: string;
// 返回的密码（掩码，非真密码）
	password: string;
// 未命中时返回 null
} | null {
// SSR 安全守卫
	if (typeof window === 'undefined') return null;
// 从当前 URL 查询参数取 u
	const fromUrl = new URLSearchParams(window.location.search).get('u');
// 调用 rememberDemoLoginHint 维护 sessionStorage 状态
	rememberDemoLoginHint(fromUrl, window.location.pathname);
// 从 sessionStorage 读取已记住的演示用户名
	const hinted = sessionStorage.getItem(DEMO_LOGIN_HINT_KEY);
// URL 和 sessionStorage 都未命中 → 不预填
	if (!isDemoLoginUsername(fromUrl) && !isDemoLoginUsername(hinted)) {
		return null;
	}
// 命中时返回演示用户名 + 密码掩码
	return {
		username: DEMO_LOGIN_USERNAME,
		password: DEMO_LOGIN_PASSWORD_MASK,
	};
}
/** 掩码 → 真密码；非演示账号或非掩码时原样返回 */
export function resolveDemoLoginPassword(
// 表单中的用户名
	username: string,
// 表单中的密码字段值（可能是掩码或用户输入的真密码）
	passwordField: string,
): string {
// 演示账号且密码字段恰好是掩码 → 返回真密码
	if (
		isDemoLoginUsername(username.trim()) &&
		passwordField === DEMO_LOGIN_PASSWORD_MASK
	) {
		return DEMO_LOGIN_PASSWORD;
	}
// 其它情况（非演示账号、或用户手动输入的密码）原样返回
	return passwordField;
}
/** 邮箱中间脱敏：如 2254180771@qq.com → 225****771@qq.com */
export function maskEmail(email: string): string {
// 找到 @ 符号位置
	const at = email.indexOf('@');
// 无 @ 或 @ 在首位 → 不脱敏，原样返回
	if (at <= 0) return email;
// 本地名（@ 前部分）
	const local = email.slice(0, at);
// 域名部分（@ 及之后）
	const domain = email.slice(at);
// 本地名 ≤2 位 → 全替换为 *
	if (local.length <= 2) return '*'.repeat(local.length) + domain;
// 本地名 ≤5 位 → 保留首尾各 1 位，中间替换为 *
	if (local.length <= 5) {
		return `${local[0]}${'*'.repeat(local.length - 2)}${local.slice(-1)}${domain}`;
	}
// 本地名 >5 位 → 保留首 3 + 尾 3，中间替换为 *
	const head = 3;
	const tail = 3;
	return `${local.slice(0, head)}${'*'.repeat(local.length - head - tail)}${local.slice(-tail)}${domain}`;
}

**改动前** · `apps/frontend/src/views/login/login-form.tsx`（基线，约 L64–L98，`formSchema` + `useForm`）

```typescript
// 旧版 formSchema：z.object 内联校验，密码必须 ≥8 位 + 字母+数字+特殊符号
const formSchema = z.object({
// 用户名：trim 后至少 2 字符
	username: z
		.string()
		.trim()
		.min(2, {
			message: t('auth.validation.usernameMin'),
		}),
// 密码：trim 后 ≥8 位 + 必须含字母+数字+特殊符号（演示掩码无法通过）
	password: z
		.string()
		.trim()
		.min(8, { message: t('auth.validation.passwordMin') })
		.regex(
			/^(?=.*[A-Za-z])(?=.*\d)(?=.*[!@#$%^&*()_+\-=[\]{};':"\\|,.<>/?]).+$/,
			{
				message: t('auth.validation.passwordComplex'),
			},
		),
// 验证码：trim 后至少 4 字符
	captchaText: z
		.string()
		.trim()
		.min(4, {
			message: t('auth.validation.captchaMin'),
		}),
});
// 旧版 useForm：defaultValues 全空，无预填
const form = useForm<z.infer<typeof formSchema>>({
// zod 解析器
	resolver: zodResolver(formSchema),
// 默认值：用户名和密码都为空
	defaultValues: {
		username: '',
		password: '',
		captchaText: '',
	},
});
```

**改动后** · `apps/frontend/src/views/login/login-form.tsx`（当前，约 L74–L139，`formSchema` + `useForm` + 预填逻辑）

```typescript
// 从 constants 导入演示账号相关常量与函数
import {
// 密码掩码常量
	DEMO_LOGIN_PASSWORD_MASK,
// 获取预填数据函数
	getDemoLoginPrefill,
// 判定是否为演示用户名
	isDemoLoginUsername,
// 掩码 → 真密码还原函数
	resolveDemoLoginPassword,
} from '@/constants';
// ...（未改动：其他 import）
// 新版 formSchema：z.object 基础结构 + superRefine 条件校验
const formSchema = z
	.object({
// 用户名：trim 后 ≥2 字符
		username: z
			.string()
			.trim()
			.min(2, {
				message: t('auth.validation.usernameMin'),
			}),
// 密码：trim 后 ≥1 字符（下限降低，真正强度校验移到 superRefine）
		password: z.string().trim().min(1, {
			message: t('auth.validation.passwordMin'),
		}),
// 验证码：trim 后 ≥4 字符
		captchaText: z
			.string()
			.trim()
			.min(4, {
				message: t('auth.validation.captchaMin'),
			}),
	})
// superRefine：根据是否演示账号决定是否跳过密码强度校验
	.superRefine((data, ctx) => {
// 演示账号且密码是掩码 → 跳过所有密码校验（掩码不是真密码，无法通过强度规则）
		if (
			isDemoLoginUsername(data.username) &&
			data.password === DEMO_LOGIN_PASSWORD_MASK
		) {
// 直接返回，不添加任何 issue
			return;
		}
// 非演示账号：密码 <8 位 → 报错
		if (data.password.length < 8) {
			ctx.addIssue({
// 自定义 issue 类型
				code: 'custom',
// 报错字段：password
				path: ['password'],
// 报错文案
				message: t('auth.validation.passwordMin'),
			});
// 报错后返回，不再检查复杂度
			return;
		}
// 非演示账号：密码不含字母+数字+特殊符号 → 报错
		if (
			!/^(?=.*[A-Za-z])(?=.*\d)(?=.*[!@#$%^&*()_+\-=[\]{};':"\\|,.<>/?]).+$/.test(
				data.password,
			)
		) {
			ctx.addIssue({
// 自定义 issue
				code: 'custom',
// 报错字段：password
				path: ['password'],
// 报错文案：密码复杂度不足
				message: t('auth.validation.passwordComplex'),
			});
		}
	});
// 获取演示预填数据：命中时返回 {username, password(掩码)}，未命中返回 null
const demo = getDemoLoginPrefill();
// useForm 初始化：预填值从 demo 取
const form = useForm<z.infer<typeof formSchema>>({
// zod 解析器（含 superRefine）
	resolver: zodResolver(formSchema),
// 默认值：有预填则用预填，无则空串
	defaultValues: {
		username: demo?.username ?? '',
		password: demo?.password ?? '',
		captchaText: '',
	},
});
// 监听用户名变化：用于判断是否隐藏密码显示按钮
const username = form.watch('username');
// 演示账号时 hidePasswordReveal = true，禁止显示密码
const hidePasswordReveal = isDemoLoginUsername(username.trim());
// useEffect：用户名从演示改为非演示时，清空掩码密码
useEffect(() => {
// 非演示账号且密码仍是掩码 → 清空（防止掩码被当作真密码提交）
	if (
		!hidePasswordReveal &&
		form.getValues('password') === DEMO_LOGIN_PASSWORD_MASK
	) {
		form.setValue('password', '');
	}
// 依赖：hidePasswordReveal 变化或 form 实例变化时触发
}, [hidePasswordReveal, form]);
```

**变更摘要**：`formSchema` 从 `z.object` 改为 `z.object().superRefine()`；演示账号 + 掩码密码跳过强度校验；`defaultValues` 从 `getDemoLoginPrefill()` 取预填值；新增 `hidePasswordReveal` 控制密码框 `readOnly` + `revealable`。

// 新版 onSubmit：先还原掩码再加密提交
const onSubmit = async (values: z.infer<typeof formSchema>) => {
	try {
// 演示账号 + 掩码 → 真密码；非演示账号原样返回
		const password = resolveDemoLoginPassword(
			values.username,
			values.password,
		);

			...values,
// 加密真密码（演示账号）或用户输入的密码（普通用户）
			password: encrypt(password),
// 验证码 ID
			captchaId: captchaInfo.captchaId,
		});
		if (res.success) {
// 存 token
			setStorage('token', res.data.access_token);
// 设置 fetch 全局 token
			http.setAuthToken(res.data.access_token);
// 存用户信息到 store
			userStore.setUserInfo(res.data);
// 跳首页
			navigate('/');
// 重置忘记密码状态
			onForgetPwd(false);

## 5. 兼容性与影响

- **向后兼容**：未配置 `VITE_DEMO_LOGIN_USERNAME` / `VITE_DEMO_LOGIN_PASSWORD` 环境变量时，`DEMO_LOGIN_USERNAME` 为空串，所有判定函数返回 `false`，功能完全不影响普通用户。
- **密码强度校验**：从 `z.object` 内联改为 `z.object().superRefine()`，普通用户的密码强度规则不变（≥8 位 + 字母+数字+特殊符号）。
- **路由变化**：编辑资料按钮从 `/account` 改为 `/profile/account`，购会员从 `/pay` 改为 `/profile/pay`（详见 [个人主页路由重构.md](../app/个人主页路由重构.md)）。
- **影响范围**：登录、忘记密码、个人资料、账号设置、微信绑定、会员充值共 6 个页面。

## 6. 风险与回归

| 风险点 | 等级 | 建议 |
| ------ | ---- | ---- |
| 环境变量泄露真密码 | 中 | 密码写在 `.env` 中，构建后会被打包进前端代码；仅用于演示环境，勿用于生产 |
| 掩码密码绕过强度校验 | 低 | 仅当用户名精确匹配演示账号且密码恰好是掩码时才跳过 |
| `sessionStorage` 跨标签页不同步 | 低 | 设计如此：每个标签页独立维护演示提示 |
| `getLoggedInUserInfoFromStorage` 返回 null | 低 | `username` 为 `undefined` → `isProtectedAccountUsername` 返回 `false`，不误拦 |
