# 代码块与 Mermaid 围栏视觉统一

> 延伸阅读：
> - [围栏工具条吸顶.md](./围栏工具条吸顶.md)（Mermaid 工具条 sticky 吸顶机制与双态样式，本文在其基础上统一配色）
> - [../monaco/Markdown底部栏.md](../monaco/Markdown底部栏.md)（代码块底部栏交互）

## 1. 背景与目标

改动前，代码块（`.chat-md-code-block`）与 Mermaid 围栏（`MermaidFenceToolbar`）的视觉存在不一致：

1. **背景色不对称**：代码块外壳用 `secondary/55%`，工具栏用 `background/50%`；Mermaid 围栏外壳用 `background/18%`，工具条吸顶时用 `background/50%`。三层背景叠色后视觉偏移。
2. **hljs 实色底覆盖围栏底色**：highlight.js 主题 CSS 给 `<code class="hljs">` 设了实色 `background`，盖住了 `.chat-md-code-block` 的 `secondary/55%` 半透明底，导致暗色主题下代码区底色与外壳脱节。
3. **圆角不衔接**：代码块工具栏用 `0.5rem 0.5rem 0 0`（顶部圆角），浮动吸顶条用 `0.5rem`（全圆角），但吸顶条应与顶部工具栏位置一致——只有底部需圆角。
4. **Mermaid 无外壳**：Mermaid 块没有与代码块对称的外壳（border + secondary 底），工具条叠在裸内容上，视觉层次不清晰。
5. **按钮高度不一**：Mermaid 工具条按钮 `h-8`，代码块工具条无显式高度约束，两者视觉节奏不齐。

本次改动统一了代码块与 Mermaid 围栏的视觉体系：同底色、同工具条配色、同圆角节奏、同按钮高度。

## 2. 改动范围

| 文件 | 改动 |
|------|------|
| `apps/frontend/src/index.css` | 代码块/工具栏/Mermaid 围栏 CSS 全面调整：border、background、border-radius、hljs 透明、新增 `.chat-md-mermaid-block` |
| `apps/frontend/src/components/design/ChatCodeToolBar/index.tsx` | 浮动吸顶条：`rounded-md` → `rounded-t-none rounded-b-md`、`bg-theme-background/50` → `bg-theme/8` |
| `apps/frontend/src/components/design/MermaidFenceToolbar/index.tsx` | 工具条常量、sentinel、sticky 容器、外层 div 加 `chat-md-mermaid-block` 外壳、按钮高度 `h-8` → `h-6` |

## 3. 实现思路

1. **统一底色体系**：所有工具条（代码块内联、浮动吸顶、Mermaid 吸顶、Mermaid 静止）统一用 `color-mix(in oklch, var(--theme-color) 8%, transparent)`（Tailwind `bg-theme/8`）。`--theme-color` 是当前强调色，8% 透明度叠在 `--theme-secondary/55%` 外壳底上，视觉上是「比底色略亮一层」。

2. **hljs 背景透明化**：给 `.chat-md-code-block code.hljs` 设 `background: transparent !important; padding: 0 !important;`，让 hljs 主题只负责**文字配色**，底色由外壳 `secondary/55%` 统一控制。避免不同 hljs 主题自带不同实色底导致视觉割裂。

3. **Mermaid 加外壳**：在 `MermaidFenceToolbarActions` 的外层 `<div>` 上加 `chat-md-mermaid-block` class + `rounded-md border border-theme/10`，使 Mermaid 块与代码块拥有对称的边框和底色。外壳内 Mermaid 内容区的 `background` 设为 `transparent`，避免二次叠色。

4. **圆角衔接**：
   - 工具条（静止态）：`rounded-t-[0.4rem]`（顶部 0.4rem 圆角，与 CSS `.chat-md-code-toolbar` 的 `0.4rem 0.4rem 0 0` 对齐）
   - 工具条（吸顶态）：`rounded-t-none rounded-b-md`（只有底部圆角，因为顶部贴在滚动区边缘）
   - 浮动吸顶条（Portal）：`rounded-t-none rounded-b-md`（同上，只有底部圆角）
   - 外壳：`rounded-md`（全圆角），工具条叠在上方

5. **按钮高度统一**：Mermaid 工具条按钮从 `h-8`（32px）改为 `h-6`（24px），与代码块工具条紧凑节奏对齐。

6. **sentinel 去高度**：哨兵 `<div>` 从 `h-px`（1px 高度）改为无高度，消除哨兵占位导致的 1px 空隙。

7. **backdrop-blur 统一**：sticky 容器加 `backdrop-blur-sm`，静止态工具条加 `backdrop-blur-[8px]`，与 CSS `.chat-md-code-toolbar` 的 `blur(8px)` 对齐。

## 5. 兼容性与影响

- **向后兼容**：纯样式调整，不改变 DOM 结构（仅新增 class 和 CSS 属性），不影响交互逻辑。
- **强调色跟随**：border 和工具栏背景改用 `--theme-color`，切换强调色时代码块和 Mermaid 围栏边框/工具条会跟随变化。
- **hljs 主题不影响底色**：透明化后，hljs 主题只控制文字配色，底色统一由 `secondary/55%` 控制，跨主题视觉一致。
- **静态 HTML 不受影响**：无 `chat-md-mermaid-block` 外壳的静态 Mermaid 仍自带 `secondary/55%` 底色。
