# 知识库长文编辑性能优化 — 实现说明

## 延伸阅读

- [知识编辑器长文本性能.md](../impact/知识编辑器长文本性能.md) — 影响面矩阵与回归清单
- [Monaco Markdown视图面板影响.md](../monaco/Markdown视图面板滚动.md) — 预览/编辑/助手 Panel 布局
- [知识库助手完成.md](./知识库助手完成.md) — 文档助手总览

## 1. 背景与目标

**用户问题**：知识库编辑页打开较长 Markdown（数万字）并开启右侧文档助手时，标题输入、正文按键、助手 ChatEntry 输入均明显卡顿。

**根因（三层叠加）**：

1. **Monaco 纯编辑态**仍向 co-mount 的隐藏 `ParserMarkdownPreviewPane` 每键传入全文，触发 Markdown 重解析。
2. **MobX + React**：`Knowledge` 整页 observer 在 render 中读取 `knowledgeStore.markdown` 全文，每键触发标题区、助手区整树 reconciler。
3. **助手输入 state 在父页**：ChatEntry 每键 `setState` 导致含 `MarkdownEditor` 的父组件重渲染。

**目标**：在不改保存/脏检查/发送语义的前提下，隔离长文订阅、停止 edit 态隐藏预览喂料、助手输入与编辑器按键解耦。

## 2. 改动范围

| 文件 | 变更摘要 |
|------|----------|
| `apps/frontend/src/components/design/Monaco/index.tsx` | `leftPreviewMarkdown` 仅在 preview/split 时等于 `value` |
| `apps/frontend/src/store/knowledge.ts` | `markdownNonempty`、`isDraftDirty` 及 `syncKnowledgeDraftDerivedFlags` |
| `apps/frontend/src/views/knowledge/KnowledgeAssistant.tsx` | `forwardRef` + `memo`；`useImperativeHandle`；订阅 boolean |
| `apps/frontend/src/views/knowledge/index.tsx` | `KnowledgeTitleField`；`assistantRef`；`knowledgeAssistantNode` useMemo |

## 3. 实现思路

1. **编辑态不解析隐藏预览**：左栏 co-mount 布局保留（切换 preview/split 无 remount 闪白），但 `edit` 时 `markdown=""` 传给隐藏预览，切模式时一次性喂最新 `value`。
2. **Store 派生 boolean**：在 `setMarkdown` / `setKnowledgeTitle` / 快照更新时 O(n) 同步 `markdownNonempty`、`isDraftDirty`；UI 只订阅 boolean，不订阅全文。
3. **标题区独立 observer**：`KnowledgeTitleField` 仅读 `knowledgeTitle` + `isDraftDirty`。
4. **助手输入内化 + ref**：`KnowledgeAssistantHandle.appendInput/focusInputAtEnd`；父页 `useMemo` 稳定 `<KnowledgeAssistant />` 节点，避免编辑器随助手按键重渲染。
5. **文档切换清输入**：由 `KnowledgeAssistant` 内 `useEffect([documentKey])` 统一清空，替代父页 `assistantArticleBinding` effect。

**未改**：`knowledgeStore.markdown` 仍为正文唯一源；保存/自动保存仍读全文或 `getMarkdownFromEditorRef`；发送助手仍 `buildKnowledgeAssistantDocumentMessage(knowledgeStore.markdown)`。

```typescript
// ponytail：长文时在 setter 内 O(n) 算 boolean，避免 UI 订阅全文
/** ponytail: O(n) trim/比较；长文编辑时由派生字段让 UI 只订阅 boolean */
// 入参为 store 实例，直接写 observable 派生字段
function syncKnowledgeDraftDerivedFlags(store: KnowledgeStore) {
	// trim 后是否有实质正文（空串与纯空白均为 false）
	store.markdownNonempty = store.markdown.trim().length > 0;
	// 标题 trim 或正文全量与 persisted 快照任一不同即脏
	store.isDraftDirty =
		store.knowledgeTitle.trim() !== store.knowledgePersistedSnapshot.title ||
		store.markdown !== store.knowledgePersistedSnapshot.content;
}

class KnowledgeStore {
	// ...（未改字段省略）

	// trim 后是否有正文；助手空态等只订阅此 boolean
	markdownNonempty = false;

	// 相对 persisted 快照是否未保存
	isDraftDirty = false;

	// 正文仍每键写入全文
	markdown = '';

	// 每次 setMarkdown 后刷新派生标志
	setMarkdown(value: string) {
		this.markdown = value;
		syncKnowledgeDraftDerivedFlags(this);
	}

	// 改标题同样刷新脏点与（间接）markdownNonempty 不变时的 isDraftDirty
	setKnowledgeTitle(value: string) {
		this.knowledgeTitle = value;
		syncKnowledgeDraftDerivedFlags(this);
	}
}
```

**变更摘要**：脏点与「是否有正文」从父组件 render 计算下沉到 Store；`clearKnowledgeDraft` / `applyKnowledgeDraftFromChatReply` / `setKnowledgePersistedSnapshot` 亦调用 sync（diff 中已接齐）。

### 4.4 `KnowledgeAssistantHandle` 与输入内化（`KnowledgeAssistant.tsx`）

**对比范围**：Handle 类型、`useImperativeHandle`、`editorHasBody`、documentKey 清输入、export `memo`。

**改动前** · `apps/frontend/src/views/knowledge/KnowledgeAssistant.tsx`（基线，摘录）

```typescript
// 无 ref 导出；父页受控 input/ragInput/focusInputAtEndKey
interface KnowledgeAssistantProps {
	documentKey: string;
	input?: string;
	setInput?: Dispatch<SetStateAction<string>>;
	ragInput?: string;
	setRagInput?: Dispatch<SetStateAction<string>>;
	focusInputAtEndKey?: number;
	onAssistantModeChange?: (mode: KnowledgeAssistantMode) => void;
}

// 单 observer 组件，无 memo
const KnowledgeAssistant = observer(({ documentKey, input: inputProp, /* ... */ }) => {
	// 是否有正文：每 render trim 全文
	const editorHasBody = Boolean((knowledgeStore.markdown ?? '').trim());

	// 正文清空 debounce：effect 依赖 knowledgeStore.markdown 全文
	useEffect(() => {
		if (assistantMode !== 'ai') return;
		const raw = knowledgeStore.markdown ?? '';
		if (raw.trim()) return;
		const id = window.setTimeout(() => {
			if (!(knowledgeStore.markdown ?? '').trim()) setInput('');
		}, 200);
		return () => window.clearTimeout(id);
	}, [knowledgeStore.markdown, setInput, knowledgeStore, assistantMode]);

	// ...（其余 UI 不变）
});

export default KnowledgeAssistant;
```

**改动后** · `apps/frontend/src/views/knowledge/KnowledgeAssistant.tsx`（当前，约 L57–62、L101–184、L768）

```typescript
// 供知识页 ref 写入选区，避免 input state 提升到整页
/** 供知识页从编辑器选区写入助手草稿，避免输入 state 提升到整页 */
export type KnowledgeAssistantHandle = {
	appendInput: (text: string, mode?: KnowledgeAssistantMode) => void;
	clearInputs: () => void;
	focusInputAtEnd: () => void;
};

// Props 仍保留可选受控 input（外部接入行为不变）
interface KnowledgeAssistantProps {
	documentKey: string;
	input?: string;
	setInput?: Dispatch<SetStateAction<string>>;
	ragInput?: string;
	setRagInput?: Dispatch<SetStateAction<string>>;
	focusInputAtEndKey?: number;
	onAssistantModeChange?: (mode: KnowledgeAssistantMode) => void;
}

// observer + forwardRef 内层
const KnowledgeAssistantInner = observer(
	forwardRef<KnowledgeAssistantHandle, KnowledgeAssistantProps>(
		function KnowledgeAssistant({ documentKey, /* ... */ }, ref) {
			// 内部 focus 计数，供 focusInputAtEnd 递增
			const [internalFocusInputAtEndKey, setInternalFocusInputAtEndKey] =
				useState(0);
			const focusInputAtEndKey =
				focusInputAtEndKeyProp + internalFocusInputAtEndKey;

			// 只订阅 markdownNonempty，不订阅全文
			const editorHasBody = knowledgeStore.markdownNonempty;

			// 选区追加逻辑从内层暴露
			const appendInputBlock = useCallback(
				(text: string, mode: KnowledgeAssistantMode = assistantMode) => {
					const next = text.trim();
					if (!next) return;
					const appendBlock = (prev: string) => {
						const cur = (prev ?? '').trim();
						return cur ? `${cur}\n\n${next}` : next;
					};
					if (mode === 'rag') {
						setRagInput((prev) => appendBlock(prev));
					} else {
						setInput((prev) => appendBlock(prev));
					}
				},
				[assistantMode, setInput, setRagInput],
			);

			useImperativeHandle(
				ref,
				() => ({
					appendInput: (text, mode) =>
						appendInputBlock(text, mode ?? assistantMode),
					clearInputs: () => {
						setInput('');
						setRagInput('');
					},
					focusInputAtEnd: () => {
						setInternalFocusInputAtEndKey((n) => n + 1);
					},
				}),
				[appendInputBlock, assistantMode, setInput, setRagInput],
			);

			// documentKey 变化清输入（替代父页 assistantArticleBinding effect）
			useEffect(() => {
				setInput('');
				setRagInput('');
			}, [documentKey, setInput, setRagInput]);

			// 正文清空 debounce：依赖 markdownNonempty
			useEffect(() => {
				if (assistantMode !== 'ai') return;
				if (knowledgeStore.markdownNonempty) return;
				const id = window.setTimeout(() => {
					if (!knowledgeStore.markdownNonempty) setInput('');
				}, 200);
				return () => window.clearTimeout(id);
			}, [
				knowledgeStore.markdownNonempty,
				setInput,
				knowledgeStore,
				assistantMode,
			]);

			// ...（AssistantShell / ChatEntry 等未改逻辑）
		},
	),
);

// 外层 memo：父页 useMemo 稳定节点时 props 不变则不重进 reconciler
const KnowledgeAssistant = memo(KnowledgeAssistantInner);

export default KnowledgeAssistant;
```

**变更摘要**：ref API + boolean 订阅 + documentKey 清输入内聚；`memo` 配合父页 `useMemo` 隔离编辑器。

## 5. 兼容性与影响

| 项 | 结论 |
|----|------|
| 保存 / 自动保存 / Diff | 仍读全文或 editor ref，**无行为变化** |
| 助手发送 / 快捷卡片 | 仍读 `knowledgeStore.markdown` 全文 |
| 纯 preview / split | 预览实时性与跟滚**不变** |
| edit → preview 切换 | 切模式时一次性喂 value；依赖既有 `useLayoutEffect` 对齐滚动 |
| 助手空态快捷卡片 | 正文**仅空白字符**时由卡片变为引导文案（`markdownNonempty` 与旧 `markdown ?` 差异） |
| 受控 `input` props | 仍可选；知识页改默认非受控 |
