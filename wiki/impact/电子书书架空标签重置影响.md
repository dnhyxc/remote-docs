# 书架分类 Tab 空态隐藏与自动回「全部」— 影响点分析

## 延伸阅读

- [电子书书架分类.md](../ebook/电子书书架分类.md) — 书架分类 Tab、筛选与移动书籍（Rail 仍展示全部自定义分类，**与改后「空分类隐藏」可能不一致**，见 §7）
- [电子书文件夹归档.md](../ebook/电子书文件夹归档.md) — 书架组件路径与 `EbookShelfCategoryRail` 定位

**阅读约定**：结论以仓库 **当前源码** 为准；「历史风险」指旧实现曾出现的问题，不代表现行代码仍会触发。

## 1. 分析目的

评估 **书架分类 Rail 空 Tab 隐藏** 与 **分类/未分类 Tab 最后一本书移走后自动切回「全部」** 是否改变或破坏已有书架能力。

**对照的既有能力**（来自 `docs/ebook/电子书书架分类.md` 与 `ebookStore`）：

- 分类 Tab：**全部 / 各分类 / 未分类**，带册数徽章，横滑
- `setActiveCategoryKey` → `fetchPage(1)` 按 `categoryId` / `uncategorizedOnly` 筛选
- `assignBookCategory` / `remove` 更新列表与 `fetchCategories` 计数
- `deleteCategory` 删当前 Tab 时切回「全部」并 `fetchPage`
- 导入默认归入 **当前选中分类** 或 **localStorage 上次选用**（`resolveImportCategoryId`）
- 换号 `resetOnUserSwitch` 清空筛选
- EPUB/PDF **阅读、进度、MOKE 助手** 与书架分类无直接耦合

**改动范围（当前 diff）**：

| 文件 | 变更 |
|------|------|
| `apps/frontend/src/views/ebook/components/shelf/EbookShelfCategoryRail.tsx` | `uncategorizedCount === 0` 时不渲染「未分类」；`bookCount === 0` 的自定义分类 Tab 也不渲染 |
| `apps/frontend/src/store/ebook.ts` | 新增 `resetActiveCategoryIfEmpty()`；`assignBookCategory` / `remove` 末尾调用 |
| `apps/frontend/src/store/ebook.ts` | `resolveImportCategoryId` 注释掉「上次选用分类」回退，并加入 `console.log`（**与 Tab 需求无直接关系，见 §4**） |
| `apps/frontend/src/views/ebook/components/shelf/EbookShelfBookCard.tsx` | 书名 Tooltip 增加 **书籍分类** 行（`ebook.shelf.bookCategory` + 书名分行展示） |
| `apps/frontend/src/i18n/locales/zh-CN.ts`、`en-US.ts` | `ebook.shelf.bookCategory` |

**结论摘要**：

| 维度 | 是否影响原有功能 | 说明 |
|------|------------------|------|
| 全部 Tab / 有书分类筛选 | **否** | 筛选 API 与 `setActiveCategoryKey` 未改 |
| 未分类 Tab 展示 | **有条件变化** | 册数为 0 时 Tab 不显示；仍可通过「移动到分类」产生未分类书后再出现 |
| 空自定义分类 Tab 展示 | **有条件变化** | `bookCount === 0` 的分类不在 Rail 显示（改前仍显示 0 徽章） |
| 移走最后一本书后的 Tab | **有条件变化** | 自动 `activeCategoryKey → all` 并 `fetchPage(1)` 拉「全部」列表 |
| 删除分类 | **否** | 仍走既有 `deleteCategory` 逻辑 |
| 导入默认分类 | **是** | `resolveImportCategoryId` 禁用 localStorage 上次分类（diff 内附带改动） |
| EPUB 阅读 / 听书 / 上传 | **否** | 未触达 |
| 后端 API / 计数 | **否** | 仅前端展示与 Store 编排 |

## 2. 改动要点（相对改前行为）

### 2.1 Rail：空 Tab 不展示

**改前**：「未分类」与各自定义分类 Tab **始终**出现在 Rail（册数可为 0）。

**改后**：

- `uncategorizedCount > 0` 才插入「未分类」chip
- `categories` 映射后 `.filter((c) => c.count > 0)`，空分类不出现在 Tab 栏

**动机**：减少无书 Tab 占位；与用户「未分类为 0 不展示」一致；空分类 Tab 同理。

### 2.2 Store：空 Tab 内最后一本书移走后回「全部」

**改前**：在某一分类/未分类 Tab 下移走或删除最后一本后，`activeCategoryKey` **不变**，列表为空，Tab 仍高亮（或未分类 Tab 仍可见）。

**改后**（`resetActiveCategoryIfEmpty`）：

```text
activeCategoryKey ≠ all 且 books.length === 0 且 safeTotal() === 0
  → activeCategoryKey = { kind: 'all' }
  → fetchPage(1, false)   // 重新拉「全部」第一页
```

调用点：`assignBookCategory`（书移出当前筛选）、`remove`（在当前 Tab 删最后一本）。

**动机**：避免用户停在「空分类」且 Tab 已隐藏或列表空白；与 `deleteCategory` 删当前分类时切回「全部」行为对齐。

**与 `deleteCategory` 差异**：删分类仍会 `fetchCategories` + `fetchPage`；本改动在 **移书/删书** 路径触发，不删分类实体。

### 2.3 附带 diff：`resolveImportCategoryId`

**改前**：非分类 Tab 时，若 localStorage 有合法 `lastImportCategoryId` 则导入归入该分类。

**改后**：该分支被注释，非分类 Tab 导入 **不再**读上次分类；并留有 `console.log`。

**动机（推测）**：调试遗留，**非** Tab 空态需求的一部分；应视为独立回归点。

## 3. 影响点矩阵

| 模块 / 场景 | 影响等级 | 分析 |
|-------------|----------|------|
| **EbookShelfCategoryRail** | 低 | 仅 chip 列表条件渲染；`setActiveCategoryKey` / `isActiveKey` 不变 |
| **未分类 Tab** | 低 | 0 册隐藏；`uncategorizedOnly` 查询仍可用（若通过代码设 key） |
| **空自定义分类 Tab** | 低 | 0 册隐藏；管理弹窗仍可看到空分类并往里加书 |
| **assignBookCategory** | 中 | 移出最后一本 → 切「全部」+ **额外** `fetchPage`（`fetchCategories` 仍会跑） |
| **remove（删书）** | 中 | 在当前 Tab 删到 0 本 → 同上 |
| **deleteCategory** | 无 | 未改；仍单独处理 Tab 切换与 refetch |
| **loadMore / 分页** | 低 | 回「全部」后 `pageNo=1`，`total` 由新 `fetchPage` 写入 |
| **导入（Tauri / 浏览器）** | **高** | `resolveImportCategoryId` 注释掉 last 分类 → 在「全部」Tab 导入可能不再归入上次分类 |
| **EbookShelfBookCard 移动到分类** | 无 | 仍调 `assignBookCategory`；计数由 `fetchCategories` 更新 |
| **EbookShelfBookCard 书名 Tooltip** | 低 | 有 `onUpdateTitle` 时展示分类名 + 书名两行；无分类时分类名为空 |
| **换号 / hydrate** | 无 | 未改 |
| **阅读页 read.tsx** | 无 | 代码路径未触达 |

## 4. 潜在风险与缓解

| 风险 | 等级 | 说明 | 建议验证 |
|------|------|------|----------|
| 空 Tab 仍选中但 Rail 无对应 chip | 中 | 若 `activeCategoryKey` 指向已隐藏分类且列表非空（分页边缘），Tab 高亮与 Rail 不一致 | 移走最后一本后应切「全部」；若仅 filter 隐藏 Tab 未 reset，需补 `fetchCategories` 后校验 |
| 回「全部」触发 `fetchPage` | 低 | 多一次 shelf API；用户曾要求避免 refetch，**当前 diff 仍调用 `fetchPage`** | 确认产品：接受 refetch 或改为 `bookCache` 拼页 |
| `bookCache` 未覆盖全部书 | 低 | 若将来去掉 `fetchPage` 仅用 cache，首屏可能不全 | 滚动 `loadMore` 补拉 |
| **导入默认分类失效** | **高** | `resolveImportCategoryId` 注释 last 分支 + debug log | 恢复 last 逻辑并删 `console.log`；在「全部」Tab 导入验证书籍 `categoryId` |
| 空分类仅隐藏于 Rail | 低 | 管理弹窗仍列出 0 册分类，与 Rail 不一致属预期 | 管理弹窗新建分类后加书 → Rail 出现 Tab |
| 与 `deleteCategory` 双 refetch | 低 | `assignBookCategory` 已 `void fetchCategories()`，reset 再 `fetchPage` | Network 面板确认无重复风暴即可 |

## 5. 未改动项

| 项 | 说明 |
|----|------|
| `setActiveCategoryKey` / `shelfQueryFromKey` | 用户 **手动** 点 Tab 仍走原 fetch |
| 后端 `GET shelf` / `categories/summary` | 契约与计数逻辑未改 |
| `deleteCategory` | 删分类清空 `categoryId`、切 Tab、refetch 逻辑保留 |
| `EbookCategoryManageDialog` | 新建/重命名/排序/删除分类 UI 未改 |
| 阅读进度、封面、书名编辑 | 与分类 Tab 正交 |
| EPUB 听书 / 听当前 | 无交叉 |

## 6. 回归清单

- [ ] 未分类册数 = 0：Rail **无**「未分类」Tab；册数 > 0 时出现且计数正确
- [ ] 某自定义分类 `bookCount = 0`：Rail **不显示**该 Tab；管理弹窗仍可见该分类
- [ ] 在分类 Tab 内 **移动最后一本** 到其他分类 → 自动选中「全部」、列表展示全书（或第一页）
- [ ] 在 **未分类** Tab 移走最后一本 → 切「全部」且未分类 Tab 消失（若计数变 0）
- [ ] 在分类 Tab **删除最后一本** → 切「全部」
- [ ] **deleteCategory**（含书分类）→ 仍切「全部」、书入未分类，行为与改前一致
- [ ] 手动点「全部 / 分类 / 未分类」Tab → 筛选与分页正常
- [ ] 导入：在 **分类 Tab** 选中时导入 → 仍归入当前分类
- [ ] 导入：在 **全部** Tab 导入 → 验证书籍分类是否符合预期（**关注 `resolveImportCategoryId` 是否恢复 last**）
- [ ] 换号登录 → Tab 回「全部」
- [ ] 控制台无残留 `resolveImportCategoryId` debug 输出（若已清理）
- [ ] 书架卡片悬停书名：Tooltip 显示 **书籍分类** 与书名（teal 高亮值）
