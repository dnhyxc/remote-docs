## 1. 分析目的

评估 **`PluginHostPage` 卡片错误态新增「返回首页」「插件开发指南」按钮** 相关改动，是否改变或破坏已有功能：

- 插件宿主页加载态 / 错误态 / 成功态渲染
- toolbar 变体（轻量错误提示 + Tooltip）
- 插件错误边界（`PluginErrorBoundary`）
- 插件全屏 / 影院态
- 路由导航（`useNavigate`）

**改动范围（当前 diff）**：

| 文件 | 变更 |
|------|------|
| `apps/frontend/src/federation/host/PluginHostPage.tsx` | 卡片错误态（非 toolbar 变体）新增两个 `Button`；布局改 `flex-col items-center justify-center`；import 新增 `CloudBackup` / `TreePalm` / `Puzzle` 图标、`useNavigate` / `openExternalUrl` / `getPluginDevGuideAbsoluteUrl` |

**结论摘要**：

| 维度 | 是否影响原有功能 | 说明 |
|------|------------------|------|
| 卡片错误态「重新加载」 | **否** | `retry` 回调不变；仅加 `CloudBackup` 图标 + `busy` 时显 `Spinner` |
| toolbar 变体错误态 | **否** | toolbar 分支提前 return，未进入卡片分支 |
| 加载态 / 成功态 | **否** | `loading` / `missingIframeUrl` / `shell` slots 未改 |
| 插件错误边界 | **否** | `PluginErrorBoundary` 未改，仍包裹 `FederationPlugin` |
| 插件全屏 / 影院态 | **否** | 未触碰 `appFullscreen` / Layout 订阅 |
| 路由导航 | **低（新增）** | 新增 `useNavigate`；仅在「返回首页」按钮 `onClick` 调 `navigate("/")` |
| 外链打开 | **低（新增）** | 「插件开发指南」调 `openExternalUrl(getPluginDevGuideAbsoluteUrl(locale))`，新窗口打开 |
| 卡片布局 | **低** | 外层 div 从 `p-4.5` 改为 `flex flex-col items-center justify-center gap-3 pt-4.5`；内容居中 |

## 2. 改动要点（相对改前行为）

### 2.1 卡片错误态按钮区

**改前**：卡片错误态仅一个「重新加载」按钮，左对齐（`w-fit`），无图标。

**改后**：三按钮并排居中（`flex justify-center w-full gap-3`）：
1. **重新加载**：`busy` 时显 `Spinner`，否则 `CloudBackup` 图标
2. **返回首页**：`variant="outline"`，`TreePalm` 图标，`navigate("/")`
3. **插件开发指南**：`variant="outline"`，`Puzzle` 图标，`openExternalUrl(getPluginDevGuideAbsoluteUrl(locale))`

外层 div 从 `p-4.5` 改为 `flex flex-col items-center justify-center gap-3 pt-4.5`，内容垂直水平居中。

**动机**：插件持续不可用时，用户缺乏离开或查文档的入口。

### 2.2 toolbar 变体不变

toolbar 变体（`part="toolbar"`）仍走原轻量文案 + Tooltip + 单按钮，提前 return，不受影响。

## 3. 影响点矩阵

| 模块 / 场景 | 影响等级 | 分析 |
|-------------|----------|------|
| **卡片错误态（非 toolbar）** | **低（增强）** | 新增两按钮 + 居中布局 + 图标；`retry` 逻辑不变 |
| **toolbar 错误态** | **无** | `v === "toolbar"` 分支提前 return，代码路径未触达卡片改动 |
| **加载态** | **无** | `loading` slot 未改 |
| **`missingIframeUrl`** | **无** | 未改 |
| **`PluginErrorBoundary`** | **无** | 仍作为 `ErrorBoundary` prop 传入 `FederationPlugin`，不受 slots 改动影响 |
| **`PluginHostSurface`（toolbar / drawer slot）** | **无** | toolbar slot 使用 `part="toolbar"`，走 toolbar 分支；drawer slot 使用卡片态但错误时才渲染按钮区，正常加载不受影响 |
| **英语学习笔记页（`PluginHostPage` 直挂）** | **低（增强）** | `englishLearning/notes/index.tsx` 直接渲染 `<PluginHostPage>`；插件加载失败时用户可返回首页或查文档 |
| **插件全屏 / 影院态** | **无** | 未触碰 `appFullscreen` / Layout 影院态订阅 |
| **路由导航** | **低** | 新增 `useNavigate`；`navigate("/")` 与 `notFound.backHome` 文案复用 404 页逻辑 |
| **外链打开** | **低** | `openExternalUrl` 新窗口打开开发指南；`getPluginDevGuideAbsoluteUrl` 返回绝对 URL |

## 4. 潜在风险与缓解

| 风险 | 等级 | 说明 | 建议验证 |
|------|------|------|----------|
| 卡片错误态布局偏移 | 低 | 外层从 `p-4.5` 改为 `flex flex-col items-center justify-center gap-3 pt-4.5`；三按钮宽度不一可能导致视觉不平衡 | 插件加载失败：卡片内容居中、三按钮并排不溢出 |
| `navigate("/")` 在全屏态行为 | 低 | 插件全屏时 `navigate("/")` 仍会路由跳转，但全屏退出由 Layout `fullscreenchange` 兜底处理 | 全屏态下插件错误 → 点「返回首页」→ 确认全屏退出 + 路由到首页 |
| `openExternalUrl` 在 Tauri 桌面端 | 低 | Tauri 下 `openExternalUrl` 走 `shell.open` 打开系统浏览器；确认 URL 正确 | 桌面端插件错误 → 点「插件开发指南」→ 系统浏览器打开正确 URL |
| 按钮文案缺失 | 低 | 复用 `notFound.backHome` 与 `home.steps.pluginDev.title`；确认 i18n 两语言均有 | 切换中/英文：两按钮文案正确 |
