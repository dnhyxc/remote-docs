---

## 2. 影响点矩阵

| 既有能力 | 判定 | 理由 |
|----------|------|------|
| 吸顶浮动条出现/消失语义 | **否** | 仍按「视口顶落在代码块内」选 winner |
| 行内代码工具栏复制/下载 | **否** | 未改 fence DOM 与 `bindMarkdownCodeFenceActions` |
| 助手同开时左栏关吸顶 | **否** | Monaco 仍 `enableCodeFloatingToolbar={!assistantRightPaneActive}` |
| 目录 / hash 跳转 | **否** | 未改预览 DOM 与 hash hook |
| 预览置顶/置底 FAB | **否** | 未改 FAB 逻辑 |
| 分屏跟滚 / 预览↔编辑滚动恢复 | **否** | 未改 Monaco scroll sync |
| 聊天长消息多代码块滚动 | **有条件变化（正向）** | 共用 layout：滚动更轻；语义不变 |
| 窗口化 / 卸 Monaco 预览 | **否（未采用）** | 本轮明确不改预览挂载结构 |

## 3. 风险与回归

| 风险 | 等级 | 缓解 |
|------|------|------|
| 块列表缓存陈旧（正文已变仍用旧 Node） | 中 | `layoutDeps` / mount 路径 `invalidate` + `refreshBlocks`；`isConnected` 失效整表刷新 |
| 二分假定文档序 | 低 | Markdown 预览/聊天输出均为文档流；绝对定位乱序不在契约内 |
| 几何短路漏更新 | 低 | 比较 top/left/width/lang + 同一 block 引用 |
| 误伤其它 viewport 多实例 | 低 | WeakMap 按 viewport 分缓存；mountCount 卸完仍 `layout(null)` |

**回归清单**：长文多代码块预览滚动；吸顶出现/消失；换文档后吸顶；助手同开左栏无吸顶；聊天多代码块滚动；目录跳转与 FAB。
