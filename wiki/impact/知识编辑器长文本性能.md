## 1. 分析目的

评估 **知识库编辑页长文场景下的渲染隔离与 Monaco 预览喂料优化**，是否改变或破坏已有功能：

- Markdown 正文编辑、标题编辑、脏点（未保存橙点）
- 保存 / 另存为 / 自动保存 / Diff 对照 / 覆盖保存
- 右侧 AI / RAG 助手：发送、流式输出、快捷卡片、会话切换、`documentKey` 激活
- 编辑器选区「复制到助手」、快捷键 `pasteToAssistant`
- Monaco 纯编辑 / 纯预览 / 分屏预览 / 分屏跟滚
- 从列表 / 回收站 / 聊天「保存到知识库」载入草稿
- `knowledgeStore` 对外数据契约（`markdown`、`knowledgePersistedSnapshot` 等）

**改动范围（当前 diff）**：

| 文件 | 变更 |
|------|------|
| `apps/frontend/src/components/design/Monaco/index.tsx` | 纯 `edit` 态不向隐藏左栏 `ParserMarkdownPreviewPane` 传入全文 `value` |
| `apps/frontend/src/store/knowledge.ts` | 新增派生字段 `markdownNonempty`、`isDraftDirty`；在 `setMarkdown` / `setKnowledgeTitle` / `setKnowledgePersistedSnapshot` / `clearKnowledgeDraft` / `applyKnowledgeDraftFromChatReply` 后同步 |
| `apps/frontend/src/views/knowledge/KnowledgeAssistant.tsx` | `memo` + `forwardRef`；输入 state 默认内化；render 订阅 `markdownNonempty`；`documentKey` 变化时清空输入 |
| `apps/frontend/src/views/knowledge/index.tsx` | 抽出 `KnowledgeTitleField` observer；助手经 `ref` 写入选区；`knowledgeAssistantNode` 用 `useMemo` 稳定化 |

**无运行时语义（可忽略）**：`apps/frontend/tsconfig.tsbuildinfo`（构建缓存）；`package.json` 末尾换行；`assistant.ts` / `splitMarkdownFences.ts` 仅缩进与空 catch 格式，逻辑不变。

**结论摘要**：

| 维度 | 是否影响原有功能 | 说明 |
|------|------------------|------|
| 正文/标题编辑与保存 | **否** | `knowledgeStore.markdown` 仍每键同步；保存、脏检查、自动保存仍读全文或 `getMarkdownFromEditorRef` |
| 未保存橙点（脏标记） | **否** | `isDraftDirty` 与改前「标题 trim + 正文全量比较快照」逻辑等价 |
| AI/RAG 发送与流式 | **否** | 发消息、快捷卡片、`buildKnowledgeAssistantDocumentMessage` 仍在回调中读 `knowledgeStore.markdown` 全文 |
| 选区复制到助手 | **否** | `onInsertSelectionToAssistant` 仍先 `getMarkdownFromEditorRef` 再写入；写入路径改为 `assistantRef.appendInput`，拼接规则不变 |
| 文档切换清空助手输入 | **否** | 原 `index.tsx` 监听 `assistantArticleBinding` 清空 → 现 `KnowledgeAssistant` 监听 `documentKey`（同源派生），语义一致 |
| 正文清空后清空 AI 输入框 | **否** | 仍 200ms debounce；判定由 `markdown.trim()` 改为 `markdownNonempty`（等价） |
| 助手空态快捷卡片展示 | **有条件变化** | 改前 `knowledgeStore.markdown` 真值即展示卡片；改后需 `markdownNonempty`（trim 后非空）。**仅空白/换行正文**时由「有卡片」变为「AI 引导文案」 |
| 纯编辑态左栏隐藏预览 | **低（增强）** | 编辑时不再每键重解析隐藏预览；切到 `preview`/`split` 时仍即时喂入全文，跟滚与 `useLayoutEffect` 换模式同步未删 |
| `KnowledgeAssistant` 受控 `input/setInput` props | **否** | 可选 props 仍保留；知识页改走默认非受控 + `ref`，外部若受控接入行为不变 |
| 其它页面 / Store 消费者 | **否** | `markdownNonempty` / `isDraftDirty` 仅知识页子树使用；未改 `setMarkdown` 签名 |

## 2. 改动要点（相对改前行为）

### 2.1 Monaco：纯编辑态停止驱动隐藏预览

**改前**：

```text
leftPreviewMarkdown = value ?? ''（任意 viewMode）
→ edit 模式下左栏 co-mount 的不可见 ParserMarkdownPreviewPane 每键收到全文并重解析
```

**改后**：

```text
leftPreviewMarkdown 仅在 viewMode === 'preview' || viewMode === 'split' 时为 value
→ edit / edit+助手 时隐藏预览 DOM 不随按键更新；用户切 preview/split 时一次性拿到最新 value
```

**动机**：长文编辑时隐藏预览解析是主要 CPU 开销之一，与可见预览/分屏跟滚路径解耦。

### 2.2 Store：派生 boolean，减少 MobX 订阅全文

**改前**：

```text
UI 在 render 中读 knowledgeStore.markdown（或 trim）→ 每键触发助手/标题区整树重渲染
脏点：父组件每次 render 全量比较 markdown 与 snapshot.content
```

**改后**：

```text
syncKnowledgeDraftDerivedFlags 在草稿变更时更新 markdownNonempty、isDraftDirty
助手空态 / editorHasBody / 清空输入判定订阅 markdownNonempty
KnowledgeTitleField 单独 observer，只订阅 knowledgeTitle + isDraftDirty
```

**动机**：长文时避免 React  reconciler 与 MobX 因「全文引用变化」拖慢标题输入与助手 ChatEntry。

### 2.3 助手输入 state 下沉与 `ref` 插入

**改前**：

```text
index.tsx 持有 assistantInput / ragAssistantInput / focusInputAtEndKey
→ 助手内每键 setState 导致 Knowledge observer 整页重渲染（含 MarkdownEditor）
```

**改后**：

```text
KnowledgeAssistant 默认内部 state；KnowledgeAssistantHandle.appendInput / focusInputAtEnd
index 仅 useMemo 稳定 <KnowledgeAssistant ref={assistantRef} documentKey=… />
```

**动机**：助手输入与流式 UI 与编辑器按键解耦；选区写入逻辑与 debounce/追加规则保持不变。

## 3. 影响点矩阵

| 模块 / 场景 | 影响等级 | 分析 |
|-------------|----------|------|
| **Monaco 纯 edit + 右侧助手** | 低 | 主修复场景：隐藏预览不再解析；Editor `onChange`→`setMarkdown`、受控 `value` 同步 effect 未改 |
| **Monaco 纯 preview** | 无 | `viewMode === 'preview'` 时 `leftPreviewMarkdown` 仍为全文，预览实时性不变 |
| **Monaco split + 跟滚** | 无 | `splitPaneMarkdown` 仍为 `viewMode === 'split' ? value : ''`；`splitPreviewScrollSyncEligible` 路径未动 |
| **edit → preview 切换** | 低 | 切换瞬间 `leftPreviewMarkdown` 从空变为全文，依赖既有 `useLayoutEffect`（`viewMode` + `leftPreviewMarkdown`）做滚动对齐；须回归切换是否闪白 |
| **Diff splitDiff** | 无 | 未改 `splitDiffModifiedText`、Diff 模型 dispose 时序 |
| **标题 Input + 橙点** | 无 | `KnowledgeTitleField` 仍 `setKnowledgeTitle`；橙点由 `isDraftDirty` 驱动，判定与改前一致 |
| **手动保存 / 自动保存** | 无 | `performSave` 仍 `formatMarkdownBeforeSaveRef` / `getMarkdownFromEditorRef` / `knowledgeStore.markdown`；自动保存 effect 仍依赖 `knowledgeStore.markdown` |
| **助手 `activateForDocument`** | 无 | `editorHasBody` 改为 `markdownNonempty`，与改前 `Boolean(markdown.trim())` 等价 |
| **助手 AI 快捷卡片（空会话）** | 低 | 仅「正文全是空白字符」时 UI 从卡片变为 intro；有实质内容时不变 |
| **助手「生成目录」写回编辑器** | 无 | 仍读 `knowledgeStore.markdown` 全文并 `setMarkdown` |
| **RAG 模式** | 无 | RAG 输入独立；`markdownNonempty` 不参与 RAG 发送体 |
| **回收站 / 列表 pick / 清空草稿** | 无 | 仍经 `setMarkdown` / `clearKnowledgeDraft`，派生字段随同步函数更新 |
| **聊天页跳转 `applyKnowledgeDraftFromChatReply`** | 无 | 直接赋 `markdown` 后调用 `syncKnowledgeDraftDerivedFlags` |
| **非知识页 MarkdownEditor 消费方** | 无 | `leftPreviewMarkdown` 条件仅影响 Markdown 语言 + `enableMarkdownPreview` 路径；其它语言单栏 Editor 无预览 co-mount |

## 4. 潜在风险与缓解

| 风险 | 等级 | 说明 | 建议验证 |
|------|------|------|----------|
| edit 态长时间编辑后切 preview，首帧预览内容滞后 | 低 | 隐藏预览在 edit 期不更新，切模式时 `viewMode` 变化才喂 value；若 layout effect 竞态可能短暂空白 | 长文编辑后点「预览」，确认全文与滚动位置合理 |
| 仅空白字符正文时快捷卡片不显示 | 低 | `markdownNonempty` 与旧 `markdown ?` 在空白串上不一致 | 正文只输入空格/换行，打开助手空态，确认仍为引导文案（可接受则关闭） |
| `memo(KnowledgeAssistant)` 遗漏 props 变化 | 低 | `documentKey` 在 `useMemo` deps 中；`assistantStore` 流式仍由内部 observer 订阅 | 流式输出、切换会话、RAG 新对话各走一遍 |
| 派生字段与直接改 `markdown` 字段不同步 | 低 | 仓库内仅三处直赋 `markdown`，均已调用 `syncKnowledgeDraftDerivedFlags` | 若未来旁路赋值须同步调用，或统一走 `setMarkdown` |
| `documentKey` 清空输入在首次 mount 执行 | 无 | mount 时输入本为空，与改前 `assistantArticleBinding` effect 等价 | 切换列表条目后助手输入不残留上一篇 |

## 5. 未改动项

| 项 | 说明 |
|----|------|
| `knowledgeStore.markdown` / `setMarkdown` | 仍为唯一正文源；长度与内容语义不变 |
| `knowledgePersistedSnapshot` | 脏检查基准不变；保存成功后仍 `setKnowledgePersistedSnapshot` |
| `assistantStore` SSE / 多会话 / ephemeral 迁入 | `assistant.ts` 仅格式 diff，发送与 SSE 逻辑不变 |
| `MarkdownEditor` `value`/`onChange`/`documentIdentity` 契约 | 知识页仍传 `value={knowledgeStore.markdown}`；Monaco rAF 合并上报未删 |
| `onInsertSelectionToAssistant` / 右键菜单 | Monaco `contextMenu` 与 `flushEditorValueToParent` 未动 |
| 分屏 Diff、`diffBaselineSource="persisted"` | 知识页 Diff 基线仍为打开时快照 |
| `KnowledgeList` / `KnowledgeTrashList` / 云端 API | 列表与持久化接口未触达 |
| 英语学习等其它 `MarkdownEditor` 调用方 | 若使用 markdown 预览，行为与知识库相同的 viewMode 规则一致 |

## 6. 回归清单

- [ ] 长文（如 50k+ 字）纯编辑：标题输入、正文输入、右侧助手输入均流畅，无明显卡顿
- [ ] 长文编辑后切换「预览」：全文正确渲染，无大面积空白或陈旧内容
- [ ] 分屏 + 跟随滚动：左右滚动仍对齐（`previewFollowsEditor` / 双向）
- [ ] 打开右侧助手 + 纯编辑：流式回复贴底、停止生成、AI/RAG 模式切换正常
- [ ] 编辑器选区 → 复制到助手（右键与快捷键）：追加/覆盖规则、自动展开助手、聚焦输入框
- [ ] 切换知识列表条目 / 回收站预览：`documentKey` 变化后助手输入清空，会话不串文
- [ ] 清空正文（或清空草稿）：200ms 后 AI 模式助手输入被清空；RAG 输入保留
- [ ] 未保存橙点：仅改标题、仅改正文、保存后消失，与改前一致
- [ ] 手动保存、自动保存（覆盖保存开启）、另存为：内容完整写入
- [ ] AI 快捷卡片（润色/总结/生成目录）：仍携带全文请求；生成目录写回文首逻辑正常
- [ ] Diff 对照进入/退出；助手打开时编辑/预览底栏按钮行为（参考 `monaco-markdown-view-panel`）
- [ ] `npx tsc --noEmit`（`apps/frontend`）
