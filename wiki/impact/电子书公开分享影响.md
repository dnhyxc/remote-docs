## 1. 分析目的

评估 **公开 EPUB、读书记录、书架 `scope=public`、visibility API** 相关改动，是否改变或破坏已有能力：

- 私有书书架（「我的」EPUB/PDF、分类、导入、封面、进度）
- 私有书阅读（进度保存、划线、想法、MOKE、听书/听当前）
- 书架 Tab / 分页 / 空分类隐藏
- 会员 COS 上传与本地书逻辑
- 换号登录 / 401 缓存清理
- PDF 阅读（不支持公开）

**改动范围（当前 diff）**：

| 文件 | 变更 |
|------|------|
| `apps/backend/src/migrations/*ebook_share*`、`*ebook_auth*` | `is_public`、`source_book_id`、`public_at`、想法 `is_public` |
| `apps/backend/src/services/ebook/ebook-book.entity.ts` | 源书 / 读书记录字段 |
| `apps/backend/src/services/ebook/ebook-thought.entity.ts` | `is_public` |
| `apps/backend/src/services/ebook/ebook.service.ts` | `getPublicShelf`、`openPublicBook`、`setBookVisibility`、`appendThoughtBookScope` |
| `apps/backend/src/services/ebook/ebook.controller.ts` | `PUT book/:id/visibility`、`POST public/:id/open`、`GET shelf?scope=public` |
| `apps/frontend/src/store/ebook.ts` | `fetchPage` scope、公开 Tab、`openPublicBook`、`setBookPublic` |
| `apps/frontend/src/views/ebook/index.tsx` | 公开书架卡片、只读操作 |
| `apps/frontend/src/views/ebook/read.tsx` | `publicSource`、书主 visibility、源书下架提示 |
| `apps/frontend/src/views/ebook/components/shelf/*` | 公开 Tab、`EbookBookVisibilitySwitch`、卡片书主信息 |
| `apps/frontend/src/i18n/locales/*.ts` | 公开相关文案 |

**结论摘要**：

| 维度 | 是否影响原有功能 | 说明 |
|------|------------------|------|
| 私有 EPUB/PDF 阅读主路径 | **否** | 仍用本人 `bookId`；进度/划线/想法 API 未改路由形态 |
| 「我的书架」列表组成 | **有条件变化** | `getShelf` 默认仅 `source_book_id IS NULL`，读书记录不再出现在「我的」列表（刻意隔离） |
| 书架「全部」Tab | **有条件变化** | 合并展示他人公开源书（带 `owner`），卡片操作只读 |
| PDF 书架与阅读 | **否** | 无公开入口；实体字段可空 |
| 想法可见性（私有书） | **低** | 新增 `is_public` 默认 true；私有书 scope 仍仅本人想法 |
| 会员 / COS / 本地导入 | **否** | 公开须先上云；未改上传鉴权主逻辑 |
| 换号 / 401 清缓存 | **否** | 既有 `ebookStore` 清空策略仍适用；公开列表随重新拉取更新 |

## 2. 改动要点（相对改前行为）

### 2.1 数据模型：源书 + 读书记录

**改前**：一书一 `ebook_book` 行，`user_id` 与 `book_id` 绑定全部进度/批注。

**改后**：书主持 **源书**（`source_book_id IS NULL`）；读者 `POST .../open` 得 **读书记录**（`source_book_id → 源书`，共享 `file_path`）；进度/划线/想法挂在读书记录 id 上。

**动机**：多人共读同一 COS 文件，批注按账号隔离。

### 2.2 书架 `scope=public` 与「我的」过滤

**改前**：`GET /ebook/shelf` 仅 `user_id = 我` 的全部书。

**改后**：默认书架加 `source_book_id IS NULL`；`scope=public` 查他人 `is_public` 源书并附 `readingBookId`、书主信息。

**动机**：公开发现入口；避免读书记录重复占「我的」格子。

### 2.3 阅读页公开模式

**改前**：仅本人书；想法/划线均本人。

**改后**：读书记录或书主读公开源书时合并他人 **公开** 想法（见 `appendThoughtBookScope`）；顶栏/卡片可切换 `is_public`（仅源书 EPUB 且已上云）。

## 3. 影响点矩阵

| 模块 / 场景 | 影响等级 | 分析 |
|-------------|----------|------|
| **私有 EPUB 阅读** | 无 | `bookId` 仍为本人源书 id；无 `sourceBookId` 时不并他人数据 |
| **私有 PDF 阅读** | 无 | 未接公开 API；`useEbookThoughtLoader` PDF 分支仍全书 list 一次 |
| **我的书架分类/导入** | 无 | 分类、导入、封面、删书逻辑仍针对 `scope=mine` |
| **全部 Tab 展示** | 中 | 他人公开书插入列表；卡片无删书/改封面/移分类（`index.tsx` 传 `undefined`） |
| **公开 Tab** | 低 | 新 Tab；与既有分类 Tab 互斥，空 Tab 隐藏规则仍适用 |
| **点击公开书进阅读** | 中 | 先 `openPublicBook` 再 navigate **读书记录 id**；进度与私有书分离 |
| **书主取消公开** | 有条件变化 | 他人书架不再展示；已有读书记录保留（SPEC 约定） |
| **源书下架/取消公开时读者** | 中 | `publicSource.isStillPublic=false` 时阅读页提示；sync 关闭（见 sync 影响点文） |
| **MOKE / 听书 / 听当前** | 无 | 未改助手与会话绑定；仍按 `bookId` |
| **阅读进度防抖** | 无 | `saveCfi` 仍写读书记录或源书 id；公开书额外触发 thought 拉取/sync（见 viewport 文） |
| **高亮 API** | 无 | 仍 `GET/POST` 按 `bookId`+`userId`；不合并他人划线 |
| **后端 `listThoughts` 范围** | 高（仅公开上下文） | 公开源书/读书记录合并多 `book_id`；**私有书**仍为 `book_id + user_id` |
| **书架 store 分页** | 低 | `activeCategoryKey.kind === 'public'` 走独立 `fetchPublicShelf` |

## 4. 潜在风险与缓解

| 风险 | 等级 | 说明 | 建议验证 |
|------|------|------|----------|
| 读者误以为自己删了书主的书 | 中 | 公开卡片无删除按钮，但「全部」里混排可能困惑 | 确认公开书有书主昵称/头像；只显示「阅读」 |
| 读书记录不占「我的」书架 | 低 | 用户从公开 Tab 进书后，「我的」里只见源书或未出现 | 从公开 Tab 续读；进度记在 `readingBookId` |
| 本地书设公开失败 | 低 | 前端 `canSetPublic` 要求 `src.kind === 'store'` | 本地 EPUB 无地球图标或 disabled + tooltip |
| 源书取消公开后仍持有读书记录 | 中 | 记录保留但 sync/合并范围收窄 | 两账号：取消公开后读者只见本人想法 |
| 分类与公开 Tab 状态串扰 | 低 | `ebookStore` 记住 `scope` | 切换 Tab 后导入分类默认行为 |
| 迁移历史数据 | 低 | 旧书 `is_public=false`、`source_book_id=null` | 存量私有书书架与阅读回归 |

## 5. 未改动项

- PDF 全链路（公开、想法、听书）
- 用户划线合并 / PopBar / 自定义色算法
- `GET /ebook/highlights/:bookId` 范围
- 电子书 MOKE 会话与分享保存
- COS 流式上传、会员拦截、`local_path` 去重
- 阅读进度 8s 远端防抖（`ebook-progress-remote-debounce`）

## 6. 回归清单

- [ ] 私有 EPUB：导入、分类、阅读、写想法、划线、进度刷新后仍正确
- [ ] 私有 PDF：书架与阅读无公开 UI 泄漏
- [ ] 「我的」书架：不出现 `sourceBookId` 读书记录行
- [ ] 「全部」：可见他人公开书；卡片不可删/改封面/移分类
- [ ] 公开 Tab：仅他人公开源书；点进创建读书记录并续读
- [ ] 书主：上云 EPUB 可公开/私有切换；本地书不可公开
- [ ] 书主取消公开：读者书架消失；读者读书记录仍可打开（若保留）
- [ ] 换号登录：书架与阅读不串数据
