# 关于子窗轻量化（独立 chunk + 已开窗 setFocus + 主题预对齐）

> 归档态实现说明。关于窗主题与登出联动见 [./登出统一主题同步.md](../auth/登出统一主题同步.md)；菜单「关于」分支见 [./Tauri系统菜单快捷键.md](../tauri/Tauri系统菜单快捷键.md) §4.1。

## 1. 背景与目标

桌面端「关于」原本和主站共用同一套入口 `main.tsx`：即便只展示版本号 + 版权 + 法律页链接，也会拉起整站 router、plugin manager、Sidebar、Toaster、全量 i18n、COS 代理等，导致关于窗冷启动慢、首帧白屏。同时：

1. **关于窗主题与主窗不同步**：原代码用 `getValue('theme')` 异步读主题再传给 `onCreateWindow`，首帧常取到旧值或 `undefined`，被系统深色接管。
2. **关于窗已存在时点击「关于」仍 emit 弹新窗**：原生侧没有「已开则 setFocus」兜底，前端 JS `setFocus` 在 macOS 常被主窗盖住无效。
3. **版本号依赖主应用 `useGetVersion` hook**：关于窗只要版本号，但 `useGetVersion` 引入更多依赖，违背「轻量」初衷。

本改动：①`main.tsx` 按路径分流——`/about` 只加载 `./about` 轻量 chunk；②新增 `apps/frontend/src/about.tsx` 独立入口，只挂 `<About>` 不加载 router/plugins；③`About` 组件用 `useState` + URL search 取版本，不再依赖 `useGetVersion`；④菜单「关于」分支在原生侧判断 `get_webview_window("about")`，已开则 `unminimize + show + set_focus`，未开才 emit；⑤`onCreateWindow` 已存在窗时 `setTheme + unminimize + show + setFocus`，不重复创建。

## 2. 改动范围

- `apps/frontend/src/main.tsx`（按 `window.location.pathname` 分流入口）
- `apps/frontend/src/about.tsx`（**新增**：关于窗独立入口，只挂 `About`）
- `apps/frontend/src/views/about/index.tsx`（版本号改 `useState` + URL search + `getVersion` 兜底；移除 `useGetVersion`）
- `apps/frontend/src/router/index.tsx`（`about` 监听改同步 + `readWindowChromeThemeSync`；`logout` 改 `performLogout`）
- `apps/frontend/src/utils/tauri.ts`（`onCreateWindow` 已存在窗时 `setTheme + unminimize + show + setFocus`）
- `apps/frontend/src-tauri/tauri.conf.json`（version bump 1.0.91 → 1.0.92，配合发布）

## 3. 实现思路

1. **入口分流**：`main.tsx` 读 `window.location.pathname`，`/about` 走 `import('./about')` 动态 chunk，其它路径走 `import('./router')` 主 chunk。两条路径互不加载对方代码。
2. **关于窗入口极简**：`about.tsx` 只 `ReactDOM.createRoot(el).render(<div><About/></div>)`，不引入 `RouterProvider`/`pluginManager`/`Sidebar`/`Toaster`，冷启 chunk 体积大幅下降。
3. **版本号自给**：`About` 组件先用 `URLSearchParams` 从 `?version=` 取版本（菜单「关于」分支已 emit 版本），无则 Tauri `getVersion()`，浏览器预览用 `VITE_APP_VERSION`，完全不依赖主应用的 `useGetVersion`。
4. **已开则聚焦**：Rust 菜单「关于」分支 `app_handle.get_webview_window("about")` 命中则 `unminimize + show + set_focus`，避免重复创建 + macOS JS `setFocus` 失效。
5. **主题预对齐**：`onCreateWindow` 传 `theme: readWindowChromeThemeSync()`，从 localStorage `dnhyxc_settings_json`/`dnhyxc_theme_bootstrap` 同步读主窗当前主题（black→dark，其余→light），关于窗首帧标题栏与主窗配色一致。
6. **已存在窗也同步主题**：`onCreateWindow` 拿到 `existing` 后先 `setTheme(theme)` 再 `unminimize + show + setFocus`，确保关于窗第二次打开时主题跟着主窗变。

## 4. 关键代码对比与注释

### 4.1 入口分流（`apps/frontend/src/main.tsx`）

**对比范围**：整个 `main.tsx` 文件。

**改动前** · `apps/frontend/src/main.tsx`（基线，约 L1–L5）

```typescript
// 旧入口：直接静态 import 主应用 router
import ReactDOM from 'react-dom/client';
import App from '@/router';

// 直接 createRoot 渲染 <App />，所有路由/插件/i18n 都被打进主 chunk
ReactDOM.createRoot(document.getElementById('root') as HTMLElement).render(
	<App />,
);
```

**改动后** · `apps/frontend/src/main.tsx`（当前，约 L1–L14）

```typescript
// 顶层只静态 import ReactDOM，不静态 import App
import ReactDOM from 'react-dom/client';

// 拿 root 容器
const el = document.getElementById('root') as HTMLElement;
// 标准化 pathname：去末尾斜杠，空则视为 '/'
const path = window.location.pathname.replace(/\/+$/, '') || '/';
// 判断是不是关于窗（菜单 onCreateWindow url='/about?version=...'，pathname 是 '/about'）
const isAboutWindow = path === '/about';

// 关于窗只拉轻量 chunk，避免冷启整站路由/插件
if (isAboutWindow) {
	// 动态 import('./about')：Vite 会单独打成 about.[hash].js，关于窗首帧不加载 router chunk
	void import('./about').then((m) => m.mount(el));
} else {
	// 主应用走动态 import('./router')，主 chunk 仍包含 router，但关于窗不会加载它
	void import('./router').then((m) => {
		// 拿到默认导出 App 再 createRoot render
		ReactDOM.createRoot(el).render(<m.default />);
	});
}
```

**变更摘要**：从静态 `import App from '@/router'` 改为按 pathname 动态 import——`/about` 走 `./about` chunk，其它走 `./router` chunk，两条路径代码分离。

### 4.3 版本号自给（`apps/frontend/src/views/about/index.tsx` · `readVersionFromSearch` + `About`）

**对比范围**：`readVersionFromSearch` 函数 + `About` 组件 `version` state 与 `useEffect` 取版本逻辑。

**改动前** · `apps/frontend/src/views/about/index.tsx`（基线，约 L1–L20）

```typescript
// 旧 import：从 @/hooks 拿 useGetVersion / useI18n / useTheme（聚合出口，会引入更多依赖）
import { Button } from '@ui/button';
import { useEffect } from 'react';
import { type ThemeName, useGetVersion, useI18n, useTheme } from '@/hooks';
import type { Locale } from '@/i18n';
import { onListen, openExternalUrl } from '@/utils';
import {

	LEGAL_PAGE_PATHS,

const About = () => {
	// 旧 useGetVersion：内部会引更多 hook / Tauri API，违背轻量初衷

	const { t, setLocale, locale } = useI18n();

	useEffect(() => {
		// 监听主题变化
		const unlistenThemePromise = onListen('theme', (value: string) => {

		});
		// ... 监听 locale
	}, [changeTheme, setLocale]);

	return (

```

**改动后** · `apps/frontend/src/views/about/index.tsx`（当前，约 L1–L65）

```typescript
// 新 import：拆细——useI18n 从 @/hooks/i18n，useTheme 从 @/hooks/theme，不再从聚合 @/hooks 引
import { Button } from '@ui/button';
import { useEffect, useState } from 'react';
import { useI18n } from '@/hooks/i18n';
import { type ThemeName, useTheme } from '@/hooks/theme';
import type { Locale } from '@/i18n';
// 拆细 event / openExternalUrl，减少打包副作用
import { onListen } from '@/utils/event';
import { openExternalUrl } from '@/utils/open-external';
import { isTauriRuntime } from '@/utils/runtime';
import {
	getLegalPageAbsoluteUrl,
	LEGAL_PAGE_PATHS,
} from '@/views/legal/legalPageUrls';

// 新增：从 URL search 读 version（菜单 onCreateWindow 已传 ?version=...）
function readVersionFromSearch(): string {
	try {
		// URLSearchParams 兼容旧浏览器，try/catch 防 SSR 报错
		return new URLSearchParams(window.location.search).get('version') ?? '';
	} catch {
		return '';
	}
}

const About = () => {
	// useState 初始化直接用 readVersionFromSearch：首帧即有版本号，无 loading
	const [version, setVersion] = useState(readVersionFromSearch);
	const { t, setLocale, locale } = useI18n();
	const { changeTheme } = useTheme();

	useEffect(() => {
		// 已有版本号（从 URL 拿到）则不再异步取
		if (version) return;
		let cancelled = false;
		(async () => {
			if (!isTauriRuntime()) {
				// 浏览器预览：用 VITE_APP_VERSION 兜底
				if (!cancelled) {
					setVersion(import.meta.env.VITE_APP_VERSION ?? '浏览器预览');
				}
				return;
			}
			// Tauri：动态 import getVersion，避免静态引入整个 @tauri-apps/api/app
			const { getVersion } = await import('@tauri-apps/api/app');
			const v = await getVersion();
			if (!cancelled) setVersion(v);
		})();
		return () => {
			cancelled = true;
		};
	}, [version]);

	useEffect(() => {
		// 监听主题变化（主窗改主题时 emit('theme')，关于窗跟随）
		const unlistenThemePromise = onListen('theme', (value: string) => {
			changeTheme(value as ThemeName, false);
		});
		// 监听语言变化（主窗切语言时 emit('locale')，关于窗跟随）
		const unlistenLocalePromise = onListen('locale', (value: Locale) => {
			void setLocale(value, { syncUrl: false, emitEvent: false });
		});
		return () => {
			unlistenThemePromise.then((unlisten) => unlisten());
			unlistenLocalePromise.then((unlisten) => unlisten());
		};
	}, [changeTheme, setLocale]);

	return (
		<div className="flex flex-col justify-center items-center w-full h-full">
			<div className="mb-10">
				{/* version 为空时显示 '…' 占位，避免首帧空白 */}
				{t('about.appVersion', { version: version || '…' })}
			</div>
			{/* ... 法律页按钮 JSX 不变 */}
		</div>
	);
};
```

**变更摘要**：删 `useGetVersion` 改 `useState(readVersionFromSearch) + useEffect 异步 `getVersion` 兜底`；`import` 拆细（`useI18n`/`useTheme`/`onListen`/`openExternalUrl` 不再从聚合出口）；version 空时显示 `'…'` 占位。

### 4.4 关于窗监听与主题预对齐（`apps/frontend/src/router/index.tsx` · `about`/`logout` listen）

**对比范围**：`App` 组件 `useEffect` 内 `listen('about')` + `listen('logout')` 分支。

**改动前** · `apps/frontend/src/router/index.tsx`（基线，约 L8–L18 + L57–L72）

```typescript
// 旧 import：从 @/utils 聚合出口拿 getValue / onCreateWindow / removeStorage
import {
	attachTauriPlainFieldClipboardShortcuts,
	getValue,
	onCreateWindow,
	removeStorage,
} from '@/utils';
import { http } from '@/utils/fetch';

// ... 旧 about 监听：async 函数 + getValue('theme') 异步取主题
const aboutUnlisten = await listen('about', async (event) => {
	const eventOptions = event.payload as { version: string };
	// 异步读主题：首帧常取到旧值或 undefined，被系统深色接管
	const theme = (await getValue('theme')) as 'light' | 'dark' | undefined;

		// ...
		theme,
	});

const logoutUnlisten = await listen('logout', () => {
	// 旧 logout：手动清 token + setAuthToken，与侧边栏登出逻辑重复且易漂移
	removeStorage('token');
	http.setAuthToken('');
```

**改动后** · `apps/frontend/src/router/index.tsx`（当前，约 L9–L18 + L57–L77）

```typescript

import { useInputsOnlyTab } from '@/hooks';
import { readWindowChromeThemeSync } from '@/hooks/theme';
import { pluginManager, routeInjector } from '@/plugins';
import {
	attachTauriPlainFieldClipboardShortcuts,
	onCreateWindow,
} from '@/utils';
import { isTauriRuntime } from '@/utils/runtime';
import { performLogout } from './authSession';

// ... 新 about 监听：改同步函数 + readWindowChromeThemeSync + encodeURIComponent
const aboutUnlisten = await listen('about', (event) => {
	const eventOptions = event.payload as { version: string };
	// 同步：避免 about 窗已开时还要等 onCreateWindow 异步判 existing
	void onCreateWindow({
		// version 用 encodeURIComponent 防特殊字符破坏 URL
		url: `/about?version=${encodeURIComponent(eventOptions.version)}`,
		label: 'about',
		title: 'dnhyxc-ai',
		width: 400,
		height: 300,
		titleBarStyle: 'visible',
		hiddenTitle: false,
		resizable: false,
		// 与主窗配色一致：非 black → light 标题栏（勿传 undefined 以免跟系统深色）
		theme: readWindowChromeThemeSync(),
	});
});
const logoutUnlisten = await listen('logout', () => {
	// Tauri File 菜单「退出登录」：需与侧边栏登出一致（清态 + 跳转）
	performLogout((to) => router.navigate(to));
```

**变更摘要**：`about` 监听改同步函数；主题用 `readWindowChromeThemeSync()` 同步读；version 用 `encodeURIComponent`；`logout` 监听改 `performLogout`（详见 [./登出统一主题同步.md](../auth/登出统一主题同步.md)）。

```typescript
const existing = await WebviewWindow.getByLabel(label);
if (existing) {
	try {
		// 先 setTheme：避免主题变化后已开窗仍用旧主题
		if (theme) await existing.setTheme(theme);
	} catch {
		// 主题失败不影响置顶
	}

		// unminimize：从 Dock 最小化状态恢复
		await existing.unminimize();
	} catch {
		// ignore
	}
	// show：从 hidden 状态显示
	await existing.show();
	// setFocus：置顶聚焦
	await existing.setFocus();
	// 调用方回调（与新建路径行为对齐）
	createdCallback?.();
	return;
}
```

**变更摘要**：已存在窗分支加 `setTheme(theme) + unminimize + show`，并补 `createdCallback?.()`；包 `try/catch` 容错主题失败。

## 5. 兼容性与影响

- **入口分流**：`/about` 走独立 chunk 后，主应用 chunk 体积下降；关于窗首帧不再加载 router/plugins。
- **版本号显示**：URL `?version=` 优先（菜单「关于」分支已传），无则 Tauri `getVersion`，浏览器预览用 `VITE_APP_VERSION`；旧 `useGetVersion` 行为对齐。
- **已开窗重复点「关于」**：原生侧 `get_webview_window("about")` 命中走 `unminimize + show + set_focus`，不再重复创建；前端 `onCreateWindow` 也兜底 `setTheme + show + setFocus`。
- **主题预对齐**：`readWindowChromeThemeSync()` 从 localStorage 同步读，关于窗首帧标题栏与主窗一致；后续主题变化靠 `onListen('theme')` 跟随 + `setThemeToAllWindows` 广播（详见 [./登出统一主题同步.md](../auth/登出统一主题同步.md)）。
- **回归点**：①macOS 上关于窗已最小化时点菜单「关于」能否恢复置顶；②主窗切深色后已开的关于窗标题栏是否跟随；③关于窗版本号首帧是否正确；④浏览器环境（非 Tauri）访问 `/about` 是否正常显示版本占位。
