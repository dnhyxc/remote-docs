# 桌面下载页视觉重构

> 延伸阅读：
> - [UI 色调打磨](./UI色调打磨.md)
> - [独立预览打磨](./独立预览打磨.md)

## 1. 背景与目标

桌面下载页作为用户获取桌面端安装包的入口，承担着「建立第一印象 + 引导下载」的双重职责。本次视觉重构聚焦以下目标：

- **跟随品牌强调色**：原页面背景使用硬编码的 `teal/cyan` 径向渐变（`rgba(45,212,191,...)`、`rgba(6,182,212,...)`），与用户在主题中自定义的 `--brand-accent` 完全脱节。重构后所有装饰色统一通过 `color-mix(in oklch, var(--brand-accent) X%, transparent)` 派生，确保页面色调随强调色联动。
- **简化卡片结构**：原页面在卡片外部散落 `secondaryLinks`（发布说明 / 用户指南 / 返回首页）内联按钮，视觉层级混乱；重构后收拢为单张 `Card`，由 header（平台切换 + 版本徽标）/ content（下载区 + 安装说明）/ footer（信息链接）三段式构成。
- **强化视觉层级**：主标题由纯色 `text-textcolor` 升级为 `--brand-accent → --brand-accent-soft` 渐变文字，并通过 `leading-snug` 与更大的 `sm:text-[2.75rem]` 提升首屏冲击力。

## 3. 实现思路

### 3.1 跟随强调色的背景渐变

通过 CSS `color-mix(in oklch, var(--brand-accent) X%, transparent)` 在运行时把品牌强调色按比例稀释为透明色块，再以四层径向渐变叠加（左上 / 右上 / 左下 / 右下）铺满全屏。这样无论用户选择何种主题（绿、紫、橙…），背景晕染都会随之联动，无需为每个主题单独维护色值。

### 3.2 渐变主标题

将标题文字包在 `<span>` 内，应用 `bg-linear-to-r bg-clip-text text-transparent` 三件套，并通过内联 `backgroundImage: linear-gradient(90deg, var(--brand-accent), var(--brand-accent-soft))` 指定渐变方向与起止色。渐变两端分别取强调色与其柔和变体，保证在浅 / 深主题下均有足够对比度。

### 3.3 单卡片三段式布局

废弃卡片外的 `secondaryLinks` 内联按钮区，全部信息收拢进单张 `Card`：

- **header**：平台 Tab 切换 + 带 `ping` 动画的版本徽标；
- **content**：macOS 下展示 Intel / Apple Silicon 下载按钮与安装说明；Windows / Linux 展示「即将到来」占位；
- **footer**：发布说明 / 用户指南 / 返回首页，统一用 `ArrowRight` 图标。

平台 Tab 的激活态由原先的 `border` 下划线改为 `bg-teal-500/80` 实心背景，配合 `text-white` 提升可识别性。

### 3.4 居中安装说明

安装说明由原先左对齐的多段并列改为 `w-fit max-w-full` 居中块，内部步骤使用 `whitespace-nowrap` 避免换行错位，整体视觉重心与卡片对齐。

改动后：

```tsx
{/* 背景装饰层：固定定位、不可点击、整体透明度提升至 0.85，强调晕染存在感 */}
<div
    className="pointer-events-none absolute inset-0 -z-10 opacity-[0.85]"
    aria-hidden
    style={{
        // 四层径向渐变叠加，全部由 --brand-accent / --brand-accent-soft 派生
        background: [
            // 左上角：强调色 5% 稀释，55% 处淡出
            'radial-gradient(55% 70% at 9% 10%, color-mix(in oklch, var(--brand-accent) 5%, transparent), transparent 55%)',
            // 右上角：强调色 10% 稀释，58% 处淡出（主光源）
            'radial-gradient(90% 70% at 70% 30%, color-mix(in oklch, var(--brand-accent) 10%, transparent), transparent 58%)',
            // 左下角：柔和变体 7% 稀释，52% 处淡出
            'radial-gradient(70% 55% at 10% 85%, color-mix(in oklch, var(--brand-accent-soft) 7%, transparent), transparent 52%)',
            // 右下角：强调色 5% 稀释，55% 处淡出（与左上角对称）
            'radial-gradient(55% 70% at 91% 90%, color-mix(in oklch, var(--brand-accent) 5%, transparent), transparent 55%)',
            // 数组拼接为逗号分隔的多背景字符串
        ].join(', '),
    }}
/>
```

## 5. 兼容性与影响

- **主题色联动**：背景与标题渐变依赖 `--brand-accent` / `--brand-accent-soft` CSS 变量，需确认主题系统已正确注入这两个变量；若缺失，渐变将退化为透明，页面背景接近纯色但仍可读。
- **浏览器兼容**：`color-mix(in oklch, ...)` 与 `bg-clip-text` 需要现代浏览器（Chrome 111+ / Safari 16.4+ / Firefox 113+），与项目既定目标浏览器一致，无额外降级。
- **i18n 文案**：`downloadPage.hero.title` 与 `downloadPage.mac.installGuide` 的 key 变更需同步 zh / en 两份语言包，否则会显示 key 原文。

## 6. 风险与回归

- **回归点 1：背景透明度由 0.35 提升至 0.85**，在浅色主题下可能让背景晕染偏重，需目测确认不影响正文可读性。
- **回归点 2：主标题改为渐变文字**，若 `--brand-accent` 与背景对比不足（如黄色系），可能出现「灰糊」感，建议在主题切换器中逐主题目测。
- **回归点 3：平台 Tab 激活态由 border 改为实心背景**，颜色硬编码为 `bg-teal-500/80`，未跟随 `--brand-accent`，后续可考虑统一。
- **回归点 4：安装说明改用 `whitespace-nowrap`**，在窄屏（< 360px）下可能触发横向滚动，需在小屏设备上验证。
