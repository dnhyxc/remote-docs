# 富文本编辑器功能实现

> **延伸阅读**：[视频播放器组件重构.md](../video/视频播放器组件重构.md)（视频播放器组件化重构）、[学习笔记实现.md](../app/学习笔记实现.md)（学习笔记 MobX Store 与导出）

## 1. 背景与目标

学习笔记插件需要一个功能完善的富文本编辑器，用于笔记的创建、编辑和预览。原项目中已有基础编辑器，但存在以下问题：

- **标题与正文分离**：笔记标题没有作为文档结构的一部分，无法在编辑时实时获取标题文本。
- **图片上传耦合**：图片上传逻辑硬编码在编辑器内，无法对接 Host 端的上传 API。
- **快捷键缺失**：缺少 Cmd/Ctrl+↑↓ 文档首尾导航、Tab 列表缩进等常用快捷键。
- **多语言支持不完善**：编辑器 UI 文案没有完整的中英文切换能力。
- **空段落删除异常**：在图片或标题后的空段落无法通过 Backspace/Delete 删除。

本轮基于 **Tiptap**（ProseMirror React 封装）构建了完整的富文本编辑器模块，支持：自定义标题节点、Tab 缩进、文档边界导航、图片粘贴/拖放上传、字数统计、多语言界面等。

## 3. 实现思路

### 3.1 整体架构

编辑器按职责拆成以下层次：

1. **节点层** (`TitleNode.ts`)：自定义 Tiptap Node，实现笔记标题作为文档首位 atom 节点。
2. **扩展层** (`extensions/index.ts`)：组装所有 Tiptap 扩展，包括自定义快捷键扩展。
3. **功能层** (image/、link/、code/、toolbar/、title/)：各功能独立模块。
4. **UI 层** (`index.tsx`)：编辑器主组件，负责 useEditor 初始化、渲染工具栏、气泡菜单、字数统计等。

### 3.2 自定义标题节点 (TitleNode)

笔记的标题需要作为文档结构的一部分，而不是独立的输入框。通过自定义 Tiptap Node 实现：

- **atom 节点**：标题是 atom 类型，内容通过 `attrs.value` 存储，不是普通文本节点。
- **单标题约束**：`group: 'title'` 且 `Content: 'title block+'`，确保文档首位只有一个 title。
- **结构修复 Plugin**：通过 `appendTransaction` 监听文档变化，自动删除多余 title、补充正文段落。
- **选区修正**：当光标落在 GapCursor 或标题内时，自动修正到正文开头。
- **快捷键处理**：Cmd+A 只选中正文（避开标题），标题输入后的 Enter/Tab 跳到正文末尾。

### 3.3 Tab 缩进扩展 (TabIndent)

自定义扩展实现列表缩进和正文 Tab 行为：

- **Tab 键**：在列表中下沉列表项（`sinkListItem`），在正文中插入 `\t`。
- **Shift-Tab**：在列表中提升列表项（`liftListItem`）。
- **codeBlock 豁免**：代码块内不拦截 Tab，让默认行为生效。

### 3.4 文档边界导航 (DocEdgeNav)

实现 Cmd/Ctrl+↑↓ 快速导航到文档首尾：

- **Cmd+↑**：光标跳到标题后的正文开头，同时滚动容器到顶部。
- **Cmd+↓**：光标跳到文档末尾，同时滚动容器到底部。
- **代码块豁免**：在代码块内不拦截。

### 3.5 空段落删除 (EmptyParagraphDelete)

解决标题/图片后的空段落无法删除的问题：

- **Backspace**：当光标在空段开头时，直接删除整个空段（前提是删除后文档仍满足最少块数）。
- **Delete**：当光标在空段末尾时，直接删除整个空段。
- **最少块数检查**：有 title 时至少保留 title + 1 段，无 title 时至少保留 1 段。

### 3.6 图片上传 (ImageUpload)

通过自定义 ProseMirror Plugin 实现粘贴和拖放图片：

- **handlePaste**：解析剪贴板中的图片文件，同时含文本时让 PM 先完成默认粘贴再异步插入图片。
- **handleDrop**：解析拖放数据中的图片文件，阻止默认行为后插入。
- **resolveSrcRef**：通过 ref 模式始终读最新的上传函数，支持对接 Host 端上传 API。

### 3.7 字数统计 (CharCount)

基于 Tiptap CharacterCount 扩展：

- **字符计数**：使用 `Intl.Segmenter` 按 grapheme 粒度计数（CJK 字符正确处理）。
- **词数计数**：CJK 字符 + 拉丁单词分别计数后求和。
- **上限检查**：超出 `maxLength` 时显示「已达字数上限」提示。

### 3.8 多语言支持 (locale)

编辑器 UI 文案完整中英双语：

- **locale 对象**：包含所有编辑器 UI 文案（占位符、工具栏按钮、对话框等）。
- **`richEditorLocaleOf`**：根据应用 locale 返回对应语言的文案对象。
- **`mergeLocale`**：支持部分覆盖，便于定制化。

```tsx
// TipTap 二次封装富文本编辑器组件
export function RichEditor({
        // 初始内容（HTML 或 JSON）
        content,
        // 默认内容
        defaultContent = '',
        // 内容变更回调
        onChange,
        // 是否可编辑
        editable = true,
        // 是否自动聚焦
        autofocus = true,
        // 占位符文本
        placeholder,
        // 外层 className
        className,
        // 编辑器内部 className
        editorClassName,
        // 字数上限
        maxLength,
        // 文本方向
        textDirection = 'auto',
        // 是否显示工具栏
        showToolbar = true,
        // 是否显示气泡菜单
        showBubbleMenu = true,
        // 是否显示字数统计
        showCharCount = true,
        // 是否显示标题
        showTitle = true,
        // 是否启用图片尺寸调整
        imageResize = false,
        // 是否启用表格列宽调整
        tableResizable = false,
        // 本地化文案（部分覆盖）
        locale: localePartial,
        // 默认扩展（覆盖默认）
        extensions,
        // 追加扩展
        extraExtensions,
        // 工具栏额外按钮
        toolbarExtra,
        // 图片上传回调
        onUploadImage,
        // 创建完成回调
        onCreate,
        // 正文滚动回调
        onBodyScroll,
        // 自定义渲染正文
        renderBody,
}: RichEditorProps) {
        // 合并本地化文案：部分覆盖 + 默认 zhCN
        const locale = useMemo(() => mergeLocale(localePartial), [localePartial]);

        // 图片上传解析函数 ref（始终读最新实现）
        const resolveImageSrcRef = useRef<ResolveImageSrc>(fileToDataUrl);
        resolveImageSrcRef.current = async (file) => {
                // 优先使用外部传入的上传函数
                if (onUploadImage) return onUploadImage(file);
                // 默认 FileReader → DataURL
                return fileToDataUrl(file);
        };

        // onChange ref（避免 useEditor 闭包问题）
        const onChangeRef = useRef(onChange);
        onChangeRef.current = onChange;

        // onCreate ref
        const onCreateRef = useRef(onCreate);
        onCreateRef.current = onCreate;

        // 无字数 UI 且无上限时不挂 CharacterCount 扩展
        const enableCharacterCount = showCharCount || maxLength != null;

        // 初始化 TipTap 编辑器
        const editor = useEditor({
                // 禁用立即渲染，等扩展准备好
                immediatelyRender: false,
                // 组装扩展（含自定义 TabIndent、DocEdgeNav 等）
                extensions: createExtensions({
                        placeholder: placeholder ?? locale.placeholder,
                        maxLength,
                        characterCount: enableCharacterCount,
                        extensions,
                        extraExtensions,
                        resolveImageSrcRef,
                        showTitle,
                        imageResize,
                        tableResizable,
                }),
                // 初始内容：有标题时包装为标题+正文结构
                content: showTitle
                        ? normalizeNoteContent(content ?? defaultContent)
                        : (content ?? defaultContent ?? ''),
                // 可编辑状态
                editable,
                // 自动聚焦
                autofocus,
                // 文本方向
                textDirection,
                // 编辑器属性
                editorProps: {
                        attributes: {
                                class: cn('tiptap focus:outline-none', editorClassName),
                                lang: 'zh-CN',
                        },
                },
                // 创建完成回调
                onCreate: ({ editor: e }) => {
                        // 焦点管理：有 title 节点时钉到正文末尾
                        const focusBodyEnd = () => {
                                if (e.isDestroyed) return;
                                // autofocus='end' 或有 title 节点时聚焦正文末尾
                                if (
                                        autofocus === 'end' ||
                                        e.state.doc.firstChild?.type.name === 'title'
                                ) {
                                        e.commands.focus('end');
                                }
                        };
                        focusBodyEnd();
                        // Title NodeView 挂载可能打乱选区，下一帧再钉到末尾
                        requestAnimationFrame(() => {
                                focusBodyEnd();
                                requestAnimationFrame(focusBodyEnd);
                        });
                        onCreateRef.current?.(e);
                },
                // 更新回调：不做 getJSON（学习笔记只用 html/text/title）
                onUpdate: ({ editor: e }) => {
                        const cb = onChangeRef.current;
                        if (!cb) return;
                        // 热路径：只取 HTML、文本和标题
                        cb({
                                html: e.getHTML(),
                                text: e.getText({ blockSeparator: '\n\n' }),
                                title: getDocTitleText(e.state.doc),
                        });
                },
        });
        // ...（渲染部分省略，见下文变更摘要）
}
```

**变更摘要**：RichEditor 组件通过 `useEditor` 初始化 Tiptap，支持标题节点、图片上传 ref 模式、受控内容同步、字数统计等核心能力。`onChange` 回调只返回 html/text/title，避免热路径上的 `getJSON` 开销。

```typescript
// Tab：列表下沉 / 正文插入缩进
const TabIndent = Extension.create({
        // 扩展名
        name: 'tabIndent',
        // 高优先级，确保在 StarterKit 之前处理
        priority: 1000,
        addKeyboardShortcuts() {
                return {
                        Tab: ({ editor }) => {
                                // 代码块内不拦截
                                if (editor.isActive('codeBlock')) return false;
                                // 列表项下沉或正文插入 \t
                                return indentEditor(editor);
                        },
                        'Shift-Tab': ({ editor }) => {
                                // 代码块内不拦截

                                // 提升列表项
                                if (editor.commands.liftListItem('listItem')) return true;
                                if (editor.commands.liftListItem('taskItem')) return true;
                                return true;
                        },
                };
        },
});

// 滚到编辑器视口顶部或底部的辅助函数
function scrollEditorViewport(
        editor: { view: { dom: Element } },
        to: 'top' | 'bottom',
) {
        // 查找最近的滚动容器
        const vp = editor.view.dom.closest(
                '[data-slot="scroll-area-viewport"]',
        ) as HTMLElement | null;
        if (!vp) return;
        // 滚动到顶部或底部
        vp.scrollTop = to === 'top' ? 0 : vp.scrollHeight;
}

// Cmd/Ctrl+↑↓：跳到文档首尾并滚动视口
const DocEdgeNav = Extension.create({
        name: 'docEdgeNav',
        addKeyboardShortcuts() {
                return {
                        'Mod-ArrowUp': ({ editor }) => {
                                // 代码块内不拦截
                                if (editor.isActive('codeBlock')) return false;
                                // 计算 title 节点后的起始位置
                                const title = editor.state.doc.firstChild;
                                const start = title?.type.name === 'title' ? title.nodeSize + 1 : 1;
                                if (start <= editor.state.doc.content.size) {
                                        editor.chain().setTextSelection(start).focus().run();
                                } else {
                                        editor.commands.focus('start');
                                }
                                // 滚动到视口顶部
                                scrollEditorViewport(editor, 'top');
                                return true;
                        },
                        'Mod-ArrowDown': ({ editor }) => {
                                // 代码块内不拦截
                                if (editor.isActive('codeBlock')) return false;
                                // 跳到文档末尾
                                editor.commands.focus('end');
                                // 滚动到视口底部
                                scrollEditorViewport(editor, 'bottom');
                                return true;
                        },
                };
        },
});
```

**改动后** · `apps/micro/src/components/design/RichEditor/title/TitleNode.ts`（当前，约 L22–110）

```typescript
// 笔记常驻标题：atom 节点 + 原生 input（attrs.value）
export const TitleNode = Node.create({
        // 节点名称
        name: 'title',
        // 分组：title 组（确保仅首位一个）
        group: 'title',
        // atom 节点：内容通过属性存储
        atom: true,
        // 不可拖拽
        draggable: false,
        // 不可选中（通过 NodeView 处理交互）
        selectable: false,

        addAttributes() {
                return {
                        // 标题文本存在 value 属性中
                        value: {
                                default: '',
                                // HTML 解析时从 data-value 或 textContent 读取
                                parseHTML: (el) =>
                                        (el as HTMLElement).getAttribute('data-value') ??
                                        (el as HTMLElement).textContent ??
                                        '',
                                // HTML 渲染时输出 data-value 属性
                                renderHTML: (attrs) =>
                                        attrs.value ? { 'data-value': attrs.value as string } : {},
                        },
                };
        },

        parseHTML() {
                return [{ tag: 'div[data-type="note-title"]' }];
        },

        renderHTML({ HTMLAttributes, node }) {
                return [
                        'div',
                        mergeAttributes(HTMLAttributes, {
                                'data-type': 'note-title',
                                'data-value': node.attrs.value ?? '',
                        }),
                        node.attrs.value ?? '',
                ];
        },

        addNodeView() {
                // stopEvent：标题内交互不交给 PM，避免和正文抢输入
                return ReactNodeViewRenderer(TitleView, {
                        stopEvent: () => true,
                });
        },

        addProseMirrorPlugins() {
                return [
                        new Plugin({
                                key: new PluginKey('singleNoteTitle'),
                                appendTransaction(transactions, _old, state) {
                                        const docChanged = transactions.some((tr) => tr.docChanged);
                                        const selectionSet = transactions.some((tr) => tr.selectionSet);
                                        if (!docChanged && !selectionSet) return null;

                                        let tr = state.tr;
                                        let changed = false;

                                        // 结构修复只在 doc 变化时做
                                        if (docChanged) {
                                                const extras: { pos: number; nodeSize: number }[] = [];
                                                let seen = 0;
                                                // 遍历文档，收集多余的 title 节点
                                                state.doc.forEach((node, offset) => {
                                                        if (node.type.name !== 'title') return;
                                                        seen += 1;
                                                        // 第二个及以后的 title 视为多余
                                                        if (seen > 1)
                                                                extras.push({ pos: offset, nodeSize: node.nodeSize });
                                                });
                                                // 倒序删除多余 title（避免位置偏移）
                                                for (let i = extras.length - 1; i >= 0; i--) {
                                                        const { pos, nodeSize } = extras[i];
                                                        tr.replaceWith(
                                                                pos,
                                                                pos + nodeSize,
                                                                state.schema.nodes.paragraph.create(),
                                                        );
                                                        changed = true;
                                                }

                                                // 检查是否有正文段落（atom 旁 GapCursor 无法输入）
                                                const doc = changed ? tr.doc : state.doc;
                                                const title = doc.firstChild;
                                                if (title?.type.name === 'title' && doc.childCount < 2) {
                                                        // 没有正文块时补一段空段落
                                                        tr = tr.insert(
                                                                title.nodeSize,
                                                                state.schema.nodes.paragraph.create(),
                                                        );
                                                        changed = true;
                                                }
                                        }

                                        // 选区修正：确保光标在正文可输入位置
                                        const nextDoc = changed ? tr.doc : state.doc;
                                        const titleNode = nextDoc.firstChild;
                                        if (titleNode?.type.name === 'title') {
                                                const titleSize = titleNode.nodeSize;
                                                const sel = changed ? tr.selection : state.selection;
                                                const $from = sel.$from;
                                                // 光标是否在正文文本块内
                                                const caretInBody =
                                                        sel instanceof TextSelection &&
                                                        sel.empty &&
                                                        $from.parent.isTextblock &&
                                                        $from.pos > titleSize;

                                                const bodyEmpty =
                                                        nextDoc.childCount < 2 ||
                                                        (nextDoc.childCount === 2 &&
                                                                nextDoc.child(1).isTextblock &&
                                                                nextDoc.child(1).content.size === 0);

                                                let needsFix = false;
                                                // 空正文时且光标不在正文 → 修正
                                                if (bodyEmpty && sel.empty && !caretInBody) {
                                                        needsFix = true;
                                                } else if (
                                                        sel.empty &&
                                                        !(sel instanceof GapCursor) &&
                                                        !$from.parent.isTextblock
                                                ) {
                                                        needsFix = true;
                                                }

                                                if (needsFix && titleSize + 1 <= nextDoc.content.size) {
                                                        // 把光标设到正文开头
                                                        tr = tr.setSelection(
                                                                TextSelection.near(nextDoc.resolve(titleSize + 1), 1),
                                                        );
                                                        changed = true;
                                                }
                                        }

                                        return changed ? tr : null;
                                },
                        }),
                ];
        },

        addKeyboardShortcuts() {
                return {
                        // Cmd+A 只覆盖正文，避开 title NodeView
                        'Mod-a': ({ editor }) => {
                                const { doc } = editor.state;
                                const title = doc.firstChild;
                                if (title?.type.name !== 'title') return false;
                                // 计算正文起始位置
                                const start = title.nodeSize + 1;
                                if (start >= doc.content.size) return true;
                                // 选中正文全部内容
                                const from = TextSelection.near(doc.resolve(start), 1).from;
                                const to = Selection.atEnd(doc).to;
                                if (from < to) {
                                        editor.commands.setTextSelection({ from, to });
                                } else {
                                        editor.commands.setTextSelection(from);
                                }
                                return true;
                        },
                };
        },
});
```

**变更摘要**：`TitleNode` 作为 atom 节点存储笔记标题，通过 ProseMirror Plugin 实现单标题约束（删除多余 title、补充空正文）和选区修正（光标落在可输入位置）。Cmd+A 只选中正文避免选中标题 input。

### 4.5 `EmptyParagraphDelete` 空段落删除扩展（`apps/micro/src/components/design/RichEditor/extensions/EmptyParagraphDelete.ts`）

**对比范围**：`EmptyParagraphDelete` Extension.create 定义（新增）。

**改动后** · `apps/micro/src/components/design/RichEditor/extensions/EmptyParagraphDelete.ts`（当前，约 L44–100）

```typescript
// 判断节点是否为空段落（仅含 hardBreak 或无内容）
function isEmptyParagraphNode(node: PmNode): boolean {
        if (node.type.name !== 'paragraph') return false;
        if (node.content.size === 0) return true;
        // <p><br></p> 也算空行
        let onlyBreaks = true;
        node.forEach((child) => {
                if (child.type.name !== 'hardBreak') onlyBreaks = false;
        });
        return onlyBreaks;
}

// 判断当前选区是否在空段落内
function emptyParagraphAt(selection: Selection) {
        if (!(selection instanceof TextSelection) || !selection.empty) return null;
        const { $from } = selection;
        const parent = $from.parent;
        if (!isEmptyParagraphNode(parent)) return null;
        return {
                $from,
                parent,
                from: $from.before(),
                to: $from.before() + parent.nodeSize,
        };
}

// 判断删除后文档是否仍满足最少块数
function canRemoveBlock(doc) {
        const min = doc.firstChild?.type.name === 'title' ? 2 : 1;
        return doc.childCount > min;
}

// 空段落删除扩展
export const EmptyParagraphDelete = Extension.create({
        name: 'emptyParagraphDelete',

        addKeyboardShortcuts() {
                return {
                        // Backspace：空段开头时删除整个空段
                        Backspace: ({ editor }) => {
                                const hit = emptyParagraphAt(editor.state.selection);
                                if (!hit || hit.$from.parentOffset !== 0) return false;
                                if (!canRemoveBlock(editor.state.doc)) return false;

                                const { from, to } = hit;
                                return editor
                                        .chain()
                                        .command(({ tr, dispatch }) => {
                                                // 删除空段
                                                tr.delete(from, to);
                                                // 选区设在合理位置
                                                const pos = Math.min(from, tr.doc.content.size);
                                                tr.setSelection(Selection.near(tr.doc.resolve(pos), 1));
                                                dispatch?.(tr);
                                                return true;
                                        })
                                        .run();
                        },
                        // Delete：空段末尾时删除整个空段
                        Delete: ({ editor }) => {
                                const hit = emptyParagraphAt(editor.state.selection);
                                if (!hit) return false;
                                if (hit.$from.parentOffset !== hit.parent.content.size) return false;
                                if (!canRemoveBlock(editor.state.doc)) return false;
                                if (hit.to >= editor.state.doc.content.size) return false;

                                const { from, to } = hit;
                                return editor
                                        .chain()
                                        .command(({ tr, dispatch }) => {
                                                tr.delete(from, to);
                                                const pos = Math.min(from, tr.doc.content.size);
                                                tr.setSelection(Selection.near(tr.doc.resolve(pos), 1));
                                                dispatch?.(tr);
                                                return true;
                                        })
                                        .run();
                        },
                };
        },
});
```

**变更摘要**：解决标题/图片后的空段落无法通过 Backspace/Delete 删除的问题。`canRemoveBlock` 确保删除后文档仍满足最少块数约束（有 title 时至少保留 title + 1 段），避免删光后无法输入。
