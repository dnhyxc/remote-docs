# 书架封面与书名编辑

**文档角色**：本轮增量实现说明（封面文件存储、书名 API、卡片 hover 交互）。全链路书架/阅读见 [电子书阅读书架.md](./电子书阅读书架.md)；卡片 UI 早期抛光见 [书架阅读打磨.md](./书架阅读打磨.md)。

**延伸阅读**：[ops/上传存储路径.md](../ops/上传存储路径.md)（`uploads/images` 落盘）、[电子书COS本地书架.md](./电子书COS本地书架.md)（COS 与本地优先）。

---

## 1. 背景与目标

用户希望在电子书书架上：

1. **自定义封面**：选图后展示在竖版卡片上，替代默认 EPUB/PDF 渐变占位。
2. **编辑书名**：在卡片下方直接改标题，回车保存，Esc/失焦取消。
3. **更清晰的 hover 操作层**：悬停时出现蒙层，居中「开始阅读 / 继续阅读」，顶栏格式与删除、底栏封面设置与进度。

封面不再存数据库 base64（体积大、难清理），改为 **`uploads/images/ebook-cover_{uuid}.jpg`** 等相对路径字段 `cover_path`，与项目其它静态图片一致。

## 3. 实现思路

### 3.1 封面：multipart 落盘 + 相对路径

- **接口**：`PUT /ebook/cover/:id`，字段名 `file`，Multer `diskStorage` 写入 `getUploadImagesDir()`，文件名 `ebook-cover_{uuid}.{jpg|png|webp}`。
- **限制**：MIME 仅 JPG/PNG/WebP，单文件 **2MB**（与前端压缩后体积对齐）。
- **持久化**：`cover_path` 存公开相对路径（如 `/images/ebook-cover_xxx.jpg`），列表 DTO 映射为 `coverUrl`。
- **换封面 / 删书**：`tryDeleteCoverFile` 解析 `/images/{filename}` 并调用 `uploadService.deleteFile`，失败不阻塞主流程。

### 3.2 书名：`PUT /ebook/title`

- Body：`{ bookId, title }`，trim 后非空，最长 512 字符（与实体列一致）。
- 校验用户归属后更新 `ebook_book.title`，返回完整 `EbookBookDto`。

### 3.3 前端：压缩 → 上传 → Toast

- `fileToCoverFile`：Canvas 缩放到最长边 640px、质量 0.85，控制上传体积。
- `ebookStore.setCover` / `updateTitle` 成功后更新列表与 `bookCache`。
- 书架页 `onSetCover` / `onUpdateTitle` 成功/失败均 Toast（与删除等操作一致）。

### 3.4 卡片 UI

- **结构**：上方 `aspect-3/4` 封面区 + 下方固定 `h-7` 书名行（编辑时不挤动卡片）。
- **有封面**：`object-cover` 铺满；无封面时保留 EPUB/PDF 渐变 + 居中图标与书名（可点进阅读）。
- **Hover**：全卡蒙层 + 三行 grid（顶：格式 chip + 删除；中：阅读按钮；底：封面设置 + 进度 chip）。
- **书名**：卡片外单行 `truncate`；点击变 Input，Enter 提交，Esc/blur 取消（Enter 提交时用 ref 避免 blur 误取消）。

### 3.5 文案

- 桌面端导入按钮：**选择本地文件**（原「打开本地文件」），与「系统文件选择器」语义一致。

### 3.6 迁移注意

- 迁移 `1781609328384` 将历史 `cover_base64` 列改为 `cover_path varchar(512)`，**旧 base64 封面数据会丢失**，需用户重新设置封面。

```typescript
async saveCover(userId: number, bookId: string, file: Express.Multer.File) {
	if (!file?.path) throw new BadRequestException('请上传封面图片');
	const book = await this.bookRepo.findOne({ where: { id: bookId, userId } });
	if (!book) throw new NotFoundException('书籍不存在');

	// Multer 落盘路径 → 对外公开相对路径 /images/...
	const coverPath = normalizeUploadPublicPath(
		this.uploadService.getStaticPath(file.path, file.mimetype),
	);
	await this.tryDeleteCoverFile(book.coverPath); // 换封面前先删旧文件
	book.coverPath = coverPath;
	await this.bookRepo.save(book);
	return this.toBookDto(book); // DTO 中 coverUrl = coverPath
}

async updateTitle(userId: number, dto: UpdateEbookTitleDto) {
	const title = dto.title.trim();
	if (!title) throw new BadRequestException('书名不能为空');
	const book = await this.bookRepo.findOne({ where: { id: dto.bookId, userId } });
	if (!book) throw new NotFoundException('书籍不存在');
	book.title = title.slice(0, 512);
	await this.bookRepo.save(book);
	return this.toBookDto(book);
}
```

```typescript
async setCover(bookId: string, file: File): Promise<void> {
	const coverFile = await fileToCoverFile(file); // 客户端先压缩
	const updated = await saveEbookCover(bookId, coverFile);
	runInAction(() => {
		this.books = this.books.map((b) => (b.id === bookId ? updated : b));
```

## 5. 兼容性与影响

| 项 | 说明 |
|----|------|
| 破坏性 | 迁移后旧 `cover_base64` 封面不可用，需重新上传 |
| 部署 | 需执行 TypeORM 迁移；确保 `uploads/images` 可写 |
| 权限 | 封面/书名接口均 `@UseGuards(JwtGuard)`，与书架其它写操作一致 |
| 展示 | 封面 URL 走现有静态资源解析链（与头像等 `/images/` 一致） |

---

## 6. 建议回归

1. 无封面 → 设 JPG/PNG/WebP 封面 → 刷新列表仍显示；换封面后旧文件不再被引用。
2. 删书后对应 `uploads/images/ebook-cover_*.jpg` 应被清理（允许失败不报错）。
3. 点击书名 → 修改 → Enter → Toast「书名已更新」；Esc / 失焦取消不改库。
4. 未改书名直接 Enter / 空标题 → 不请求 API。
5. 桌面端按钮文案为「选择本地文件」。
6. Hover 卡片：阅读、删除、封面设置、进度 chip 均可操作且不挡书名编辑区。
