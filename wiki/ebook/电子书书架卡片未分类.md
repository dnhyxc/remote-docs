# 书架卡片未分类兜底文案

> 延伸阅读：本轮同步还有一篇姊妹专题 [电子书书架排序最近阅读.md](./电子书书架排序最近阅读.md)（书架按最近阅读时间排序），与本篇无强耦合。

## 1. 背景与目标

书架卡片悬停书名时会显示 **所属分类**（`categories.find((c) => c.id === book.categoryId)?.name`）。问题：

- 书的 `categoryId` 为 `null`（未分类）时，`find` 返回 `undefined`，`.name` 为 `undefined`，渲染出 **空白**。
- 即便 `categoryId` 有值但分类已被删除（脏数据），同样空白。

用户看到「所属分类：」后跟空白，会以为界面坏了。本次改动在分类名缺失时回退显示 **未分类** 文案，与「未分类」Tab 的命名一致。

用户可感知：悬停书名时不再出现空白分类名。

## 2. 改动范围

- `apps/frontend/src/views/ebook/components/shelf/EbookShelfBookCard.tsx` — 书名 Tooltip 分类名展示加 `|| 未分类` 兜底

## 3. 实现思路

1. **复用既有 i18n key**：`ebook.shelf.category.uncategorized`（中文「未分类」/ 英文「Uncategorized」）已在 i18n 资源里存在，被「未分类」Tab 使用。直接复用，无新增文案。
2. **最小改动**：在 `?.name` 后加 `|| t('ebook.shelf.category.uncategorized')`。`undefined || '未分类'` → `'未分类'`；有分类名时短路返回分类名，不影响已有行为。
3. **不修复根因数据**：书的 `categoryId` 为 `null` 是合法状态（未分类），不是 bug；分类被删除后的脏数据由后端清理逻辑兜底，前端只负责展示。

**为何不在 `categories` 数组里塞一个虚拟「未分类」项**：会让分类管理逻辑（新建/重命名/删除）误判，且「未分类」不是真实分类实体。

## 4. 关键代码对比与注释

### 4.1 书名 Tooltip 分类名展示

**对比范围**：`EbookShelfBookCard` 组件内书名 Tooltip 中分类名 `<span>` 的内容表达式（摘录，单行改动）。

**改动前** · `apps/frontend/src/views/ebook/components/shelf/EbookShelfBookCard.tsx`（基线，约 L662）

```tsx
{/* 分类名 span，teal-600 主题色 */}
<span className="text-teal-600">
    {/* 旧版：直接取分类名；categoryId 为 null 或分类已删时返回 undefined，渲染空白 */}
    {categories.find((c) => c.id === book.categoryId)?.name}
</span>
```

**改动后** · `apps/frontend/src/views/ebook/components/shelf/EbookShelfBookCard.tsx`（当前，约 L661–L663）

```tsx
{/* 分类名 span，teal-600 主题色 */}
<span className="text-teal-600">
    {/* 新版：find 分类名，取不到时回退到「未分类」文案 */}
    {categories.find((c) => c.id === book.categoryId)
        /* 可选链取 name；有值短路返回，undefined 时落到 || 右侧 */
        ?.name || t('ebook.shelf.category.uncategorized')}
</span>
```

**变更摘要**：`?.name` → `?.name || t('ebook.shelf.category.uncategorized')`。分类名缺失时显示「未分类」而非空白。

## 5. 兼容性与影响

- **兼容**：纯展示层改动，无数据/接口变化。
- **行为变化**：仅影响 `categoryId` 为 `null` 或分类已删的书的 Tooltip 展示；有分类的书行为不变。
- **i18n**：复用既有 key，中英文资源均已存在，无需新增。

## 6. 风险与回归

建议测试：

- **未分类书**：悬停书名 → Tooltip 分类名显示「未分类」（中文）/「Uncategorized」（英文）。
- **已分类书**：悬停书名 → Tooltip 分类名显示真实分类名，不变。
- **分类删除后**：删除某分类后，原属于该分类的书的 Tooltip 应显示「未分类」（取决于后端是否把 `categoryId` 置空；若后端已置空则命中兜底）。
- **切换语言**：中英文切换后 Tooltip 文案跟随。
