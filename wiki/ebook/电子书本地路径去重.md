# 电子书：按 local_path 去重，避免重复云端上传

**延伸阅读**：

- 会员上传策略：[电子书会员上传.md](./电子书会员上传.md)
- 桌面先 path 后 COS：[电子书COS本地书架.md](./电子书COS本地书架.md)

---

## 1. 背景与目标

**问题**：桌面端会员再次「选择本地文件」时，若该书已在书架（同一绝对路径），仍会走读盘 + COS 上传，浪费带宽与时间。

**目标**：用 Tauri 文件选择器得到的**本地绝对路径**，在数据库按 `local_path` 查询；已登记则**跳过上传**并提示「该书籍已在书架中，无需重复上传」。

---

## 3. 实现思路

1. **后端**：`findBookByLocalPath(userId, path)` → `bookRepo.findOne({ userId, localPath: trimmed })`。
2. **API**：`GET /ebook/by-local-path?path=...` 返回 `{ book: EbookBookDto | null }`（须登录）。
3. **前端时机**：仅在 `shouldUploadEbookToCos()` 为 true（会员）时调用查询；非会员不上传，无需查库。
4. **命中后**：直接用返回的 `book` 更新书架列表，Toast info，**不**调用 `uploadBookToCloud`。
5. **未命中**：照旧 `addEbookFromPath`（后端 `addFromPath` 内也有同路径去重，双保险）。

数据流：

```
pickTauri → path
  → [会员] GET by-local-path
      → 有 book：更新书架 + Toast，结束
      → 无 book：add-path → upload COS
  → [非会员] add-path only
```

## 4. 关键代码与注释

### 4.1 后端：按 local_path 查库

**来源**：`apps/backend/src/services/ebook/ebook.service.ts`（`findBookByLocalPath`，约 L172–L186）

```typescript
async findBookByLocalPath(
	userId: number,
	path: string,
): Promise<EbookBookDto | null> {
	const trimmed = path.trim();
	if (!trimmed) {
		return null;
	}
	// 说明：与 addFromPath 去重条件一致，按当前用户 + 完整本地路径
	const book = await this.bookRepo.findOne({
		where: { userId, localPath: trimmed },
	});
	return book ? this.toBookDto(book) : null;
}
```

### 4.2 前端 Service

**来源**：`apps/frontend/src/service/index.ts`（`findEbookByLocalPath`，约 L1886–L1895）

```typescript
export const findEbookByLocalPath = async (
	path: string,
): Promise<Book | null> => {
	const res = await http.get<{ book: Book | null }>(EBOOK_BY_LOCAL_PATH, {
		querys: { path },
		silent: true,
	});
	return res.data?.book ?? null;
};
```

### 4.3 Store：上传前分支

**来源**：`apps/frontend/src/store/ebook.ts`（`addFromTauri`，约 L168–L210）

```typescript
const uploadToCos = shouldUploadEbookToCos();
const existingByPath = uploadToCos
	? await findEbookByLocalPath(picked.path)
	: null;

const book =
	existingByPath ?? (await addEbookFromPath(picked.path, picked.fmt));

// ... 更新书架列表 ...

if (existingByPath) {
	Toast({
		type: 'info',
		title: translateSync('ebook.shelf.alreadyImportedTitle'),
		message: translateSync('ebook.shelf.alreadyImportedMessage'),
	});
	return book;
}

if (uploadToCos) {
	void uploadBookToCloud(this, book.id, picked.path, picked.fmt);
}
```

## 5. 兼容性与影响

- 以**数据库**为准，不依赖前端书架分页是否已加载该书。
- 路径字符串须与登记时一致（Tauri 返回的绝对路径）；移动文件后路径变化会被视为新书。
- `add-path` 仍保留后端去重，即使未先调 `by-local-path` 也不会重复插行。

---

## 6. 建议回归

1. 会员桌面：首次导入某路径 → 出现上传进度。  
2. 再次选**同一路径** → 仅 info Toast，无上传条。  
3. 换账号：同路径在 B 账号下应视为新书（`userId` 隔离）。

若与仓库最新源码不一致，以源码为准。
