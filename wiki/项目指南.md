# 产品功能详解与使用教程

本文面向普通用户，介绍本产品的主要功能、适用场景与操作方法，帮助你从“能用”到“用得顺手”。（内容会随版本持续更新）

---

## 1. 你可以用它做什么

你可以把它理解为一个“**带知识库的 AI 助手**”：

- **对话（Chat）**：进行日常问答、方案讨论、写作润色、代码与文档协作等。
- **知识库（Knowledge）**：用 Markdown 记录与整理资料（可云端/本地两种模式），并在写作与检索中复用。
- **英语学习**：按主题流式生成单词包与经典句；支持 JSON 导入与**资源库**分页浏览、拉取历史、Agent 多会话、收藏与导出 Word（DOCX）等（需登录后使用主能力）。
- **Markdown 增强**：支持数学公式、代码高亮、任务列表、Mermaid 图表等，适合写技术笔记与方案文档。正文中的外部链接默认在新标签页打开，不会替换当前应用页面。
- **桌面端体验**：在桌面客户端可使用更多系统能力（例如全局快捷键、选择目录、开机自启等）。
- **动态功能模块（插件中心）**：独立部署的功能模块可以在运行时按需接入主界面，在**插件中心**统一查看与开关；是否启用会按你的账号记录，**换端、换设备、切号登录**后都保持一致，新账号默认全部关闭。

## 2. 运行形态与差异（桌面端 vs 浏览器）

### 2.1 桌面端（推荐）

适合需要“更强本地能力”的用户：

- 可使用**全局快捷键**（跨应用生效）
- 可选择本地目录作为文件存储位置
- 可使用部分系统级能力（如开机自启等）
- 适合重度写作/长期知识管理

### 2.2 浏览器端

适合快速访问、临时使用：

- 功能以网页可实现的能力为主
- 一些系统级能力会提示“仅桌面端可用”
- **未登录时**：仍可浏览首页、打开**知识库（默认仅本地模式）**、阅读部分公开说明页（如产品指南、更新说明、服务政策等）；需要账号的主流程（如智能对话）会在进入后按策略引导登录。

## 3. 快速上手（5 分钟）

### 3.1 第一次使用建议

1. 先进入**对话**：尝试问一个你正在做的任务（例如“帮我写一份周报”、“帮我做一个方案对比”）。
2. 再进入**知识库**：创建一篇 Markdown 记录，把对话结论沉淀下来。
3. 如你经常写技术文档：试试 **任务列表**、**数学公式**、**Mermaid 图表**。

### 3.2 常见使用姿势

- **边聊边记**：先用对话梳理思路，再把结论写入知识库。
- **资料整理**：把外部资料（链接、摘要、要点）整理为 Markdown，形成可检索、可复用的笔记。
- **方案沉淀**：用 Markdown 写“背景—目标—方案—权衡—结论”，配 Mermaid 流程图/时序图。

### 3.3 首页「快速开始」：步骤卡与顶栏

首页「快速开始」区域里，**步骤列表**与**顶栏主按钮**分工不同，避免把「注册账号」和「直接进入对话」混在同一个入口上：

- **顶栏「快速开始」类主按钮**：仍用于**尽快进入智能对话**（进入 **`/chat`** 主界面），适合已经准备好直接开聊的用户。
- **步骤卡片（整行可点）**：例如「**注册账号**」一步会带你打开登录页并**直接呈现注册表单**（地址栏会带上 **`mode=register`** 查询参数，便于刷新或复制链接后仍停在注册视图）；另一步「**开始使用**」等与顶栏一致，进入对话主界面。
- **在登录页内切换「登录 / 注册」**时，界面与地址栏会同步更新；为减少历史记录堆叠，通常使用 **replace** 方式写入地址，行为以当前版本为准。

若你通过书签或外链打开 **`/login?mode=register`**，也会直接看到注册表单。

> **在线演示账号**：当站点配置了演示测试账号后，访问首页时带指定参数即可在登录页**自动预填用户名和密码**（密码以掩码 `••••` 显示，审查元素不会泄露真实密码），方便快速体验完整功能。测试账号登录后**禁止修改个人资料、购买会员、重置密码、绑定 / 解绑微信**，个人资料页的邮箱也会做中间脱敏显示（如 `d•••e@xx.com`），防止演示账号被篡改。未配置环境变量时该功能不影响普通用户。

### 3.4 如何启用插件：默认关闭与跨端同步

如果你在侧栏或首页里**没看到某个功能入口**（例如学习笔记、想法列表等独立模块），通常是因为它**尚未开启**：

1. 进入**插件中心**：以卡片列表展示全部可用的独立功能模块，每张卡片右侧有一个开关，标题旁会显示当前版本与简介。
2. **默认全部关闭**：当你第一次登录某个账号时，所有功能模块都会保持关闭，不会一上来就把侧栏或首页塞得很满，方便你按兴趣慢慢启用。
3. 点开关**启用（上架）**：对应模块会立刻在主界面注册入口——侧栏可能新增菜单项，首页可能新增卡片或快捷入口。此时模块的代码会在运行时**按需加载**；加载失败会给出稳定提示，通常可手动重试，不会白屏。
4. 点开关**停用（下架）**：对应模块的入口会立即从主界面移除；如果你此刻正打开该模块页面，关闭开关后页面会自动卸载并回到安全的空状态，不会残留已下线的模块界面。
5. **账号级跨端同步**：开关偏好是按**登录账号**保存的。在电脑 A 的浏览器里启用过的模块，换电脑 B 或换成桌面客户端登录同一账号时，会自动按相同状态挂载。切换账号（登出后换号登录、或会话失效被引导重新登录）时，也会重新按**新账号**的偏好自动刷新入口，不需要手动刷新页面。
6. **本地旧记录自动迁移**：如果你曾在更早版本中**只保存在本机**过开关记录，首次进入插件中心时会自动把它们**一次性迁移到当前账号的云端偏好**下，迁移完成后即使清理浏览器缓存也不会丢失。
7. **开关操作的交互细节**：每张卡片的开关**与对应说明文字绑定正确**——点开关本身、或点同一张卡片右侧的「启用」「关闭」说明文字，都会切换**同一张卡片**的状态，不会误切到别的卡片；页面即便同时有几十个开关，也能放心用鼠标或键盘操作。
8. **加载失败会给出可读原因**：当插件中心或清单加载出错时，页面会以更具体的文案告诉你是「网络未连通」「登录凭证已过期需重新登录」「清单格式异常请联系维护者」还是「其它内部错误」，方便你先自行排查（切网络、重新登录）再联系我们。

### 3.5 首屏舞台卡片与焦点轮播

首页打开后看到的第一屏（首屏）由**舞台卡片**与**焦点轮播**两个部分组成，下方才是功能展示卡、步骤列表与快捷入口。

- **舞台卡片（壳层）**：从上到下依次是**顶栏品牌条**（品牌名 + 副标题 + 右侧在线状态呼吸圆点）、**焦点轮播主内容区**、**底部水印**（随当前主题色渐变的大号品牌字）、**底栏入口**（按列均分的功能快捷按钮，常见为三项：左对齐 / 居中 / 右对齐）。底栏入口与下方功能展示卡的「快速开始」步骤分工不同——底栏入口用于**快速跳转到核心功能**（如知识库、对话等），步骤卡则提供更详细的上手引导。
- **鼠标跟随 3D 倾斜与分层视差**：鼠标移入首屏卡片时，整卡会随鼠标方向微微凸起（3D 倾斜），同时**顶栏 / 底栏 / 主内容区 / 水印**按不同幅度反向位移，形成分层视差的纵深感。鼠标移开后自动平滑回正。若你的系统设置了「减少动画」偏好，倾斜会自动关闭；卡片滚动到屏幕外不可见时也会停止计算。
- **焦点轮播**：主内容区展示多张**焦点轮播页**，每页含编号徽章、双色标题（主色 + 强调色）、副标题与一组可点击的行动按钮。轮播支持以下交互：
  - **自动播放**：约 5 秒自动切换下一页；鼠标悬停在轮播区时暂停，移开恢复。
  - **箭头切页**：底部控制条左右箭头可手动切页。
  - **圆点跳页**：控制条中间的圆点可直接跳转到对应页；当前页圆点加宽高亮。
  - **计数器**：控制条右侧显示「当前页 / 总页数」。
  - **触屏滑动**：在触屏设备上左右滑动可切页（纵向滑动不误触）。
  - **水平滚轮**：在触控板上水平滑动可切页（纵向滚动不误触）。
- **控制条左侧提示**：在桌面端宽屏下，控制条左侧会显示一段提示文案（如服务总览），窄屏下自动隐藏。

## 4. 对话（Chat）详细教程

### 4.1 基础对话

你可以直接输入问题或任务描述。为了获得更稳定的结果，推荐按以下结构提问：

- **背景**：我在做什么？现状是什么？
- **目标**：我希望得到什么输出？（结论/步骤/清单/文案/代码）
- **约束**：字数、风格、受众、是否需要可执行步骤、是否需要对比方案等
- **输出格式**：例如“用表格对比”、“按 1/2/3 步骤给我”

示例：

- 我在做一个产品需求评审。目标是输出一页 PRD 摘要，约束是 300 字以内，格式用要点列表。

### 4.2 流式输出与停止/续写

- **流式输出**：回答会边生成边展示，方便快速阅读。
- **停止生成**：如果你已经看到想要的方向，可以停止，避免继续跑偏或过长。
- **续写**：当你希望在当前回答基础上继续展开，可以续写。
- **代码块横向浏览**：流式输出含宽代码行时，可在代码块区域内左右滚动查看；代码块已输出完毕而回答仍在继续时，也可正常横滚，无需等整段生成结束。
- **代码块与图表视觉统一**：代码块和 Mermaid 图表块拥有对称的外壳与一致的配色，工具条（复制、下载、切换代码/图表等）在吸顶时保持底部圆角，切换强调色时边框与工具条底色跟随变化。
- **分支与重生成**：同一会话内可在消息树形态下分支或重生成；分享只读页与在线阅读在复杂分支场景下也会尽量保持消息顺序与排版一致（与下文「分享会话」说明一致）。

服务端对话生成已统一经硅基流动兼容接口调度，你侧仍按上述方式使用即可，无需额外配置。

### 4.3 联网检索与引用

当你需要：

- 获取最新信息（例如某个产品/框架的近期变化）
- 需要来源佐证（例如写报告、写评审材料）

你可以明确要求“请联网检索并给出引用”。你也可以要求：

- 只引用权威来源
- 给出可点击的引用
- 先列引用再总结

### 4.4 附件与 OCR（图片/截图文字）

当你有截图、图片中的文字内容需要分析时，可以上传附件并要求：

- “提取文字并总结要点”
- “识别表格并转换为 Markdown 表格”

上传成功后，附件会出现在输入框上方；**图片类附件可点击卡片打开预览**。若文件名含中文，预览与下载会自动处理编码；Web 与桌面端均可在对话内直接查看，无需手动复制图片链接到新标签页。在浏览器访问线上站点时，预览走与对话相同的站点地址，一般无需单独配置图片静态路径；部署新版本后若仍无法预览，请确认前后端均已更新并重启服务。

发送带图片的消息时，系统会先在服务端识别图中文字与画面要点，再交给对话模型作答；该识别能力与设置页里选择的对话大模型无关。若你自行部署实例，需在服务端配置智谱 API 凭证，图片附件才能被正常理解。

### 4.5 桌面端语音输入（Tauri，桌面壳）

当你使用**桌面客户端**进行对话时，底部输入区可在**文本输入**与**语音输入**之间切换：

- 将指针移到**圆形主按钮**上，会展开「输入模式」菜单，在其中选择文本或语音。
- 选择**语音**后，点击主按钮开始说话，识别出的文字会**持续写入**输入框；再次点击主按钮结束录音，当前框内文字即为本次会话中已识别的内容（过程中可随时编辑再发送）。
- 将应用界面语言切换为英文后，上述菜单与相关提示也会随语言切换显示。

> **发送钮视觉统一**：智能对话与知识库助手的发送按钮现已使用同一套轻量样式（浅色渐变底 + 柔和光晕），暗色主题下更贴合卡片背景；停止生成按钮与桌面端语音菜单的交互（悬停展开、离开延时关闭、点即发送）不变。

## 5. 知识库（Knowledge）详细教程

知识库用于“长期沉淀”。你可以把它当成你的个人文档空间。

### 5.1 两种模式：云端 vs 本地

- **云端模式**：适合多设备同步与集中管理。
- **本地模式**：适合把知识库放在你自己的文件夹里（Markdown 文件可被任何编辑器打开）。

如果你未登录，知识库会默认走**本地模式**，并隐藏不适用的入口（例如回收站）。

### 5.2 创建与编辑

一般流程：

1. 新建一篇文档（标题 + 正文）
2. 用 Markdown 写内容
3. 保存（手动保存 / 自动保存）

建议的文档结构模板：

- 标题
- 背景
- 目标
- 结论（先写结论）
- 过程与论据
- 待办（任务列表）
- 参考链接

### 5.3 保存、覆盖保存与自动保存

你会遇到三种保存体验：

- **手动保存**：适合你希望“确认一次再落盘/提交”的场景。
- **覆盖保存**：你希望同名时直接覆盖（适合持续维护同一篇文档）。
- **自动保存（防抖）**：当你停止编辑一段时间后自动保存，减少忘记保存的风险；它会尽量避免打断你输入。
- **保存前自动格式化**：无论是手动保存还是自动保存，落盘前都会先对当前正文做一次与编辑器内「格式化」一致的排版整理，再写入存储。

建议：

- 写长文时开启自动保存
- 做结构化整理时用手动保存更可控

### 5.4 本地文件夹：扫描、打开、删除与外部编辑器

当你选择本地文件夹作为知识库来源时：

- 列表会递归扫描该目录下的 Markdown 文件
- 你可以打开文件进行编辑与保存
- 也可以在外部编辑器中打开（适合你习惯用 Cursor 等工具编辑）
- **在访达中显示**（桌面端）：悬停列表行时点击「在访达中显示」按钮，系统文件管理器（macOS 访达 / Windows 资源管理器）会打开并选中该文件，便于快速定位磁盘位置或用其它工具操作同一目录。
- **删除更可控**：在桌面端（Tauri，桌面壳）删除时，会根据条目的来源提供不同选项：
  - **本地文件夹列表中的文件**：删除仅影响本地磁盘文件（不会删除云端数据）。
  - **云端知识条目且已关联到本地同名文件**：删除确认框会提供 **「删除本地文件 / 删除在线文件 / 同时删除」** 三种操作，方便你按需处理（例如只清理云端记录但保留本地笔记）。

### 5.5 回收站（如可用）

当你使用云端管理时，删除内容可能会进入回收站，便于误删恢复。

### 5.6 文档内 AI 助手（需登录）

当你**已登录**并在知识库中编辑文档时，可在编辑器底部使用**知识库文档助手**：结合当前 Markdown 正文与 AI 多轮对话，便于润色、总结与答疑。

- **未登录不展示**：未登录时不会出现该助手区域，避免占用版面或产生无效入口；本地编辑知识文档不受影响。
- **长对话滚动**：助手对话列表变长后，可在输入框右上方使用**滚动到底部 / 滚动到顶部**按钮，快速跳转；流式生成时若你上滑阅读历史，可再滚回底部或点「置底」以继续跟随最新输出。**流式结束后**若你曾上滑打断自动贴底，列表会**保持当前阅读位置**，不会强制跳到底部。
- **选区发送至助手**：在 Markdown 编辑器中选中一段正文后，可将选中文本**发送到**底部文档助手（右键菜单「复制选中内容到助手」或 **⌘/Ctrl+Shift+V**），再结合 **AI 模式** 或 **RAG 模式** 提问；发送后输入框会自动聚焦且光标落在已写入内容的末尾，便于直接补问。若多次框选重叠内容，产品侧会对重复上下文做收敛，具体以当前版本为准。
- **选用 Skill（斜杠）**：在助手输入框输入 **`/`**，可打开 Skill 选择浮层，按关键字过滤后**多选**已保存的 Skill，确认后发送问题；本轮回复会按所选 Skill 的说明与工具能力生成，消息仍落在**当前文档的助手会话**里，历史抽屉可继续浏览。回复旁可看到本轮应用的 Skill 名称；刷新或从草稿保存进正式文档后，该提示仍会保留。未保存的草稿也可以选用 Skill，但草稿会话与已保存文档的历史分轨，保存文档后再开助手即可走文档会话。
- **多轮上下文**：AI 模式下，助手会结合当前文档已保存的会话历史继续回答（在系统 token 预算内自动裁剪较早轮次）；RAG 模式每轮主要依据当次检索到的知识库片段作答。服务端生成链路已与主站对话统一为硅基流动兼容接口，交互方式不变。
- **桌面端文本/语音与界面语言**：在**桌面客户端**且已登录时，助手底部输入区与对话页类似，支持通过悬停主按钮展开「输入模式」菜单，在**文本输入**与**语音输入**之间切换；菜单与相关提示会随你在设置中选择的**界面语言**（如中文/英文）显示。语音模式下，识别文字会**实时填入**输入框，停止录音后保留当前内容以便你修改或发送。
- **「生成目录」自动写入文首**：在 **AI 模式**（非 RAG）下，可使用快捷卡片 **「生成目录」**；模型流式结束后，系统会把抽取出的目录块插入左侧编辑器**文首**，并在目录列表上方加上 **`## 目录`** 二级标题。若文首已是 **`## 目录`**，会提示不再重复插入；若仅有锚点列表或用了其它级别的「目录」标题，会**补全或规范为** `## 目录` 而不重复整段列表。
- **流式回复**：助手生成过程中仅展示正文与「正在生成中…」状态，不展示模型内部思考链；加载指示可正常动画。

### 5.7 长文编辑（较长 Markdown）

编辑**较长**文章（例如数万字）并开启底部文档助手时，纯**编辑**模式下输入标题、正文与助手问题应明显更跟手。切换到**预览**或**分屏预览**后，全文仍会正常渲染；保存、自动保存与助手发送逻辑与改前一致。

### 5.8 本地文件夹目录树浏览

在桌面端使用**本地知识库模式**时，选择文件夹后会自动扫描其中的 Markdown 文件，并以可展开的**目录树**形式展示：

- **目录结构**：按文件实际路径构建层级，空目录自动过滤，仅展示含 .md 文件的路径。
- **展开/收起**：点击目录行或按 Enter / Space 键可展开或收起子目录；默认展开所选根目录。
- **文件操作**：点击文件行可在应用内编辑；右键或操作按钮可打开外部编辑器、删除文件。
- **层级缩进**：文件按所在目录层级自动缩进，方便识别归属。
- **云端模式不受影响**：仅本地文件夹模式使用目录树，云端知识库仍使用列表视图。

### 5.9 按文档标题搜索（列表与回收站）

当你的知识库或回收站里条目较多时，可在对应抽屉顶部使用**搜索框**按文档标题快速定位：

- **如何触发搜索**：在顶部搜索框中输入文档名称的关键字（如「周报」「API」），按 **Enter** 提交即可。键入过程中不会立即发请求，避免每敲一个字符都刷新列表。
- **云端模式**：按已提交的关键字请求后端分页过滤，与正常分页加载、滚动「加载更多」兼容，可继续翻页。
- **本地文件夹模式**：搜索在前端本地完成，命中文件后会**自动展开所有命中行所在的目录**，不必你手动一层层点开父目录。
- **回收站**：同样支持按文档名过滤，搜索命中为空时会提示「未找到匹配的文档」。
- **大小写不敏感**：无论你输入的是「Report」还是「report」，匹配规则都会忽略大小写，结果一致。
- **清空搜索**：把搜索框内容全删后再按一次 Enter（或输入仅空白），即可恢复完整列表。

### 5.10 知识库分类管理

在云端知识库列表抽屉中，可以使用**分类**来组织大量文档：

- **分类标签栏**：列表搜索框下方有可横向滚动的分类标签栏，包含「全部」、各分类名（带文档计数徽章）和「未分类」（仅有未分类文档时显示）。点击标签即可筛选对应分类的文档。
- **管理分类**：点击标签栏左侧的「管理分类」按钮，在弹窗中可新建、重命名、删除分类，以及用上下箭头调整分类排序。
- **默认分类**：首次打开分类管理时，系统会自动创建 5 个默认分类（中文界面为「笔记 / 文档 / 教程 / 工作 / 其他」，英文界面为「Notes / Docs / Tutorials / Work / Other」）。你最多可创建 **50** 个分类。
- **文档归类**：将鼠标悬停在列表中某文档行上，会出现「移动到分类」按钮，点击后可在下拉菜单中选择目标分类或移至未分类。仅**本人文档**可改分类，他人公开文档不可移动。
- **删除分类**：删除分类后，该分类下的文档会自动移至**未分类**，不会被删除。
- **公开优先**：列表中公开的文档始终排在前面，组内按更新时间倒序。
- **适用范围**：分类仅在**云端模式**下可用，本地文件夹模式不显示分类标签。

### 5.11 知识库「公开」Tab：浏览他人分享的文档

当有其他用户将文档设为**公开**时，知识库分类标签栏中会额外出现一个**「公开」**标签，仅展示**他人公开**的条目（你自己公开的文档不会出现在这里，仍在「全部」与对应分类下查看）：

- **显示条件**：只有当他人公开文档的总数大于 0 时，标签栏才会显示「公开」入口；没有公开文档时自动隐藏，避免空 Tab 噪声。
- **切换过滤**：点击「公开」标签即可切换到仅他人公开的视图；仍支持按标题搜索与滚动加载更多，行为与其他 Tab 一致。
- **「全部」角标包含公开数量**：「全部」标签右侧的计数角标现在显示为「本人文档总数 + 他人公开总数」，与标签栏实际可浏览的文档范围对齐。
- **不可改他人公开文档分类**：公开 Tab 下他人公开文档的「移动到分类」入口不会显示，避免误操作。
- **适用范围**：公开 Tab 仅在**云端模式**下显示，本地文件夹模式下不展示分类标签栏与公开筛选。

### 5.12 电子书书架：按书名搜索

在电子书书架页面，可以通过搜索快速找到书籍：

- **打开搜索**：点击书架标题栏右侧的**搜索**按钮，搜索输入框会以展开动画显示。
- **输入搜索**：在输入框中输入书名关键字（如「Python」「三体」），按 **Enter** 提交。搜索**不区分大小写**，本人书架和公开书架的结果会同步过滤。
- **关闭搜索**：再次点击按钮（此时显示为「关闭搜索」）或按 **Esc** 键即可收起搜索框；如果当前有搜索关键字，关闭时会自动清除并恢复完整列表。
- **空结果**：搜索命中为空时会显示「未找到匹配的书籍」提示。

### 5.13 Skill 管理与试跑

侧栏进入 **Skill**（路由 **`/skills`**）可管理个人 Skill，并在右侧试跑：

- **列表与编辑**：左侧浏览已保存 Skill；可新建、重命名、改描述、用编辑器改正文并保存或删除。
- **试跑 / 生成**：右侧对话可验证 Skill 效果；支持多路试跑会话与历史切换。试跑历史只在本页，不会出现在英语学习 Agent 的历史抽屉里。
- **会话重命名**：鼠标悬停历史抽屉中的会话项，会出现编辑图标，点击后可直接修改会话标题；中文输入法选字时按回车不会误提交。
- **与知识库助手的关系**：在知识库助手用 `/` 选用的是这里已保存的 Skill；编辑与试跑在本页完成，文档内对话仍走知识库助手壳。

## 8. 设置项建议（推荐配置）

### 8.1 文件存储

- 桌面端可选择更适合你的默认存储目录（例如同步盘/工作目录）

### 8.2 启动与关闭行为（桌面端）

- 若你希望随时可用：开启开机自启、关闭时最小化到托盘
- 若你更注重资源释放：关闭时直接退出程序

### 8.3 大模型（自定义配置）

1. 登录后进入 **设置**，在顶栏选择 **大模型**（路径 **`/setting/llm`**）。
2. 填写 **API Key**、**Base URL**、**模型名称**。API Key 仅在您曾在本页保存过后由接口回显；未保存前输入框为空。
3. **Base URL** 与 **模型名称** 可直接输入，也可点输入框右侧按钮展开预设：可选「智谱 GLM」「硅基流动」或「DeepSeek」等配对地址与模型；从一侧选择预设时另一侧会自动同步，仍可手填其它服务商地址。切换预设或模型时**不会清空**已填写的 API Key。
4. 填写完整后点击 **保存** 即启用自定义模型。底部若显示绿色「**某某** 模型配置生效中」，表示**当前登录账号**在对话、知识库助手、英语学习等模块会使用该配置；其它账号互不影响。
5. 未保存自定义时：底部灰色提示「当前默认 **某某** 模型生效中」——**有效会员**对应硅基流动默认模型，**非会员**对应智谱 GLM；与 **§2** 会员权益衔接。
6. 有未保存修改时，底部会提示「有未保存更改，请保存」或「可保存设置让自定义模型生效」；任一必填为空时提示补全三项并无法保存。
7. 需要改回服务器默认时：点击 **恢复默认配置**（会关闭自定义并恢复与会员状态对应的默认表单项）。

说明：API Key 输入框支持右侧眼睛图标切换显示/隐藏。

**向量模型（知识库 RAG，与上方大模型独立保存）**

1. 在同一页面向下滚动至 **向量模型** 区块（**超级管理员**开启全站「仅使用 BGE 向量库」后，**非超级管理员**不再显示该区块，全员走系统 BGE 库）。
2. 填写 **API Key**、**向量模型 URL**（完整 URL，非 Base URL 拼接）、**重排模型 URL**、**向量模型名称**、**重排模型名称**、**向量库名称**；各字段支持预设下拉（如硅基流动、bge / Qwen3、默认库名等）。从预设选择 **BGE** 或 **Qwen3** 档位时，向量模型名称、重排模型名称与向量库名称会**自动配对**；切换时**不会清空**已填写的向量 API Key。
3. **超级管理员**可开关「仅使用 BGE 向量库」：开启后对你本人及全站其它用户生效，知识库向量化与 RAG 统一使用系统 BGE 模型与默认 bge 向量库（需你先保存有效的向量 API Key）。
4. 点击 **保存向量配置** 即启用；底部绿色提示表示当前账号的知识库向量化与 RAG 检索走你的配置。未保存时灰色提示使用服务端默认。
5. 每次保存会将当前「向量库 + 模型」**累积记录**；下方 **已纳入检索的向量库** 列表展示历史库。RAG 会并行检索列表中的库，并**始终包含**系统默认 bge 库（即使用户未单独保存过）；**有效会员**还会自动纳入会员默认 Qwen3 向量库。
6. 新保存的文章写入**当前选定的向量库**；旧库中的文章仍可通过多库 RAG 被检索到。
7. 需要恢复时点击 **恢复向量默认**（不影响上方对话大模型配置）。

### 8.4 语音设置

1. 进入 **设置**，在顶栏选择 **语音设置**（路径 **`/setting/cloud-tts`**）。**所有用户**均可打开该页。
2. 页面上方为 **本机语音设置**：按女声/男声分组选择浏览器本机朗读音色，可试听；偏好按当前登录账号保存在本设备。
3. **朗读来源**（页顶，互斥）：**所有登录用户** 可选 **本机语音** 或 **Edge 云端**（Microsoft 在线语音，免费、无需 Key）。**有效会员** 另可选 **MiniMax 云端**、**讯飞云端**。决定英语学习与电子书听读默认走哪条合成链路；不可用时会回退本机。选择任一 **云端** 来源时，**本机语音设置** 区不可编辑（本机区试听仍走浏览器音色）。
4. 选择 **Edge 云端** 后，在 **Edge 语音设置** 区块（位于 MiniMax 之前）配置 **发音人** 与 **语速 / 音量 / 音高**，可 **Edge 试听** 或 **恢复默认**；未选 Edge 时该区块不可编辑。
5. 选择 **MiniMax 云端** 后，在 **云端语音设置** 区块填写 **API Key**（留空则用服务端默认）与 **模型**（可直接输入，或点预设选 **`speech-2.8-turbo`（默认，更快）** / **`speech-2.8-hd`（音质更好）**；仅支持此两项），并可调整音色、**MiniMax 专用** 语速/音量/音高、情感、音频格式、语言增强等；**语言增强** 为 **中文** 时，**音色类别** 仅显示中文系统音色（含普通话与粤语）；为 **英语** 时仅显示英文音色；**自动** 显示全部可选音色。**采样率、码率、声道** 等高级项一般保持默认。标题旁 **?** 可查看字段说明。未选 MiniMax 云端时，该区块不可编辑。
6. 选择 **讯飞云端** 后，在 **讯飞语音设置** 区块填写 **APPID、APIKey、APISecret**（三项均填才使用你的讯飞应用；留空则用服务端默认），并配置 **发音人** 与 **讯飞专用** 语速、音量、音高（音量/音高范围 0–100，50 为默认），可 **讯飞试听** 或 **恢复默认**；未选讯飞时该区块不可编辑。
7. 三套云端参数的 **语速 / 音量 / 音高** **分别保存**（调整 MiniMax 不会影响讯飞或 Edge）；偏好保存在你的账号下（换设备登录同一账号可同步）。
8. **英语学习中的播放**：由上述 **朗读来源** 决定本机、Edge、MiniMax 或讯飞；**非会员** 仅 **本机** 或 **Edge**。
9. **较长段落（云端）**：选择 **Edge、MiniMax 或讯飞云端** 后，朗读 **较长文字**（如电子书 **听当前** 的书摘、长经典句）时会 **按句读分段合成**：**首段完成即可出声**，播放过程中 **预取下一段**；**短词/短句** 仍为单次合成。云端暂时不可用时会 **提示** 并 **回退本机** 朗读。
10. **切换页面自动停止与媒体控件清理**：在英语学习里点喇叭朗读经典句或单词后，**切换到其它子页面或离开英语学习**时声音会立即停止，不会跨页继续朗读。点击另一条触发停播后，**系统媒体控件**（Touch Bar / 控制中心 / 蓝牙耳机弹窗）不再残留无声进度条。经典句与单词的云端朗读改为**整段一次合成**，首包等待更短。

### 8.5 账户头像（云存储）

1. 登录后进入 **`/profile` 个人主页** 或 **`/profile/account` 账户设置**（侧栏头像区域亦可进入账户设置）。**个人资料、账户设置、会员充值**现已统一收口到 **`/profile/*`** 路径下，旧链接 `/account`、`/pay` 会自动跳转。
2. 在头像区域选择本地图片上传；上传过程需保持已登录状态。
3. 上传成功后会显示预览，点击保存后头像在侧栏与资料页同步更新。
4. 若图片无法显示：请确认已重新上传（旧云存储链接可能失效）；Web 站点请使用与对话相同的站点地址访问，避免在浏览器中单独打开已过期的外链。
5. 在头像大图预览中可点击工具栏**下载**保存到本地；上传区悬停时的下载按钮行为相同。完成后会有成功或失败提示；若下载失败，请确认仍已登录且云图可正常预览。

说明：智能对话中的**聊天附件**与头像一样保存在腾讯云对象存储；历史会话里若仍为旧式本地路径，展示与解析会尽量兼容，新上传一律走云存储。

### 8.6 会员充值（Stripe）

1. 登录后进入 **`/profile/pay` 会员充值**——也可从 **`/profile` 个人主页** 点击「购买会员」进入。旧链接 **`/pay`** 会**自动跳转**到新路径，无需手动改地址。

4. 支付成功后会**自动跳转到个人主页**：可看到**金色「会员」徽章**与**金色「会员有效期至 …」**文案；若已是会员再购，会在**原到期日之后**续期叠加。

> **布局优化**：会员充值页现已适配个人主页路由壳层，内容超出时可在页面内滚动，不再溢出或被遮挡；移除了顶部冗余标题与徽标，文案更简洁，整体视觉更清爽。

### 8.7 主题色（强调色）

1. 进入 **设置**，在顶栏选择 **主题**（路径 **`/setting/theme`**）。
2. 页面「主题色设置」区列出 10 种预设：**默认（青绿）**、青柠、桃红、靛青、赭石、缃黄、杏橙、黛青、松花、苍翠。每行展示色块圆点、色名、hex 徽章与一句描述，当前选中的颜色右侧有对勾。
3. 点选任一颜色即立即生效：全站 hover、选中、链接、按钮等交互强调色会随之变化（例如特性卡入口箭头、设置页对勾、各处链接高亮）。无需额外保存，所选颜色按**当前登录账号**持久化，换设备登录同一账号会自动同步。
4. 主题色与上方「彩色主题」（白 / 深 / 红 / 米等）**正交**：彩色主题决定背景与文字色相，主题色决定交互强调色，两者可任意组合。
5. 刷新页面或重启桌面端不会闪回默认色（首屏已提前应用你的选择）。
6. 部分装饰区（如首页快速开始渐变按钮、英语学习侧栏今日记词 / 单词包渐变、单词资料流式进度条、词包数量按钮）**刻意保持原版青绿**，不随主题色变化，属设计预期而非异常。
7. **独立页 / 外链打开时强调色会跟随主站**：通过分享链接、外链或独立页（如下载页、更新说明等）打开时，地址栏的 **`?accent=`** 参数会自动解析并应用你选择的强调色；首屏内联脚本会在渲染前同步读取，避免闪烁。生成分享链接时也会自动追加该参数，确保对方看到的配色与你一致。

## 9. 常见问题（FAQ）

### 9.1 为什么有些功能提示“仅桌面端可用”？

浏览器受安全限制无法直接调用某些系统能力（例如全局快捷键、文件系统目录选择等）。桌面端拥有这些能力，因此体验更完整。

### 9.2 我写的 Markdown 为什么显示和预期不一样？

建议：

- 检查代码块围栏是否闭合
- Mermaid/公式是否符合语法
- 尝试将内容拆成更小段落排查
- 如果你在知识库编辑器里粘贴了大段 ` ```tsx`，并且围栏内容包含 “```mermaid” 等字面量，格式化时可能会出现围栏反引号数量变化；属复杂围栏边界情况，建议先备份正文或分段粘贴再格式化。

### 9.3 如何把对话结论沉淀成可复用的知识？

推荐流程：

1. 对话中让 AI 输出“结论 + 关键要点 + 待办清单”
2. 复制到知识库文档中
3. 补上你的背景、约束与最终决策

### 9.4 换账号登录后还会看到上一个账号的内容吗？

不会（在**同一浏览器标签页、未整页刷新**的前提下）。当你**登出**、用**另一个账号登录**，或登录态因 **401** 失效被清理时，应用会自动清空与上一账号相关的前端展示缓存，例如知识库未保存草稿、文档助手与 RAG 对话、英语学习 Agent 聊天、进行中的单词包/经典句进度等。若你**仅更新同一账号的资料或会员状态**（仍是同一个用户），这些编辑与对话**不会被**清空。若仍有异常，可尝试刷新页面或重新登录。

## 10. 术语小字典

- **Tauri（桌面壳）**：把 Web 前端打包成桌面应用的一种方式。
- **SSE（Server-Sent Events，服务端事件）**：服务器持续向客户端推送数据的方式，常用于流式输出。
- **OCR（Optical Character Recognition，光学字符识别）**：从图片中识别并提取文字。
- **GFM（GitHub Flavored Markdown，GitHub 风格 Markdown）**：Markdown 的常用扩展规范。
- **Mermaid（图表语法）**：用文本写流程图/时序图等的语法。
- **Debounce（防抖）**：在停止操作一段时间后才执行动作，常用于减少频繁保存/请求。
- **RAG（Retrieval-Augmented Generation，检索增强生成）**：在回答前先从你的资料中检索相关片段，再结合模型生成答案的一种方式（本产品在知识库助手中提供相关模式）。

## 11. 分享、RAG 模式与界面语言

### 11.1 分享会话（只读浏览）

当你希望把一段对话给同事或客户**只读查看**时，可使用产品内的**分享**能力生成链接；对方在浏览器中打开即可阅读，无需安装桌面客户端。分享页的消息顺序会与你在对话里看到的顺序对齐（含分支/重生成等复杂情况）；若原对话里用户消息带有图片或文件附件，分享页也会显示相同的附件卡片，可预览或下载。页面排版、用户消息中的代码块与知识正文预览等与在线会话阅读体验一致。

在知识库中已保存到云端的文章，可通过 **分享** 生成 **`?type=knowledge`** 的公开链接；打开后标题下方会显示 **「更新 …」**，时间与你在 **云端知识库列表** 中看到的最近更新时间一致（按你设备所在时区的本地时间展示）。请先 **保存到知识库** 再分享，以确保对方看到的是已落库正文与时间。

### 11.2 知识库助手：AI 模式与 RAG 模式

在知识库中编辑并已登录时，底部**文档助手**除默认的 **AI 模式**（结合当前 Markdown 正文多轮对话）外，还可切换到 **RAG 模式**（检索增强）：系统会结合检索到的资料片段作答，适合「对着资料问具体问题」的场景。模式切换、输入区与流式输出与对话页风格一致，检索命中内容通常会以引用或摘录形式参与回答，便于核对出处。

### 11.3 界面语言（中文 / 英文）

在**设置**中将界面语言切换为**英文**或**中文**后，对话页、知识库助手、菜单与常见提示会随语言包切换显示。个别能力还依赖运行环境（例如桌面端语音需要系统麦克风权限）。若你发现某处文案未随语言切换，多半是后续新增界面尚未接入翻译键，可向维护者反馈。

## 12. 编辑器里还能做什么（知识库 Markdown）

除正文编辑、分屏预览与「修改对照（Diff）」外，你还可以：

- **预览侧目录与锚点跳转**：长文可在预览区通过目录或小标题快速定位，支持标题锚点与 hash 跳转。
- **右键上下文菜单**：在编辑区选中文本后，可通过快捷菜单完成常用编辑动作；与底部操作栏能力互补。
- **Mermaid 图表缩放与预览**：复杂图表可放大、预览查看，减少误读。
- **代码块格式化**：在支持的围栏语言下可对代码块做格式化；若粘贴了带嵌套围栏的复杂片段（例如大段 ` ```tsx`），可能出现反引号数量变化等边界情况，建议先备份或分段处理。
- **预览/编辑与文档助手**：底部栏可在**预览**、**编辑**、**分屏**之间切换。**纯预览**时正文预览占满编辑区宽度。已打开**文档助手** Panel 时，切换预览/编辑**不会关闭**助手：预览模式下左侧为渲染预览，编辑模式下左侧为 Monaco 编辑器，右侧仍为助手；切换时系统会**双向**尽量保持当前阅读滚动位置（含助手已打开时从编辑切到预览）。从**分屏**切回全屏预览时，滚动位置也会尽量保留。
- **长文预览与助手同开滚动**：文档很长或含较多图表时，预览区滚动与右侧助手对话滚动会尽量保持跟手；助手正在流式输出时，仍可上滑阅读历史，不会被每条增量强行拖回底部（主动滚回底部后才会继续跟随）。若文档很长且含大量代码块，纯预览下持续滚动也应尽量跟手；滚到代码块时顶部仍可出现吸顶操作条，块内复制/下载照常可用。

## 13. 英语学习（单词包、经典句与收藏）

在侧栏进入**英语学习**专区（需登录后主流程可用）后，你可以围绕一个**主题**生成结构化学习内容，并管理个人收藏。

### 13.1 单词包与经典句（流式生成）

- **按主题生成**：为单词包或经典句等能力填写主题、数量等条件后发起生成；生成过程以**流式**方式在界面中逐步展示，便于中途阅读。
- **取消与错误提示**：生成过程中可按产品提供的操作取消请求；若网络或服务异常，界面会给出可读错误说明，具体文案以当前版本为准。
- **主检索与按需联网、RAG**：生成主阶段由助手汇总要点；**联网检索**会在模型判断需要时触发（例如主题涉及时效、日期类信息），减少无意义的例行检索。若你已在知识库中沉淀资料，也可结合 **RAG（检索增强生成）** 等模式，让回答带可核对的引用与摘录（与知识库助手域能力一致）。

### 13.2 快捷意图（工具栏「芯片」）

工具栏提供若干**快捷意图**（形如可点的「芯片」条目），为本次发送内容附加固定前缀或意图说明；再次点击同一项通常可**取消选中**。文案会随你在设置里选择的**界面语言**切换。

### 13.3 左栏表单与返回页面

在英语学习路由内填写的主题、数量等左栏条件，在你**暂时离开再返回**该页面时，一般会尽量恢复，减少重复填写（与生成流式状态的全局单例等实现协同，以实际版本为准）。

### 13.4 收藏、抽屉与导出 Word（DOCX）

- **收藏**：单词或经典句支持一键收藏；收藏列表在**抽屉**中分页浏览与管理（折叠状态等交互以实现为准）。
- **收藏列表虚拟滚动 + 续读**：收藏列表同样使用**虚拟滚动网格**（与资源库词条列表同引擎），窄屏 1 列、中屏 2 列、宽屏 3 列自适应，收藏再多也不卡顿。列表会记住你上次浏览到第几条，下次进入直接定位到附近继续浏览，关闭浏览器或退出桌面应用后也不丢失。右下角有**悬浮角标按钮**，可一键置底或置顶，长列表快速跳转无需拖拽滚动条。删除收藏后列表**原地刷新**，不跳回首屏。
- **批量取消收藏**：在收藏抽屉中可多选条目，经**二次确认**后批量取消收藏；单条也可快速移除。
- **导出 DOCX**：可将**单词收藏**或**经典句收藏**分别**一键导出为 Word（DOCX）** 文件。导出由服务端按你的账号汇总至多约 **3000** 条（按收藏时间倒序），与抽屉里分页浏览的「当前页」无关；在**浏览器**与**桌面客户端（Tauri）** 下均走二进制下载与本地保存流程，桌面端若已有同名去重或提示，以实现为准。单词收藏导出可包含**词性（pos）**等字段（以当前版本为准）。

### 13.5 资源库与 JSON 导入

除「按主题拉取」外，你还可以把本地 **JSON 单词包 / 经典语句包** 导入为长期保存的**资源库**：

- **导入入口**：在英语学习左栏的「单词库 / 语句库」区域进入导入；独立页路径为 **`/english-learning/import`**，通过查询参数 **`kind=vocab`**（单词）或 **`kind=classic`**（经典句）区分类型。
- **导入流程**：支持拖拽或选择 `.json` 文件；可在编辑器中预览与手改 JSON；校验通过并填写标题后保存。上传较大文件时产品会走适合大体积的上传方式，避免普通请求体大小限制导致失败。
- **导入后**：保存成功后会跳转到**资源库**并选中刚创建的库，便于立刻浏览词条。
- **文件名预填**：选择文件后，导入标题可自动用**去掉后缀的文件名**预填，减少手输。

### 13.6 资源库浏览与管理

- **自适应虚拟网格**：选中左侧某个单词库或语句库后，右侧词条以**响应式网格**展示词条卡片——窄屏显示 1 列、中屏显示 2 列、宽屏显示 3 列，拖动窗口宽度会自动平滑切换，不会闪烁；即使库里有几万条单词/经典句，也只渲染屏幕可见的内容（行级虚拟滚动），快速上下滑动不会出现长列表常见的白屏或掉帧。
- **续读记忆 + 深续读秒呈现**：右侧词条列表会记住你上次读到的位置——即使关闭浏览器、退出桌面应用或刷新整页，下次再进同一个库也会**直接滚到上次阅读的那条附近继续浏览**，不再回到首屏从头翻。若你上次读到的位置已经很深（例如第 3000 条以后），进入时不会只孤零零显示最后一页，而是一次性把从第 0 条到续读位置之后的窗口完整呈现，向上、向下滚动都立即有内容，不需要慢慢等补加载。
- **切换库秒开 + 滚动位置保留**：在同一会话内切换库或暂时离开再返回时，会优先从本地暂存的快照中恢复已加载词条、滚动位置和续读锚点，几乎秒开；只有暂存内容无法覆盖你要续读的位置时，才会重新拉取数据。浏览进度会在你离开页面、切后台或关闭窗口时上报到账号，下次在任意设备登录同一账号都能恢复；公开库的非所有者拥有自己独立的进度，不会与所有者或其他访客互相覆盖；切换账号会清空上一账号的本地暂存。
- **删除词库**：可对不再需要的单词库执行删除，经**二次确认**后移除库及其词条（经典语句库逻辑对称，以实现为准）。
- **收藏星标**：资源库与包列表中的词条，收藏星标会随词条本身一同按分页范围加载——卡片出现在屏幕上的那一刻，星标就已经是正确状态（已收藏/未收藏），不会先空后亮造成视觉闪烁；收藏与取消收藏的操作会按你的账号保存，并在练习、收藏抽屉等页面实时同步。
- **向下无限加载**：滚到列表底部时自动加载下一批词条；续读首屏已经把窗口加载完整后，后续只需单向往下滚动即可，页面逻辑更轻量。

### 13.7 拉取历史、结果页与停止生成

- **历史抽屉**：单词包 / 经典句拉取区可打开**历史记录**列表，查看以往生成会话；进行中的会话会显示进行中标识，且通常**不可删除**，直至结束。
- **打开历史**：点击某条历史会进入**流式结果页**查看当时生成的词条，**不会**用历史主题覆盖你左栏正在填写的新拉取表单。
- **删除历史**：可对已结束的历史记录删除；删除后相关已落库词条一并清理（以实现为准）。
- **结果页**：页头展示本次主题与联网摘要等信息；进行中的拉取与纯历史查看在分页与交互上有所区分，避免切换历史后丢失当前进度。
- **停止生成**：流式拉取过程中可停止；停止后界面以已生成内容为准，且一般不会因「用户主动停止」再弹出刺眼的错误提示。

### 13.8 英语学习 Agent（多会话）

- 在英语学习主界面可使用 **Agent 对话**：支持**多路会话**，可在历史抽屉中分页浏览并切换；点「新对话」会清空当前展示，**首条消息发送时**再创建服务端会话。
- **历史隔离**：历史抽屉只展示英语学习 Agent 会话，不会混入知识库助手选用 Skill 或 Skill 管理页试跑产生的记录。
- **长对话滚动**：输入区右上方可「滚动到底部 / 滚动到顶部」；流式中上滑阅读后，可再滚回底部恢复跟随；**流式结束后**若你曾上滑打断贴底，不会强制跳到底部。
- **选区右键朗读与复制**：在 Agent 消息正文中**选中一段文本后右键**，可弹出自定义菜单选择 **朗读** 或 **复制**。朗读复用听书同款按段云端语音，首句出声快、逐句预览；播放期间输入框上方显示**悬浮控制条**，可播放/暂停、停止、调速，并支持**拖动**到任意位置。未选中文本时仍为系统默认右键菜单。
- **悬浮控制条的拖动与缩放**：朗读开始后出现的悬浮控制条支持 **拖动**（按住左侧手柄拖到面板内任意位置）与 **缩放**（右下角或右上角拖角调整宽高）；当高度超过一定阈值时，控制条会自动切换为**纵向布局**（预览文本在上、操作按钮在下），便于单手操作；调速范围为 **0.5×～3×**，与听书保持一致。
- **进度高亮更准确**：中英混排文本朗读时，逐句高亮不再出现整段中文被跳过或英文段落超前的情况；TTS 等待期间调整的倍速在音频就绪后会立即生效，无需重新朗读。
- **快捷意图**仅影响当轮模型输入，**不会**写入会话历史正文。
- 将 Agent 回答保存到知识库后，产品可引导你进入**知识库**继续编辑（以实现为准）。

### 13.9 列表与左栏交互细节

- **列表折叠**：已拉取的单词或经典句卡片列表标题旁可**收起 / 展开**网格，默认展开；新一轮拉取开始时会自动展开，便于看到新内容。
- **快捷意图折叠**：左栏快捷意图较多时，默认只展示前几条，可展开查看全部，与主列表折叠交互风格一致。
- **词性展示**：单词包词条可显示英文缩写形式的**词性（如 n、v、adj）**，便于区分同一词形的不同用法。

### 13.10 网络不稳定时的体验（尤其桌面端）

在**桌面客户端**访问远程服务时，列表首屏、加载更多或收藏状态查询若遇到瞬时网络失败，产品会尽量**自动重试**只读请求，并以**可读文案**提示失败原因，避免把底层技术错误原文直接展示给你。收藏、取消收藏等写入操作通常不会重复提交，以免产生副作用。

### 13.11 听写与拼写练习（单词与经典句）

- **单词入口**：在**单词收藏**底部、**单词资源库**（左侧词库列表悬停耳机图标，以及**右侧当前词库词条列表顶栏**）、**单词词包结果页**顶栏、**单词历史拉取记录抽屉**，以及**错题集页底栏**（单词 Tab），可进入听写或「看中写」练习。
- **经典句入口**：在**经典句收藏**底部、**语句资源库**（左侧语料库悬停耳机图标与右侧语句列表顶栏）、**经典句词包结果页**顶栏、**经典句历史抽屉**，以及**错题集页底栏**（语句 Tab），可进入听写或「看中写」练习（按整句英文作答）。
- **练习设置**：进入练习后先选模式、题量与顺序；页顶会显示**词表来源名称**，右侧显示词表总量（单词为「128 词」，经典句为「20 句」）。
- **练习流程**：逐题作答；听写模式可播放读音后输入英文，拼写模式根据中文释义输入英文。**判分**忽略大小写；单词另忽略句末标点，经典句另忽略全部标点（仍须字母与空格一致）。
- **提示**：作答过程中可点题卡右上角 **提示** 展开线索，再次点击 **收起提示**。**单词**：听写可查看中文释义与音标（仍不显示英文词），拼写可在释义下方查看音标。**经典句**：听写可查看中文释义、出处或赏析（仍不显示英文原句），拼写可在释义下查看出处或赏析；本题无可用线索时按钮不可用；进入下一题后提示会自动关闭。
- **答错后重答**：**第一次**答错时只标红你的答案并自动展开提示（仍不显示英文正确答案），以字段表展示线索并可播放；底栏左侧播放、中间引导文案、右侧圆形 **看答案**（与播放钮同款样式）。点 **看答案** 或按 **→** 进入完整揭示时，**若正在朗读会继续播完**（两页共用播放状态）。**再次答错**则直接显示完整正确答案（含英文、音标/分词/例句或语句出处等）。可点 **再试一次** 在本题重答，**上一题**（非首题）回到上一道并重练，或 **下一题** 记入本轮并继续。**键盘**：作答 **Enter** 检查；**Shift + 空格** 播放/停止；首次答错与完整揭示后 **↑** 上一题、**←** 再试、**↓** 下一题；首次答错另可用 **→** 看答案。题卡顶栏会标明**单词听写**、**语句听写**、**单词看中写**或**语句看中写**。
- **看中写提示与播放**：顶栏点 **提示** 展开后，除音标等线索外还可**播放**读音；首次答错提示区同样可播放。
- **听写播放**：进入题目、换题与听写 **再试一次** 时自动连续播放 **3 次**（间隔约 **3 秒**），可点停止。仅**未展开提示时**题卡中央**大号播放钮**亦为 **3 次**；**Shift + 空格** 与答错页手动播放为 **1 次**（未展开提示时 Shift+空格 亦为三连播）。**看答案** 不会打断进行中的朗读。
- **快捷键说明**：练习页顶栏右侧 **?** 图标可打开下拉列表，按「作答中 / 首次答错 / 看答案后」查看 **Enter** 与方向键对应操作（图标展示，无路径说明）。
- **练习报告（结算）**：本轮结束后进入报告页，顶部展示正确率与分项统计；下方**作答明细**先列出错误词、再列出正确词（正确项以**绿色左边框**区分，错误项为**红色左边框**），可点击播放读音复习。
- **结算后操作**：可**重练错题**、**继续练习**（在词表范围内尽量抽取尚未练过的词）、**重新设置**；可将本轮错词**加入错题集**；可**进入错题集**查看已保存的错词；**返回**为页眉左侧**返回图标**。
- **返回去向**：从**英语学习首页**的历史记录进入练习时，返回会回到**首页**；从**词包结果页**的历史抽屉进入时，若练习的是另一条记录，返回后仍保持原先选中的那条记录；从**单词或语句错题集**进入练习后，返回会回到对应的错题集页。

### 13.12 错题集（单词与语句）

- **进入方式**：在**英语学习首页**侧栏点击**单词错题集**或**语句错题集**（直达对应分类）；也可打开错题集页后在顶栏 Tab 切换（布局与「我的收藏」一致）。同一侧栏还提供 **今日复习**（见 **§13.14**）。
- **错题列表虚拟滚动 + 续读**：错题集列表同样使用**虚拟滚动网格**（与资源库词条列表同引擎），窄屏 1 列、中屏 2 列、宽屏 3 列自适应，错题再多也不卡顿。列表会记住你上次浏览到第几条，下次进入直接定位到附近继续浏览，关闭浏览器或退出桌面应用后也不丢失。右下角有**悬浮角标按钮**，可一键置底或置顶。删除错题后列表**原地刷新**，不跳回首屏。
- **顶栏**：标题旁显示**总数 / 已加载**；右侧切换**单词错题集** / **语句错题集**。
- **单词内容**：错词含词面、音标、释义、例句与上次错拼；**语句内容**：错句含英文、中文释义、出处、赏析与上次错拼；均支持播放、勾选**全选已加载**、**移除所选**。
- **再次练习**：底栏右侧 **听写 / 拼写** 以当前 Tab 的错题集为词表来源；无错题时禁用。
- **与结算页关系**：练习报告可先**加入错题集**再**进入错题集**核对；已存在的词形或同一句若错拼与上次不同会**更新上次错拼**，错拼相同则不变。

### 13.13 语句错题字段说明

- **语句错题列表**展示英文原句、中文释义、出处、赏析与上次错拼；播放为整句朗读。其余操作见 §13.12。

### 13.14 今日复习（间隔复习）

- **位置**：**英语学习首页**左栏 **今日复习** 区块（玫瑰金色图标），分别显示 **单词复习**、**语句复习** 按钮及各自待复习数量；无到期项时对应按钮不可用。
- **来源**：通常来自你在听写/拼写结算页**加入错题集**的条目；仅**新加入**或**错拼有变化**的错题会进入「今日待复习」。很久以前已在错题集、但尚未产生复习计划的条目，一般不会自动出现在今日队列。
- **开始练习**：点击 **单词复习** 或 **语句复习** 后进入听写/拼写**设置页**（与收藏、错题集入口一致），请自行选择 **听写 / 看中写**、**题量**（如 10～50），再点 **开始练习**。复习队列由系统按到期顺序抽取，设置页不展示「顺序 / 随机」选项。
- **结算**：完成一轮后，系统根据每题对错调整下次复习时间；答对的条目会从「今日待复习」中移出，侧栏计数会刷新。复习场次结算页**不会**再次提供「加入错题集」（条目本身来自错题集）。
- **返回**：从侧栏进入的练习，结束后 **返回** 会回到 **英语学习首页**。
- **继续练习**：结算页 **继续练习** 会在尚未练过的到期项中尽量再抽一批；若今日已无更多到期项，会提示无更多可复习内容。

### 13.15 今日记词

- **位置**：**英语学习首页**左栏 **今日记词** 区块；可设置 **每轮词数**（10～50），点 **开始记词** 进入 **`/english-learning/daily`**。
- **流程**：介绍页 → 认读（听发音、看释义）→ 点 **考考我** 做四选一 → 正/错反馈 → **下一词** 直至完成；练完后写入记词记录并纳入间隔复习，可在 **记词记录** 页查看。
- **四选一**：错误选项优先来自本轮其它词的释义，并尽量与当前词 **词性、释义长度** 相近，减少同一轮内重复出现相同干扰项。
- **底栏按钮**：介绍页 **开始记词** 与听写/拼写设置页 **开始练习** 底栏间距一致；认读与反馈页的 **考考我 / 下一词 / 完成** 为全宽主按钮，无额外深色边框间隙。

### 13.16 资源库编辑与公共词库

- **编辑入口**：在**单词库 / 语句库**左侧列表中，悬停或选中某个库卡片时，删除按钮左侧有**编辑**图标。**创建者**对**尚未公开**的自有库可见；**已公开**的资源库仅**超级管理员**可见编辑（用于维护公开状态）。
- **修改名称**：点击编辑后，在弹窗中可修改**资源库名称**（最多 **50** 字，输入框右侧显示当前字数）；仅**创建该库的用户**可保存改名；浏览他人公共库时名称输入框为只读。有未保存变更时，在弹窗内按 **Enter** 可快捷保存。
- **设为公共**（超级管理员）：若你的账号为**超级管理员**，同一弹窗内会出现 **设为公共资源库** 开关；开启并保存后，全站登录用户都能在资源库中看到并使用该库（浏览词条、听写/拼写、今日记词等）；关闭则恢复为仅创建者可见。**新导入的库默认不公开**，须由超管在此手动开启。
- **删除与标签**：你只能删除**自己创建**的库；他人公共库无删除按钮。列表上的 **公共** 小标签在库已公开时对**所有登录用户**可见，便于识别全站可读资源库。

### 13.17 首页左栏布局与交互

- **卡片分区**：英语学习首页左侧各功能（今日记词、快捷意图、单词库/语句库、按主题拉取、收藏、今日复习、错题集等）以独立**卡片**呈现，标题左侧有彩色图标区，整体风格与右侧 Agent 区、知识库侧栏的细边框浅底一致；各区块按钮仍保留原有配色（如今日记词、词包拉取等色相不同）。
- **导入 JSON 示例**：在单词库/语句库卡片内，**JSON 格式示例默认收起**；点击「展开导入示例」类标签可查看示例并再次点击收起，便于对照格式又不占满首屏。
- **快捷意图排布**：快捷意图默认展示前几条，点 **展开** 后芯片在窄侧栏以**双列**排布；侧栏拉宽时会自动增加列数，避免意图条目挤成单列竖排。

### 13.18 学习笔记

- **入口**：在**英语学习**侧栏进入 **学习笔记**，或打开 **`/english-learning/notes`**。
- **使用**：页面展示笔记模块内容（由独立功能模块加载）。若提示模块不可用，可确认网络后点击 **重新加载**；其它英语学习页面不受影响。
- **富文本编辑**：笔记编辑器支持 **格式化文本**（加粗、斜体、删除线、代码等）、**高亮标记**、**有序 / 无序列表**、**代码块** 等编辑能力，记录学习收获时可灵活排版与标注。工具栏按钮在鼠标悬停时，图标会以细描边的方式「画」出线条，交互更有层次。
- **左右分栏**：编辑区左侧为笔记列表，右侧为编辑器与预览；列表宽度可拖拽调整，也可收起列表让编辑器占满全屏。
- **保存**：点击工具栏保存或按 **⌘/Ctrl+S** 写入账号；有未保存修改时，保存图标右上角会出现**橙色圆点**。新建笔记时从编辑器首行自动提取标题。
- **公开 / 私有笔记**：笔记默认仅自己可见。要分享给其他同学或在不同设备间查阅，可以把笔记设为**公开**：
  - **列表页**：鼠标悬停自己的笔记卡片，在右上角操作区点击「地球」图标，经二次确认后即可公开；再次点击则取消公开。
  - **预览页**：打开笔记后，在顶栏可见「公开 / 取消公开」按钮（只有作者本人能看到）。
  - **他人公开笔记**：在学习笔记列表里，除了自己的笔记，还会显示其他同学的公开笔记——卡片上有天蓝色「公开」徽章、作者昵称，只保留查看权限，不会出现编辑或删除按钮。
- **列表与刷新**：笔记列表采用响应式网格卡片布局，自动根据宽度多列展示。面板顶部提供 **刷新** 按钮，保存或切换状态后可随时重新拉取最新列表；滚动到底部会自动加载更多。

### 13.19 续读模块开关与一键清除

英语学习首页侧栏的**单词库 / 语句库 / 我的收藏 / 错题集 / 每日记词记录**五个模块，已经各自记住了「上次读到第几条」。如果你不想让某个模块再继续记位置，或者想把旧进度清掉从头看起，可以使用侧栏标题旁的齿轮菜单：

- **齿轮位置**：五个模块的**标题右侧**各有一个齿轮图标，点击后下拉显示「设置」标题与两项操作。
- **清除阅读进度**：点击后会弹出**二次确认**对话框，确认后会把当前模块**本地与服务端的续读位置一并归零**，列表立即从首屏重新加载。适合换主题或重新开始浏览时使用。
- **关闭 / 开启阅读进度**：
  - **关闭**后该模块**不再记录续读位置**——本设备与其它设备登录同账号都一致；列表也会立即从首屏重新加载。
  - **关闭后再开启**可恢复续读能力，下次进入会按已存在的续读位置继续（若之前已清除则从第 0 条开始）。
- **状态同步**：开关状态按**账号保存**，跨设备登录同账号一致；**未登录**时仅本地缓存（默认全开，刷新页面即重置）；**切换账号**会清空上一账号的禁用状态，新账号默认全开。
- **不影响其它模块**：五个模块的开关互相独立，关闭其中一个不影响另外四个的续读。
- **不新建续读表**：关闭后已存在的旧续读位置不会自动删除，需要你主动点「清除阅读进度」才会归零；开启后若仍有旧位置，会从旧位置继续。

### 13.20 收藏星标不再闪烁、跨页面同步

在英语学习的**资源库 / 我的收藏 / 错题集 / 每日记词 / 复习队列**等列表里，每张卡片右上角的**收藏星标**之前在组件重挂载或列表来回滚动时，常出现「先空后亮」的闪烁。本次优化后，星标状态**一旦点亮就一直保持**，并且在任意页面收藏 / 取消收藏某条后，其它已加载该条的列表卡片也会**立即同步**显示新状态：

- **会话内缓存**：当前会话内已查过的词条，收藏状态会暂存在本地；重挂载或从本地快照恢复列表时直接复用，不再重新请求服务端。
- **后端带回收藏 ID**：词包历史、错题、每日记词、复习队列、随机抽词等接口的响应体里会**直接带回收藏 ID**，前端无需再发一次「查收藏状态」的请求即可点亮星标。
- **跨页面即时同步**：在资源库收藏了一条单词后，再切到「我的收藏」或「错题集」中查看该条，星标会立刻是激活态；取消收藏同理，无需手动刷新页面。
- **切换账号清空**：退出或换号登录会清空上一账号的会话缓存，新账号看到的是该账号自身的收藏状态。

### 13.21 练习页直接收藏与每日反馈面板统一

**练习答题页顶栏**新增**收藏按钮**，作答过程中可直接收藏当前题，无需等到结算页或跳到收藏抽屉；**每日记词**答对 / 答错反馈面板也做了视觉与交互统一：

- **练习页内收藏**：听写 / 拼写 / 看中写等练习的题卡顶栏右上角会出现**星标按钮**，点一下即可收藏当前单词或经典句，再次点击取消；状态与资源库、收藏抽屉实时同步。
- **反馈面板合并**：每日记词答对（绿色）与答错（红色）两张反馈面板**共用同一布局**——顶栏统一为「状态图标 + 文案 + 收藏按钮 + 播放按钮」，仅以色调区分对错；视觉与其它卡片一致，避免之前两套样式漂移。
- **播放按钮统一**：每日反馈面板里的播放按钮改用系统统一按钮样式，hover 颜色与收藏激活色统一为青绿色，与资源库、收藏抽屉的按钮风格对齐。

### 13.22 学习笔记图片云端化与自动回收

学习笔记正文里的图片改由**服务端上传云端对象存储**，正文只保留云端 URL，不再塞 base64；桌面端粘贴图片也与浏览器一致走云端上传。同时新增**孤儿对象自动回收**，避免上传后没用的图长期残留。

- **正文只存云端 URL**：粘贴或拖入图片时，图片先上传到云端对象存储，再以云端地址插入正文。好处是几张截图不再撑爆笔记、序列化更顺滑；导出 Word 时也无需对每张图做二次转码，长笔记导出更稳。
- **桌面端粘贴自动上传**：桌面端**粘贴图片**（截图、文件列表、富文本里的本地图）现在会**自动走云端上传**，与浏览器粘贴体验一致——不再以 base64 形式塞进笔记正文。
- **孤儿对象自动回收**：
  - **新建笔记没保存就关闭**：先粘贴若干图但没保存笔记就关掉页面，1 小时后云端会**自动清理**这些没被任何笔记引用的图。
  - **编辑期删图后保存**：编辑已有笔记时先粘图、随后又删掉再保存，被删的图会按**引用计数**回收（同一张图被多篇笔记引用时，删一篇只删引用，不影响其它笔记里的同图）。
  - **删整篇笔记**：删除整篇笔记时，该笔记引用的图若没被其它笔记同时引用，也会一并清理，避免长期残留。

### 13.23 学习笔记独立弹窗与多窗口同步

桌面端学习笔记可以独立弹窗打开了——侧栏笔记卡片上点「独立打开」，笔记会弹出到独立窗口，与主窗并排，边学边记。

- **独立打开**：桌面端首页侧栏的学习笔记卡片上新增「独立打开」按钮，点击后笔记以独立窗口形式打开（尺寸略小于主窗），不再占用主窗视口；已打开的弹窗再点会直接置顶，不会重复开窗。
- **实时双向同步**：弹窗与主窗之间做了实时双向同步——一窗编辑草稿，另一窗即时看到内容变化；一窗保存或删除笔记，另一窗的列表与预览自动刷新；这些同步在宿主层自动完成，插件无需感知。
- **托管关窗保存**：关闭弹窗时不会直接销毁窗口，而是先拦截关闭按钮，等未保存的草稿写入后端后再真正关窗；断网时保存失败也不卡死，窗口仍可关闭。
- **外观跟随**：弹窗的主题（深 / 浅）、强调色、语言会跟随主窗实时切换，不会出现深浅不一或语言不一致。

## 16. 电子书（书架与阅读）

### 16.1 进入书架与导入书籍

- **入口**：左侧导航 **书架**，或访问 **`/ebook`**。
- **登录**：管理书架、上传与同步阅读进度需**登录**；未登录时页面可打开但无法正常使用书架能力。
- **会员与导入**：
  - **有效会员**：**浏览器**可 **导入文件** 上传至云端书架；**桌面端**选择本地文件后会**登记路径并备份至云端**（大文件显示进度）。
  - **非会员**：**浏览器**无法导入（点击时会提示需开通会员）；**桌面端**仍可用 **选择本地文件** 登记本机路径并**本地阅读**，**不会**发起云端备份。
- **桌面端（Tauri）**：点击 **选择本地文件**，在系统文件选择器中选 **epub** 或 **pdf**。选中后**立即加入书架**并可马上点 **阅读**；**会员**在后台将文件**备份到云端**。若**同一本地路径**已在书架中，会提示**无需重复上传**。本机文件保留在原位置，阅读时**优先读本地**；若文件被移动或删除，且已成功备份，则尝试从云端打开。**同一本书** 的阅读进度始终一致。
- **浏览器**：**会员**点击 **导入文件**，从本机选择 epub/pdf 上传至账号书架；成功后留在书架，需点击卡片 **阅读** 进入。
- **体积说明**：浏览器与云端备份单文件约 **120MB** 上限；桌面端本地阅读允许更大文件（约 **512MB**），超过上传上限仍可本地阅读，但可能无法完成云端备份。
- **书架列表**：书籍较多时**向下滚动**自动加载更多；各 **分类 Tab** 旁数字为对应册数。书架卡片按 **最近阅读时间** 倒序排列——刚读过的书会自动浮到最前，未读过的书仍按加入时间排；阅读过程中进度保存后顺序即时更新，无需手动刷新。
- **书架卡片**：竖版卡片展示封面（可自定义）、格式（EPUB/PDF）、四边阅读进度；进度文案为 **整数百分比**（如「已读约 12%」）；**悬停**卡片出现蒙层，可 **开始阅读 / 继续阅读**、**设置封面**、查看进度或 **删除**（二次确认）。卡片**下方书名**可点击编辑，**回车**保存，**Esc** 或点击外部取消；保存成功有提示；**悬停书名** 可查看 **所属分类** 与完整书名（未分类或分类已删时显示 **未分类**）。
- **顶栏与分类**：应用**主顶栏**显示 **墨客书屋 › 我的书架**（与阅读页 **墨客书屋 › 阅读** 一致；点击「墨客书屋」回到书架根路径）。书架**区内顶栏**左侧为 **管理分类**，中间为 **全部 / 公开 / 自定义分类 / 未分类** Tab（可左右滑动；**无书的分类** 与 **无未分类书** 时对应 Tab **不显示**），右侧为 **导入**（悬停按钮可查看导入说明）。**管理分类** 可新建、重命名、删除或调整顺序；在卡片**下方书名右侧**点击 **文件夹图标**，可将书 **移动到分类**（编辑书名时该按钮会隐藏）。**删除分类后**，原书籍会归入 **未分类**。在某一分类内 **移走或删除最后一本书** 后会 **自动回到「全部」**。导入新书时，默认加入 **当前选中的分类**（系统会记住你上次导入时用的分类）。
- **公开书籍**：**已上云 EPUB 源书** 的书主可在书架卡片或阅读页顶栏将书设为 **公开 / 私有**（**地球 / 锁** 图标，二次确认）。**公开** 后全站登录用户可在 **全部** 或 **公开** Tab 看到该书（显示 **书主昵称/头像**），点 **阅读** 即可打开，**无需链接**。**本地未上云** 的书须先 **备份至云端** 才可公开。**PDF** 暂不支持公开。读者 **进度、划线、本人想法** 独立保存；可见书主 **公开想法**（见 **§16.6** 虚线色与叠层）。书主 **取消公开** 后他人书架不再展示；读者已有读书记录保留。

### 16.2 阅读、目录与翻页

- **阅读页**：顶栏左侧 **返回** 回到书架；中间为书名；右侧 **EPUB 在「分页翻页」模式下** 显示 **上一页 / 下一页**（**连续滚动** 模式下顶栏不显示 EPUB 翻页按钮，请用滚动衔接章节）；EPUB 与 PDF 均提供 **目录** 按钮（抽屉标题 **书籍目录**；PDF 目录来自文件内书签，无书签时提示无目录）。打开目录时，**当前阅读位置对应的章节会高亮显示**，长列表会自动滚到可见区域；列表右下角有 **滚动按钮**，连点可依次 **滚到底部 → 顶部 → 当前章**（图标随之切换）。**连续滚动** 模式下点目录条目会 **滚到该章开头**（或该书内锚点），便于从目录直接开读。
- **PDF 页码**：PDF 在顶栏翻页按钮之间显示当前页 / 总页数（无底部翻页栏）。
- **PDF 缩放**：顶栏 **缩小 / 放大** 按钮与百分比（**100% = 适应宽度满宽**）；范围约 50%～300%，偏好保存在本机。
- **PDF 滚动换页**：长页在阅读区内上下滚动；滚到**顶部或底部并停稳后**再滚一下，可自动翻到上一页或下一页（类似 EPUB 连续滚动的章节衔接）。整页能一屏显示时，滚轮可直接翻页。顶栏翻页按钮与 **↑ / ←**、**↓ / →** 仍可用。
- **PDF 滚动条**：长页 PDF 在阅读区内上下滚动时，滚动条为细条、随应用主题配色，与 EPUB 连续滚动时的滚动条风格一致。
- **进度**：阅读过程中进度会自动保存；再次从书架打开同一本书可尽量恢复到上次位置。**刷新页面、关闭标签或切到后台** 时会尽量立即同步到账号，减少强制刷新后位置丢失；听书等连续阅读时云端同步会合并发送，本地续读位置仍即时更新。
- **EPUB 文字颜色**：在 **阅读设置** 中可选 **12 档文字颜色**（含跟随应用）；所选字色会同步作用于 **顶栏、侧栏、输入框、听书菜单、设置面板与目录** 等阅读区外围界面，与正文一致可读。
- **窗口尺寸变化**：**放大窗口或全屏** 后，EPUB 正文会 **自动居中重排** 至新的阅读区宽度，无需刷新；拖动 **MOKE/想法** 分栏时仍保持流畅、避免白屏（见 **§16.3** 阅读设置与分栏说明）。
- **键盘**：**↑** 或 **←** 上一页；**↓** 或 **→** 下一页。打开目录抽屉或在输入框内输入时不响应翻页键。
- **顶栏标题**：应用主顶栏在阅读页显示 **墨客书屋 › 阅读**；具体书名在阅读区顶栏展示。

### 16.3 EPUB 阅读设置（仅 EPUB）

- **入口**：阅读 EPUB 时，顶栏 **目录** 按钮右侧的 **阅读设置**（闪电图标）。
- **可调项**：**字号**、**行间距**；**阅读背景** 与 **文字颜色** 各 **12 种**（色块点选，含「跟随应用/跟随主题」）；选「跟随应用」时背景与 **设置 → 主题配色** 一致。**阅读背景** 会同步作用于 **顶栏**、**右侧分栏**（读书想法 / MOKE 问书）与 **设置面板本身**；**文字颜色** 会同步 **侧栏按钮、分隔线、MOKE 输入框、听书分句/倍速菜单、目录当前项高亮** 等，与正文观感一致。
- **翻页方式**：**连续滚动**（默认，纵向滚动；滚到章节底/顶自动衔接下一章/上一章）或 **分页翻页**（按屏切换）。**连续滚动** 时顶栏与右键菜单 **不显示** EPUB **上一页/下一页**；**分页翻页** 时仍显示。顶栏用**两个并排按钮**切换翻页方式，不再使用下拉框。
- **关闭面板**：**阅读设置**、听书 **分句** 或 **倍速** 菜单打开时，点击 **左侧阅读区正文** 可关闭（与点击页面其它区域类似）。
- **恢复默认**：设置面板底部可一键恢复（默认 **连续滚动**）。
- **说明**：偏好保存在**本机**；换设备或清除站点数据后需重新调整。切换翻页方式时会短暂重载当前书，尽量保留阅读位置。设置项较多时面板内可滚动，滚动条样式与应用其它列表一致。

### 16.4 MOKE 智能助手（EPUB 与 PDF）

- **入口**：
  - 阅读 **EPUB** 或 **PDF** 时，点击顶栏 **Bot 图标**，或在阅读区 **右键 → 智能助手**。
  - EPUB 另可在正文 **右键**（无选中时菜单含智能助手；**须先拖选文字** 再右键才会出现 **复制 / MOKE 问书 / 写想法**，直接右键不会自动选中词语）。
  - 打开右键菜单时，若此前有 **浮动工具条**（选区工具条），工具条会 **直接收起**。
- **布局**：左侧阅读、右侧 MOKE 智能助手，中间分隔条可拖拽（默认约各占一半宽度）；**非弹窗/抽屉**。拖拽分栏时 EPUB 正文 **重排更流畅**，**用户划线不会白屏闪烁**。从 **读书想法** 侧栏打开 MK 问书时 **分栏宽度不变**；关闭 MK 问书后若无其它右侧面板则 **阅读区恢复全宽**，若此前在想法列表/详情则会 **回到想法面板**。**想法列表右上角关闭**、**删除最后一条想法** 或 **开发热更新后** 阅读区 **立即** 恢复全宽，不留右侧空白。
- **使用**：需**登录**；可向 AI 提问本书内容、背景或读后感；流式滚动与知识库助手一致（上滑可打断自动贴底，流式结束后保持阅读位置）。助手按**每本书**保留独立对话会话。
- **输入焦点**：从选区打开 **MK 问书**（或顶栏打开助手后进入输入）时，右侧输入框会在分栏就绪后自动聚焦；与 **读书想法** 来回切换时，当前可见面板的输入框也会自动聚焦，可直接键入。
- **AI 回复操作**：悬停助手消息可 **复制**、**保存到知识库**（跳转知识库页编辑）、**分享** 当前问答对。
- **PDF 说明**：PDF 正文暂无法选中，**无 MOKE 问书**；其余助手能力同 EPUB。
- **键盘**：助手打开且焦点在输入框时，不响应阅读区翻页快捷键（↑/←/↓/→）。

### 16.5 PDF 阅读右键菜单（仅 PDF）

- **入口**：PDF 阅读区内 **右键**。
- **菜单项**（自上而下）：**智能助手** → **目录** → **放大 / 缩小** → **上一页 / 下一页**。
- **说明**：连续点击放大/缩小时菜单保持打开；目录与翻页与顶栏按钮行为一致。

### 16.6 EPUB 读书想法（仅 EPUB）

- **入口**：
  - 阅读 **EPUB** 时在正文 **选中文字** → 选区上方 **浮动工具条** 或 **右键** → **写想法**。
  - 浮动工具条为 **半透明毛玻璃** 样式，在 **深色阅读背景** 与 **各配色主题** 下仍易于辨认；**复制** 成功后会短暂显示 **已复制** 再收起选区。
  - 点击已有 **细琥珀色虚线下划线** 打开该段 **想法列表**。
- **界面**：列表、详情与写想法均在 **右侧分栏**（与 **§16.4** MK 问书 **互斥**、同栏可拖拽）；顶栏左侧为标题（列表页旁显示 **共 N 条**），右上角 **关闭**；写/编辑时 **取消/保存** 在面板底部，查看时为 **删除/编辑**。
- **列表与详情**：展示 **头像**、**用户名**、**发布时间** 与正文；引用段落卡片下方可 **复制**、**写想法**、**MK 问书**、**分享书摘**（与 **§16.4**、**§16.8** 衔接）。
- **写想法 / 编辑**：正文最多 **500 字**；**Enter** 保存，**Shift / Ctrl / Cmd + Enter** 换行；输入区固定于分栏底部，引用与详情在上方滚动。从选区打开 **写想法** 后，输入框会在分栏就绪后自动聚焦，可直接键入；与 **MK 问书** 切换后再回到写想法时同样会自动聚焦。
- **标记**：保存成功后该段下方出现虚线下划线；再次打开同一本书会自动恢复。**阅读公开分享的 EPUB** 时，**书主/他人** 想法为 **灰色虚线**，**本人** 为 **琥珀色**；与本人想法重叠处 **只显示本人虚线**；本人多条部分相交的想法同样 **只显示一条** 虚线。
- **查看流程**：点击下划线 **先打开列表**（即使只有 1 条），点选进入详情；从列表进入详情后 **关闭详情会回到列表**（若列表已无想法则 **收起侧栏**）。
- **删除**：在详情中 **删除** 想法后，若当前列表 **已无剩余条目**（「共 0 条」），**读书想法分栏会自动关闭**；若仍有其它条目则回到列表。列表与详情中想法正文 **垂直位置一致**。
- **点击聚合**：侧栏会 **智能聚合** 与本次点击相关的想法。**嵌套选区**（例如整段 + 前半句 + 后半句）点击任一处 → 引用区 **默认展示整段摘录**，列表 **同时列出** 各层选区下的全部想法。**同句相邻短语** 仅在中间 **标点或换行也已单独标注想法** 时合并展示；**未标注** 的逗号、换行 **不会** 把两处想法合并进同一列表。多选区分组时 **分段标题** 可 **展开 / 收起** 长摘录。
- **列表操作**：**单击列表中某条想法** 直接 **进入详情**（不再单击切换引用摘录）；列表引用区文字 **不可点击** 跳转正文 PopBar（划线等操作请用底部操作条）。
- **阅读位置与引用保持可见**：打开或关闭右侧分栏、拖动中间分隔条或缩放窗口时，左侧正文 **当前阅读行会尽量留在视口内**；若侧栏展示某一 **引用摘录**，对应段落也会 **尽量保持在当前屏幕内**，不会因分栏变窄或恢复全宽而滚出视野。
- **重叠选区**：嵌套或部分相交的重叠，正文只显示 **一条** 虚线；点击后按上条 **聚合规则** 打开列表（不再只显示最短选区）。
- **选字**：拖动选中 **松手不会** 弹出列表，需 **主动点击** 下划线。
- **登录与同步**：需 **登录**；想法保存在账号下，换设备可拉取；**删除书架中的该书** 时该书下想法一并删除。
- **说明**：**PDF** 暂不支持读书想法；与 MOKE 问书可分别使用。

### 16.7 EPUB 用户划线（仅 EPUB）

- **入口**：阅读 **EPUB** 时在正文 **选中文字** → 选区上方 **浮动工具条** → **划线**；或点击已有 **彩色标记** 打开工具条改样式/删除。想法侧栏引用区也可 **划线**（无标记时会自动创建）或 **删除划线**（与选区工具条一致：仅当 **当前展示的引用摘录全文** 均已划线时才显示 **删除划线**，否则显示 **划线** 并为整段引用补划）。同一工具条还提供 **分享书摘**（见 **§16.8**）。
- **样式**：**背景高亮**、**直线下划线**、**波浪下划线** 三选一；**粉 / 紫 / 蓝 / 绿 / 黄** 五色预设，另可在样式条打开 **自定义色** 选取任意颜色并调节 **填充透明度**（每条划线独立保存）。
- **顶栏样式条**：**全新选区**（尚未划线）时 **不展示** 顶部 **样式/颜色条**；**已有彩色划线**（含只覆盖选区一部分）时展示，便于改样式或换色。
- **合并**：两次划线若 **重叠或首尾相接**（例如前一段以某字结尾、后一段从同一字开始），会 **合并为一条**，颜色与样式以 **最后一次** 为准。
- **识别范围**：划线按 **正文位置** 识别；书中 **重复出现的相同句子** 互不影响（各划各的、各删各的）。
- **工具条按钮**：选区已全部划线时显示 **删除划线**；混选（含未划与已划）或整段未划时显示 **划线**（同一槽位切换，无空白占位）。
- **流畅度**：划线、删线与写想法后正文标记 **更快出现**，同步时 **不再长时间卡住滚动**；切换划线状态时工具条 **不再整栏闪烁**。
- **与想法**：用户划线为 **实色标记**；想法为 **琥珀虚线**（见 **§16.6**）。同一段可同时存在；被彩色高亮 **完全盖住** 的虚线会暂时隐藏，删除划线后虚线恢复。
- **登录与同步**：需 **登录**；划线保存在账号下；**删除书架中的该书** 时该书下划线一并删除。
- **说明**：**PDF** 暂不支持用户划线。

### 16.8 EPUB 书摘分享（仅 EPUB）

- **入口**：阅读 **EPUB** 时在正文 **选中文字** → 选区上方 **浮动工具条** → **分享书摘**；或在 **读书想法** 列表/详情引用卡片底部操作条点击 **分享书摘**。
- **生成**：弹出 **分享书摘** 对话框，自动生成带 **当天日期**、**书摘正文**、**书名** 与 **墨客读书** 品牌标识的 **图片卡片**；尽量保留原文字号与字重比例。
- **弹窗与预览**：对话框 **标题与按钮** 会跟随 **阅读设置** 的 **背景与字色** 保持可读；**分享图片** 与 **预览区底色** 仍为 **固定浅灰日历卡** 风格（便于对外分享）。
- **操作**：可 **复制图片** 到系统剪贴板后粘贴到微信等应用，或 **下载** PNG 文件。
- **说明**：打开分享对话框时 **选区工具条可保持显示**；**MK 问书** 侧栏不受分享操作影响。**PDF** 暂不支持书摘分享。

### 16.9 EPUB 引用朗读「听当前」（仅 EPUB）

- **入口**：阅读 **EPUB** 时在正文 **选中文字** → 选区上方 **浮动工具条** → **听当前**；或在 **读书想法** 列表/详情引用卡片底部操作条点击 **听当前**。
- **播放**：从 **选中文字所在的那一句** 起播，并像 **听书** 一样 **继续向下朗读**（不只读选区）；使用与英语学习相同的朗读能力（有效会员默认云端，失败或非会员时本机）。按钮文案固定为 **听当前**（每次点击重新从当前选区起播）；**暂停 / 继续** 请用底部播放条。
- **播放条**：听当前后与 **听书** 共用底部 **播放条**（暂停/继续、停止、**分句** 列表跳转、**上一章 / 下一章**、**播放倍速** **0.5×～3×**）；语音加载中播放钮显示 **加载中**。
- **选区工具条**：点 **听当前** 后工具条 **收起**，正文 **选中高亮清除**。
- **播放背景**：当前句 **淡黄色底**；换句时上一句清除；与用户划线、想法下划线独立。
- **自动跟随**：播放时当前句自动滚入视口；**手动滚动** 或 **划选正文** 会暂停跟随，右下角 **回到播放位置** 可滚回并恢复。
- **说明**：**PDF** 暂无此入口。

### 16.10 EPUB 边听边读「听书」（仅 EPUB）

- **入口**：阅读 **EPUB** 时，顶栏 **Bot 图标左侧** 的 **耳机图标** → **听书**；再次点击 **停止听书**。
- **播放**：从 **当前屏幕可见章节** 的起始位置（或当前阅读 CFI 对应句）起连续朗读；**云端** 下按 **段落合成**，正文仍 **逐句淡黄高亮**（首句更快出声）；节末自动衔接 **下一章**；全书读完有提示。**连续滚动** 阅读方式下会按滚动容器内 **逐段衔接** 下方正文续播。章节中的整行装饰分隔符（如一长串星号）**不会朗读**。
- **播放条**：阅读区底部固定 **播放条**（暂停/继续、停止、**分句** 列表跳转、**上一章 / 下一章**、**播放倍速** **0.5×～3×**（刻度尺 **0.1** 步进）、章节与句进度）。播放中 **上一章 / 下一章** 或从分句列表跳转 **不会退出听书**。
- **暂停与继续**：暂停后再点继续，会从 **刚才停下的位置** 接着播；也可使用系统控制中心或耳机上的媒体键，状态与播放条一致。点 **停止** 或再次点顶栏 **听书** 退出时，朗读结束并卸掉媒体键绑定。
- **分句菜单**：点击播放条 **分句**（列表图标）打开当前章 **逐句列表**，点选任一句即 **从该句开始播放**，并将该句 **滚到屏幕中央**；菜单打开时会 **自动滚到正在播放的那一句**；长章列表为 **虚拟滚动**；标题栏右侧有 **滚动按钮**，连点可依次 **滚到底部 → 顶部 → 当前句**（图标随之切换）。句级跳转请用本菜单（底栏箭头已改为切章）。切换 **阅读背景** 后，当前正在播放的那一句在列表中的高亮底色与字色会跟着阅读文字颜色变化，保持可读。
- **播放等待**：只要当前要播的语音还在加载、尚未出声（开始听书、切章、跳句、段间合成等），播放钮都会显示 **加载中**且不可点；出声后变为暂停图标。加载中请勿依赖 Touch Bar / 控制中心操作——出声后系统媒体键才会与播放条对齐。后台预取下一段不会单独触发加载态。
- **倍速**：点击播放条右侧 **倍速按钮**（如 `1.0 X`）打开 **刻度尺面板**，可 **拖拽** 或点 **圆形预设**（1.0、1.5、2.0 等）选择 **0.5×～3×**；**云端语音** 下切换后听感应与界面一致。倍速会 **同步到账号**：默认对所有书生效；打开面板下方 **设置为本书籍** 开关后，仅当前书使用该倍速，其它书用各自设置或默认 **1.0×**。语音 **加载中** 时仍可打开/调整倍速，已打开的面板不会因句间加载自动关闭。
- **播放背景**：当前句 **淡黄色底**（与 **听当前** 同色）；句末清除；与用户划线、想法下划线独立；**调整右侧分栏或开关想法列表** 时背景会随阅读区宽度 **自动对齐** 当前句。
- **自动跟随**：播放时 **当前句自动滚入视口**；**手动滚动、滚轮** 或 **划选正文** 后自动跟随 **暂停**，右下角 **回到播放位置** 按钮可滚回并恢复跟随（**连续滚动** 下即使滚到很远的章节也可回位）。
- **目录 / 底栏切章**：听书中打开 **书籍目录** 换章，或点播放条 **上一章 / 下一章**，都会从该节（目录项）**开头** 自动继续朗读并 **保留倍速**。若一书中 **多个目录项共用同一文件**（靠页内锚点区分），点目录或切章会落到 **对应小节**，而不是整文件开头。底栏切章以 **正在朗读的位置** 判定当前节，再选前后邻项。
- **与听当前**：选区/想法 **听当前** 会切入与顶栏 **听书** **同一套** 播放会话并续读；新开听当前会从新选区重新起播。**PDF** 暂无听书。
- **与助手选区朗读的互斥**：在阅读页内，**听书** 与助手面板的 **选区朗读** 共用同一套音频引擎，因此严格互斥——启动听书会自动停掉正在播放的选区朗读；在助手面板中对选中文本点 **朗读**，会先停掉当前的章节听书再开始新的朗读。若希望连续朗读，请统一使用听书功能；若希望对某段文字单独朗读，请在停止听书后再使用选区朗读。

### 16.11 EPUB 阅读页插件（全书想法 / 全书划线）（仅 EPUB）

- **入口**：阅读 **EPUB** 时顶栏 **目录** 旁的 **全书想法**（灯泡图标）或 **全书划线**（荧光笔图标）按钮。
- **全书想法**：点击后在底部抽屉浏览本书 **全部读书想法**，滚动分页加载；顶部显示书名与已加载条数；点击任一条目可 **跳转到对应划线位置** 并打开想法详情。
- **全书划线**：点击后在底部抽屉浏览本书 **全部用户划线**，滚动分页加载；点击任一条目可 **跳转到对应位置**。
- **说明**：需 **登录**；数据与 **§16.6** 读书想法、**§16.7** 用户划线同源。仅 EPUB，PDF 暂不支持。

## 17. 插件中心（功能模块管理）

主站支持在运行时加载独立部署的功能模块（与主站共享界面框架）。你可以在 **插件中心** 统一查看与开关这些模块。

### 17.1 进入插件中心

- **入口**：左侧导航的 **插件中心**（花朵图标），或访问 **`/plugins`**。
- **登录**：开关模块与编辑注册表需 **登录**。

### 17.2 上架 / 下架（启用 / 停用）

- **卡片列表**：页面以卡片展示所有可用模块，含名称、说明与 **开关**。
- **上架（开启开关）**：状态会保存到账号，**即时生效**——侧栏出现对应入口，可点进使用；若模块尚未下载，首次进入时会加载。
- **下架（关闭开关）**：状态同样保存到账号，**即时生效**——侧栏入口消失，已打开的页面会卸载；再次上架可恢复。
- **加载失败**：若模块加载失败，页面会 **稳定提示并可手动重试**，不会反复闪烁，也不影响主站其它功能。

### 17.3 注册表编辑页（高级）

- **入口**：插件中心内的 **注册表编辑** 入口（需 **超级管理员** 账号；普通登录用户看不到该入口）。
- **权限**：保存 JSON 清单的接口仅超级管理员可写入；普通用户即便手动打开路由，保存时也会被服务端拒绝并提示「需要超级管理员权限」。
- **用途**：以 **JSON 原文** 查看与编辑模块清单，保存后系统会 **自动重新加载** 模块配置。
- **字段说明**：标题旁信息图标可查看各字段含义（含 `version` 与 Host 接口兼容范围的区别）。
- **设置项目图标**：标题栏可打开模块列表，为指定模块 **上传 SVG 图标**；成功后写入该模块的侧栏与（若有）阅读页等触发器图标字段。单色稿会跟随主站选中色，悬停时有与主站一致的画线动画；换图标只需改清单并上传，不必改主站。
- **快捷键**：支持 **⌘/Ctrl+S** 保存；有未保存修改时保存按钮显示橙点。
- **校验**：保存时会做结构校验，并检查各模块的 Host 接口兼容范围；不正确会提示，不会写入。

### 17.4 视频播放器插件

- **启用**：在 **插件中心** 打开「视频播放器」卡片的开关；侧栏会出现播放器入口（电视图标）。
- **上传视频**：进入页面后，点击中央区域或直接把本地视频文件拖拽到上传区，支持同时选择多个视频（最多 100 个）。
- **播放方式**：左上角模式按钮可切换「自动播放」「单集循环」「播放完停止」三种行为。
- **自定义控制条**：
  - 底部进度条可点击跳转，hover 会显示**视频帧缩略图预览**和时间 tip；鼠标靠近进度条边缘时预览框会自动向内避让；拖拽滑块可精确调整进度。
  - 右侧图标依次是：**镜像翻转**、**设置面板**（播放方式/倍速）、**画中画**、**全屏**、**选集**。
  - 音量按钮点开后可垂直滑块调节，支持静音切换。
  - **倍速**按钮点开后可用刻度盘或键盘方向键调整，范围 0.5X–3.0X（0.1 步进），也可点击 0.5X / 1.0X / 1.5X / 2.0X / 3.0X 预设按钮。刻度标签、预设按钮在亮色 / 暗色主题下都会自适应，不会出现白字白底或白字深底看不清的情况。
- **画中画（PiP）**：点击画中画按钮可将视频缩小到悬浮窗口播放，支持 Chrome / Edge / Firefox / Safari（macOS / iOS）等主流浏览器；进入画中画后主播放器位置会显示提示覆盖层，画中画内的播放/暂停操作会同步回主播放器；播放中进入画中画，退出后自动续播；暂停中进入画中画，退出后保持暂停。
- **气泡提示（tooltip）**：进度条、音量、倍速、选集等控件上的小提示在独立预览模式和主站插件模式下都能正常显示，不再出现某些入口下提示不出来的情况。
- **播放器语言跟随主站**：切换界面语言（中/英）后，播放器内部的缓冲提示等会自动切换为对应语言。
- **影院态全屏**：点击全屏按钮后主站侧栏、顶栏、备案 footer 会**全部隐藏**，进入影院态；Tauri 桌面端会把应用窗口拉到系统级全屏，浏览器端会降级为文档级全屏；按 **Esc** 或再次点击全屏按钮即可退出。在 macOS 桌面端，用**绿色按钮**或**窗口菜单「全屏窗口」**退出全屏时，侧栏和顶栏也会在缩窗动画开始前就同步收起，视觉体验与按 Esc 完全一致。
- **多文件选集**：上传多个视频时，右下角列表图标会弹出选集，可滚动浏览并点击切换；播放结束会按当前播放方式自动切换或停止。
- **退出清理**：离开播放器页面时会自动退出影院态并清理播放器实例，不会影响主站其它页面。
- **继续添加 / 重置**：播放过程中点击右下角「+ 继续选择」可再次拖入或点选更多视频；若想重头开始，点击「重置」会彻底清空当前播放列表、预览状态和已占用的本地文件句柄。

### 17.5 插件 / 应用分类与卡片

- **Tab 分类**：插件中心顶部有「插件」与「应用」两个 Tab。**业务内嵌型**模块（如电子书阅读页插件，在业务页面内自动挂载）归入「插件」；**独立路由型**模块（如视频播放器，有独立页面入口）归入「应用」。每个 Tab 带计数徽章，空态也有对应提示。
- **卡片三段式**：每张卡片自上而下分为——**头区**：图标（优先使用注册表配置的 SVG 图标，缺省时插件显示拼图图标、应用显示应用窗口图标）、标题与版本号、上架开关；**中区**：描述；**底栏**：单行展示路由路径、侧栏有无、信任级别（如「未信任」会带中文释义）。
- **应用类「进入」按钮**：应用 Tab 下的卡片底栏右侧有「进入」按钮——上架后可直接点击跳转到对应页面，无需先去侧栏找入口；未上架、切换中或无路由时按钮禁用。
- **未信任插件主题跟随**：运行在隔离 iframe 中的**未信任**模块会**实时跟随主站主题与强调色**——切换「设置 → 强调色」或深浅主题后，iframe 内按钮、链接、边框颜色同步变化；暗色态下描边按钮边框不再消失。
- **插件页切换不闪白底**：暗色主题下进入或切换**未信任插件**页面时，容器会先铺上主站主题背景色，插件内部就绪后再无缝衔接，不再出现握手阶段短暂的白底闪烁。

### 17.6 主题与侧抽屉的浅色体验

- **深浅主题切换**：在「设置 → 外观」中可切换浅色与深色主题，并为强调色挑选不同色板；选中后全站卡片、弹窗、侧抽屉、按钮等会自动跟随。
- **侧抽屉边界**：从右、左、上、下任一方向滑出的侧边抽屉（Sheet），在浅色主题下四周都会有一条**柔和的墨色描边**，不会像纯白块「浮」在白底上；深色主题保持既有观感。
- **卡片/弹窗边缘**：插件中心、知识库列表、书架等处的卡片边缘、淡底背景在浅色下都有**淡淡的墨色轮廓**，不再「浮空」。
- **正文可读性**：浅色主题下的正文说明、标题、描述文本均使用深色墨色，不会出现白字白底看不清的情况。
- **Hero 渐变字保持原效果**：首页舞台顶部的渐变标题在浅色主题下仍是白色渐变文字，与墨色正文 token 互不干扰。
