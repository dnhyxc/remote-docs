## 2. 账号与访问控制

- **路由级登录守卫**（更新：2026-04-05）：未登录时，访问受保护页面会被引导到登录页；公开页面不受影响。
- **鉴权失效收敛**（更新：2026-04-05）：接口返回 401（未授权）时统一清理会话并触发重新登录，避免“看似已登录但实际已过期”的状态漂移。
- **公开访问路径策略**（更新：2026-05-14）：未登录仍可访问首页、登录、关于、分享链接、**知识库**（默认仅本地模式，见 **§6**）、系统设置及其子路径、桌面端下载说明页、产品指南、用户服务政策、用户服务协议、结构化更新说明等；智能对话等需登录的主流程仍由守卫拦截；独立公开页与 **§21、§22** 所列路由一致。
- **头像与聊天附件迁至腾讯云 COS**（更新：2026-05-26）：账户头像与智能对话中的聊天附件均改由服务端上传至腾讯云对象存储，不再使用七牛前端直传或应用服务器本地目录。上传成功后保存完整对象地址；Web 端通过同源 **`/ext-cos/`** 代理展示，避免混合内容拦截；大图预览与附件下载已适配，并在成功或失败时给出提示。部署需在服务端配置 COS 密钥与桶信息，并保证对象可被正常读取（推荐公有读或等价策略）。
- **Stripe 会员充值（三档套餐）**（更新：2026-06-08）：登录后可在 **`/pay`** 选择**月度（¥9.9）/ 季度（¥25.9）/ 年度（¥99.9）** 固定套餐，价格在页面内**不可自行修改**；通过 Stripe 嵌入式收银台完成支付。支付成功后会开通或续期会员（在原有到期日上叠加时长），并自动进入 **`/profile` 个人主页** 查看会员徽章与有效期。会员到期后登录或访问资料时会自动校正为非会员；资料页对非会员展示开通引导文案。
- **会员开通幂等修复**（更新：2026-06-08）：修复同一笔 Stripe 支付因 Webhook 与支付完成回调并发而**重复叠加会员时长**的问题（例如月度套餐到期日多显示约一个月）。新支付不再重复加时；若历史账号已多算，需联系运维在后台校正到期日。
- **登录后立即被踢出修复**（更新：2026-06-08）：修复「云端朗读参数账号同步」上线后，部分账号**登录成功瞬间又被判未登录、跳回登录页**的问题（后台同步朗读偏好时凭证尚未就绪）。现已调整登录顺序与会员预拉取策略，线上可正常保持登录态。
- **切换账号时清空本地缓存**（更新：2026-06-08，**2026-06-17 补充**）：在同一浏览器内**登出、换号登录**或会话**401 失效**时，会自动清空与上一账号相关的前端展示缓存，包括知识库**未保存草稿**、文档**助手 / RAG 对话**、**英语学习 Agent** 聊天与进行中的单词包/经典句进度、**电子书书架列表与 MOKE 阅读助手**等，避免误看到他人内容。同一账号仅更新资料或会员状态（用户 id 不变）时不会清空。
- **个人主页会员标识优化**（更新：2026-06-08）：**`/profile` 个人主页**上，有效会员的「会员」徽章与「会员有效期至 …」文案改为**高对比金色**展示，深色背景下更易识别；会员状态判定逻辑在前端统一维护，与大模型设置页的会员默认策略保持一致。

- **微信小程序登录与账号关联**（更新：2026-07-09）：新增微信小程序一键登录能力，使用微信即可快速注册登录，无需手动输入账号密码；同时支持与已有 Web 账号绑定——在 Web 端账号设置页生成 6 位关联码，在小程序中输入即可完成绑定，两边的书架、阅读进度、划线、想法等数据完全互通；已绑定的账号可随时在 Web 端解除绑定，解绑后微信登录的会话会立即失效。
- **登出统一与多窗口主题同步**（更新：2026-08-01）：登出操作现在从侧边栏菜单、文件菜单与鉴权失效（401）三个入口均走同一套清理流程，无论从哪里登出，本地缓存、会话状态与界面都会一致地回到未登录态，不再出现「从菜单登出后仍有残留状态」的情况。切换主题配色时，所有已打开的桌面子窗口（如关于窗口等）会同步更新配色，不再出现子窗口主题与主窗口不一致的问题。
- **测试账号预填与保护**（更新：2026-09-04）：新增在线演示用测试账号——访问首页时带指定参数即可在登录页自动预填用户名和密码（密码以掩码显示，审查元素不泄露真密码），一键登录体验完整功能。测试账号登录后**禁止修改个人资料、购买会员、重置密码、绑定/解绑微信**，个人资料页的邮箱也会做中间脱敏显示，防止演示账号被篡改。未配置环境变量时该功能不影响普通用户。
- **个人主页路由统一**（更新：2026-09-04）：**个人资料**、**账号设置**、**会员充值**三个页面现已统一收口到 `/profile/*` 路径下——从个人主页可直接进入资料编辑或会员充值，无需跳到独立页面。此前收藏的 `/account`、`/pay` 旧链接会自动跳转到新路径，不影响使用。
- **支付页布局优化**（更新：2026-09-04）：**会员充值页**适配新的个人主页路由壳层，内容超出时可在页面内滚动，不再溢出或被遮挡；移除了顶部冗余标题与徽标，文案更简洁（如「开启支付」代替「在页面内打开收银台」），整体视觉更清爽。
- **文档页迁移到独立站**（更新：2026-09-08）：「更新说明」「产品指南」「插件开发手册」三个页面从应用内独立页迁移到**独立文档站**——点击后会在系统浏览器或新标签页打开，不再占用应用内页面。打开时会自动带上当前的语言、深浅主题和强调色，视觉与应用内保持一致；文档内容的更新也不再依赖应用发版，可随时独立更新。

## 3. 桌面端与浏览器双端体验

- **同一套前端双端运行**（更新：2026-04-13）：桌面端（Tauri，桌面壳）与独立浏览器均可运行同一套前端应用。
- **能力降级与提示**（更新：2026-04-13）：在浏览器环境中，目录选择、开机自启、全局快捷键等仅桌面端能力会自动降级为提示，不会导致页面崩溃或白屏。
- **外链打开策略统一**（更新：2026-04-13）：外链打开行为在不同运行环境下保持一致与安全（避免不必要的权限与上下文泄露）。
- **macOS 生产包允许特定 HTTP 域名访问**（更新：2026-04-23）：通过 Info.plist 的 ATS（App Transport Security，应用传输安全）配置放行指定 `http` 域名，保证生产环境可正常访问该域名资源。
- **Tauri / 浏览器双端一致性**（更新：2026-05-02）：注意入口初始化顺序、能力降级与外链策略，避免在纯浏览器环境因桌面专用 API 误用导致白屏或异常。
- **桌面端网络请求自动重试**（更新：2026-07-02）：**Tauri 桌面端**访问远程接口时，若出现瞬时「未收到响应」类网络失败（不限于列表加载），会自动短暂重试后再提示，减少误报「网络异常，请检查网络后重试」；**浏览器**行为不变。
- **动态远程功能模块**（更新：2026-07-20）：主站支持按清单在运行时加载独立部署的功能模块（与主站共享界面框架）。加载失败时页面会稳定提示并可手动重试，不会反复闪烁；部分演示入口会出现在侧栏（视清单配置而定）。
- **插件中心与上架/下架**（更新：2026-07-22，**2026-08-11 补充**）：新增 **插件中心** 页面，以卡片展示所有可用功能模块，每张卡片带 **开关**，点击即可 **上架（启用）** 或 **下架（停用）** 对应模块，状态会持久化到账号并即时生效——上架后侧栏出现入口、可进入使用，下架后入口消失、已打开的页面会卸载。另提供 **注册表编辑页**（需登录），可直接查看与编辑模块清单原文（JSON），保存后自动重新加载。补充：注册表编辑页可在标题栏 **设置项目图标**——为指定模块 **上传 SVG**，成功后自动写入该模块的侧栏/触发器图标字段；自定义图标会跟主站选中色与悬停画线动画对齐（单色稿），换图标不必改主站代码。
- **插件界面跟随主站语言**（更新：2026-07-22，**2026-07-27 补充**）：功能模块（含学习笔记、想法列表等远程插件）的界面文案现在会 **跟随主站界面语言** 自动切换中英文；切换语言后插件即时更新，无需重新加载。独立预览模式下也可手动切换语言。补充：**插件中心卡片标题与描述、顶栏面包屑** 也改为从插件自带的多语言清单中解析，不再依赖主站内置文案；新增或改名插件只改清单即可，不必同步改主站词典。
- **桌面端插件更新更可靠**（更新：2026-07-29）：发布新版功能模块后，桌面端会根据模块入口清单文件的内容变化自动拉最新代码，无需为刷新缓存去改平台侧模块清单；模块清单本身也禁止被长时间缓存。若仍看到旧版，请更新到最新桌面应用后再试。
- **插件中心白屏修复**（更新：2026-07-29）：修复部分线上环境进入 **插件中心** 时因路由上下文异常导致白屏的问题。
- **注册表编辑更安全**（更新：2026-07-29）：注册表页提供字段说明入口；保存前会检查模块清单中的 Host 接口兼容范围，避免误改导致模块无法加载。支持 **⌘/Ctrl+S** 保存；有未保存修改时保存按钮显示橙点提示。
- **插件开关偏好按账号持久化与跨端同步**（更新：2026-07-31）：在插件中心开启或关闭功能模块后，偏好会按当前登录账号保存到服务端，而不是只保存在本机浏览器——**换设备登录、切换 Web 与桌面端，或同一设备登出再登录**后都能看到一致的开关状态；未登录或无偏好时默认**全部关闭**，避免新账号一上来出现陌生入口。切换账号时侧栏入口会自动按新账号的偏好重新挂载或移除，不需要手动刷新页面；旧版本地存储的开关记录会在你首次登录时一次性迁移到账号下，无需重配。同时插件中心页面加载失败会显示更具体的错误原因（网络 / 权限 / 清单格式错误等），便于你先排查环境再联系维护者。
- **多卡片 Switch 点 Label 修复**（更新：2026-07-31）：修复插件中心等页面里，有多张卡片同时出现开关和说明文字时，点击其中一张卡片右侧的说明文字，经常会**串到第一张卡片的开关**上（该开的没开、不该关的被关）。现在点击某张卡片的文字会只切换同一张卡片对应的开关；给页面内的开关指定了稳定的唯一身份，同屏即使有几十个开关也不会互相串。
- **macOS 窗口缩放零露白**（更新：2026-08-01）：修复 macOS 桌面端双击标题栏或点击绿色按钮缩放窗口时，页面内容来不及跟随窗口尺寸变化而出现**白色闪烁**的问题。现在缩放过程中页面会先按目标尺寸布局好再揭开，过渡更顺滑，不再出现壳已变大但内容仍停留在旧尺寸的「露白」现象。
- **系统菜单与快捷键体系**（更新：2026-08-01）：macOS 桌面端菜单栏现在有完整的**文件、编辑**等系统菜单，菜单项支持中英文、使用统一的系统图标（SF Symbols）；在设置中改完快捷键后，菜单栏中的加速键会**即时更新**，无需重启应用。全局快捷键在窗口失焦时自动释放（仅保留「显示/隐藏应用」一项），避免抢占其它应用的快捷键；页面内快捷键与全局快捷键统一管理，冲突时录制阶段即提示。
- **视频播放器插件**（更新：2026-08-08）：新增独立的**视频播放器**功能模块，可在插件中心开启后从侧栏进入，上传本地视频文件后即可播放；支持多文件选集、自定义控制条（进度、音量、倍速、画中画、全屏、镜像）、0.5X–3.0X 倍速、键盘方向键微调、播放方式（自动/循环/停止）等完整交互；组件卸载时会自动清理播放器、退出影院态，避免离开页面后主站卡住。本轮对播放器做了组件化重构：播放器本体、上传、弹出提示、分段选择、音量等已拆成通用组件，未来其它业务可直接复用；暗色模式下的倍速面板、刻度标签也换成了主题语义色，不再出现白字白底看不见的问题；播放器的气泡提示（tooltip）在独立预览模式和主站插件模式下都能正常显示。
- **视频播放器体验增强**（更新：2026-08-08，**2026-08-09 补充**）：播放器在组件化基础上进一步增强了交互体验：**进度条缩略图预览**——鼠标悬停进度条任意位置会弹出视频帧缩略图，帮助快速定位片段，边缘位置自动避让不溢出；**多平台画中画**——画中画功能现已支持 Safari（macOS / iOS）等浏览器，进入画中画后主播放器位置会显示覆盖层提示文案，画中画内的播放/暂停操作也能正确同步回主播放器；**播放器语言跟随主站**——切换界面语言后，播放器内部提示（如缓冲进度）会自动切换为对应语言；**重置更彻底**——点击「重置」后会完全清理预览、进度条、hover 状态和播放器实例，不会残留画中画覆盖层；**长视频刻度优化**——10 分钟以上的视频刻度节点数量有上限，避免鼠标悬停进度条时出现卡顿；**拖拽松手不再右抖**——拖拽进度条松手后，播放器会在 seek 完成前短暂保持拖拽位置，不再出现瞬间从拖拽像素跳回当前播放位置的「右抖」现象，副条（miniTimeline）也能跟随拖拽实时刷新；**循环单条可重播**——播放列表只有一条视频时，开启循环模式后现在会在本条视频末尾原地重播，不再无动作；**播放器背景跟随主题**——非影院态下播放器底色改为跟随当前主题背景（包括用户自定义的强调色），切换主题时播放器本体不再保持 xgplayer 自带的纯黑；**控制条毛玻璃更跟手**——控制条显隐改用 `visible` 切换，不再因父级 `opacity` 建立合成层导致 `backdrop-filter`（毛玻璃）采样慢一拍。
