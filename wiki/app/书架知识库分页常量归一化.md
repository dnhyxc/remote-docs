# 书架与知识库分页常量归一化

## 1. 背景与目标

**要解决的问题**：前端分页量「每页 20 条」存在多处重复定义：

1. 电子书 Store 中使用从 `@/constants` 导入的 `EBOOK_SHELF_PAGE_SIZE`。
2. 知识库 Store 内部自己定义了同名局部 `const DEFAULT_PAGE_SIZE = 20`，并额外定义了 `const SCROLL_LOAD_THRESHOLD_PX = 72`。

这样既造成「改一处另一处不同步」的维护风险，也与知识库已有「列表与回收站同一分页量级」的产品意图不一致（两者其实应走**同一**全局默认分页值）。

**目标**：

- 把知识库 Store 私有常量迁移到 `apps/frontend/src/constants/index.ts`，与书架统一引用。
- 将 `EBOOK_SHELF_PAGE_SIZE` 改名为更通用的 `DEFAULT_PAGE_SIZE`，从命名上表达其「通用默认分页」的语义。
- 电子书与知识库两处都改为从 `@/constants` 引入同一个常量。

延伸阅读：
- [知识库公开文档Tab筛选.md](../knowledge/知识库公开文档Tab筛选.md)
- [书架全部标签统一分页.md](../ebook/书架全部标签统一分页.md)

## 2. 改动范围

| 模块 | 路径 |
| ---- | ---- |
| 全局常量 | `apps/frontend/src/constants/index.ts` |
| 电子书 Store | `apps/frontend/src/store/ebook.ts` |
| 知识库 Store | `apps/frontend/src/store/knowledge.ts` |

---

## 3. 实现思路

1. **常量归属地归一**：统一在 `apps/frontend/src/constants/index.ts` 提供一个通用的 `DEFAULT_PAGE_SIZE = 20`，并保留同样是横切能力的 `SCROLL_LOAD_THRESHOLD_PX`。
2. **老名字不再保留**：删除 `EBOOK_SHELF_PAGE_SIZE`，避免后续同事误用旧名；调用侧同步改为 `DEFAULT_PAGE_SIZE`。
3. **知识库 Store 删除本地重复**：移除 `knowledge.ts` 顶部私有 `DEFAULT_PAGE_SIZE` 与 `SCROLL_LOAD_THRESHOLD_PX`，从 `@/constants` 统一引入，保证与电子书等模块取值同源。
4. **不调值，只调名与出处**：数值保持 20 / 72 不变，避免分页行为变化；仅做「出处收敛 + 命名归一」。

## 5. 兼容性与影响

- **运行时值未变**：`DEFAULT_PAGE_SIZE` 仍为 `20`，`SCROLL_LOAD_THRESHOLD_PX` 仍为 `72`，书架与知识库列表的首屏数量与滚动加载体验都不变，**纯重构、无行为差异**。
- **编译期出口收窄**：任何旧代码若还 `import { EBOOK_SHELF_PAGE_SIZE } from '@/constants'` 会在 TS 编译期直接报错，可被一次性检索修复；本轮已同步所有使用点。
- **后续扩展**：如后续新增「英语文库、学习笔记列表」等横切列表分页，可直接复用 `DEFAULT_PAGE_SIZE`，不再各自为政。
- **回归建议**：检查电子书书架与知识库列表的首屏数量、滚动加载更多、切 Tab 重新加载等分页行为，确认仍按预期触发（不会出现数量突增/突减）。
