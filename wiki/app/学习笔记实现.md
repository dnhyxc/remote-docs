# 学习笔记实现

> **延伸阅读**：[富文本编辑器特性.md](../ui/富文本编辑器特性.md)（富文本编辑器功能实现）、[视频播放器组件重构.md](../video/视频播放器组件重构.md)（视频播放器组件化重构）

## 1. 背景与目标

学习笔记插件需要完整的笔记管理能力，包括笔记的创建、编辑、预览、删除、导出等。此前项目中已有基础的笔记 CRUD，但存在以下问题：

- **状态管理分散**：笔记列表、编辑态、预览态等状态分散在各组件中，难以维护。
- **分页缺失**：笔记列表不支持分页加载，大量笔记时性能差。
- **导出功能缺失**：无法将笔记导出为 DOCX 文件。
- **可见性管理缺失**：不支持笔记的公开/私密状态管理。
- **API 层耦合**：HTTP 调用直接写在组件中，难以测试和维护。

本轮基于 **MobX** 构建了集中式的 `LearningNotesStore`，实现了完整的笔记管理能力，包括分页列表、CRUD、预览、导出 DOCX、公开状态管理等。

## 3. 实现思路

### 3.1 架构分层

学习笔记模块按职责拆成以下层次：

1. **API 层** (`api.ts`)：基于 `HostHttp` 工厂函数创建笔记 CRUD 接口，与后端 `/english-learning/notes/*` 对接。
2. **Store 层** (`learningNotes.ts`)：MobX Store 集中管理列表、编辑、预览、导出等状态。
3. **组件层** (views/learning-notes/)：UI 组件通过 `observer` 包裹，订阅 Store 状态变化。
4. **通用组件层** (components/design/)：`NotePreview` 等通用 UI 组件。

### 3.2 MobX Store 设计

`LearningNotesStore` 采用单例模式（`export default new LearningNotesStore()`），所有状态变更通过 `makeAutoObservable` 自动追踪：

- **列表状态**：`list`、`total`、`pageNo`、`loading`、`refreshing`、`loadingMore`
- **视图状态**：`listOpen`（列表面板开关）、`preview`（当前预览笔记）、`editingId`（编辑中的笔记 ID）
- **编辑器状态**：`editorSeed`（用于强制重新挂载编辑器）、`editorInitial`（初始内容）
- **对话框状态**：`confirmOpen`（删除确认）、`visibilityConfirmOpen`（公开状态确认）
- **操作状态**：`saving`、`exportingDocx`

### 3.3 Host API 注入

Store 通过 `bind()` 方法注入 Host 端的 API 依赖：

- `http`：Host HTTP 客户端（提供 `get`/`post`/`put`/`delete` 方法）
- `toast`：Toast 提示函数
- `t`：翻译函数（`translateSync`）
- `downloadBlob`：文件下载函数（Web / Tauri 双端适配）

这种设计使得 Store 可以独立于 Host 运行（Mock 模式），也可以在 Host 挂载时动态绑定。

### 3.4 分页与列表加载

采用**累积分页**模式：

- **首次加载**：`fetchPage(1, false)` 替换整个列表
- **加载更多**：`fetchPage(pageNo + 1, true)` 追加到现有列表
- **刷新**：`refreshList()` 调用 `fetchPage(1, false)` 替换
- **去重**：追加时通过 `Set` 过滤已存在的笔记 ID
- **状态保护**：`loading`/`refreshing`/`loadingMore` 状态互斥，避免并发请求

### 3.5 预览与编辑切换

- **打开预览**：`openPreview(id)` 先立即进入预览壳（显示标题和 loading），再异步拉取详情
- **打开编辑**：`openEdit(note)` 清除预览态，设置 `editingId` 和 `editorInitial`
- **新建笔记**：`openNew()` 清除预览和编辑态，`editorInitial` 设为 `EMPTY_NOTE_DOC`
- **编辑器重新挂载**：通过 `editorSeed` 递增触发 React key 变化，强制卸载旧编辑器并挂载新实例

### 3.6 保存逻辑

`saveNote()` 方法处理保存流程：

1. **校验**：检查 `dirty` 标记、标题非空、正文非空
2. **区分新建/更新**：有 `editingId` 时调用 `api.update()`，否则调用 `api.save()`
3. **成功后刷新列表**：`refreshList()` 更新列表数据
4. **Toast 提示**：根据操作类型显示「已保存」/「已更新」

### 3.7 DOCX 导出

`exportPreviewDocx()` 实现笔记导出为 Word 文档：

1. **获取当前预览笔记**：从 `this.preview` 取 ID
2. **调用服务端导出 API**：`api.exportDocx(id)` 获取 ArrayBuffer
3. **安全文件名**：清理标题中的非法字符，限制长度 60
4. **调用 Host downloadBlob**：双端适配（Web 直接下载，Tauri 通过原生落盘）
5. **Toast 反馈**：成功/失败提示，尊重 Host 是否已 Toast（`hostToasted` 标记）

### 3.8 公开/私密状态管理

- **请求变更**：`requestVisibility(id, isPublic)` 设置 `pendingVisibility` 并打开确认对话框
- **确认变更**：`confirmVisibility()` 调用 `api.setVisibility()` 更新状态，成功后同步列表和预览中的 `isPublic`/`isOwned` 字段
- **取消变更**：关闭对话框时自动清空 `pendingVisibility`

### 3.9 API 层设计

`createNotesApi()` 工厂函数基于 `HostHttp` 创建类型安全的 API 对象：

- **list**：分页获取笔记列表
- **detail**：获取单篇笔记详情
- **save**：新建笔记
- **update**：更新笔记
- **remove**：删除笔记
- **setVisibility**：设置公开状态
- **exportDocx**：导出 DOCX（服务端生成）

所有 API 方法都通过 `unwrapData()` 处理统一响应格式（`{ data: ... }` 或直接返回数据）。

### 4.3 `fetchPage` 分页加载（`apps/micro/src/store/learningNotes.ts`）

**对比范围**：`fetchPage(page, append)` 方法定义。

**改动后** · `apps/micro/src/store/learningNotes.ts`（当前，约 L112–L162）

```typescript
// 分页获取笔记列表
async fetchPage(page: number, append: boolean): Promise<void> {
        // API 不可用时提示并返回
        if (!this.api) {
                this.toast(this.t('learningNotes.toast.httpDeniedSync'), 'error');
                return;
        }
        // 状态互斥：已有请求在进行中则跳过
        if (this.loading || this.refreshing) return;
        if (append) {
                // 追加模式：检查是否正在加载更多或已无更多
                if (this.loadingMore || !this.hasMore) return;
                this.loadingMore = true;
        } else if (this.list.length > 0) {
                // 非首次加载：标记为刷新（不卸列表）
                this.refreshing = true;
        } else {
                // 首次加载
                this.loading = true;
        }
        try {
                // 调用 API 获取分页数据
                const data = await this.api.list(page, this.pageSize);
                runInAction(() => {
                        // 关闭列表后丢弃迟到回包
                        if (!this.listOpen) return;
                        this.total = data.total;
                        this.pageNo = page;
                        if (append) {
                                // 追加模式：按 ID 去重
                                const seen = new Set(this.list.map((n) => n.id));
                                this.list = [
                                        ...this.list,
                                        ...data.list.filter((n) => !seen.has(n.id)),
                                ];
                        } else {
                                // 替换模式：直接覆盖
                                this.list = data.list;
                        }
                });
        } catch {
                // Host http 已 Toast，不再重复提示
        } finally {
                runInAction(() => {
                        // 清除所有加载状态
                        this.loading = false;
                        this.loadingMore = false;
                        this.refreshing = false;
                });
        }
}
```

**变更摘要**：`fetchPage` 实现了累积分页加载，支持首次加载、刷新、加载更多三种模式。状态互斥防止并发请求，追加模式通过 ID 去重避免重复，关闭列表后丢弃迟到回包防止数据污染。

**改动后** · `apps/micro/src/store/learningNotes.ts`（当前，约 L185–L220）

```typescript
// 打开预览（先进入预览壳，再异步拉详情）
async openPreview(id: string): Promise<void> {
        if (!this.api) return;
        // 在列表中查找已有数据（乐观更新）
        const listHit = this.list.find((n) => n.id === id);
        // 立刻进入预览壳：卸掉编辑器，避免双实例并存
        runInAction(() => {
                this.loadingDetail = true;
                this.preview = {
                        id,
                        // 优先使用列表中的数据，其次用当前 preview 的数据
                        title: listHit?.title ?? this.preview?.title ?? '',
                        html: this.preview?.id === id ? this.preview.html : '',
                        at: listHit?.at ?? this.preview?.at ?? Date.now(),
                        author: listHit?.author ?? (this.preview?.id === id ? this.preview.author : ''),
                        isPublic: listHit?.isPublic ?? (this.preview?.id === id ? this.preview.isPublic : false),
                        isOwned: listHit?.isOwned ?? (this.preview?.id === id ? this.preview.isOwned : true),
                };
        });
        try {
                // 异步拉取完整详情
                const note = await this.api.detail(id);
                runInAction(() => {
                        // 慢网下用户可能已点开另一篇
                        if (this.preview?.id === id) this.preview = note;
                });
        } catch {
                // Host http 已 Toast（如「笔记不存在」）
                runInAction(() => {
                        // 失败且无内容时清除预览
                        if (this.preview?.id === id && !this.preview.html) {
                                this.preview = null;
                        }
                });
        } finally {
                runInAction(() => {
                        this.loadingDetail = false;
                });
        }
}
```

**变更摘要**：`openPreview` 采用「乐观更新 + 异步拉详情」模式，先立即展示标题和 loading 状态，再异步获取完整内容。慢网下用户切换到其他笔记时，回包不会覆盖新选择。失败时清除预览避免残留空壳。

```typescript
// 保存笔记（新建或更新）
async saveNote(input: {
        title: string;   // 笔记标题
        html: string;    // 笔记 HTML 内容
        text: string;    // 纯文本内容（用于空值校验）
        dirty: boolean;  // 是否有未保存修改
}): Promise<boolean> {
        // 无修改时提示并返回
        if (!input.dirty) {
                this.toast(this.t('learningNotes.toast.noSave'), 'info');
                return false;
        }
        // 标题为空时提示
        if (!input.title.trim()) {
                this.toast(this.t('learningNotes.toast.needTitle'), 'info');
                return false;
        }
        // 正文为空时提示
        if (!input.text.trim()) {
                this.toast(this.t('learningNotes.toast.needContent'), 'info');
                return false;
        }
        // API 不可用时提示
        if (!this.api) {
                this.toast(this.t('learningNotes.toast.httpDeniedSave'), 'error');
                return false;
        }
        this.saving = true;
        try {
                // 构造保存 payload
                const payload = {
                        title: input.title.trim() || this.t('common.untitledNote'),
                        html: input.html,
                };
                if (this.editingId) {
                        // 更新已有笔记
                        const updated = await this.api.update(this.editingId, payload);
                        runInAction(() => {
                                this.editingId = updated.id;
                        });
                        this.toast(this.t('learningNotes.toast.updated'), 'success');
                } else {
                        // 新建笔记
                        const { id } = await this.api.save(payload);
                        runInAction(() => {
                                this.editingId = id;
                        });
                        this.toast(this.t('learningNotes.toast.saved'), 'success');
                }
                // 保存成功后刷新列表
                await this.refreshList();
                return true;
        } catch {
                // Host http 已 Toast
                return false;
        } finally {
                runInAction(() => {
                        this.saving = false;
                });
        }
}
```

**变更摘要**：`saveNote` 实现了完整的保存校验流程（dirty 检查 → 非空校验 → API 调用 → 列表刷新），区分新建和更新操作，Toast 提示操作结果。所有错误路径都有相应的用户提示。

### 4.6 `exportPreviewDocx` DOCX 导出（`apps/micro/src/store/learningNotes.ts`）

**对比范围**：`exportPreviewDocx()` 方法定义。

**改动后** · `apps/micro/src/store/learningNotes.ts`（当前，约 L335–L388）

```typescript
// 导出当前预览笔记为 DOCX
async exportPreviewDocx(): Promise<void> {
        const note = this.preview;
        // 无预览笔记时提示
        if (!note?.id) {
                this.toast(this.t('learningNotes.toast.exportEmpty'), 'info');
                return;
        }
        // API 不可用时提示
        if (!this.api) {
                this.toast(this.t('learningNotes.toast.httpDeniedExport'), 'error');
                return;
        }
        // 无下载能力时提示
        if (!this.downloadBlob) {
                this.toast(this.t('learningNotes.toast.exportNoDownload'), 'error');
                return;
        }
        // 防止重复点击
        if (this.exportingDocx) return;
        this.exportingDocx = true;
        try {
                // 调用服务端导出接口，获取 DOCX 二进制
                const buf = await this.api.exportDocx(note.id);
                // 清理文件名：移除非法字符，限制长度
                const safe =
                        note.title
                                .replace(/[\\/:*?"<>|]+/g, '_')
                                .trim()
                                .slice(0, 60) || 'learning-note';
                // 调用 Host downloadBlob 落盘
                const result = await this.downloadBlob({
                        fileName: `${safe}-${Date.now()}.docx`,
                        data: buf,
                        mimeType: DOCX_MIME,  // 'application/vnd.openxmlformats-officedocument.wordprocessingml.document'
                });
                if (!result.ok) {
                        // 下载失败且 Host 未 Toast 时才提示
                        if (!result.hostToasted) {
                                this.toast(
                                        result.message || this.t('learningNotes.toast.exportFail'),
                                        'error',
                                );
                        }
                        return;
                }
                // 下载成功：Tauri 已 Toast，Web 端需要提示
                if (!result.hostToasted) {
                        this.toast(this.t('learningNotes.toast.exportOk'), 'success');
                }
        } catch (e) {
                // 接口错误 Host 已 Toast；仅本地校验错误再提示
                toastUnlessHostHttp(this.toast, e, this.t);
        } finally {
                runInAction(() => {
                        this.exportingDocx = false;
                });
        }
}
```

**变更摘要**：`exportPreviewDocx` 实现了从服务端生成 DOCX 到客户端落盘的完整流程。关键设计点：`exportingDocx` 状态防止重复点击；`hostToasted` 标记避免 Toast 重复（Tauri 原生下载已提示，Web 端需要手动提示）；文件名安全化处理防止路径注入。

```typescript
// 基于 HostHttp 创建笔记 API
export function createNotesApi(http: HostHttp) {
        return {
                // 分页获取列表
                async list(pageNo = 1, pageSize = NOTES_PAGE_SIZE): Promise<NoteListPage> {
                        const res = await http.get(
                                `${BASE}/list?pageNo=${pageNo}&pageSize=${pageSize}`,
                        );
                        const page = unwrapData<{ list: NoteListItem[]; total: number }>(res);
                        const rows = Array.isArray(page?.list) ? page.list : [];
                        return {
                                list: rows.map(toNote),    // 转换为 Note 类型
                                total: typeof page?.total === 'number' ? page.total : rows.length,
                                pageNo,
                                pageSize,
                        };
                },

                // 获取详情
                async detail(id: string): Promise<Note> {
                        const res = await http.get(`${BASE}/detail/${id}`);
                        return toNote(unwrapData<NoteRecord>(res));
                },

                // 导出 DOCX（服务端生成）
                async exportDocx(id: string): Promise<ArrayBuffer> {
                        const res = await http.get(`${BASE}/export-docx/${id}`);
                        const data = unwrapData<unknown>(res);
                        if (data instanceof ArrayBuffer) return data;
                        if (ArrayBuffer.isView(data)) {
                                const v = data as ArrayBufferView;
                                return v.buffer.slice(
                                        v.byteOffset,
                                        v.byteOffset + v.byteLength,
                                ) as ArrayBuffer;
                        }
                        throw new Error(translateSync('learningNotes.toast.exportInvalid'));
                },

                // 新建笔记
                async save(input: { title: string; html: string }): Promise<{ id: string }> {
                        const res = await http.post(`${BASE}/save`, {
                                title: input.title.trim() || null,
                                content: input.html,
                        });
                        return unwrapData<{ id: string }>(res);
                },

                // 更新笔记
                async update(
                        id: string,
                        input: { title: string; html: string },
                ): Promise<Note> {
                        const res = await http.put(`${BASE}/update/${id}`, {
                                id,
                                title: input.title.trim() || null,
                                content: input.html,
                        });
                        return toNote(unwrapData<NoteRecord>(res));
                },

                // 删除笔记
                async remove(id: string): Promise<void> {
                        await http.delete(`${BASE}/delete/${id}`);
                },

                // 设置公开状态
                async setVisibility(id: string, isPublic: boolean): Promise<Note> {
                        const res = await http.put(`${BASE}/visibility/${id}`, { isPublic });
                        return toNote(unwrapData<NoteListItem>(res));
                },
        };
}
```

**变更摘要**：`createNotesApi` 工厂函数基于 `HostHttp` 创建类型安全的 API 对象，与后端 `/english-learning/notes/*` 对接。`unwrapData` 处理统一响应格式（`{ data: ... }` 或直接返回），`toNote` 转换后端数据为前端 `Note` 类型。
