# 拦截拖放文件导航：阻止 WKWebView 顶掉 SPA

> **文档角色**：`dragDropEnabled: false` 下 WKWebView 会把拖入的文件当导航打开（顶掉 SPA），通过 Rust 导航拦截 + 前端 `preventDefault` 双层修复
> **延伸阅读**：[macOS拖拽选择器崩溃.md](../tauri/macOS拖拽选择器崩溃.md)（拖拽闪退修复）；[统一文件选择.md](../app/统一文件选择.md)（通用文件选择）

## 1. 背景与目标

**复现路径**（需求 `demand.md`）：
1. 用户将视频、HTML 文件、图片、Markdown 等文件直接拖入 Tauri 应用窗口
2. WKWebView 把拖入的文件当作导航请求（`file://` URL），直接在窗口中渲染图片 / 播放视频 / 渲染 HTML
3. 前端 SPA 被顶掉，应用变成一个文件查看器

**根因**：
- `tauri.conf.json` 中 `dragDropEnabled: false`（让 HTML5 drag 事件传到页面，由前端 drop 区处理）
- 但 macOS WKWebView 在 `dragDropEnabled: false` 时，如果页面没有 `preventDefault` 拦截 `drop` 事件，会把文件 URL 作为导航请求加载
- 页面的 drop 区（`DragDropFileUpload`）只在自身范围内 `preventDefault`；拖到 drop 区外面时 WKWebView 直接导航

**目标**：双层拦截，彻底阻止文件拖入导致的导航：
1. **Rust 层**：注册 `block_file_drop_navigation` 插件，在 `on_navigation` 回调中拦截 `file://` scheme
2. **前端层**：`main.tsx` 在 `window` 级别注册 `dragover` / `drop` 监听器，对 `Files` 类型 `preventDefault`

## 3. 实现思路

| # | 要点 | 说明 |
|---|------|------|
| 1 | Rust `on_navigation` 拦截 | `PluginBuilder::new("block-file-drop-nav").on_navigation(\|_webview, url\| url.scheme() != "file")` — `file://` 返回 `false` 阻止导航 |
| 2 | 前端 `preventDefault` | `window.addEventListener('dragover', handler)` + `window.addEventListener('drop', handler)` — 对 `Files` 类型 `preventDefault`，阻止 WKWebView 默认导航行为 |
| 3 | 双层冗余 | Rust 层拦截 `file://` 导航 + 前端层 `preventDefault` 拦截事件——任一层生效即可阻止 |
| 4 | 不影响 HTML5 拖放 | `preventDefault` 仅拦截 `drop` 的默认行为（导航），不影响 `dataTransfer.files` 的读取——页面 drop 区仍可正常获取文件 |
| 5 | 仅 Tauri 运行时 | `isTauriRuntime()` 检查——Web 端不需要此逻辑（浏览器本身不会导航到拖入的文件） |

**改动后** · `apps/frontend/src-tauri/src/plugin/init.rs`（当前，约 L1–L21）

```rust
// 旧版 import 保留
use tauri::Runtime;
// 新增 import：PluginBuilder 和 TauriPlugin 用于构造导航拦截插件
use tauri::plugin::{Builder as PluginBuilder, TauriPlugin};

use crate::system::shortcut::handle_shortcut;

// 新增 doc comment：说明为何需要此插件
/// `dragDropEnabled: false` 时 WKWebView 会把落盘文件当导航打开（顶掉 SPA）。
/// 拦截 `file://`，拖放仍走 HTML5，由页面自己的 drop 区处理。
// 新增函数：构造一个拦截 file:// 导航的 Tauri 插件
fn block_file_drop_navigation<R: Runtime>() -> TauriPlugin<R> {
    // 插件名（仅用于内部标识）
    PluginBuilder::new("block-file-drop-nav")
        // 导航回调：url.scheme() == "file" 时返回 false（阻止导航）
        .on_navigation(|_webview, url| url.scheme() != "file")
        // 构建插件
        .build()
}

// trait 定义（未改动）
pub trait CustomInit {
    fn init_plugin(self) -> Self;
}

// impl（新增注册行）
impl<R: Runtime> CustomInit for tauri::Builder<R> {
    fn init_plugin(self) -> Self {
        let builder = self
            // 新增：注册导航拦截插件（排在第一个）
            .plugin(block_file_drop_navigation())
            // 旧版 http 插件（未改动）
            .plugin(tauri_plugin_http::init())
            // ...（其余插件未改动）
```

**变更摘要**：新增 `block_file_drop_navigation` 函数，构造一个 `on_navigation` 回调拦截 `file://` scheme 的插件。在 `init_plugin` 中作为第一个插件注册。

## 5. 双层拦截关系

```
用户拖入文件到 Tauri 窗口
         │
         ├─ 拖到 drop 区内（DragDropFileUpload）
         │    └─ drop 区自身 onDrop → preventDefault → 读取 files → 上传
         │
         └─ 拖到 drop 区外（窗口任意位置）
              │
              ├─ 前端层：window dragover/drop → preventDefault（阻止 WKWebView 默认行为）
              │    └─ 文件不会导航，事件被吞掉
              │
              └─ Rust 层（兜底）：on_navigation → file:// scheme → return false
                   └─ 即使前端未拦截，Rust 也阻止导航
```

两层互为冗余：
- **前端 `preventDefault`**：第一道防线，在事件层面阻止 WKWebView 触发导航
- **Rust `on_navigation`**：兜底，即使前端未拦截（如 JS 未加载、事件被覆盖），Rust 仍阻止 `file://` 导航

## 6. 兼容性与影响

| 项目 | 说明 |
|------|------|
| `dragDropEnabled: false` | 已在 `tauri.conf.json` 中设置（非本轮新增）；本轮新增拦截其副作用 |
| HTML5 拖放 | `preventDefault` 仅阻止默认导航行为；`dataTransfer.files` 仍可被 drop 区读取 |
| Web 端 | `isTauriRuntime()` 检查——Web 端不注册监听器，无影响 |
| 关于窗 | `dragover` / `drop` 监听器在关于窗也生效（注册在 `isAboutWindow` 判断之前） |
| 插件顺序 | `block_file_drop_navigation` 排在 `init_plugin` 第一个——导航拦截优先于其它插件 |
| 版本号 | 1.0.119 → 1.0.121（无功能影响） |

## 7. 风险与回归清单

| 风险 | 排查 |
|------|------|
| drop 区无法获取文件 | `preventDefault` 不影响 `dataTransfer.files` 读取；检查 drop 区 `onDrop` 是否正常 |
| `dragover` 未拦截导致 `drop` 不触发 | 已同时注册 `dragover` + `drop`；浏览器要求 `dragover` 也 `preventDefault` 才能触发 `drop` |
| Rust 导航拦截误伤 | `on_navigation` 仅拦截 `file://` scheme；`http://` / `https://` 不受影响 |
| 插件名冲突 | `"block-file-drop-nav"` 是自定义名称，不与 Tauri 官方插件冲突 |
| React 未加载时拖入文件 | 前端监听器在 `main.tsx` 顶层注册（React 渲染前）；Rust 层兜底 |

建议回归：
1. **拖文件到 drop 区**：文件正确上传，SPA 不被顶掉
2. **拖文件到窗口空白处**：SPA 不被顶掉，无导航发生
3. **拖图片文件**：不在窗口中渲染图片
4. **拖 HTML 文件**：不在窗口中渲染 HTML
5. **拖视频文件**：不在窗口中播放视频
6. **拖 Markdown 文件**：不在窗口中渲染 Markdown
7. **Web 端**：拖文件行为不受影响（`isTauriRuntime` 返回 false）
8. **正常导航**：应用内路由跳转不受影响（非 `file://` scheme）
