# 书架与知识库列表按钮视觉微调

## 1. 背景与目标

电子书书架与知识库列表是两个独立的业务页面，但二者顶部工具栏存在大量结构相似的图标/文本按钮（分类管理、导入、搜索）。此前这些按钮的视觉表现并不一致：

- 电子书侧部分按钮缺少统一的悬停反馈；
- 电子书导入按钮的 Tooltip 朝下展开，与按钮位于页面顶部的布局语义不符（知识库侧已统一朝上）；
- 初始加载期间导入按钮仍可点击，可能导致加载未完成时误触发上传流程；
- 知识库分类管理按钮图标比电子书侧小一号（`size-3.5` vs `size-4`），视觉不齐；
- 知识库分类标签使用 `variant="ghost"` 且带有 `font-medium`、`shrink-0` 等样式，比电子书侧厚重且不可换行。

目标：

1. 为书架与知识库列表的图标按钮统一添加 `lucide-stroke-draw-hover` 悬停描边动画，使交互反馈一致；
2. 将电子书导入按钮 Tooltip 方向从 `bottom` 改为 `top`，与知识库工具栏一致；
3. 导入按钮在 `showInitialLoading` 期间禁用，防止加载中误触；
4. 知识库分类管理按钮图标从 `size-3.5` 放大到 `size-4`，与电子书侧对齐；
5. 知识库分类标签从 `variant="ghost"` 改为 `variant="link"` 并精简样式，视觉更简洁且可自动换行。

## 2. 改动范围

| 路径 | 变更类型 | 说明 |
|------|----------|------|
| `apps/frontend/src/views/ebook/components/shelf/EbookShelfSearch.tsx` | 修改 | 搜索按钮 className 增加 `lucide-stroke-draw-hover` |
| `apps/frontend/src/views/ebook/index.tsx` | 修改 | 分类管理按钮 className 增加 `lucide-stroke-draw-hover`；Tauri 与 Web 导入按钮 Tooltip `side` 从 `bottom` 改 `top`、className 增加 `lucide-stroke-draw-hover`、`disabled` 增加 `showInitialLoading` 条件；Tauri 导入按钮额外加 `transition-none` |
| `apps/frontend/src/views/knowledge/KnowledgeList.tsx` | 修改 | 分类管理按钮 className 增加 `lucide-stroke-draw-hover`、图标从 `size-3.5` 放大到 `size-4`；分类标签 Tab 按钮 `variant` 从 `ghost` 改 `link`、className 移除 `shrink-0` / `font-medium` / `dark:hover:bg-transparent` |

## 3. 实现思路

- **`lucide-stroke-draw-hover` 统一描边动画**：该 CSS 类为 lucide 图标在悬停时添加描边绘制动画效果（纯 CSS，无 JS 逻辑）。将其追加到各图标按钮的 className 首部，使电子书书架与知识库列表的图标按钮获得一致的悬停反馈。追加在 className 字符串首位，不影响后续布局类名。
- **Tooltip 方向统一朝上**：电子书导入按钮（Tauri 与 Web 两路）位于书架页 `EbookPanelHeader` 的 `trailing` 区，处于页面顶部。将 Tooltip 的 `side` 从 `"bottom"` 改为 `"top"`，使内容朝远离工具栏的方向展开，避免被工具栏自身遮挡，同时与知识库工具栏已有的 `side="top"` 保持一致。
- **初始加载期间禁用导入**：`showInitialLoading` 表示书架正在进行首次加载（`ebookStore.loading && !ebookStore.loadingMore`）。将导入按钮的 `disabled` 从 `uploading` 扩展为 `uploading || showInitialLoading`，防止用户在列表尚未加载完成时误触导入，导致状态错乱。
- **Tauri 导入按钮 `transition-none`**：`lucide-stroke-draw-hover` 的描边动画依赖 CSS transition。Tauri 导入按钮的 `pr-0!`（无右内边距）与描边动画的 transition 属性可能产生冲突，追加 `transition-none` 禁用按钮自身的过渡动画，确保描边动画不被干扰。Web 导入按钮使用 `px-0!`，无此冲突，故不加。
- **知识库图标放大**：知识库分类管理按钮的 `CircuitBoard` 图标从 `size-3.5`（14px）放大到 `size-4`（16px），与电子书侧 `EbookShelfPage` 同名按钮的 `size-4` 一致，消除两侧视觉落差。
- **分类标签 variant 与样式精简**：知识库分类标签 Tab 按钮从 `variant="ghost"` 改为 `variant="link"`，后者无背景色、更轻量，视觉更简洁。同时移除 className 中的 `shrink-0`（允许标签在空间不足时自动换行而非溢出）和 `font-medium`（与 `variant="link"` 的默认字重一致，无需额外加粗），并移除 `dark:hover:bg-transparent`（`variant="link"` 本身 hover 无背景色变化，无需覆写暗色模式）。

## 5. 兼容性与影响

- **`lucide-stroke-draw-hover`**：为图标按钮添加悬停时描边绘制动画，纯 CSS 类无 JS 逻辑，不影响交互行为与布局。
- **Tooltip 方向 `bottom` → `top`**：电子书导入按钮（Tauri 与 Web 两路）的 Tooltip 改为向上展开。若触发器距视口顶部过近，Radix 会自动避让到其它方向（仍由 Radix 的 collision padding 处理）。
- **导入按钮初始加载禁用**：`disabled={uploading || showInitialLoading}` 在首次列表加载期间禁用导入按钮，防止误触。加载完成后按钮自动恢复可用，不影响正常导入流程。
- **`transition-none`**：仅 Tauri 导入按钮追加，禁用按钮自身过渡动画以避免与 `lucide-stroke-draw-hover` 的描边 transition 冲突。Web 导入按钮不加，因 `px-0!` 无此冲突。
- **知识库图标 `size-3.5` → `size-4`**：分类管理按钮图标放大 2px，与电子书侧一致，不影响布局（按钮仍为 `h-8`）。
- **分类标签 `variant="ghost"` → `"link"`**：标签视觉更轻量（无 hover 背景色）；移除 `shrink-0` 后标签在空间不足时可自动换行而非横向溢出；移除 `font-medium` 后字重由 `variant="link"` 默认值控制；移除 `dark:hover:bg-transparent` 后暗色模式 hover 行为与亮色一致。
