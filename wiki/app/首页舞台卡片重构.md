# 首页舞台卡片重构

## 1. 背景与目标

旧版首页首屏由一整段内联 JSX 构成：氛围光晕、顶栏品牌条、焦点轮播（`HERO_SLIDES` + 方向位移 + blur）、控制条（箭头 / 圆点 / 计数器）、底栏入口（`FEATURES`）。轮播的状态管理（`heroIndex` / `heroDir` / 自动播放定时器 / 悬停暂停）全部写在 `Home` 组件内部，与首页其它逻辑耦合；首屏视觉也缺乏鼠标跟随的 3D 倾斜与分层视差。

本次重构将首屏抽离为两个可复用组件：

- **`StageCard`**（`apps/frontend/src/views/home/StageCard.tsx`）：舞台卡片壳层，负责顶栏、近景内容区、水印、底栏入口，以及可选的鼠标跟随 3D 倾斜与分层视差（远景光晕 / 中景顶栏与底栏 / 近景主内容 / 水印）。
- **`FocusCarousel`**（`apps/frontend/src/components/design/FocusCarousel/index.tsx`）：焦点轮播通用组件，封装叠层 fade + 方向位移 + blur 的切页动画，支持自动播放、悬停暂停、触屏滑动、水平滚轮切页、受控 / 非受控两种模式。

目标：

1. 把首屏结构与首页业务逻辑解耦，`Home` 组件不再维护轮播定时器。
2. 赋予首屏鼠标跟随的 3D 倾斜与分层视差，提升沉浸感。
3. 保留原有交互（自动播放、圆点跳页、箭头切页、计数器、底栏入口），同时新增触屏滑动与水平滚轮切页。
4. 组件可复用：`FocusCarousel` 放在 `@/components/design/` 下，未来其它页面可直接使用。

## 3. 实现思路

### 3.1 拆分策略

将首屏拆为「壳层」+「内容」两层：

- **壳层（StageCard）**：管理整体布局（顶栏 + 近景区 + 底栏）、3D 倾斜与分层视差的 motion 值，以及水印。壳层本身不关心轮播逻辑，只接收 `children` 作为近景内容。
- **内容（FocusCarousel）**：作为 `StageCard` 的 `children` 传入，负责多页叠层切换、自动播放、触屏 / 滚轮交互。组件内部用 `forwardRef` 暴露 `go` / `setIndex` / `getIndex` 命令句柄。

### 3.2 3D 倾斜与分层视差

`StageCard` 通过单个 `motion.div` 容器接收鼠标坐标（归一化到 `[-0.5, 0.5]`），用 `useTransform` + `useSpring` 派生出各层的位移与旋转：

| 层 | motion 值 | 范围 | 刚度 / 阻尼 | 作用 |
|----|----------|------|-------------|------|
| 卡片旋转 | `rotateY` / `rotateX` | ±3° | 70 / 13 | 整卡跟随鼠标凸起 |
| 远景光晕 | `glowX` / `glowY` | ±5 / ±3 | 50 / 18 | 背景光晕反向漂移 |
| 中景（顶栏 / 底栏） | `midX` / `midY` | ±10 / ±6 | 70 / 15 | 顶栏与底栏反向位移 |
| 近景（主内容） | `nearX` / `nearY` | ±18 / ±12 | 90 / 16 | 轮播区位移最大 |
| 水印 | `wmX` | ±3 | 40 / 20 | 水印水平微移 |

为避免高频 `mousemove` 直接写 `motion` 值导致卡顿，采用 `requestAnimationFrame` 节流：`onTiltMove` 只记录待处理坐标到 `tiltPendingRef`，由 `flushTiltMove` 在下一帧统一写入 `tiltMx` / `tiltMy`。鼠标离开或组件不可见时调用 `endTiltSession` 取消 RAF、清理定时器、复位位移，避免泄漏。

旋转角度经实测收敛到 `rotateY ±3°` / `rotateX ±3°`（旧版探索期曾用 ±8° / ±6°，会导致圆角与内容遮挡），配合 `clipPath: inset(0 round 0.375rem)` 保证 3D 倾斜后圆角不失效。

### 3.3 无障碍与性能守卫

- `prefers-reduced-motion`：检测到用户偏好减少动画时，关闭倾斜。
- `IntersectionObserver`：卡片不可见时停止倾斜会话。
- `will-change` 按需开关：鼠标进入时设为 `transform`，离开时恢复 `auto`，避免常驻合成层。
- 窗口缩放时若正处于倾斜热区，重新同步 `getBoundingClientRect`。

### 3.4 FocusCarousel 受控 / 非受控双模式

- 非受控（默认）：组件内部 `useState` 维护 `uncontrolledIndex`，外部通过 `onIndexChange` 监听变化。
- 受控：外部传入 `index` prop，组件只负责触发 `onIndexChange`，由外部驱动实际下标。
- 自动播放、触屏、滚轮切页均内部封装，通过 `autoplayMs={false}` / `swipe={false}` / `wheel={false}` 可逐项关闭。

**改动后** · `apps/frontend/src/views/home/StageCard.tsx`（当前，约 L44–L130，摘录组件函数体前半：ref 声明与 motion 值派生）

```typescript
/** 首页首屏舞台卡片：顶栏 + 近景内容 + 水印 + 底栏入口，可选鼠标 3D 倾斜与分层视差。 */
export function StageCard({
// 解构 props，brand / headline / status / header / children / entries 等从父传入
	className,
	brand,
	headline,
	status,
	header,
	children,
	entries,
	entriesAriaLabel,
// 水印默认 DNHYXC
	watermark = 'DNHYXC',
// 倾斜默认开启
	tilt = true,
// 光晕默认开启
	glow = true,
// 底栏遮罩默认开启
	mask = true,
}: StageCardProps) {
// 卡片根节点 ref，用于 getBoundingClientRect 与 will-change 控制
	const tiltCardRef = useRef<HTMLDivElement>(null);
// 鼠标归一化 x 坐标 motion 值（范围 [-0.5, 0.5]）
	const tiltMx = useMotionValue(0);
// 鼠标归一化 y 坐标 motion 值（范围 [-0.5, 0.5]）
	const tiltMy = useMotionValue(0);
// 倾斜空闲复位定时器句柄 ref（1.5s 无操作后归零）
	const tiltIdleRef = useRef<number | null>(null);
// requestAnimationFrame 句柄 ref（0 表示无待执行帧）
	const tiltRafRef = useRef(0);
// 待处理的鼠标坐标 ref（由 mousemove 写入，由 RAF 回调消费）
	const tiltPendingRef = useRef<{ x: number; y: number } | null>(null);

			tiltIdleRef.current = null;

		setTiltWillChange(false);
	};
```

```typescript
				const next = (((prev + delta) % total) + total) % total;
				indexRef.current = next;
				onIndexChange?.(next, nextDir);
				return next;
			});
		}
		resetTimer();
	};
```

```typescript
// 触屏开始：记录起始坐标
	const onTouchStart = (e: ReactTouchEvent<HTMLDivElement>) => {
// 未启用滑动则直接返回
		if (!swipe) return;
		const t = e.touches[0];
		if (!t) return;
		touchStartRef.current = { x: t.clientX, y: t.clientY };
	};
// 触屏结束：根据位移判断是否切页
	const onTouchEnd = (e: ReactTouchEvent<HTMLDivElement>) => {
		if (!swipe) return;
		const start = touchStartRef.current;
// 清除起始坐标
		touchStartRef.current = null;
		if (!start) return;
		const end = e.changedTouches[0];
		if (!end) return;
// 计算水平 / 垂直位移
		const dx = end.clientX - start.x;
		const dy = end.clientY - start.y;
// 水平位移不足阈值则不切页
		if (Math.abs(dx) < swipeThreshold) return;
// 水平位移小于垂直位移 1.2 倍时视为纵向滚动，不切页
		if (Math.abs(dx) < Math.abs(dy) * 1.2) return;
// 水平正向（右滑）→ 上一页，与旧版一致
		go(dx > 0 ? -1 : 1);
	};
// 滚轮事件：水平位移为主时切页
	const onWheel = (e: ReactWheelEvent<HTMLDivElement>) => {
		if (!wheel) return;
		const dx = e.deltaX;
		const dy = e.deltaY;
// 水平 delta 不大于垂直 delta 时视为纵向滚动，不切页
		if (Math.abs(dx) <= Math.abs(dy)) return;
// 水平 delta 不足阈值则不切页
		if (Math.abs(dx) < wheelThreshold) return;
// 冷却期内不响应
		if (wheelLockRef.current) return;
// 加锁
		wheelLockRef.current = true;
// 冷却结束后解锁
		wheelTimerRef.current = window.setTimeout(() => {
			wheelLockRef.current = false;
			wheelTimerRef.current = null;
		}, wheelCooldownMs);
// 与触屏一致：水平正向 → 上一页
		go(dx > 0 ? -1 : 1);
	};
```
