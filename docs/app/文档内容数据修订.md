# 文档内容数据修订

## 1. 背景与目标

三个文档页的正文数据（sections）在本轮变更中同步修订，内容变化反映「文档页从应用内独立页迁移到独立文档站」这一产品决策。同时修复了插件开发手册中代码示例因 `String.raw` 导致 hljs 渲染异常的问题，以及更新了产品指南中对「更新说明」「产品指南」页的描述措辞，使之与独立站架构一致。

## 2. 改动范围

- `src/views/updateInfo/updateInfoSections.ts` — 新增 `s2-17` 条目「文档页迁移到独立站」
- `src/views/updateInfo/updateInfoSectionsEnOverlay.ts` — 新增 `s2-17` 英文映射
- `src/views/projectGuide/projectGuideSections.ts` — 修订 `pg-s14-1`、`pg-s15-2`、`pg-s15-3` 描述
- `src/views/projectGuide/projectGuideSectionsEnOverlay.ts` — 修订对应英文 title + description
- `src/views/pluginDevGuide/pluginDevGuideSections.ts` — 修复 `CODE_IFRAME_APPLY_APPEARANCE` 与 `CODE_IFRAME_HOST_CLIENT` 的 `String.raw` 问题；iframe 通信协议表格改用有序列表

## 3. 实现思路

### 3.1 更新信息新增条目

在 `s2` 分区末尾追加 `s2-17` 条目，中英文双语记录「三个文档页迁移到独立文档站」这一变更。ID 续号 `s2-17`（前一条为 `s2-16`），日期标注 `2026-09-08`。

### 3.2 产品指南措辞修订

`pg-s14-1`（专题说明材料）：原文提到「应用内『更新说明』独立页（/update-info）」，修订为「『更新说明』会在系统浏览器或新标签页中打开」，反映独立站架构。

`pg-s15-2`（更新说明独立页）：标题从「独立结构化页」改为「独立文档站」；描述强调「由应用拼出独立文档站地址（自动附带当前语言、深浅主题、强调色）」「内容更新无需重新发布应用包」。

`pg-s15-3`（产品功能指南独立页）：同样从「独立结构化页」改为「独立文档站」；描述补充「桌面端 Tauri」与「纯网页端」的区分。

### 3.3 插件手册 String.raw 修复

**问题**：`CODE_IFRAME_APPEARANCE` 和 `CODE_IFRAME_HOST_CLIENT` 原先用 `String.raw` 模板字面量包裹。这两个代码段内含 `${...}` 模板占位符和 `\` 反斜杠。`String.raw` 会原样保留反斜杠，导致 hljs（highlight.js）语法高亮器将整个代码段识别为「未闭合的模板字面量」，整段变绿。

**修复**：改用普通模板字符串（去掉 `String.raw`），让 JavaScript 引擎正常解析转义序列。`${...}` 中的反斜杠会被正常处理，hljs 能正确识别代码结构。

### 3.4 iframe 通信协议表格改有序列表

**问题**：原表格使用 Markdown 管道符 `|` 分隔列，其中 `value|error` 的 `|` 被 Markdown 解析器误认为表格分隔符，导致渲染错乱。

**修复**：改为有序列表格式（`1. ready｜iframe→Host｜...`），用全角 `｜` 竖线代替 ASCII `|`，避免 Markdown 表格歧义。
